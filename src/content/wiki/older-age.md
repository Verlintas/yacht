## 一、年龄影响什么

**年龄不改变「你是不是跨性别」，但它影响两件事：**

| 影响 | 说明 |
| --- | --- |
| **HRT 能改变什么** | 青春期前、青春期、成年后，可改变的范围不同 |
| **HRT 的风险大小** | 部分风险随年龄上升 |

**上游对效果表的说明 [4]：** 青春期人群的激素水平一般低于成年，**雌二醇期望值无需向成年靠拢**。

**上游对骨骼的说明 [4]：** 雌激素在青春期人群中「有引导骨骼生长女性化的作用」——**即骨骼层面的作用依赖青春期窗口**。

**换句话说：** 青春期之后开始的，骨骼架构、身高、声音这些不会因激素改变。**但这不等于「太晚了」。** 见下。

## 二、上游对「年龄较大」的明确表述

### 2.1 关于乳腺癌风险

**上游的明确表述 [1]：**

> **年龄较大的跨性别者可以考虑停止激素治疗，以降低患乳腺癌的风险。**

**这句话的含义需要仔细读：**

| 它说的是 | 它没有说 |
| --- | --- |
| 「可以考虑」——是一个选项 | 不是「应该停」 |
| 目的是降低乳腺癌风险 | 不是「HRT 不安全」 |
| — | 不是「年龄大了就不该用」 |

**⚠️ 这是一个需要和医生一起权衡的决定，不是自己判断的。** 停药涉及骨密度、情绪、生活质量等多方面的影响，见下。

**相关背景 [1]：** 接受性别肯定激素治疗的跨性别女性的乳腺癌风险是**顺性别男性的 46 倍，但仍低于顺性别女性**；筛查建议是**遵循与顺性别者相同的筛查指南**。

**延伸阅读：**[乳腺癌风险](https://tfsci.mtf.wiki/zh-cn/articles/breast-cancer/) [6]

### 2.2 关于螺内酯

**上游列出的高钾血症高风险人群 [5]：**

> **高年龄（超 45 岁）**、肾功能不全、与其它利钾药物合用、钾补剂的服用等，须格外注意。

**即：45 岁以上用螺内酯，需要更密切地监测血钾。**

### 2.3 关于血栓

**上游指出年龄是血栓风险的相关因素之一 [见[血栓风险与自我评估](/wiki/thrombosis-risk/)]。**

**上游的血栓相对风险率数据中，不同雌激素类型的风险差异很大 [1]：**

| 类型 | 风险率 |
| --- | --- |
| 透皮雌二醇 ≤ 50 μg/天 | **0.9 倍** |
| 口服雌二醇 ≤ 1 mg/天 | 1.2 倍 |
| 口服雌二醇 > 1 mg/天 | 1.4 倍 |

**所以「年龄大」不是单一变量——剂型选择的影响可能更大。** 这也是为什么透皮途径常被推荐给年龄较大的人。

## 三、中年以后开始过渡：现实预期

**⚠️ 本站没有找到针对这一人群的专门指南。** 以下基于上游的效果表与说明整理。

### 3.1 激素能改变的

**上游效果表中的项目仍然适用 [4]：**

| 作用效果 | 出现时间 | 稳定时间 |
| --- | --- | --- |
| 乳房发育 | 3–6 月 | 2–5 年 |
| 体脂重新分布 | 3–6 月 | 2–5 年 |
| 肌肉质量、力量降低 | 3–6 月 | 1–2 年 |
| 皮肤变软、油性减少 | 3–6 月 | 未知 |
| 肢端毛发生长减少 | 6–12 月 | ≥ 3 年 |
| 性欲减退 | 1–3 月 | 1–2 年 |

**⚠️ 注意「2–5 年」这个尺度。** 中年以后开始，意味着需要更长的耐心。

### 3.2 激素不能改变的

**上游的明确表述 [4]：**

> 部分已发育成熟的男性化特征（**骨骼架构、嗓音音高、体毛分布**等）难以仅凭激素治疗完全逆转。

**这些需要其他手段：**

| 项目 | 手段 |
| --- | --- |
| 骨骼架构 | 手术（见[手术五类导览](/wiki/surgery-overview/)） |
| 声音 | 训练或手术（见[声音训练入门](/wiki/voice-training/)） |
| 体毛分布 | 脱毛（见[脱毛方式对比](/wiki/hair-removal/)） |
| 脱发 | 见[脱发与头发](/wiki/hair-loss/) |

### 3.3 上游对年龄的一句话

**上游在 HRT 简明指南里写道 [3]：**

> 请记住：HRT 介入的最佳时机是十年前和现在；**任何时候用药都不晚**。事实上，本文编者在 25 岁才开始用药。诚然，大龄能改变的地方有限，但又如何呢？**过好当下每一天，比什么都重要。**

**这段话值得完整读一遍。** 它承认了限制，但没有把限制当成否决。

## 四、长期用药的考虑

**如果打算长期（数十年）使用激素，需要关注：**

| 项目 | 说明 |
| --- | --- |
| **定期复查** | 稳定后每年至少一次，见[治疗期间的监测](/wiki/monitoring-index/) |
| **骨密度** | 见[骨密度与骨骼健康](/wiki/bone-density/) |
| **乳腺筛查** | 按女性筛查指南，见[器官筛查与定期体检](/wiki/organ-screening/) |
| **心血管与代谢指标** | 血脂、血糖、血压 |
| **肝功能** | 见[肝功能指标怎么看](/wiki/liver-function/) |
| **慢性病的出现** | 年龄增长本身会带来新的健康问题，见[慢性病与 HRT](/wiki/chronic-conditions/) |

**⚠️ 上游的一条重要原则 [4]：**

> **不宜同时出现雌激素和雄激素「双低」的情况**：长此以往，将引起骨质疏松、盗汗等一系列更年期症状。

**上游的另一条 [4]：**

> 如不存在血栓风险等特殊情况，**一般需长期服用雌二醇**；即使切除了性腺 (SRS) 以后亦然。

**即：如果决定继续用药，就需要长期用，而不是「用几年就停」。** 是否停、什么时候停，需要医生评估。

## 五、关于「停药」的权衡

**如果考虑停药，值得同时考虑这几件事：**

| 考虑项 | 说明 |
| --- | --- |
| **乳腺癌风险** | 上游提到年龄较大者可考虑停药以降低此风险 [1] |
| **骨密度** | 停药后如果两种激素都低，会影响骨密度 [4] |
| **情绪与生活质量** | 上游提到停药反应「尤其是精神上的不适可能较明显」[4] |
| **已获得的变化** | 部分变化会缓慢回退（脂肪分布、肌肉量等） |
| **其他健康问题** | 如出现新的慢性病，可能需要重新评估 |
| **心血管风险** | 需综合评估 |

**⚠️ 这是一个需要医生参与的决定。** 不要自行停药，也不要因为「年纪大了」就默认该停。

**如果决定停，应当逐步减量。** 见[漏服、停药与调整](/wiki/missed-dose/)。

## 六、给中年以后才开始的人

**⚠️ 以下为本站整理，不是上游原文。**

| 建议 | 说明 |
| --- | --- |
| **先做全面体检** | 年龄越大，基线检查越重要，见[体检项目清单](/wiki/health-checkup/) |
| **把慢性病管理起来** | 见[慢性病与 HRT](/wiki/chronic-conditions/) |
| **和医生讨论剂型** | 年龄相关的风险可以通过剂型选择部分规避 |
| **预期要现实** | 激素能改变的有限，其他手段要单独规划 |
| **社会层面的调整不必等** | 称呼、着装、社交——这些不需要医疗流程，见[日常入门的顺序](/wiki/daily-basics/) |
| **心理支持同样重要** | 见[怎么找心理咨询](/wiki/finding-counselor/) |
| **不必和年轻人比较** | 起点不同，时间表不同 |

**中年以后开始过渡的人不少。** 你不是特例，也不是「太晚了」。

## 上游的建议

来自 [MtF.wiki《HRT 简明指南》](https://mtf.wiki/zh-cn/docs/medicine/zero-to-hrt)的用药前注意事项：

> 治疗前，接受一次全面体检，尤其注意肝肾功能、雌二醇和睾酮指标。

> 务必整理**既往病史、过敏史、家族病史和现正服用的药物清单**，如实报告给医生。医生会依照体检结果和既往史，判断药物治疗的风险。

> **有血栓、心血管疾病、肝/肾疾病或既往史的，要格外注意。家族成员有乳腺癌病史的亦须注意。**

## 建议检查的项目

| 类别 | 项目 | 为什么 |
| --- | --- | --- |
| 激素 | 雌二醇、睾酮（激素六项） | 建立基线 |
| 激素 | 泌乳素 | 基线值，后续对比 |
| 肝功能 | ALT、AST、GGT、胆红素等 | 用药安全性评估 |
| 血液 | 血常规 | 整体状态 |
| 凝血 | 凝血相关项目 | 血栓风险评估 |
| 肾功能 | 肌酐、尿素氮 | 用药安全性评估 |
| 电解质 | 钾、钠等 | 部分抗雄药物相关 |
| 代谢 | 血脂、血糖 | 长期评估基线 |
| 影像 | 乳腺、肝脏超声（视医生建议） | 基线参考 |
| 骨密度 | 视医生建议 | 见[骨密度与骨骼健康](/wiki/bone-density/) |

**这是一份参考框架，不是标准处方。** 上游要求的是「全面检查」并特别点出肝肾功能、雌二醇、睾酮三项；上表其余项目属于常见体检范围，**具体查哪些由医生决定**。

## 为什么要建基线

**有了用药前的数值，后面才知道什么是「变化」。**

例如：

- 用药前 ALT 是 30，用药后 45 —— 是升高，但幅度小
- 用药前不知道 ALT，用药后 45 —— 无法判断是药物影响还是本来就高

**基线是后续所有判断的参照。**

## 就诊时提供的清单

提前整理好，写在纸上或手机备忘录：

- [ ] **既往病史** —— 肝病、心血管疾病、血栓、偏头痛、精神科病史
- [ ] **手术史**
- [ ] **过敏史**
- [ ] **家族病史** —— 尤其血栓、乳腺癌、心血管疾病
- [ ] **正在使用的全部药物** —— 处方药、非处方药、保健品、中药
- [ ] **吸烟与饮酒情况**
- [ ] **生育计划**

<div class="guide">
<strong>为什么这些都要说</strong>
<p>不是医生好奇，是这些信息直接决定<b>方案是否安全</b>。</p>
<p>例如：有血栓家族史 → 可能优先考虑经皮途径；吸烟 → 血栓风险更高；肝病史 → 影响剂型选择。</p>
<p><b>如实提供信息，受益的是你自己。</b></p>

## 关于「全面检查」的实际情况

**上游没有说明各医院的具体执行差异。** 以下为操作建议，非资料性结论：

- 各院流程不同，不是所有医院都会做全套
- 部分项目需要自费
- 可以主动询问是否需要补查某些项目
- 已有近期体检报告可以带上，避免重复检查

## 多久做一次

**上游对监测频次有明确建议：**

| 阶段 | 频次 |
| --- | --- |
| 开始前 | 一次全面检查 |
| 用药第一年 | 每三个月（或遵医嘱）复查 |
| 稳定后 | 每年至少一次 |

**来源：**[治疗期间的监测](https://mtf.wiki/zh-cn/docs/medicine/monitoring)

**本页的体检项目清单主要针对「开始前」这一次。** 后续复查的项目会少一些，以激素、肝功能、血常规为主。

**具体安排由医生决定，见[治疗期间的监测](/wiki/monitoring-index/)。**

## 常见问题

**「一定要做全套吗？」**
**上游要求的是「全面检查」，不是指定项目清单。** 上表的项目是常见范围，**具体查哪些由医生决定**。

**「可以不做某些项目吗？」**
可以。**但建议先问医生为什么开这项** —— 有些项目是为了建立基线，跳过会影响后续判断。

**「已有近期体检报告能用吗？」**
**可以，带上避免重复检查。** 上游提到北医三院承认外院检查结果，且检查有效期通常为三个月。

**「需要空腹吗？」**
**上游明确要求采血前须空腹。** 具体哪些项目需要空腹，问医院。

**「什么时候去最好？」**
**上午**，因为多数项目要求空腹，且部分检查（如超声）需要预约。

**「要花多少钱？」**
北医三院列出的初诊检查总花费介于 **1000–2000 元**之间。见[费用与时间规划](/wiki/cost-timeline/)。

**「多久能出结果？」**
血液检查很快，最晚次日；**超声排期可能较长（上游提到可能需要等待 3 个工作日以上）**；**染色体检查需要 30 天**。

**「为什么要查染色体？」**
上游把染色体检查列为**可选**项目。**具体为什么查，问医生。**

## 各项检查的意义

**上游列出这些项目的背景原因（部分）：**

| 项目 | 意义 |
| --- | --- |
| **性激素六项** | 建立基线，判断方案是否达标 |
| **肝功能** | 部分药物经肝脏代谢；CPA 与比卡鲁胺尤其需要 |
| **凝血七项（含 D-Dimer）** | 雌激素影响凝血，评估血栓风险 |
| **血生化** | 覆盖转氨酶、胆红素、肌酐、尿酸、钙磷、钾钠氯、血糖、血脂 |
| **糖化血红蛋白** | 衡量近期血糖平均水平 |
| **甲功三项** | 雌激素可刺激甲状腺素结合球蛋白分泌 |
| **甲状旁腺素** | 与血钙、无机磷相关 |
| **2,5-羟维生素 D** | 骨密度相关；上游提到大部分人会有骨量减少，需要补充维生素 D |
| **空腹胰岛素** | 雌激素及部分抗雄药物可影响糖耐量 |
| **腹部超声（肝胆胰）** | 基线 |
| **乳腺超声** | **发育前基线检查** |
| **骨密度** | 基线检查（双能 X 线法或超声，部位是腰椎和髋关节） |

**⚠️ 上表的意义说明基于上游的监测条目，不是对每一项的完整解释。具体问医生。**

## 基线为什么重要

**有了用药前的数值，后面才知道什么是「变化」。**

| 情况 | 判断 |
| --- | --- |
| 用药前 ALT 是 30，用药后 45 | 是升高，但幅度小 |
| **用药前不知道 ALT**，用药后 45 | **无法判断是药物影响还是本来就高** |

**基线是后续所有判断的参照。** 这也是为什么上游要求「在开始激素治疗之前」做一次全面检查。

**特别提醒：** 上游把**乳腺超声**列为「发育前基线检查」——即在 HRT 开始前做，作为后续对比的基准。

## 检查当天的实用建议

**⚠️ 以下为经验整理，非上游资料。**

| 建议 | 原因 |
| --- | --- |
| **早到** | 部分检查需要预约，来得早可能约到当天 |
| **先抽血** | 抽血后可以进食，其他检查不要求空腹 |
| **带水和小食** | 抽完血可以补充 |
| **穿方便穿脱的衣服** | 超声、骨密度可能需要 |
| **不要戴金属饰品** | 部分检查会受影响 |
| **带充电宝** | 排队时间长 |
| **把问题写下来** | 见医生时可以逐条问 |
| **记下每项检查的预约方式** | 超声、骨密度可能需要单独预约 |

**上游提到一个细节：** 生化结果 CO₂ 偏低是空腹太久了，属正常现象。

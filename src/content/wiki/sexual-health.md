## HRT 会带来的变化

**上游的效果表列了这几项** [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]：

| 变化 | 出现时间 | 稳定时间 |
| --- | --- | --- |
| 性欲减退 | 1–3 月 | 1–2 年 |
| 自发勃起减少 | 1–3 月 | 3–6 月 |
| 男性性功能障碍 | 未知 | 2 年 |
| 睾丸体积减小 | 3–6 月 | 2–3 年 |
| 精子产量减少 | 不定 | 不定 |

**这些是常见变化，不是「问题」。** 性欲与性功能的改变本身是很多人的期待之一。

**如果这些变化让你困扰**（有些人希望保留部分功能），可以在就诊时和医生讨论——通过调整方案有时可以改善。**不要自己停药。**

## 关于「用进废退」

**上游资料提到，长期不使用可能导致组织萎缩。如果希望保留功能，保持规律使用（包括自慰）通常有帮助。**

**具体做法与预期，问医生。本站不复述具体方案。**

## 定期检查

**跨性别者同样需要常规的性健康检查。**

| 检查 | 说明 |
| --- | --- |
| **前列腺相关** | 未切除前列腺者仍需关注；**具体筛查建议咨询医生** |
| **乳腺检查** | HRT 后乳腺组织发育，**需按医生建议进行自检与筛查** |
| **性传播感染** | 有性行为者按常规建议筛查 |
| **术后复查** | 手术后按医嘱复查，见[术后护理与恢复](/wiki/surgery-recovery/) |

**乳腺相关的背景见[乳腺癌风险](https://tfsci.mtf.wiki/zh-cn/articles/breast-cancer/)。**

**不要因为身份原因回避体检。** 需要向医生说明用药情况，但不必解释身份。

## 术后

**如果做过生殖器相关手术：**

| 事项 | 说明 |
| --- | --- |
| **扩张（如适用）** | 按医嘱进行，频率与时长遵医嘱，见[术后护理与恢复](/wiki/surgery-recovery/) |
| **清洁与感染预防** | 按医嘱 |
| **异常情况** | 及时联系手术医院 |
| **恢复期性行为** | **避免**，具体时间问医生 |
| **性传播感染防护** | 术后仍需注意 |

**上游的[术后护理](https://mtf.wiki/zh-cn/docs/srs/care)条目有更详细的说明。**

## 避孕与生育

| 事实 | 说明 |
| --- | --- |
| **HRT 不是避孕手段** | 如果想避免怀孕，需要采取常规避孕措施 |
| **HRT 会显著影响生育力** | 见[生育力保存](/wiki/fertility/) |
| **停药后生育力可能部分恢复** | 但过程有代价，见[漏服、停药与调整](/wiki/missed-dose/) |

## 沟通与边界

- **你有权在任何时候拒绝任何性行为。** 「不」是完整的回答。
- **不必因为「已经做了手术」而感到有义务。**
- **如果伴侣施压**，这是关系问题，见[交友与亲密关系](/wiki/dating-relationships/)。
- **遇到暴力或强迫**，这是需要外部介入的情况，见[常见法律问题索引](/wiki/legal-faq-index/)。
- **不需要向伴侣交代全部医疗史**，但涉及安全的部分（如避孕、性传播感染防护）需要沟通。

## 常见问题

**「HRT 后性功能会完全消失吗？」**
上游效果表列的是「性欲减退」（1–3 月出现，1–2 年稳定）与「自发勃起减少」（1–3 月出现，3–6 月稳定）。**是减退，不是消失。**

**「希望保留部分功能怎么办？」**
上游资料提到，长期不使用可能导致组织萎缩，**保持规律使用通常有帮助**。**具体做法与预期问医生**，不要自己调整用药。

**「这些变化让我困扰，可以停药吗？」**
**不要自己停药。** 可以在就诊时和医生讨论——通过调整方案有时可以改善。见[漏服、停药与调整](/wiki/missed-dose/)。

**「术后还需要避孕吗？」**
**取决于具体术式。** 生殖器相关手术的术式不同，术后是否仍有生育能力也不同。**必须问你的手术医生。**

**「HRT 期间需要避孕吗？」**
**需要。HRT 不是避孕手段。** 如果想避免怀孕，需要采取常规避孕措施。

**「需要做性传播感染筛查吗？」**
**有性行为者按常规建议筛查。** 术后同样需要注意防护。具体频率与项目问医生。

**「体检时会被问性生活史吗？」**
可能会。**可以只回答与检查相关的部分**，不需要展开私人生活。

## 关于「用进废退」

**上游提到长期不使用可能导致组织萎缩。**

**这条的实际含义：**

| 情况 | 说明 |
| --- | --- |
| 希望保留功能 | 规律使用（包括自慰）通常有帮助 |
| 不介意变化 | 不需要为了「保留」而刻意做什么 |
| 术后（如适用） | **按医嘱进行扩张**，频率与时长遵医嘱，见[术后护理与恢复](/wiki/surgery-recovery/) |
| 不确定 | 问医生 |

**⚠️ 具体做法与预期，必须问医生。** 本站不复述具体方案。

## 沟通与边界的细节

**这一节讲的是实际场景里怎么处理。**

| 场景 | 可以怎么做 |
| --- | --- |
| **对方追问身体细节** | 「这个我不太想聊」是完整的回答 |
| **对方以「不理解」为由施压** | 你没有义务用身体去换取理解 |
| **对方要求你「证明」性别** | **拒绝。** 没有任何人有资格要求这个 |
| **对方以「已经做了手术」为由提要求** | **手术不是义务的来源。** 「不」在任何时候都成立 |
| **关系中的沟通** | 涉及安全的部分（避孕、性传播感染防护）需要沟通；其余不必交代 |
| **遇到暴力或强迫** | 这是需要外部介入的情况，见[常见法律问题索引](/wiki/legal-faq-index/) |

## 关于体检时的隐私

**部分检查会涉及隐私部位。你可以：**

- [ ] 提前问清检查流程与必要性
- [ ] 要求同性医护在场
- [ ] 要求第三方在场（如陪同的人）
- [ ] 询问是否有替代检查方式
- [ ] **拒绝与检查目的无关的项目**

**「这是常规检查」不等于你必须接受。** 你可以要求对方说明必要性。

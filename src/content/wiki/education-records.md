## 两套完全不同的流程

| | 在读 | 已毕业 |
| --- | --- | --- |
| 办理对象 | 学校学籍管理部门 | 毕业院校的学籍/档案部门 + 学历认证机构 |
| 主要动作 | 变更在校学籍信息 | 变更学历证书信息或出具证明 |
| 难度 | 相对可控，学校有明确流程 | 视学校配合程度而定，可能较慢 |
| 时效 | 建议在校期间就办 | 没有时间压力，但越久越难 |
| 能否一次性办完 | 通常可以 | 往往需要多次往返 |

**在读期间办，通常比毕业后办容易得多。** 如果还在读书，**值得优先处理**。

上游的[学籍学历变更指引](https://mtf.wiki/zh-cn/docs/useful-info/education)有更细的整理。

## 需要准备什么

- 身份证、户口本（**已变更后的**）
- 医院相关证明
- 学校要求的申请表
- 部分地区或学校要求公证材料

**具体以学校规定为准。** 建议先打电话问清，再准备材料。

## 在读期间：找谁办

| 事项 | 找谁 |
| --- | --- |
| 学籍信息 | 学籍管理部门 / 教务处（**不是辅导员**） |
| 档案 | 学生档案管理部门 |
| 教务系统显示名 | 信息中心 / 教务处 |
| 图书馆、门禁、宿舍系统 | 各自的管理部门 |
| 校园卡 | 后勤 / 卡务中心 |

**「找对人」比「说对话」重要。** 辅导员通常没有学籍变更的权限。

## 容易被忽略的三件事

### 1. 档案（最容易被漏掉）

**档案里的信息也需要跟着更新。**

档案通常在学校、人才市场或工作单位，**个人一般接触不到**，但以下环节都会用到：

- 考研
- 考公
- 入职政审
- 职称评定
- 退休办理

**办完学籍变更后，问一句「档案里的信息怎么处理」。**

### 2. 学位证与毕业证

**已发放的证书通常不能直接改。**

常见做法：**由学校出具证明**，说明信息变更情况。这份证明在后续使用时和证书一起提交。

**所以要保管好这份证明。** 建议多开几份，加密留存。

### 3. 学信网

学历信息在学信网上有记录。**变更后需要确认线上记录是否同步更新。**

否则会出现「证书改了、网上还是旧的」的情况——在求职或考研审核时可能出问题。

**验证方法：** 登录学信网查看自己的学历信息。

## 在校期间的其他事

| 事项 | 说明 |
| --- | --- |
| 宿舍与体育课 | 可以跟学工部门或体育部沟通，见[宿舍、体育课与校园生活](/wiki/dorm-sports/) |
| 请假就医 | 「就医」两字通常足够，见[请假与考试](/wiki/leave-exam/) |
| 校园系统显示名 | 教务、图书馆、门禁可能各自独立，**要逐个确认** |
| 隐私 | 是否需要向全班公开由你决定，**学校无权替你公开** |
| 心理咨询 | 注意保密范围，见[怎么找心理咨询](/wiki/finding-counselor/) |

## 如果学校不配合

**处理顺序：**

1. **先找学籍管理部门（不是辅导员）**，问清依据和流程
2. **书面提交申请**，保留回执（邮件也可以）
3. **逐级反映**：院系 → 学生工作部门 → 教务处 → 教育主管部门
4. **咨询公益组织**，见[常见法律问题](https://mtf.wiki/zh-cn/docs/useful-info/legal-faq)
5. **评估成本与安全**，见[被拒绝后的申诉路径](/wiki/appeal-path/)

**注意：** 学校环境相对封闭，信息传播快。**在确认安全之前，控制知情范围比争取「公开支持」更重要。**

## 常见问题

**「学校要求我提供手术证明才给改，合理吗？」**
**各地各校要求不同，本站无法判断具体情形的合理性。** 可以问清依据，必要时走申诉渠道。

**「毕业多年了还能改吗？」**
可以，但流程更复杂，需要联系毕业院校。**先打电话问清需要什么材料。**

**「学历认证会受影响吗？」**
信息变更后需要做认证的场合，建议同时提供学校出具的变更证明。

**「考研报名怎么办？」**
报名使用当前有效证件信息。如果变更期间与报名时间冲突，**提前咨询报考点**。

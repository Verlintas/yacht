## 一、为什么需要一张地图

**中文跨性别资料不是集中在一个地方的。** 不同站点由不同的人维护，各有侧重：

| 站点 | 侧重 |
| --- | --- |
| 医疗与证件资料整合 | 一家的资料库 |
| 学术文献翻译 | 另一家的项目 |
| 校园生活 | 又一家的板块 |
| 社群与互助 | 分散在各类组织中 |

**不了解分布的话，容易在两个地方重复找同一个答案，也容易错过真正有用的那份。**

## 二、主要的资料库

### 2.1 MtF.wiki

**这是中文资料里最系统的一个，也是本站的主要上游。**

| 项 | 说明 |
| --- | --- |
| **覆盖** | 药物/HRT（逐药条目）、心理科（逐城市逐医生）、HRT 医疗资源（逐医院）、SRS/FFS/隆乳/嗓音/脱毛、实名与学籍变更、医保、法律 FAQ |
| **维护方** | [Project Trans](https://project-trans.org/) |
| **内容源码** | [github.com/project-trans/MtF-wiki](https://github.com/project-trans/MtF-wiki) |
| **入口** | <https://mtf.wiki/zh-cn/docs/> |

**它的两个特色机制：**

| 机制 | 用途 |
| --- | --- |
| [已过时列表](https://mtf.wiki/zh-cn/docs/outdated) | 判断信息是否已失效 |
| [未确认列表](https://mtf.wiki/zh-cn/docs/unconfirmed) | 未经核实的内容 |

**查任何信息之前先看这两个清单，能省掉大部分判断成本。**

### 2.2 Transfeminine Science（中文译文）

**学术文献的翻译项目。**

| 项 | 说明 |
| --- | --- |
| **侧重** | 激素治疗的原理、药代动力学、风险研究 |
| **原文** | [transfemscience.org](https://transfemscience.org/)（英文） |
| **中文译文** | <https://tfsci.mtf.wiki/> |
| **特别收录** | **各类 HRT 药物的说明书和译文** |

**上游对它的评价：** 「囊括了和 HRT 相关的方方面面，见解独到，引经据典」[见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

**为什么说明书值得看：** 说明书是原始依据，比任何二手总结都可靠。

### 2.3 RLE.wiki

**校园生活板块独立出来的站点。**

| 项 | 说明 |
| --- | --- |
| **侧重** | 校园生活、就读体验 |
| **来源** | 上游说明「为了用户更好的体验，本版块目前已经移至 RLE.wiki，投稿限制降低，增加反馈功能」[2] |
| **入口** | <https://rle.wiki> |

**「RLE」指真实生活体验（Real Life Experience）**——即在日常生活中以目标性别生活。部分流程会涉及这一概念。

### 2.4 colleges.chat

**大学性少数群体信息站。**

| 项 | 说明 |

| **上游的推荐** | 「民间有对各个大学的生活质量的问卷结果可以在 colleges.chat 查阅」[见[校园指南](https://mtf.wiki/zh-cn/docs/campus)] |
| **入口** | <https://colleges.chat> |

**如果你在选学校，这个值得看。**

## 四、怎么选

| 你的需求 | 去哪 |
| --- | --- |
| **查具体医院 / 医生** | MtF.wiki 对应城市条目 |
| **查药物剂量 / 用法** | 上游药物条目 + 说明书（[tfsci](https://tfsci.mtf.wiki/) 有译文） |
| **查某个说法的证据** | Transfeminine Science 中文译文 |
| **查证件流程** | MtF.wiki 实用信息 |
| **选学校** | colleges.chat + RLE.wiki |
| **找社群 / 求助** | 上游公益组织名单 |
| **给家人看** | NHS、APA 的公众页面 |
| **系统了解 HRT** | 本站 [HRT 完整指南](/wiki/hrt-complete-guide/) |

## 五、怎么判断一份资料是否可靠

**通用方法见[如何判断一条信息是否可信](/wiki/info-literacy/)。**

**针对资料库的三条：**

| 检查项 | 说明 |
| --- | --- |
| **有没有列来源** | 逐条引用的比没有引用的可靠 |
| **有没有更新日期** | 没有日期的按「可能过时」处理 |
| **有没有纠错机制** | 有 GitHub 仓库、有贡献者指南的，说明可以纠错 |

## 六、关于「能不能贡献」

**可以，而且门槛比想象中低。**

| 方式 | 门槛 |
| --- | --- |
| **提 issue** | 不需要懂 Git，说明哪一页有什么问题即可 |
| 改 Markdown | 不需要是程序员 |
| **补充自己的经验** | 上游最缺的就是「刚经历过的人」的信息 |
| 翻译 | 见[如何向上游贡献](/wiki/contribute-upstream/) |

**上游有完整的[贡献者指南](https://mtf.wiki/zh-cn/docs/contributor-guide)。**

## 按需要选，不要通读

**这些资料加起来是几十万字。通读既没必要，也读不完。**

建议按当前问题选：

| 你现在的状态 | 读什么 |
| --- | --- |
| 想先搞懂基本概念 | [MtF.wiki 简明指南](https://mtf.wiki/zh-cn/docs/medicine/zero-to-hrt) |
| 想了解医疗流程 | [MtF.wiki 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview) |
| 想知道国际标准怎么说 | [WPATH SOC-8 中文版](https://project-trans.org/SOC-8/) |
| 想深入激素原理 | [Transfeminine Science 中文译文](https://tfsci.mtf.wiki/) |
| 想了解诊断分类 | [WHO ICD-11](https://icd.who.int/) |
| 想找医院与医生 | [MtF.wiki 医疗资源](https://mtf.wiki/zh-cn/docs/hrt/overview) |
| 想了解证件流程 | [MtF.wiki 实用信息](https://mtf.wiki/zh-cn/docs/useful-info/real-name-info) |
| 想找社群 | [公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations) |

## 三类资料的可信度

| 类型 | 例子 | 怎么用 |
| --- | --- | --- |
| **指南与共识** | WPATH SOC-8、内分泌学会指南 | 权威性最高，但更新慢，且是国际视角 |
| **社群资料库** | MtF.wiki、Transfeminine Science | 更新快、有本地经验；注意查看来源与「已过时」标记 |
| **科普页面** | NHS、APA 的公众页面 | 适合给家人看，语言平实 |

**给家人看的话，NHS 和 APA 的页面比社群帖子有效得多。**

## 怎么读不浪费时间

1. **先读目录，再读内容。** 上游资料结构清晰，先看目录能定位到你需要的那一篇。
2. **查两个清单。** 上游专门维护了[已过时列表](https://mtf.wiki/zh-cn/docs/outdated)和[未确认列表](https://mtf.wiki/zh-cn/docs/unconfirmed)。
3. **看来源。** 有引用的资料比没有引用的可靠。
4. **看日期。** 医疗与政策信息，超过两三年要重新确认。
5. **不要一次读太多。** 信息过载会带来焦虑，也会记不住。

<div class="guide">
<strong>一个实用建议</strong>
<p>不要试图「读完再决定」。<b>读到你需要的下一个行动点就停下来去行动。</b></p>
<p>例如：读到「先挂精神科」就够了，去挂号。剩下的等到了那一步再读。</p>

## 关于「英文资料」

**Transfeminine Science 和 WPATH SOC-8 的原文都是英文，但有中文译文。**

- Transfeminine Science 有[中文翻译站](https://tfsci.mtf.wiki/)，收录了参考价值较高的一批文章，还包括**各类药物的说明书和译文**
- WPATH SOC-8 有[中文电子版](https://project-trans.org/SOC-8/)

**说明书是特别值得看的**——它是原始依据，比任何二手总结都可靠。

## 一、为什么 HRT 期间要关注睡眠

**上游提到性激素会影响认知、情绪和行为** [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。睡眠是其中最容易被影响、也最容易被忽略的一环。

**可能的关联路径：**

| 路径 | 说明 |
| --- | --- |
| **情绪波动** | 焦虑、抑郁都会影响入睡与睡眠质量 |
| **激素水平变化** | 开始用药、调整剂量、漏服或停药后可能出现波动 |
| **身体变化** | 乳房胀痛、潮热、盗汗可能影响睡眠 |
| **性别焦虑** | 睡前安静下来时反刍增加 |
| **术后恢复期** | 疼痛、活动受限、作息改变 |

**⚠️ 本站没有找到「HRT 对睡眠影响」的专门研究来源。** 上表是常见的关联路径，**不是因果结论**。

**但可以确认的是：** 睡眠问题与情绪问题会互相加重。**睡不好会加重焦虑，焦虑又会让你更睡不好。** 所以睡眠值得单独处理。

## 二、一般人群的睡眠建议（NHS）

**以下是一般人群的睡眠卫生建议 [2]，不是跨性别专属建议：**

| 方向 | 具体做法 |
| --- | --- |
| **固定作息** | 每天同一时间起床（**比固定入睡时间更重要**） |
| **限制午睡** | 午睡过长或过晚会影响夜间睡眠 |
| **规律运动** | 但避免睡前剧烈运动 |
| **减少咖啡因** | 下午和晚上避免咖啡、茶、可乐、能量饮料 |
| **减少酒精** | 酒精帮助入睡但会破坏睡眠质量 |
| **睡前放松** | 阅读、温水澡、放松练习 |
| **卧室环境** | 安静、黑暗、凉爽 |
| **床只用于睡觉** | 不在床上工作、刷手机 |
| **睡不着就起来** | 躺超过 20 分钟睡不着，起来做点安静的事，有困意再回床 |
| **限制屏幕** | 睡前减少强光刺激 |

**具体建议与适用条件见 [NHS 失眠页面](https://www.nhs.uk/conditions/insomnia/) [1] 与 [NHS 睡眠与疲劳页面](https://www.nhs.uk/live-well/sleep-and-tiredness/) [2]。**

## 三、如果睡前反刍停不下来

**这是很多人最实际的困扰：身体躺下了，脑子还在转。**

**一些常见的做法（本站整理，非上游原文）：**

| 做法 | 说明 |
| --- | --- |
| **把担心的事写下来** | 睡前 10 分钟写下「今天的事」和「明天要做的」，把循环从脑子里移到纸上 |
| **设一个「担心时间」** | 白天固定一段时间专门想这些事，睡前不处理 |
| **区分「能控制」和「不能控制」** | 见[情绪管理](/wiki/emotion-management/) |
| **不要在床上解决白天的问题** | 床和「思考」的关联越强，越难入睡 |
| **呼吸或放松练习** | 见 [NHS 自助指南](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/) [3] |
| **限制睡前信息摄入** | 尤其是社群里的比较与负面信息 |

## 四、什么时候该就医

**⚠️ 本站没有找到针对跨性别者的睡眠医学建议。** 以下是一般人群的常见判断 [1]：

| 情况 | 建议 |
| --- | --- |
| 睡眠问题持续超过一个月 | 就诊 |
| 明显影响白天功能（困倦、注意力差、情绪差） | 就诊 |
| 伴随明显的情绪问题 | 同时处理，见[焦虑与抑郁](/wiki/anxiety-depression/) |
| **打鼾严重、呼吸暂停、白天极度嗜睡** | **尽快就诊**（可能涉及睡眠呼吸暂停） |
| 靠酒精或安眠药才能入睡 | 尽快找专业帮助 |
| 睡眠问题与用药调整时间重合 | **带记录找医生，不要自行停药** |

**注意：安眠类药物需要医生处方，且部分与 HRT 用药存在相互作用。** 见[药物相互作用与合并用药](/wiki/drug-interactions/)。

## 五、关于「作息乱了」

**长期作息紊乱（晚睡晚起、作息不固定）会带来实际影响：**

| 影响 | 说明 |
| --- | --- |
| **睡眠质量下降** | 睡眠时长够但质量差 |
| **情绪波动** | 与焦虑、抑郁相关 |
| **代谢影响** | 与体重、血糖相关，见[体重、饮食与运动](/wiki/weight-nutrition/) |
| **就诊困难** | 很多检查要求上午采血，见[治疗期间的监测](/wiki/monitoring-index/) |
| **服药时间混乱** | 影响依从性，见[漏服、停药与调整](/wiki/missed-dose/) |

**「作息」这件事没有统一的正确答案，但有两件事值得固定：**

1. **起床时间**（比入睡时间更容易控制）
2. **服药时间**（与固定日常动作绑定，见[用药记录怎么做](/wiki/hrt-log/)）

## 六、一个提醒

**「睡不好」不是意志力问题，也不是「不够累」。**

**它是一个可以被处理的问题，而且处理之后，情绪、精力、注意力通常都会跟着改善。**

**如果长期睡不好，别硬扛——去就诊。**

## 常见问题

**「HRT 会影响睡眠吗？」**
**本站没有找到专门研究来源。** 但情绪波动、激素水平变化、身体变化都可能间接影响睡眠。

**「睡前想事情停不下来怎么办？」**
见下「如果睡前反刍停不下来」。

**「睡不好要吃安眠药吗？」**
**需要医生处方**，且部分与 HRT 用药存在相互作用。**不要自行购买。**

**「作息乱了怎么调整？」**
**先固定起床时间**，比固定入睡时间更容易控制。

**「打鼾严重怎么办？」**
**尽快就诊**，可能涉及睡眠呼吸暂停。

**「可以靠喝酒助眠吗？」**
**不行。** 酒精帮助入睡但会破坏睡眠质量。

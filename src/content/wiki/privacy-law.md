## 哪些信息受保护

**这一页涉及具体法律条文，本站不逐条引用。** 上游的[常见法律问题](https://mtf.wiki/zh-cn/docs/useful-info/legal-faq)条目讨论了隐私与信息相关的常见情形，原始规定可查[中国政府网](https://www.gov.cn/)。

一般认识是：个人信息保护相关法律把**医疗健康信息**列为**敏感个人信息**，处理这类信息需要更严格的条件（单独同意、必要性等）。**具体条文与适用条件请咨询律师。**

这意味着：

| 场景 | 说明 |
| --- | --- |
| 医院 | 对你的病历与就诊信息负有保密义务 |
| 学校 / 单位 | 因管理需要接触到的个人医疗信息同样受保护 |
| 网络平台 | 收集敏感信息需单独同意，且需说明用途 |
| 他人 | 未经同意公开他人医疗信息可能构成侵权（具体认定需法律判断） |

**但要注意：你自己主动公开的内容不受此保护。** 这是最容易忽略的一点，也是[安全与隐私基础](/wiki/safety-privacy/)反复强调它的原因。

## 常见的泄露情形

| 情形 | 常见发生方式 |
| --- | --- |
| 病历被议论 | 医护人员在非必要场合提及 |
| 学校公开处理 | 把学生的身份信息作为「案例」通报 |
| 单位人事泄露 | 办理社保、合同等业务时被同事知晓 |
| 前伴侣 / 熟人公开 | 报复性公开身份或照片 |
| 网络人肉 | 通过零散信息拼出你的身份 |

## 被泄露了怎么办

**顺序很重要：先固定证据，再行动。**

1. **截图 / 保存。** 包括发布时间、账号、内容、浏览量。**趁早，很多内容会被删。**
2. **要求删除。** 向发布平台投诉，要求下架。
3. **要求停止侵害。** 向泄露方（机构或个人）发出书面要求。
4. **咨询律师。** 涉及损害后果时，评估是否提起诉讼。
5. **联系公益组织。** 上游的[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)名单里部分提供法律支持或转介，另见[常见法律问题索引](/wiki/legal-faq-index/)。

<div class="guide">
<strong>一个判断标准</strong>
<p>问自己：「这条信息如果被更多人看到，会造成什么具体损害？」</p>
<p>名誉受损、工作受影响、人身安全受威胁 —— 有具体损害时，维权更有依据，也更值得投入。</p>

## 日常减少暴露的做法

- **分层账号。** 法定身份层、社图层、公开层尽量不共用邮箱、手机号、头像。见[安全与隐私基础](/wiki/safety-privacy/)。
- **照片去元数据。** 部分手机拍的照片带 GPS 坐标。
- **不在公开平台发证件、病历、检查单。**
- **需要提问时先打码。** 遮掉姓名、证件号、医院名称、医生姓名、住址。
- **检查旧账号。** 早年发过的内容可能还留着。
- **注意定位。** 连续发布某个地点的照片等于公开活动范围。
- **谨慎授权。** App 的通讯录、相册、定位权限按需给。

## 关于「信息公开」的边界

**有些信息你可以选择公开，有些最好不要。**

| 信息 | 建议 |
| --- | --- |
| 称呼、代词、认同 | 由你决定，没有义务 |
| 正在做的医疗步骤 | 通常没必要公开，多数场合不需要 |
| 具体用药与剂量 | 不建议公开（属于个人医疗信息） |
| 医院与医生姓名 | 视情况，通常不必 |
| 证件信息 | 绝不公开 |
| 可定位的照片 | 谨慎，尤其不要连续发布 |

## 一句话

**非二元（non-binary，社群也写作 enby）指的是性别认同不完全落在「男」或「女」这两个点上的人。**

**这不是「还没想清楚」，也不是「两边都想占」。它是一个有效的自我描述。**

## 一些常见的自我描述

| 说法 | 大致意思 |
| --- | --- |
| **非二元** | 不在二元框架内 |
| **genderfluid** | 认同在不同状态间流动 |
| **agender** | 感觉自己没有性别，或性别对自己不重要 |
| **demigirl / demiboy** | 部分认同为女性/男性 |
| **女性倾向（transfeminine）** | 偏向女性一侧，但不完全是女性 |

**这些词的含义在不同人嘴里不完全一样。** 想知道对方具体指什么，**直接问比查词表准**。

## 医疗上的不同选择

**这是非二元和二元跨性别者最容易产生差异的地方：你可能只想要一部分效果，不想要另一部分。**

**常见的诉求组合：**

| 诉求 | 说明 |
| --- | --- |
| 想要去男性化，但**不想乳房发育** | — |
| 想要部分女性化，但**保留生育力** | — |
| 想要声音变化，但**不想改变身体其他部分** | — |
| 不想要任何医疗干预，只做社会层面的调整 | — |

**对应地，上游资料里有一类非常规方案：**

| 方案 | 思路 |
| --- | --- |
| **SERM + 抗雄** | 用[选择性雌激素受体调节剂](https://mtf.wiki/zh-cn/docs/medicine/SERMs)（如雷洛昔芬）维持骨密度，同时避免乳房发育；**抗雄仍需要** |
| **低剂量雌激素 + 抗雄** | 沿用常规方案但降低雌激素用量，目标雌二醇 30–50 pg/mL |

**上游的说明：**

> SERM 本身不会降低、甚至可能增加雄激素水平，为实现去男性化，抗雄激素药物仍然是必要的；其用量和常规方案一致或略为增加。

**这些方案的证据比常规方案少，需要医生评估。** 具体看上游的[非二元方案说明](https://tfsci.mtf.wiki/zh-cn/articles/nonbinary-transfem-overview/)与 [HRT 简明指南](https://mtf.wiki/zh-cn/docs/medicine/zero-to-hrt)。

**中国大陆可用的 SERM 有雷洛昔芬、他莫昔芬等**（见[雷洛昔芬](https://mtf.wiki/zh-cn/docs/medicine/SERMs/raloxifene)）。

<div class="guide">
<strong>就医时怎么说</strong>
<p>跟医生沟通时，<b>直接说清楚你想要什么、不想要什么</b>，比先解释自己的认同标签有效得多。</p>
<p>例如：「我希望声音和体毛有变化，但不希望乳房发育，也不希望影响生育力。」这句话医生能直接用。</p>
</div>

## 会遇到的现实问题

| 问题 | 说明 |
| --- | --- |
| **流程默认你是二元的** | 表格、系统、医生的问诊习惯通常只有两个选项。这不是你的问题，但需要你有心理准备 |
| **证件上没有非二元选项** | 国内目前的实名信息变更通常只能在男/女之间变更 |
| **社群内部也会有摩擦** | 有人不理解非二元，这很常见。**找到能理解的那部分人就好** |
| **被要求「证明」** | **你没有义务证明自己**。可以简单说明，也可以不解释 |
| **医疗资源更少** | 愿意处理非常规方案的医生更少 |

## 关于「要不要用医疗手段」

**完全由你决定。**

| 选项 | 说明 |
| --- | --- |
| 只用社会层面的调整 | 称呼、代词、着装、发型 |
| 只用部分医疗手段 | 例如只用抗雄，或低剂量方案 |
| 用常规方案 | 也可以 |
| 完全不用 | 也可以 |

**没有「非二元就必须怎样」的规则。**

## 常见问题

**「非二元是「还没想清楚」吗？」**
**不是。** 它是一个有效的自我描述，不是过渡状态。

**「非二元需要医疗干预吗？」**
**完全由你决定。** 可以只用社会层面的调整，也可以用部分或全部医疗手段。

**「流程会认非二元吗？」**
**多数流程默认是二元的。** 表格、系统、医生的问诊习惯通常只有两个选项。**这不是你的问题，但需要你有心理准备。**

**「证件上有非二元选项吗？」**
**国内目前没有。** 实名信息变更通常只能在男/女之间变更。

**「被要求证明怎么办？」**
**你没有义务证明自己。** 可以简单说明，也可以不解释。

**「社群内部不理解怎么办？」**
**这很常见。** 找到能理解的那部分人就好。

## 医疗上的不同选择（完整对照）

**这是非二元和二元跨性别者最容易产生差异的地方。**

| 诉求组合 | 对应方案 | 注意 |
| --- | --- | --- |
| 想要去男性化，但**不想乳房发育** | SERM + 抗雄 | **抗雄仍需要**；常规抗雄疗法在 SERM 方案下不适用 |
| 想要部分女性化，但**保留生育力** | 低剂量雌激素 + 抗雄 | 目标雌二醇 30–50 pg/mL |
| 想要声音变化，但**不想改变身体其他部分** | 嗓音训练（不涉及药物） | 完全可逆 |
| 想要**去男性化但不要女性化** | 抗雄（单独或配合低剂量） | **注意双低风险** |
| 不想要任何医疗干预 | 只做社会层面调整 | — |

**⚠️ 这些方案的证据比常规方案少，需要医生评估。**

## SERM 方案的详细说明

**上游的明确表述：**

> SERM 本身不会降低、甚至可能增加雄激素水平，为实现去男性化，抗雄激素药物仍然是必要的；其用量和常规方案一致或略为增加。

**⚠️ 一个重要限制（上游原文）：**

> 值得注意的是，**不同于雌二醇，雷洛昔芬无抗促性腺激素作用，因此其不可与孕激素联合来充分降低雄激素水平**。而单独使用孕激素只可降低睾酮水平约 50%-70%，且长期使用下睾酮水平会发生一定程度的回升；螺内酯不能有效拮抗高水平的雄激素。**该方案下，一般的抗雄激素疗法（CPA 或螺内酯，皆需与雌激素合用）不适用。**

**即：SERM 方案下，抗雄方案的选择与常规不同。** 具体看上游的[非二元方案说明](https://tfsci.mtf.wiki/zh-cn/articles/nonbinary-transfem-overview/)。

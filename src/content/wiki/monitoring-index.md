## 为什么监测是必须的

激素水平、肝功能、血液指标的变化**大部分没有体感**。你不会「感觉到」转氨酶升高或泌乳素异常。等到有感觉的时候，通常已经偏离得比较远了。

监测是唯一能提前发现问题的环节。它不是为了走流程，是整个用药过程里保护你的那一部分。

## 复查节奏（有来源）

上游给出的频次建议：

| 阶段 | 频次 |
| --- | --- |
| 开始激素治疗**之前** | 进行一次全面检查，排查疾病问题 |
| 用药**第一年** | 每三个月（或遵医嘱）复查一次激素，咨询医师调整剂量 |
| 用药**稳定后** | 每年复查激素与其它常规**至少一次** |

上游同时说明：**依检查结果和身体反应，可能需酌情增加复查频率。**

见 [MtF.wiki · 治疗期间的监测](https://mtf.wiki/zh-cn/docs/medicine/monitoring)。

**本站不给出替代方案。** 你的具体复查安排由医生决定，上述是上游的通用建议。

## 查哪些项目

上游在监测条目里把项目分为几类：

| 类别 | 项目 | 为什么 |
| --- | --- | --- |
| **性激素** | 雌二醇、睾酮 | 判断方案是否达到预期、是否抑制过度 |
| **泌乳素** | PRL | 部分孕激素类药物相关 |
| **肝功能** | ALT、AST 等 | 部分药物经肝脏代谢 |
| **血常规** | 红细胞、白细胞、血小板等 | 整体状态 |
| **电解质** | 钾、钠等 | 部分抗雄药物相关 |
| **肾功能** | 肌酐、尿素氮等 | 用药安全性评估 |
| **其它** | 视医生判断 | 骨密度、血脂、血糖等 |

**具体查哪些、组合成什么套餐，各医院不同。** 有些医院有现成的「激素六项」，有些可以分开查。

## 采血时间点：最容易出错的地方

**结果和「上次给药到现在多久」直接相关。**

不同途径的波动幅度差别很大：

| 途径 | 波动 |
| --- | --- |
| 口服 / 含服 | 服药后数小时达峰，之后下降 |
| 经皮（贴片 / 凝胶） | 相对平稳 |
| **注射** | **波动最大**，峰谷差可达数倍 |

**上游资料提到，以「日雌」（戊戊酸雌二醇 10 mg）为例，注射后预计雌二醇峰值可达 590 pg/mL**（见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)）。

**所以：**

- 医生要求空腹就空腹
- 要求「下次给药前抽血」就按那个时间点去
- 不要自行改时间，否则数据没法解释
- 注射方案尤其要严格遵守时间点

## 化验单上的参考范围

**不同实验室的参考范围不同**，因为检测方法与标准品不同。所以：

- **以你报告单上印的范围为准**
- **不要拿不同医院的数值直接比较**，即使单位相同
- 需要换算单位时，见[激素换算工具](/wiki/hormone-converter/)

LabCorp 的[内分泌参考值与单位换算表](https://specialtytesting.labcorp.com/sites/default/files/2021-07/L5167-0421-18%20Endocrine%20Expected%20Values_0.pdf)是上游引用的参考值来源之一。

## 不复诊会发生什么

短期看不出问题，长期风险累积：

1. **方案没有跟着你的身体调整。** 激素水平可能偏高或偏低，但你没有依据知道。
2. **问题被发现得太晚。** 肝功能、泌乳素这类指标异常，早发现通常好处理。
3. **影响后续环节。** 手术、办证都可能要求近期的检查报告。
4. **用药记录断层。** 换医院时说不清既往方案。

## 记录建议

上游在监测部分建议：**注意进行身体状况的记录，如血常规、电解质、激素六项、肝肾功能和不良反应。**

**建一张表，每次检查后填：**

| 字段 | 说明 |
| --- | --- |
| 日期 | 检查日期 |
| 检查项目与结果 | **带上单位** |
| 当时用药 | 药名与剂型（不必写剂量） |
| 采血时间点 | 距上次给药多久 |
| 身体与情绪变化 | 关键词即可 |

**复诊时带着，医生能更快了解你的情况。** 这份记录属于个人隐私，**不要公开发布**，见[用药记录怎么做](/wiki/hrt-log/)与[材料与档案管理](/wiki/records-management/)。

## 什么情况要提前就医（不必等复查）

- 皮肤或眼白发黄、尿色明显变深
- 持续恶心、食欲明显下降、右上腹疼痛
- 单侧肢体肿痛、呼吸困难、胸痛
- 持续加重的头痛、视力变化
- 注射部位明显红肿化脓

**出现这些不要等到下次复查。**

## 常见问题

**「多久复查一次？」**
**上游：用药第一年每三个月一次；稳定后每年至少一次。** 肝功能：治疗期间每三个月；用 CPA/比卡鲁胺时前六个月每月一次。

**「只查三项可以吗？」**
**可以。** 上游：「可以在完全六项检查之后一段时间里，只检查所关注的几项。」

**「需要空腹吗？」**
**看项目。** 上游：「是否空腹抽血请遵医嘱。」**多数抽血项目要求空腹。**

**「采血时间点有多重要？」**
**非常关键。** 结果和「上次给药到现在多久」直接相关。

**「复查可以在本地做吗？」**
**可以。** 上游提到北医三院承认外院检查结果，且检查有效期通常为三个月。

**「指标异常要停药吗？」**
**不要自己停。** 带报告找医生。

| 阶段 | 频次 | 依据 |
| --- | --- | --- |
| **开始前** | 一次全面检查 | [HRT 简明指南](https://mtf.wiki/zh-cn/docs/medicine/zero-to-hrt) |
| **用药第一年** | **每三个月**（或遵医嘱） | [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview) |
| **稳定后** | **每年至少一次** | 同上 |
| **肝功能** | **治疗期间每三个月** | [治疗期间的监测](https://mtf.wiki/zh-cn/docs/medicine/monitoring) |
| **肝功能（用 CPA / 比卡鲁胺）** | **前六个月内每个月** | 同上 |
| **骨密度** | 视医生判断 | 同上 |

**依检查结果和身体反应，可能需酌情增加复查频率。**

## 检查项目的完整清单

**应监测：**

| 项目 | 说明 |
| --- | --- |
| **性激素六项** | 其中雌二醇、睾酮、泌乳素较重要 |
| **肝功能** | 见上表频次 |

**可酌情监测：**

| 项目 | 为什么 |
| --- | --- |
| **空腹血糖和胰岛素** | 雌激素及比卡鲁胺等可影响糖耐量 |
| **空腹血脂** | 雌激素可降低 LDL、提高甘油三酯；螺内酯、比卡鲁胺可提高 LDL |
| **骨密度** | 双低状态需谨慎 |
| **肾功能** | 肾功能不全者慎用螺内酯与雌激素 |
| **离子六项** | 螺内酯可能影响钾、钠、钙、镁 |
| **凝血功能** | 雌、孕激素可增强凝血 |
| **血常规** | 雌激素可增加血小板；CPA、比卡鲁胺可减少红细胞 |
| **甲状腺功能** | 雌激素可刺激 TBG 分泌 |
| **乳腺扫描** | 长年服用雌、孕激素应注意 |
| **脑部 MRI** | 长年、高剂量 CPA 需注意脑膜瘤风险 |
| **体重和体脂** | MtF 群体普遍可见 GAHT 后体重体脂增加 |
| **无机磷与 PTH** | 与雌二醇、血钙相关 |
| **血清铁** | 在贫血、肝病可能时辅助鉴别 |

## 采血时间点的完整要求

**上游的明确要求：**

> 应当在**接近下一次用药前**进行抽血检查，**不要在服用药物之后立即进行激素检查**。

**不同途径的波动幅度：**

| 途径 | 波动 |
| --- | --- |
| 口服 / 含服 | 服药后数小时达峰，之后下降 |
| 经皮（贴片 / 凝胶） | 相对平稳 |
| **注射** | **波动最大**，峰谷差可达数倍 |

**⚠️ 透皮药物的具体坑：**

> 如果您正在使用任何透皮类的雌激素药物，请确保您在**采血前没有在采血的手臂使用药物**，否则测出的结果将会异常偏大且没有参考价值，甚至超出仪器最大量程（有编者曾测出 E2 > 19856.78 pmol/L）。

## 什么时候做比较合适

**上游的 HRT 效果表显示，乳房发育需要 2–5 年才稳定** [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

这意味着：

- **太早做，可能低估了自己发育的潜力**
- **建议等 HRT 效果基本稳定后再评估是否需要**
- 具体等待时长与判断，要由医生结合你的情况决定

<div class="guide">
<strong>先问自己这三个问题</strong>
<p>· 我等够时间了吗？（HRT 效果是否已稳定）</p>
<p>· 我期待的是「更大」还是「形状更好」？（两者方案不同）</p>
<p>· 我能接受可能的二次手术吗？</p>
</div>

## 主要术式与材料

| 类别 | 说明 |
| --- | --- |
| **假体植入** | 最常见。假体有不同形状、表面与填充物 |
| **自体脂肪移植** | 用自身脂肪，效果受脂肪存活率影响 |
| **联合方案** | 假体 + 脂肪，用于改善轮廓与过渡自然度 |

**切口位置、假体放置层次（乳腺后 / 胸肌后）等细节，由医生根据你的组织条件决定。** 具体看上游的[隆乳手术综述](https://mtf.wiki/zh-cn/docs/breast-augmentation/breast-overview)。

**上游未把隆乳列为证件变更的必要条件**，所以这项手术在流程上是完全独立的。

## 术前要问清的问题

| 类别 | 问题 |
| --- | --- |
| 术式 | 你建议哪种？为什么？ |
| 假体 | 类型、品牌、寿命是多久？需要定期检查吗？ |
| 更换 | 需要更换吗？多久？ |
| 切口 | 切口在哪？疤痕明显吗？ |
| 恢复 | 恢复期多长？多久能正常活动？ |
| 并发症 | 常见并发症有哪些？ |
| 二次手术 | 需要二次手术的比例大概多少？ |
| 费用 | 多少？包含复查与修复吗？ |
| 哺乳 | 会不会影响哺乳能力？ |
| 筛查 | 对乳房自检与疾病筛查有什么影响？ |

## 风险与注意事项

**上游未在综述里给出具体的发生率数字。** 可确认的方向包括：

| 方向 | 说明 |
| --- | --- |
| 植入物并发症 | 任何植入物都可能有并发症，且部分需要再次手术处理 |
| 包膜挛缩 | 假体周围组织形成的纤维包膜收缩 |
| 移位 | 假体位置改变 |
| 感染 | 手术相关感染 |
| 感觉变化 | 乳头或乳房感觉改变 |
| 随访要求 | 术后需要定期检查（部分指南建议影像随访） |

**具体风险与发生率，看上游条目与你的医生的说明。**

**乳腺癌风险与隆乳的关系：** 隆乳本身不改变乳腺癌的发病风险，但**会影响筛查的影像判读**，所以需要告知影像科医生你的手术史。相关背景见[乳腺癌风险](https://tfsci.mtf.wiki/zh-cn/articles/breast-cancer/)。

## 与其他步骤的关系

| 关系 | 说明 |
| --- | --- |
| **不影响 HRT** | 但建议在 HRT 效果稳定后做 |
| **不影响证件变更** | 通常不是证件变更的必要条件 |
| **可以与 FFS 等项目分开安排** | 避免恢复期叠加 |
| **孕激素** | 上游认为孕激素对乳房发育的作用尚无定论，见[孕激素与乳房发育](https://tfsci.mtf.wiki/zh-cn/articles/progestogens-breast-dev/) |

## 一个提醒

**胸部大小不是「够不够女性化」的标准。**

有人做了，有人没做，都正常。决定应该基于你自己的困扰，而不是任何外部期待。

**如果你因为外部压力（家人、伴侣、社群）而考虑这项手术，值得先停下来想清楚。** 见[交友与亲密关系](/wiki/dating-relationships/)与[家庭沟通](/wiki/family/)。

## 常见问题

**「什么时候做合适？」**
**上游效果表显示乳房发育需要 2–5 年才稳定。** 太早做可能低估了自己的发育潜力。

**「会留疤吗？」**
取决于切口位置。**咨询时直接问医生。**

**「假体需要更换吗？」**
**需要了解假体的寿命与更换周期。** 具体问医生。

**「会影响哺乳吗？」**
**可能影响。** 如果有此考虑，提前说明。

**「会影响乳腺癌筛查吗？」**
**会影响筛查的影像判读**，所以需要告知影像科医生你的手术史。

**「可以只做脂肪填充吗？」**
可以，但**效果受脂肪存活率影响**，可能需要多次。

**「不对称怎么办？」**
术前评估会考虑。**如果术后出现明显不对称，可能需要修整。**

## 术式与材料的详细对照

| 类别 | 说明 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **假体植入** | 最常见。假体有不同形状、表面与填充物 | 效果可控、一次成型 | 需要更换、可能有包膜挛缩 |
| **自体脂肪移植** | 用自身脂肪 | 无异物、触感自然 | 效果受存活率影响、可能需要多次 |
| **联合方案** | 假体 + 脂肪 | 改善轮廓与过渡自然度 | 费用更高、恢复更复杂 |

**切口位置、假体放置层次（乳腺后 / 胸肌后）等细节，由医生根据你的组织条件决定。**

## 假体的关键参数

| 参数 | 说明 |
| --- | --- |
| **形状** | 圆形 / 水滴形 |
| **表面** | 光面 / 毛面 |
| **填充物** | 硅胶 / 生理盐水 |
| **体积** | 按 cc 计算 |
| **放置层次** | 乳腺后 / 胸肌后 / 双平面 |

**⚠️ 本站不推荐具体参数。** 这些由医生根据你的组织条件与期望决定。

## 乳腺癌风险与筛查

**隆乳本身不改变乳腺癌的发病风险，但会影响筛查的影像判读。**

| 事项 | 说明 |
| --- | --- |
| 发病风险 | 隆乳本身不改变 |
| **筛查影响** | **会影响影像判读** |
| **要告知医生** | 做乳腺检查时主动说明手术史 |
| 相关背景 | 见[乳腺癌风险](https://tfsci.mtf.wiki/zh-cn/articles/breast-cancer/) |
| 筛查安排 | 见[器官筛查与定期体检](/wiki/organ-screening/) |

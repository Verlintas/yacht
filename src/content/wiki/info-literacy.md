## 核心思路

**你不需要成为专家才能判断一条信息靠不靠谱。只需要检查它的证据形态。**

下面是可操作的六步流程。

## 第一步：看它属于哪一类

| 类型 | 例子 | 判断方式 |
| --- | --- | --- |
| **指南与共识** | WPATH SOC-8、国家级诊疗规范 | 看版本号和发布日期，注意是否被新版本取代 |
| **药品说明书** | 药厂说明书、药典 | 看是否与手上的剂型一致 |
| **社群整理的资料库** | MtF.wiki 一类 | 看单条目的来源、是否在已过时/未确认清单里 |
| **个人经验分享** | 帖子、视频、聊天记录 | 可以看，但**只能当参考，不能当依据** |
| **广告与引流** | 「专家坐诊」「包成功」 | 默认不信 |

## 第二步：查两个清单

**上游专门维护了两份清单，这是最省事的验证手段：**

| 清单 | 用途 |
| --- | --- |
| [已过时列表](https://mtf.wiki/zh-cn/docs/outdated) | 判断信息是否已失效 |
| [未确认列表](https://mtf.wiki/zh-cn/docs/unconfirmed) | 未经核实的内容 |

**先查这两个，能省掉大部分判断成本。**

## 第三步：看时间

| 检查项 | 说明 |
| --- | --- |
| 有没有日期 | **没有日期的资料默认按「可能过时」处理** |
| 医疗与政策信息 | 超过两三年的要重新确认 |
| 医院名单、医生接诊情况 | 变化更快，**按季度看比较稳妥** |

## 第四步：看它怎么谈剂量

**这是最容易出事的部分：**

| 情况 | 判断 |
| --- | --- |
| 给出了具体数字，**并标明出处** | 可用，但仍应和医生确认 |
| 给出了具体数字，**但没说出处** | **不用** |
| 说「大家都这么吃」 | **不用** |
| 说某个剂量「绝对安全」 | **不用** |

**本站的做法是：每个数字都附来源，页尾列出全称与链接，状态标草稿。** 看[药物剂量速查](/wiki/medication-doses/)或 [HRT 完整指南](/wiki/hrt-complete-guide/)时可以照着来源逐条核对。

## 第五步：交叉验证

**同一个说法，在两个互相独立的来源里都出现，可信度才明显上升。**

**注意「互相独立」：** 两个都在转载同一篇帖子，不算两个来源。

## 第六步：看它有没有在卖东西

**如果一条信息最终指向某个购买链接、某个「咨询服务」、某个私人渠道，先把它的结论打个折，再去找不带商业动机的来源核对。**

见[中介与骗局识别](/wiki/scam-awareness/)。

## 红旗清单

**看到下面这些，直接提高警惕：**

| 红旗 | 为什么 |
| --- | --- |
| 承诺确定性（「一定」「百分百」「包好」） | 医学和行政事务都不存在保证 |
| 只有结论没有过程 | 无法验证 |
| 拒绝给出原始来源（「不方便说」「你自己去找」） | 通常是因为没有 |
| 用恐惧推动决策（「不这样做就完了」） | 制造紧迫感以绕过思考 |
| 用身份压制质疑（「你不是跨性别你不懂」） | 身份不构成论据 |
| 要求私下交易或转账 | 无法追责 |
| 要求提供敏感信息才能加入 | 见[线上社群安全](/wiki/online-community-safety/) |

## 一个反向检查

**问自己：「如果这条信息是错的，谁会受损？」**

| 答案 | 含义 |
| --- | --- |
| 只有我自己 | 值得多花十分钟核实 |
| 发这条信息的人会赚到钱 | **更要花十分钟** |
| 别人也会受损 | 值得记录下来提醒他人 |

## 把不确定标出来

**最后一条，也是最有用的：允许自己说「这条我不确定」。**

把不确定的地方写下来，比强行形成结论安全得多。**本站每个条目都标了状态，就是这个道理。**

**同样的做法可以用在自己的笔记里：** 记下「这条我查过来源」和「这条只是听说」的区别。

## 关于「本站可信吗」

**本站也应该被这样检查。**

- 每个条目有来源列表（页尾）
- 有审核状态（草稿 / 有来源 / 已核对 / 已过时）
- 有 AI 声明（内容由 AI 协助整理）
- 操作性条目有「经验整理」标注

**如果你发现某条内容与来源不符，那是本站的错误。** 欢迎提 issue 或直接修改。

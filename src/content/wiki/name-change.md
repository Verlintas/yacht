## 先分清两件事

**改名**和**变更性别信息**是两项不同的户籍业务。

| | 改名 | 性别信息变更 |
| --- | --- | --- |
| 业务类型 | 姓名变更登记 | 户籍信息变更 |
| 常见要求 | 理由、次数限制、年龄条件 | 医院出具的相关证明 |
| 能否合并 | **各地规定不同** | 同左 |
| 先后顺序 | **各地规定不同** | 同左 |

**办之前一定先问窗口：「这两项能不能一起办？如果分开，先办哪个？」**

**顺序错了可能要重跑**，见[实名信息变更总览](/wiki/real-name-overview/)。

## 改名的一般要求

各地规定不同，通常会考虑：

| 考虑项 | 说明 |
| --- | --- |
| 是否成年 | 未成年人一般需监护人同意 |
| 改名理由 | 各地对理由的接受程度不同 |
| 是否有未了结的法律事务 | 如债务、诉讼 |
| 改名次数与间隔 | **部分地方有限制** |
| 是否涉及规避义务 | 如逃避债务、逃避法律追究 |

**具体条件以当地窗口为准。** 上游的[实名信息变更指引](https://mtf.wiki/zh-cn/docs/useful-info/real-name-info)有整理。

## 办理要点

- [ ] **先电话咨询当地窗口**，问清条件、材料和顺序
- [ ] 准备书面申请（**理由怎么写，可以问窗口要参考格式**）
- [ ] 户口本、身份证原件
- [ ] 如与性别信息一起办，带上医院材料
- [ ] 问清办理周期，以及期间能否使用旧证件
- [ ] 问清是否需要本人到场

**理由的常见写法（供参考）：** 「现用名不符合本人的性别表达，给日常生活造成困扰，申请变更。」**具体表述以窗口要求为准。**

## 改完之后要跟着改的东西

**这是最容易被低估的部分。** 名字改了，一串东西都要更新：

| 类别 | 具体项目 |
| --- | --- |
| **证件** | 身份证、护照、港澳通行证、台湾通行证、驾驶证 |
| **学历** | 学籍、学历证书（见[学籍与学历变更](/wiki/education-records/)） |
| **金融** | 银行卡、信用卡、证券账户、支付账户、基金/理财账户 |
| **通信** | 手机号实名、宽带、固话 |
| **社会保障** | 医保、社保、公积金 |
| **工作** | 劳动合同、单位人事系统、工牌、邮箱 |
| **生活** | 房产、车辆登记、会员卡、各类互联网账号 |
| **其他** | 保险单、租房合同、水电燃气户名 |

**建议做一张表逐项打勾。** 跨几个月很正常，见[材料与档案管理](/wiki/records-management/)。

**最容易漏的三项：**

1. **各类互联网账号**（尤其是绑定了实名信息的）
2. **保险单**（变更可能需要主动申请）
3. **水电燃气户名**（换房或过户时才会发现）

## 关于「曾用名」

**户籍系统会保留曾用名记录。** 这是正常行政记录，不影响使用。

**需要用到曾用名的场合：**

- 学历认证（证明新旧信息是同一个人）
- 银行账户变更
- 部分境外签证申请

**但要注意：曾用名会把新旧身份关联起来。** 所以在公开场合（社群、社交平台）**不要透露自己的曾用名**。

## 几个实际建议

1. **名字选一个能长期用的。** 频繁改名会增加后续麻烦，各地也可能有限制。
2. **注意生僻字。** 生僻字在银行、机票、签证系统里可能无法录入。**选之前先试试能不能在常用输入法里正常打出、显示。**
3. **先问清顺序再动手。** 改名和性别变更的顺序错了，可能要重跑。
4. **保留旧证件的复印件或扫描件**（加密保存），用于证明身份沿革。
5. **改名后尽早更新常用证件。** 新旧证件混用期间办事容易出问题。

**关于名字怎么选，见[名字的选择](/wiki/choosing-name/)。**

## 常见问题

**「一定要有理由才能改吗？」**
各地规定不同，多数需要填写理由。**具体接受什么理由，问窗口。**

**「改过还能再改吗？」**
**可能有限制**，具体看当地规定。这也是建议第一次就选一个能长期用的名字的原因。

**「未成年能改吗？」**
通常需要监护人同意。具体要求问当地窗口。

**「改名后学历证书怎么办？」**
已发放的证书通常不能直接改，常见做法是由学校出具证明，见[学籍与学历变更](/wiki/education-records/)。

**「改名后签证怎么办？」**
换发护照后旧签证通常失效，见[护照与旅行证件](/wiki/travel-documents/)。

## 隐私提醒

改名申请、户籍材料、曾用名信息都属于个人隐私。

**不要在公开平台透露自己的曾用名**，那会把新旧身份关联起来。见[安全与隐私基础](/wiki/safety-privacy/)。

## 先分清两件事

**改名**和**变更性别信息**是两项不同的户籍业务。可以分开办，也可以一起办，但**顺序和能否合并，各地规定不同**。

办之前一定先问窗口：「这两项能不能一起办？如果分开，先办哪个？」

## 改名的一般要求

各地规定不同，通常会考虑：

- 申请人是否成年（未成年人一般需监护人同意）
- 改名理由（各地对理由的接受程度不同）
- 是否有未了结的法律事务（如债务、诉讼）
- 改名的次数与间隔限制

**具体条件以当地窗口为准。** 上游的[实名信息变更指引](https://mtf.wiki/zh-cn/docs/useful-info/real-name-info)有整理。

## 办理要点

- [ ] 先电话咨询当地窗口，问清条件、材料和顺序
- [ ] 准备好书面申请（理由怎么写，可以问窗口要参考格式）
- [ ] 户口本、身份证原件
- [ ] 如与性别信息一起办，带上医院材料
- [ ] 问清办理周期，以及期间能否使用旧证件

## 改完之后要跟着改的东西

这是最容易被低估的部分。名字改了，一串东西都要更新：

| 类别 | 具体项目 |
| --- | --- |
| 证件 | 身份证、护照、港澳台通行证、驾驶证 |
| 学历 | 学籍、学历证书（见[学籍与学历](/wiki/education-records/)） |
| 金融 | 银行卡、信用卡、证券账户、支付账户 |
| 通信 | 手机号实名、宽带 |
| 社会保障 | 医保、社保、公积金 |
| 工作 | 劳动合同、单位人事系统、工牌 |
| 生活 | 房产、车辆、会员卡、各类互联网账号 |

**建议做一张表逐项打勾**，跨几个月很正常。

## 关于「改名记录」

户籍系统会保留曾用名记录。这不是问题，属于正常行政记录。需要使用曾用名证明身份一致性的场合（如学历认证），可以用户籍材料说明。

## 几个实际建议

1. **名字选一个能长期用的。** 频繁改名会增加后续麻烦，各地也可能有限制。
2. **注意生僻字。** 生僻字在银行、机票、签证系统里可能无法录入，选之前可以先试试能不能在常用输入法和系统里正常显示。
3. **先问清顺序再动手。** 改名和性别变更的顺序错了，可能要重跑。
4. **保留旧证件的复印件或扫描件**（加密保存），用于证明身份沿革。

## 隐私提醒

改名申请、户籍材料、曾用名信息都属于个人隐私。**不要在公开平台透露自己的曾用名**，那会把新旧身份关联起来。

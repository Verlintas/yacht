## 先说清楚：孕酮不是 HRT 的必需项

**上游的 HRT 方案里，孕酮不是必需组成。**

**MtF.wiki 的[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)页把孕激素风险单列了一节，内容不长**——这本身就说明上游掌握的证据有限。

**「要不要加孕酮」是社群讨论最多、证据最薄的问题之一。** 本页只整理上游明确写了的部分，以及几组容易被搞混的药名。

## 孕激素、孕酮、黄体酮是三个词

| 词 | 指什么 |
| --- | --- |
| **孕酮（Progesterone）** | 一种天然甾体激素，也叫**黄体酮** |
| **孕激素（Progestogen）** | 一类具有孕激素作用的物质的总称，**包含天然孕酮和人工合成的** |
| **人工合成孕激素** | 如**醋酸环丙孕酮（CPA）**、**醋酸甲羟孕酮（MPA）**、**地屈孕酮**、**醋酸氯地孕酮** |

**⚠️ 关键：CPA 本身是一种人工合成孕激素。** 它的抗雄作用是额外的。

**所以「用 CPA 就等于用了孕激素」这个说法在药理上是对的**，但社群通常说的「加孕酮」指的是**天然孕酮（黄体酮）**，这是两回事。

## 上游明确写了的三条

**以下是 MtF.wiki [用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)页「孕激素用药风险」一节的完整内容框架：**

| 上游表述 | 含义 |
| --- | --- |
| **「已知口服孕酮与类似于酒精的神经甾体副作用有关」** | 口服途径有明确的已知副作用 |
| **「非口服孕酮无任何已知副作用」** | 上游对非口服途径的表述是「无任何已知副作用」 |
| **「人工合成孕激素（如醋酸环丙孕酮）详见『抗雄激素用药风险』」** | 合成孕激素的风险归到抗雄一节 |

**⚠️ 注意上游的措辞差别：** 「已知……有关」对口服是**有限定**的表述；「无任何已知副作用」对非口服是**基于现有资料的**表述。**两者都不等于「安全」或「不安全」的结论。**

## 口服孕酮的核心问题：吸收率

**Transfeminine Science 有一篇专文讨论这件事**：口服孕酮达到的血药浓度很低，孕激素效力也弱。

| 要点 | 说明 |
| --- | --- |
| **口服后血药浓度低** | 大部分在肠道和肝脏被代谢掉 |
| **效力弱** | 浓度低意味着孕激素作用有限 |
| **非口服途径浓度高得多** | 直肠给药等途径可绕过首过效应 |

**MtF.wiki 在雌二醇片（芬吗通）页面引用了这篇文献**，用来说明为什么复方片里的地屈孕酮「无法确保能够提供完全孕激素效力」。

**所以「口服孕酮到底有没有用」这个问题的关键在途径，不在剂量。** 加大口服剂量并不等于获得更高的有效暴露。

## 芬吗通里的地屈孕酮：上游怎么写的

**芬吗通（Femoston）是雌二醇／地屈孕酮复方包装，很多人在药盒上第一次见到「孕酮」两个字。**

**上游在[雌二醇药物](https://mtf.wiki/zh-cn/docs/medicine/estrogen/estradiol)页的说明：**

| 上游表述 | 含义 |
| --- | --- |
| 「属于孕激素类成分，但**无法确保能够提供完全孕激素效力**」 | 效力不确定 |
| 「**不具有抗雄作用**」 | **不能当抗雄药吃** |
| 「且**风险尚不明确**，请谨慎使用」 | 风险资料不足 |

**⚠️ 常见误解：把芬吗通当成「雌激素 + 抗雄」的复方。上游明确说地屈孕酮不具抗雄作用。**

**另一个常见误解：** 把芬吗通的复方片当成「自带孕酮」的方案。**上游的表述是效力无法确保。**

## 「日色」是什么（重要混淆）

**上游在[醋酸环丙孕酮](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/cyproterone)页明确提示：**

> 「日色」为**醋酸氯地孕酮（Chlormadinone Acetate）**，同样具有抗雄激素活性，但**并非醋酸环丙孕酮，请不要误用**。

| 药名 | 是什么 | 能否当 CPA 用 |
| --- | --- | --- |
| **醋酸环丙孕酮（CPA）** | 俗称「色普龙／色谱龙」 | — |
| **醋酸氯地孕酮** | 俗称「日色」 | **不能，上游明确说不要误用** |
| **醋酸甲羟孕酮（MPA）** | 俗称「安宫黄体酮」 | **上游：可作替代品，但效果稍差** |

**三种药名字都带「孕酮／孕激素」，作用并不相同。**

## 醋酸甲羟孕酮（MPA）：上游的定位

**上游对 MPA 的表述：**

| 上游表述 | 含义 |
| --- | --- |
| 「是一种类固醇孕激素，具有抗促性腺激素作用，可以抑制体内雄激素水平」 | 有抗雄作用 |
| 「在无法获取到醋酸环丙孕酮（色普龙）时**可作为替代品**服用」 | 替代选项 |
| 「**但效果稍差**」 | 效力弱于 CPA |

**⚠️ MPA 是处方药，具体用不用、怎么用，必须由医生决定。**

## 血栓风险：孕激素会叠加

**MtF.wiki [用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)页的血栓相对风险率表里，有专门对比「合并孕激素」的行：**

| 用药 | 血栓相对风险率 |
| --- | --- |
| 口服雌二醇 ≤ 1 mg/天 | 1.2 倍 |
| 口服雌二醇 > 1 mg/天 | 1.4 倍 |
| **口服雌二醇约 1 mg/天合并孕激素** | **1.4–1.8 倍** |
| 口服结合雌激素 ≤ 0.625 mg/天 | 1.4 倍 |
| **口服结合雌激素约 0.625 mg/天合并孕激素** | **1.5–2.4 倍** |
| 透皮雌二醇 ≤ 50 μg/天 | 0.9 倍 |
| 透皮雌二醇 > 50 μg/天 | 1.1 倍 |
| **单用高剂量醋酸环丙孕酮** | **3–5 倍** |

**读法：** 同样是口服雌二醇约 1 mg/天，**加上孕激素后风险率从 1.2 倍升到 1.4–1.8 倍。**

**⚠️ 注意这是「相对风险率」，不是「绝对风险」。** 完整读法见[血栓风险](/wiki/thrombosis-risk/)。

**另外，上游在[监测](https://mtf.wiki/zh-cn/docs/medicine/monitoring)页提到：雌激素、孕激素可增强凝血，增加静脉血栓风险；血栓是雌、孕激素的禁忌症之一。**

## 证据现状：为什么社群说法互相矛盾

**⚠️ 以下是本站对上游资料状态的整理，不是研究结论。**

| 常见说法 | 上游依据状态 |
| --- | --- |
| 「孕酮能让乳房发育得更好」 | **TFS 有专文讨论，结论是证据有限／未确立** |
| 「孕酮能提升性欲」 | **TFS 有专文讨论；上游另有「性欲减退」属雌激素效果的表述** |
| 「孕酮能改善睡眠和情绪」 | **本站未找到上游的明确支持** |
| 「孕酮能让人更女性化」 | **本站未找到上游的明确支持** |
| 「口服孕酮没用，必须直肠给药」 | **TFS 的讨论针对口服吸收率，非口服途径浓度更高** |
| 「孕酮会显著增加乳腺癌风险」 | **TFS 有专文讨论合成孕激素与乳腺癌风险** |

**⚠️ 上表只说明「上游有没有讨论这件事」，不构成对任何一种说法的支持或否定。**

**注意：MtF.wiki 的 HRT 效果表里并没有「孕酮」这一行。** 也就是说，**上游没有把孕酮列为产生某类效果的标准手段。**

## 常见问题

**「孕酮是必须吃的吗？」**
**上游的 HRT 方案里不是必需项。** 效果表里也没有孕酮这一行。

**「CPA 就是孕酮吗？」**
**CPA 是人工合成孕激素，但不是天然孕酮。** 社群说的「加孕酮」通常指天然孕酮。

**「芬吗通自带孕酮，是不是就不用单独加了？」**
**上游说地屈孕酮「无法确保能够提供完全孕激素效力」，且不具抗雄作用。**

**「口服孕酮没用吗？」**
**上游的表述是口服孕酮与类似酒精的神经甾体副作用有关；TFS 指出口服达到的浓度很低、效力弱。**

**「非口服就没有副作用吗？」**
**上游的表述是「非口服孕酮无任何已知副作用」。** 注意这是「无已知」，不是「已证明安全」。

**「加孕酮会让乳房变大吗？」**
**本站没有找到支持这一说法的上游依据。** TFS 有专文讨论，可作为进一步阅读。

**「日色能代替色普龙吗？」**
**不能。上游明确说「并非醋酸环丙孕酮，请不要误用」。**

**「MPA 能代替 CPA 吗？」**
**上游说「可作为替代品服用，但效果稍差」。** 具体由医生决定。

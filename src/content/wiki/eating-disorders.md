## 为什么这一页有必要

**跨性别群体的进食障碍发生率显著高于一般人群。** 这一点在 [WPATH SOC-8](https://www.wpath.org/publications/soc) 与相关临床资料中都有提及。

**原因不神秘：**

| 因素 | 说明 |
| --- | --- |
| **身体意象压力** | 对身体的强烈不满，可能转向控制进食 |
| **「先瘦下来再说」** | 把体重当成「能不能开始过渡」的前置条件 |
| **激素与体重变化** | HRT 会影响体脂分布与食欲 |
| **被误认的关联** | 有人以为「瘦一点就不那么显肩宽」 |
| **抑郁与焦虑共病** | 情绪问题与进食障碍经常同时出现 |
| **控制感** | 当很多事无法控制时，进食是看起来「可控」的那一件 |

**⚠️ 本站不把进食障碍写成「跨性别的结果」。** 它是一个**需要单独治疗**的健康问题，和性别认同是两条线。

## 常见类别

**以下是 NHS 列出的主要类别：**

| 类别 | 特征 |
| --- | --- |
| **神经性厌食（Anorexia nervosa）** | 限制进食、体重显著偏低、对增重的强烈恐惧 |
| **神经性贪食（Bulimia nervosa）** | 暴食后通过催吐、泻药、过度运动等方式补偿 |
| **暴食障碍（Binge eating disorder）** | 反复暴食，但没有规律的补偿行为 |
| **回避／限制性摄食障碍（ARFID）** | 因感官、恐惧等原因限制进食种类或总量 |
| **其他特定进食障碍（OSFED）** | 不符合上述全部标准但有临床意义的症状 |

**⚠️ 重要：进食障碍不以体重为判断标准。**

**「看起来正常」或「体重正常」的人同样可能有进食障碍。** 这是最常见的误解之一。

## 可能的信号

**⚠️ 以下为一般性提示，不是诊断标准。诊断必须由专业人员做出。**

| 类型 | 表现 |
| --- | --- |
| **行为** | 严格限制食物种类或总量；频繁称重；躲着吃；饭后立刻去厕所；过度运动 |
| **对食物的想法** | 持续占据注意力；对某些食物有强烈恐惧；「好食物／坏食物」的二分 |
| **身体** | 体重明显波动；怕冷；脱发；停经（如适用）；反复头晕；牙齿问题 |
| **情绪** | 与进食相关的强烈羞耻感；进食后极度自责；情绪低落 |
| **社交** | 回避一起吃饭；因进食安排而推掉活动 |

**⚠️ 出现这些信号不等于有进食障碍。但如果有几项长期存在，值得找专业人员评估。**

## 为什么需要专业治疗

| 原因 | 说明 |
| --- | --- |
| **不是意志力问题** | 进食障碍是健康问题，不是「管不住嘴」或「太在意」 |
| **有躯体风险** | 长期限制或催吐可导致电解质紊乱、心律失常等严重问题 |
| **共病常见** | 抑郁、焦虑、创伤经历经常同时出现 |
| **自我纠正的难度大** | 越晚干预，恢复过程通常越难 |
| **营养状况会影响 HRT 与手术** | 体重过低可能影响方案安排与手术条件 |

**⚠️ 如果出现严重体重下降、持续呕吐、晕厥、心悸，属于需要尽快就医的情况。**

## 求助路径

| 渠道 | 说明 |
| --- | --- |
| **综合医院精神科／心理科** | 多数三甲医院可评估与转诊 |
| **精神专科医院** | 部分设有进食障碍专病门诊 |
| **心理咨询** | 见[怎么找心理咨询](/wiki/finding-counselor/) |
| **学校心理中心** | 见[校园](/wiki/campus/) |
| **内分泌科** | 如果同时有 HRT 相关诉求 |
| **急诊** | **出现严重躯体症状时** |

**⚠️ 本站不复述具体医院名单、热线号码或费用。** 见[资源地图](/wiki/resource-map/)与[危机资源](/wiki/crisis-resources/)。

## 就诊时怎么说

**不需要一上来就讲全部背景。** 可以从具体的事说起：

- [ ] 「我最近吃饭这件事很困扰我。」
- [ ] 「我会因为吃了某样东西而非常自责。」
- [ ] 「我控制不住地吃，然后又想办法补回来。」
- [ ] 「我一直在称体重，不称会很难受。」

**如果担心性别话题影响就医体验：** 进食障碍本身的评估不依赖性别信息。**你可以先只谈进食问题。**

**如果同时需要谈 HRT 相关的事**，可以分开就诊，或明确告诉医生「这是两件事」。

## 和性别过渡的关系

**⚠️ 以下是本站对上游资料的整理，不是研究结论。**

| 情形 | 说明 |
| --- | --- |
| **把体重当成过渡的前置条件** | 「瘦下来再开始」是一个常见但危险的循环 |
| **用限制进食控制身体形态** | 长期看会损害健康，且不改变骨骼结构 |
| **HRT 后的体重变化** | 上游提到 MtF 群体普遍可见 GAHT 后体重体脂增加 |
| **术前体重要求** | 部分手术有 BMI 相关条件，**需要和医生讨论，而不是自行极端减重** |
| **进食障碍会影响手术资格** | 营养状况与术后恢复直接相关 |

**⚠️ 如果医生以体重为由推迟手术，正确做法是问清具体标准与转诊路径，而不是自行极端减重。**

## 可以立刻做的事

- [ ] **不要每天称体重**，或把秤收起来
- [ ] **规律吃饭**，哪怕量少
- [ ] **不要用「好／坏」给食物分类**
- [ ] **告诉一个可信任的人**你的困扰
- [ ] **停止催吐、泻药、过度运动等补偿行为**
- [ ] **预约一次专业评估**
- [ ] **不要因为「还没严重到需要看医生」而拖延**

**⚠️ 如果出现晕厥、心悸、持续呕吐、明显体重下降，尽快就医。**

## 常见问题

**「我体重正常，会有问题吗？」**
**会。进食障碍不以体重为判断标准。**

**「我只是想控制一下，不算病吧？」**
**如果它已经影响你的情绪、社交或身体健康，就值得找专业人员评估一次。** 评估不等于「确诊」。

**「看医生会不会被记录？」**
**会形成就诊记录。** 医疗记录受法律保护，见[个人信息与隐私保护](/wiki/privacy-law/)。

**「会不会因为进食障碍被拒绝开 HRT？」**
**本站没有找到关于这一问题的统一规定。** 各机构做法不同，**建议直接问医生。**

**「HRT 会让我更容易得进食障碍吗？」**
**本站没有找到支持这一因果关系的上游依据。** 可以确认的是：**这一群体的发生率高于一般人群，且共病常见。**

**「可以和性别的事一起谈吗？」**
**可以，也可以分开。** 由你决定。

## 恢复：通常不是直线

**⚠️ 以下是关于恢复过程的一般性说明，不是治疗方案。**

| 事实 | 说明 |
| --- | --- |
| **恢复通常不是线性的** | 有反复是常见现象，不是「失败」 |
| **需要时间** | 以月、年计 |
| **通常需要专业支持** | 单纯靠自我调整难度很大 |
| **共病要一起处理** | 抑郁、焦虑、创伤常同时存在 |
| **营养恢复是基础** | 躯体状况要先稳定 |
| **心理部分要单独做** | 只恢复体重不等于恢复 |

**⚠️ 出现反复不等于前功尽弃。** 也不代表「你做不到」。

## 营养与身体：几个常被忽略的点

**⚠️ 以下为一般性提示。具体的营养方案必须由医生或营养师给出。**

| 事项 | 说明 |
| --- | --- |
| **不要极端节食** | 会加重躯体风险 |
| **规律进食比「吃对」更重要** | 先建立节奏 |
| **不要用「好／坏」分类食物** | 这种二分本身会加重问题 |
| **避免自行使用泻药或减肥药** | 风险高 |
| **过度运动同样属于补偿行为** | 不只是「自律」 |
| **体重不是唯一指标** | 见上文「不以体重为判断标准」 |
| **电解质要关注** | 长期催吐或限制可能导致严重紊乱 |

**⚠️ HRT 会影响食欲与体脂分布**，所以营养状况和激素治疗是相互影响的。**两件事要一起和医生说。**

## 家人与朋友能做什么

**这一节是写给支持者的。** 见[给家人与朋友](/wiki/for-family-friends/)。

| 建议做 | 说明 |
| --- | --- |
| **不要评论体重和外观** | 即使出于关心 |
| **不要催着吃饭** | 压力会加重问题 |
| **不要当营养警察** | 监视进食通常适得其反 |
| **一起吃饭，正常地吃** | 提供榜样而非监督 |
| **听，不评判** | — |
| **鼓励专业求助** | 而不是自己当治疗者 |
| **照顾好自己的情绪** | 支持者也需要支持 |

| 不要做 | 原因 |
| --- | --- |
| **拿进食当话题反复讨论** | 强化关注 |
| **用「你看看别人」比较** | 无效且伤人 |
| **威胁或惩罚** | 会加重问题 |
| **把进食障碍和性别认同混为一谈** | 两件事要分开处理 |
| **忽视躯体症状** | 有紧急风险 |

## 几个常见误解

| 误解 | 实际情况 |
| --- | --- |
| 「只有瘦的人才有进食障碍」 | **不以体重为判断标准** |
| 「这是意志力问题」 | **是健康问题，不是自控力** |
| 「能正常吃饭就没问题」 | 行为可以隐藏，困扰仍在 |
| 「是跨性别导致的」 | **是独立需要治疗的健康问题** |
| 「瘦下来才能开始过渡」 | **这个前提本身会带来危险** |
| 「催吐没什么大不了」 | **有明确的躯体风险** |
| 「过一段时间就好了」 | **越早干预，恢复通常越容易** |

## 如果你正在犹豫要不要求助

**常见的犹豫：**

| 犹豫 | 回应 |
| --- | --- |
| **「还没严重到需要看医生」** | 评估不等于「确诊」，**早评估成本更低** |
| **「怕被记录」** | 医疗记录受法律保护，见[个人信息与隐私保护](/wiki/privacy-law/) |
| **「怕影响 HRT」** | **建议直接问医生**，本站没有统一结论 |
| **「不知道怎么开口」** | 见上文「就诊时怎么说」 |
| **「不想让家人知道」** | 未成年人的就诊通常涉及监护人，**这需要单独了解** |
| **「怕被当成在闹」** | 进食困扰是常见的就诊原因 |

**⚠️ 如果你出现晕厥、心悸、持续呕吐或明显体重下降，不要再等。**

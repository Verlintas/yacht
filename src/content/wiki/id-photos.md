## 为什么值得认真对待

**证件照会跟很多年。** 身份证通常有效期较长，学历证书上的照片则是永久的。

**而且证件照是别人核对身份时的第一参照**——照片与本人是否相符，直接影响办事时的顺畅程度。

## 什么时候需要重拍

| 场景 | 说明 |
| --- | --- |
| **身份证换领** | 必须重新采集 |
| **护照换发** | 必须重新采集 |
| 学历/学籍变更 | 视学校要求 |
| **外观变化较大** | 建议主动更新，减少核验摩擦 |
| 驾照换证 | 按当地要求 |

**如果你已经过渡一段时间、外观与旧照片差异较大，更新证件照会让日常办事顺很多。**

## 拍摄前的准备

### 着装

| 要点 | 说明 |
| --- | --- |
| **深色、有领的上衣** | 与背景形成对比 |
| 避免高领 | 会遮挡颈部线条 |
| 避免花哨图案 | — |
| 避免与背景同色 | 身份证照背景通常为白色 |

### 妆发

| 要点 | 说明 |
| --- | --- |
| **淡妆即可** | **不要改变面部特征的浓妆** |
| 头发 | **不要遮挡眉毛与耳朵**（多数证件照有此要求） |
| 刘海 | 可以留，但不能遮住眼睛 |
| 耳朵 | 部分规格要求露出 |

### 其他

- **前一晚保证睡眠**，减少浮肿
- 拍摄时保持自然表情，不要过度微笑
- 可以带梳子、吸油纸
- 穿浅色内搭避免透出

<div class="guide">
<strong>关于「会不会被要求证明身份」</strong>
<p>身份证照片采集通常由公安机关统一进行，按流程走即可，一般不会有额外问题。</p>
<p>社会照相馆拍证件照时，工作人员可能会多看两眼，但正常流程不会拒绝服务。</p>
</div>

## 去哪拍

| 类型 | 说明 | 适用 |
| --- | --- | --- |
| **公安机关采集点** | 办身份证时统一采集 | 身份证 |
| **社会照相馆** | 质量可控 | 学历、简历、签证 |
| **自助证件照机** | 便宜、快 | 应急 |

**用于学历或证书的照片，先问清学校或机构的具体要求**（尺寸、底色、是否要求回执）。

## 拍多张备用

**建议一次多要几份**（电子版 + 纸质版）：

- [ ] 不同尺寸的规格（一寸、二寸）
- [ ] **电子版原图**（以后可以自己裁切）
- [ ] 纸质版若干张

**证件照是消耗品。** 需要时才发现没有，就得重拍。

## 关于「照片与本人是否相符」

**这是实际办事中最容易遇到摩擦的点。**

| 建议 | 说明 |
| --- | --- |
| **外观变化较大时，尽早更新证件照** | 最有效的办法 |
| **办事时主动出示辅助证件**（如有） | 减少核验困难 |
| **如果被质疑** | 保持平静，配合核验。**你有权要求对方按流程办理** |
| **不要为了「符合照片」而刻意打扮成另一个样子** | 照片是用来核对你，不是让你去核对照片 |

## 关于「照片上的性别特征」

**证件照本身不标注性别，但照片会传达观感。**

**如果照片与证件上的性别信息不一致，可能引起额外询问。**

**处理方式：** 证件信息变更后尽快更新照片；变更前办事时保持平静配合。

## 关于电子版保存

**电子版原图比纸质版更有用**——可以自己裁切不同尺寸、随时打印。

| 保存要点 | 说明 |
| --- | --- |
| **保留原图** | 不要只存裁切后的版本 |
| **加密保存** | 证件照含生物特征信息，见[材料与档案管理](/wiki/records-management/) |
| 多处备份 | 本地 + 离线备份 |
| **不要放在公开云盘** | — |
| **不要发到社交平台** | 包括「帮我看看行不行」这类请求 |

**如果照相馆只给电子版，确认分辨率足够**（打印一寸照通常需要 300dpi 以上）。

## 社群能提供什么

- **信息**：哪家医院接诊、流程怎么走、材料怎么准备
- **经验**：别人踩过的坑，能省很多时间
- **情绪支持**：不用解释自己是谁的地方
- **现实帮助**：临时住宿、陪同就医、材料转介

**这些是纸面资料给不了的。** 上游整理了两份入口：[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)和[友情链接](https://mtf.wiki/zh-cn/docs/friendship)。

## 怎么判断一个空间是否安全

| 观察点 | 安全信号 | 危险信号 |
| --- | --- | --- |
| 隐私规则 | 明确说明什么内容不外传 | 鼓励发照片、证件、定位 |
| 准入方式 | 有基本管理，不要求提供敏感信息 | 要求提供证件、就诊记录才让进 |
| 讨论氛围 | 允许不同选择，不催人做决定 | 逼人「证明自己」，攻击未做医疗的人 |
| 商业行为 | 不推销 | 频繁推荐特定机构、药品渠道、付费「指导」 |
| 管理者 | 会处理骚扰 | 对骚扰视而不见，或本身就是骚扰者 |

**任何要求你提供证件、就诊记录、私密照片才能加入的「社群」，直接退出。**

## 线下见面的安全做法

- 第一次约在公共场所，白天
- 告诉一个信得过的人时间、地点、对方信息
- 手机保持有电，随时可以离开
- 不喝离开过视线的饮料
- 需要过夜时自己订住处
- 直觉不对就走，不用找理由

## 危机时

**如果出现伤害自己的想法或行为，这是紧急情况，需要立刻求助：**

- 当地急救电话与警方
- 就近医院急诊
- 心理危机干预机构，上游的[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)页面列有相关渠道

**本站不复述具体热线号码**，因为号码会变更或停用，直接看上游页面更可靠。

如果只是情绪低落、需要有人说话，可以先找社群里的朋友，或者联系咨询师，见[怎么找心理咨询](/wiki/finding-counselor/)。

## 关于「社群里也会受伤」

社群不是避风港，也会有冲突、排挤、小圈子、观点之争。这很常见，不代表你哪里不对。

- 不必参与所有讨论
- 不必认同所有人的观点
- 可以随时退出任何群组
- 找到两三个真正能说话的人，比待在十个大群里更有用

## 你能给别人的

等你走完某一段路，回头看会发现自己的经验对别人很有价值：

- 记录就诊流程与材料要求
- 补充上游资料里过时或缺失的部分
- 回答新人的问题
- 陪同需要就医的人

上游的[贡献者指南](https://mtf.wiki/zh-cn/docs/contributor-guide)说明了怎么参与资料维护。**这比单独建一个平行资料库更有价值。**

## 怎么参与社群

**参与方式有很多种，不必都做：**

| 方式 | 门槛 | 说明 |
| --- | --- | --- |
| **只看不说** | 最低 | 潜水也是参与，很多人长期这样 |
| 提问 | 低 | 注意先脱敏，见[线上社群安全](/wiki/online-community-safety/) |
| 回答别人的问题 | 中 | 你的经验对后来的人有用 |
| **线下活动** | 中 | 注意安全做法 |
| 陪同就医 | 中 | 见[就医陪同](/wiki/hospital-companion/) |
| **贡献资料** | 高 | 见[如何向上游贡献](/wiki/contribute-upstream/) |

**从最低门槛开始就好。** 不需要「准备好」才能参与。

## 常见问题

**「一定要加入社群吗？」**
**不必。** 有人靠朋友和家人就够了，有人完全不需要。

**「社群里的人都很懂吗？」**
**不一定。** 社群里的信息质量参差，**上游资料比社群发言更可靠**。社群的价值在于经验和陪伴，不在于权威性。

**「群里有人逼我证明身份怎么办？」**
**你没有义务证明。** 可以简单说明、无视、或退出该群。见[线上社群安全](/wiki/online-community-safety/)。

**「社群里也会受伤怎么办？」**
**这很常见。** 社群不是避风港，也会有冲突、排挤、小圈子。不必参与所有讨论，可以随时退出。

**「找不到同城的人怎么办？」**
线上社群也有价值。见[线上社群安全](/wiki/online-community-safety/)。

**「怎么判断一个空间是否安全？」**
见[线上社群安全](/wiki/online-community-safety/)里的对照表。

**「可以只潜水不说话吗？」**
**可以。** 潜水也是参与，很多人长期这样。

## 社群能提供的四类支持

| 类型 | 具体 |
| --- | --- |
| **信息** | 哪家医院接诊、流程怎么走、材料怎么准备 |
| **经验** | 别人踩过的坑，能省很多时间 |
| **情绪支持** | 不用解释自己是谁的地方 |
| **现实帮助** | 临时住宿、陪同就医、材料转介 |

**这四类里，前两类上游资料也能提供，后两类是社群独有的。**

## 关于「社群内部的摩擦」

**⚠️ 以下为本站观察，不是上游原文。**

| 摩擦类型 | 说明 | 应对 |
| --- | --- | --- |
| **观点之争** | 关于医疗方案、身份定义的争论 | 不必参与，也不必认同所有人 |
| **小圈子** | 有些群有固定圈子，新人难融入 | 换一个群 |
| **催人做决定** | 「你怎么还不去做手术」 | **明确拒绝。** 时间表由你定 |
| **比较** | 「我三个月就……」 | 起点不同，不要比较 |
| **信息误导** | 未经验证的「经验」传播 | 回上游核对 |
| **商业化** | 有人推销机构、渠道 | 见[中介与骗局识别](/wiki/scam-awareness/) |

**一条实用原则：找到两三个真正能说话的人，比待在十个大群里更有用。**

## 先说原则

1. **先做安全评估**，见[出柜策略与安全评估](/wiki/coming-out/)。
2. **说自己的感受，不用术语。** 家人朋友不需要理解分类学。
3. **不需要一次说完。** 第一次的目标可以只是「让对方知道」，不是「让对方接受」。
4. **不需要辩论。** 对方有情绪时，讲道理没有用。
5. **允许自己说不下去。** 中途停下完全可以。

## 对朋友

**最轻松的场景，可以用来练习。**

> 有件事想跟你说一下。我一直觉得自己应该是女生，这件事我想了挺久了。告诉你是因为我信任你，也因为我希望在你面前能做自己。你不用马上说什么，我就是想让你知道。

**为什么这样写：** 说明事实、说明为什么告诉你、给对方留出空间。

## 对家人

**最难也最重要的场景。建议先选家里最可能支持的那一位。**

> 我想跟你们说一件事，这件事我想了很久，也花了很久才敢说。
> 我从小就觉得……（说具体感受，例如：照镜子的时候会难受 / 一直被当成另一个性别让我很累）。
> 这不是一时冲动，也不是学坏了。我查了很多资料，也（打算）去看医生。
> 我知道你们需要时间，我不要求你们马上理解。我只是不想再瞒着你们。

**关键点：**

- 用**具体感受**开场，不用抽象概念
- 明确说「不是冲动」「不是学坏」，这是家人最常见的担心
- **不要求立刻接受**，给时间
- 说明你有在认真对待（查资料、看医生）

## 对同事 / 同学

**信息最小化。多数人只需要知道怎么称呼你。**

> 之后请叫我（名字），用「她」。其他的不用特别在意，也不用帮我跟别人解释。

**如果有人追问私人问题：**

> 这个我不太想聊。

**这是一句完整的回答，不需要补充理由。**

## 最常见的追问与回应

| 追问 | 可以怎么回应 |
| --- | --- |
| 「你是不是想变成另一个人？」 | 「不是，是想成为我自己。」 |
| 「是不是受了什么影响？」 | 「不是。我很久以前就有这种感觉了。」 |
| 「那你要做手术吗？」 | 「这是我的私人医疗事务，我不太想讨论。」 |
| 「你考虑过我们的感受吗？」 | 「考虑过，所以我想了很久才说。我也希望你们考虑我的感受。」 |
| 「能不能先别告诉别人？」 | 「可以，但我需要能按自己的方式生活。」 |
| 「去看医生能不能治好？」 | 「这不是需要治的问题。看医生是为了获得需要的医疗服务。」 |
| 「你以后怎么办？」 | 「一步一步来。现在我需要的是时间。」 |

## 如果对话变糟

- **停止对话。** 「我们今天先到这里，等大家都冷静一点再说。」
- **离开现场。** 如果涉及安全风险，见[家庭沟通](/wiki/family/)里的「需要警惕的情况」。
- **找支持。** 提前告诉一个信得过的人你在做这件事，事后有人可以说。
- **不要求自己当场解决问题。** 第一次谈话通常不是结论。

## 宿舍

**这是校园里最需要提前处理的事。**

| 情况 | 可以怎么做 |
| --- | --- |
| **想换宿舍** | 向学工部门或宿管中心申请调整，**理由不必细说** |
| **想单独住** | 部分学校有单人间或可申请校外住宿 |
| **担心安全** | **优先处理安全**，再考虑公开程度 |
| **室友已知道且支持** | 可以维持现状，不必强求调整 |
| **不想让室友知道** | 申请独立卫浴的房间，或错峰使用公共设施 |

**申请理由可以用「个人原因」「作息不合」「身体原因」等中性表述。**

**学校通常没有权力要求你说明具体医疗情况。**

## 体育课与体测

**各校处理方式不同，常见路径：**

| 路径 | 做法 |
| --- | --- |
| 1 | 跟体育部或教务处沟通，说明情况，询问是否有调整方案 |
| 2 | 申请免修或替代项目（部分学校有保健课、体育理论课等替代形式） |
| 3 | 如果涉及体测，问清是否有免测或延期政策 |
| 4 | 涉及集体项目的，问是否可以调整分组方式 |

**沟通时说明「身体情况需要调整」即可。详细医疗信息属于隐私。**

## 公共浴室与更衣室

**这是很多人最紧张的场景。** 现实中的做法：

| 做法 | 说明 |
| --- | --- |
| **错峰使用** | 人少的时间段 |
| **询问是否有单间或无障碍浴室** | 部分学校有 |
| **和宿管沟通** | 看是否有其他安排 |
| **申请使用单独设施** | 如果学校有条件 |

**这不是「麻烦别人」，是合理的需求。**

**如果学校无法提供替代方案**，错峰使用通常是最实际的解决办法。

## 校园系统里的姓名与性别

**教务、图书馆、门禁、宿舍系统可能各自独立。** 改完学籍信息后要逐个确认：

- [ ] 教务系统
- [ ] 图书馆借阅系统
- [ ] 门禁与考勤
- [ ] 宿舍管理系统
- [ ] 校园卡
- [ ] 邮箱与账号
- [ ] 各类在线教学平台
- [ ] 社团与活动报名系统

**一个没改，就可能在某个环节被叫到旧名字。**

**建议更新完两周后自查一遍。**

## 与老师、辅导员沟通

| 事项 | 找谁 |
| --- | --- |
| 学籍信息 | 学籍管理部门 / 教务处 |
| 宿舍 | 学工部门 / 宿管中心 |
| 体育课 | 体育部 / 教务处 |
| 请假就医 | 辅导员 / 教务 |
| 心理支持 | 校心理咨询中心（**注意保密范围**） |
| 档案 | 学生档案管理部门 |

**辅导员不是万能的。** 涉及学籍、宿舍的正式变更，要找对应的职能部门。

## 同学关系

| 情况 | 建议 |
| --- | --- |
| **没有义务对全班公开** | 是否公开由你决定 |
| **被问到私人问题** | 「这个我不太想聊」是完整的回答 |
| **遇到骚扰或歧视** | 记录时间、地点、在场人，逐级反映 |
| **想找支持** | 找到一两个支持你的人，校园生活会轻松很多 |
| **社团活动** | 可以选择不参加需要集体住宿或更衣的活动 |

## 一个现实提醒

**校园里的信息传播速度快，而且难以收回。**

**在确认安全之前，控制知情范围是更稳的策略。**

**这不等于永远隐瞒。** 只是不需要在还没准备好的时候，被环境推着走。

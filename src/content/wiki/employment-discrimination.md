## 三个阶段

### 招聘阶段

| 问题 | 说明 |
| --- | --- |
| 因性别认同被拒 | 招聘中的歧视较难举证，但聊天记录、邮件可以留 |
| 面试被问私人问题 | 你有权不回答与岗位无关的问题 |
| 要求提供医疗信息 | 入职体检通常不涉及相关项目；额外要求可以问用途 |
| 背调透露信息 | 前雇主的评价如果涉及身份信息，可能构成侵权 |

### 在职阶段

| 问题 | 说明 |
| --- | --- |
| 同事骚扰、议论 | 记录时间、地点、在场人、具体言论 |
| 被调岗、降薪 | **要求书面说明理由** |
| 绩效突然变差 | 注意时间点是否与出柜重合，这本身是线索 |
| 人事信息被扩散 | 用人单位对个人医疗信息有保密义务 |

### 离职阶段

| 问题 | 说明 |
| --- | --- |
| 被辞退 | 辞退需要合法理由和书面文件 |
| 离职证明被写不利内容 | 可以要求更正 |
| 社保、档案处理 | 跟进转移手续 |

## 关键动作：固定证据

**这是所有后续动作的基础，必须在事情发生时就开始做。**

- [ ] **书面通知**（邮件、纸质文件、系统截图）
- [ ] **聊天记录**（导出备份，不要只留在 App 里）
- [ ] **绩效记录**（各期考核结果，用于对比）
- [ ] **录音**（在合法范围内作为个人记录）
- [ ] **时间线**（什么时候、谁、说了什么、有谁在场）
- [ ] **工资与社保记录**

<div class="guide">
<strong>「绩效突然变差」为什么重要</strong>
<p>如果出柜前后绩效考核出现明显变化，这个<b>时间上的重合</b>本身就是一种线索。</p>
<p>所以：把出柜的时间点、以及此前此后的绩效记录都整理出来。</p>
</div>

## 渠道

1. **单位内部**：HR 上级、工会、纪检监察
2. **劳动监察**：向当地人社部门反映
3. **劳动仲裁**：涉及劳动争议（**注意时效，通常较短，尽早咨询**）
4. **法院诉讼**：一般平等就业权、人格权纠纷
5. **律师与公益组织**：见[常见法律问题索引](/wiki/legal-faq-index/)

**劳动仲裁有申请时效限制。** 决定维权就要尽早，不要等到想清楚了才动手。

## 现实考量

**维权需要时间、精力和情绪成本，还可能影响背调。** 所以：

- 先评估「最坏情况我能承受多久」
- 优先保住收入和退路
- 决定推进时，从成本最低的渠道开始
- **不要独自扛**，找人商量，见[社群与互助](/wiki/community/)

## 找工作时

- **不必在面试时主动公开。** 没有义务在录用前说明。
- **入职需要身份证时**，可以和 HR 单独沟通，请对方注意保密。
- **背调**：提前想好说法；如果前一段经历不愉快，可以准备简短中性的解释。
- **体检**：常规入职体检通常不涉及相关项目。遇到额外要求，可以问清用途与保密范围。

## 通用原则

**以你手上药品的说明书为准。** 下面只是常见规律的概括，来源为上游各剂型条目。

| 项 | 常见要求 |
| --- | --- |
| **温度** | 多数片剂室温即可；部分针剂需要冷藏 |
| **避光** | 多数药物需要避光保存 |
| **干燥** | 浴室、厨房不适合放药 |
| **原包装** | 保留铝箔/瓶身，便于确认批号与有效期 |
| **儿童与宠物** | 放在拿不到的地方 |

## 各类剂型的注意点

### 片剂（口服/含服）

- 铝箔包装未拆时通常到标注有效期
- **拆开后按说明书要求使用**，受潮可能影响质量
- 不要分装到没有标识的容器里长期存放

**上游说明：口服剂基本上均允许舌下或面颊含服**（见[戊酸雌二醇片](https://mtf.wiki/zh-cn/docs/medicine/estrogen/estradiol-valerate)）。

### 贴片

- 注意有效期与储存温度
- **上游说明：如果贴附紧密，洗澡和游泳不会影响贴片；不慎掉落可立即贴回原位**
- 更换周期按产品说明（不同品牌不同，见[雌激素类药物对照](/wiki/estrogen-compare/)）

来源：[外用雌二醇贴片](https://mtf.wiki/zh-cn/docs/medicine/estrogen/estradiol-patch)

### 凝胶

**上游的注意事项：**

- **涂抹处 2 小时内不得碰水**
- 衣物剐蹭、洗澡和游泳可能影响吸收
- **不得涂抹于乳房处**
- 各部位吸收率不同，按说明使用
- 注意管口清洁，用后拧紧

来源：[雌二醇凝胶](https://mtf.wiki/zh-cn/docs/medicine/estrogen/gel)

### 针剂

- 储存条件看具体产品说明书（**上游说明了不同产品的包装与用法差异**）
- 不要冷冻
- 注意避光
- 开封后按说明期限使用
- **针具单独存放，避免扎伤**

来源：[雌激素针剂](https://mtf.wiki/zh-cn/docs/medicine/estrogen/injection) · [自我注射](https://mtf.wiki/zh-cn/docs/medicine/estrogen/injection/at-home-injection/at-home-injection)

## 出门带药

### 短途（当天往返）

- 带够当天的量
- 用原包装或带标识的小盒
- 贴片/凝胶按更换日携带

### 长途（几天到几周）

- **带足量并多带几天备用**
- **分开存放**（随身 + 行李各一份），避免全部丢失
- 保留原包装与说明书
- **处方或就诊记录复印件**（过安检或海关时可能用得上）

### 坐飞机

| 事项 | 说明 |
| --- | --- |
| **液体、凝胶类** | 有容量限制，按民航规定 |
| **需要冷藏的针剂** | 提前联系航空公司确认是否可以携带及保存方式 |
| **医疗用品** | 通常有豁免，但需要证明 |
| **随身 vs 托运** | **药物建议随身**，托运行李可能丢失或受温度影响 |

<div class="guide">
<strong>过安检时</strong>
<p>不必主动解释用途。如果被问，说「个人处方药」即可。</p>
<p>被要求出示证明时，提供处方或就诊记录。这也是为什么要带复印件。</p>
</div>

## 过期了怎么办

| 做法 | 说明 |
| --- | --- |
| **不要用过期药** | 效力下降，且部分药物降解产物可能有害 |
| **不要自行加量来「补偿」** | — |
| **按当地规定处理废弃药品** | 不要随手扔进下水道 |
| **定期检查库存** | 避免临时发现不够用 |

## 一个实用做法

**建一个小库存表：**

| 字段 | 说明 |
| --- | --- |
| 药名 | — |
| 规格 | 每片/每支的剂量 |
| 开封日期 | — |
| 有效期 | — |
| 剩余量 | — |
| 下次开药时间 | — |

**在剩余量够用两周时就去开药**，避免因为挂号排期而断药。

**这一条对需要定期复诊开药的方案尤其重要**——号源紧张时，两周可能不够。

## 常见问题

**「需要冷藏吗？」**
**看具体产品。** 多数片剂室温即可；部分针剂需要冷藏。**以说明书为准。**

**「开封后能放多久？」**
**按说明书要求。** 受潮可能影响质量。

**「出门几天怎么带？」**
带足量并**多带几天备用**，分开存放（随身 + 行李各一份）。

**「坐飞机能带针剂吗？」**
**可以，但要注意储存条件与运输规定。** 需要冷藏的针剂要提前联系航空公司。

**「过期了还能吃吗？」**
**不要。** 效力下降，且部分药物降解产物可能有害。

**「可以分装到小盒里吗？」**
**短期可以，但不要长期。** 受潮和混淆是风险。

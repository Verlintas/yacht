## 三个不同的东西

| 概念 | 指什么 | 例子 |
| --- | --- | --- |
| **指派性别** | 出生时根据身体特征被登记或判定的性别 | 出生证明、户口本上的性别 |
| **性别认同** | 你内心认为自己是什么性别 | **这是唯一能定义「你是谁」的一项** |
| **性别表达** | 你通过穿着、行为、声音等向外呈现的样子 | 着装、发型、说话方式 |

**这三者互不决定。** 这是 [WPATH SOC-8](https://project-trans.org/SOC-8/) 与 [美国心理学会](https://www.apa.org/topics/lgbtq/transgender)在相关议题上采用的区分方式。

一个性别表达偏中性的人，认同可能很明确；一个表达很符合刻板印象的人，认同也可能和指派性别不一致。

## 常见的混淆

### 「你打扮成这样，还说自己是跨性别？」

**表达不等于认同。**

有人喜欢中性打扮，有人喜欢很女性化的打扮，这跟认同是两件事。**同样地，表达方式也不构成任何证明。**

### 「你以前不也穿裙子/打球吗？」

**表达会变，认同不一定变。**

而且童年行为从来不是判据——按这个逻辑，所有男孩都必须只玩卡车。

**这也是为什么评估不依赖童年行为。** 见[诊断标准是什么](/wiki/diagnosis-criteria/)。

### 「那你喜欢男生还是女生？」

**这是性取向，和性别认同是两条独立的轴。**

跨性别者的性取向分布和顺性别群体一样多样。

| 轴 | 说的是什么 |
| --- | --- |
| 性别认同 | 我是谁 |
| 性取向 | 我喜欢谁 |

**两者互不决定。**

### 「生理性别是客观事实吧？」

**「生理性别」包含染色体、性腺、激素水平、内外生殖器等多个维度，这些维度并不总是一致。**

把它当成单一、非此即彼的事实是简化过的说法。这一区分同样见于 [WPATH SOC-8](https://project-trans.org/SOC-8/)。

**具体的生物学细节本站不复述**，需要时看医学与生物学资料。

## 为什么分清这些有用

| 用处 | 说明 |
| --- | --- |
| **减少自我怀疑** | 如果你表达方式不符合某种期待，不代表你的认同不成立 |
| **减少无谓争论** | 很多争论其实是双方在用不同的定义说话 |
| **帮助沟通** | 跟医生、家人解释时，说清楚你在讲哪一层，比笼统地说「性别」有效 |
| **理解他人的差异** | 非二元、性别流动等概念都建立在这些区分之上 |

## 一个实用提醒

**没有「够不够跨性别」这回事。**

不需要满足任何清单——不需要从小就如何、不需要讨厌某些衣服、不需要做任何医疗步骤、不需要符合任何刻板印象。

**认同是你自己的陈述，不是一场考试。**

## 怎么跟别人解释

**不必讲理论，用一个具体的例子通常更有效：**

| 对方的问题 | 可以怎么回应 |
| --- | --- |
| 「这三个有什么区别？」 | 「就像一个人穿什么、别人怎么登记、自己心里怎么认，是三件不同的事。」 |
| 「那你到底是哪一种？」 | 「我自己怎么认，这个只有我能说。」 |
| 「为什么要在意称呼？」 | 「因为被叫错的时候会不舒服，这很直接。」 |

**不需要说服对方。** 解释一次就够，反复争论通常没有收益。

**如果对方持续追问或质疑**，「这个我不太想聊」是完整的回答。

**如果对方是你需要长期相处的人**（家人、同事、伴侣），可以先说明「我不需要你完全理解，只需要你尊重我的称呼」。这比追求「完全理解」更现实，也更容易达成。

## 常见问题

**「这三个哪个最重要？」**
**性别认同。** 它是唯一能定义「你是谁」的一项。指派性别是别人登记的，性别表达是向外呈现的。

**「我的表达和认同不一致，正常吗？」**
**正常。** 表达方式不构成任何证明，也不影响你的认同是否成立。

**「如果我不符合任何刻板印象，还算跨性别吗？」**
**算。** 没有清单，没有考试。见[常见误区与谣言](/wiki/myths/)。

**「性别表达会变吗？」**
会。表达可以随心情、场合、年龄变化。**认同不一定跟着变。**

**「非二元算哪一种？」**
见[非二元是什么](/wiki/nonbinary/)。

**「别人用错代词我该纠正吗？」**
**由你决定。** 可以纠正，也可以不纠正。**没有义务教别人怎么做。**

**「怎么跟不理解的人解释？」**
不必讲理论，用一个具体例子通常更有效，见下。

## 关于「生理性别」这个说法

**这个词本身包含多个维度：**

| 维度 | 说明 |
| --- | --- |
| 染色体 | 不只有 XX/XY 两种组合 |
| 性腺 | 睾丸、卵巢、或两者混合 |
| 激素水平 | 随年龄、用药、疾病变化 |
| 内生殖器 | 子宫、输卵管等 |
| 外生殖器 | — |

**这些维度并不总是一致。** 把它们当成单一、非此即彼的事实，是简化过的说法。

**这一区分同样见于 [WPATH SOC-8](https://project-trans.org/SOC-8/)。**

## 一、HRT 会带来什么（有上游依据）

**上游的明确表述 [1]：**

> 睾酮水平降低将使得脂肪组织（尤其是皮下脂肪）增加，而雌激素可促进前体脂肪细胞成熟和分化，并减少皮下脂肪的分解；因此，**MtF 群体中普遍可见接受 GAHT 以后体重和体脂增加的现象**。应定期测量体重，适当运动，控制饮食，避免超重。

**效果表里的相关条目 [2]：**

| 作用效果 | 出现时间 | 稳定时间 |
| --- | --- | --- |
| **体脂重新分布** | 3–6 月 | 2–5 年 |
| **肌肉质量、力量降低** | 3–6 月 | 1–2 年 |

**这两条合起来意味着：**

| 变化 | 结果 |
| --- | --- |
| 皮下脂肪增加 | 体重可能上升 |
| 肌肉量降低 | **基础代谢率下降** → 同样食量更容易长胖 |
| 体脂分布改变 | 脂肪从腹部转向臀部、大腿（这是期待的变化） |

**所以「体重上升」和「体脂分布女性化」是同一件事的两面。** 不是所有体重变化都是坏事。

**上游把「体重和体脂」列为可酌情监测项目，并要求「定期测量体重」[1]。**

## 二、需要区分三件事

**很多人把这三件事混在一起焦虑：**

| 事项 | 说明 | 是不是问题 |
| --- | --- | --- |
| **体脂分布改变** | 脂肪从腹部转向臀腿 | **这是 HRT 的预期效果**，不是问题 |
| **肌肉量减少** | 力量下降，基础代谢降低 | 预期效果，但需要主动应对 |
| **体重绝对值上升** | 秤上的数字变大 | **看情况**——可能来自脂肪增加，也可能来自肌肉流失 |

**所以「体重涨了」不等于「变胖了」。** 更有意义的指标是腰围和体脂分布的变化。

**⚠️ 本站没有找到针对跨性别者的体重管理专属指南。** 下面的内容是**一般人群指南**，不是跨性别专属建议。

## 三、一般人群的运动建议（WHO）

**世界卫生组织的建议 [3]：**

| 人群 | 建议 |
| --- | --- |
| 成年人（18–64 岁） | 每周 150–300 分钟中等强度有氧活动，**或** 75–150 分钟高强度有氧活动；**加上每周 2 天以上的肌肉强化活动** |
| 减少久坐 | 用任何强度的活动替代久坐时间 |

**具体数值与适用条件见 [WHO 身体活动页面](https://www.who.int/news-room/fact-sheets/detail/physical-activity) [3]。**

**为什么「肌肉强化活动」对你特别重要：**

**HRT 会降低肌肉量，而肌肉量决定基础代谢。** 不主动维持肌肉，同样的饮食就会导致体重上升。

| 类型 | 例子 | 作用 |
| --- | --- | --- |
| **抗阻训练** | 自重训练、弹力带、哑铃、器械 | **维持肌肉量**，抵消 HRT 带来的流失 |
| 有氧 | 快走、慢跑、游泳、骑车 | 心肺与能量消耗 |
| 柔韧与平衡 | 拉伸、瑜伽 | 辅助 |

**注意：** 抗阻训练**不会让你变得「壮」**——HRT 后的激素环境不支持明显的肌肉增长，训练主要作用是维持而非增长。

## 四、一般人群的饮食建议（WHO）

**世界卫生组织关于健康饮食的要点 [4]：**

| 方向 | 说明 |
| --- | --- |
| **蔬菜水果** | 足量摄入 |
| **膳食纤维** | 全谷物、豆类 |
| **脂肪** | 减少饱和脂肪与反式脂肪，用不饱和脂肪替代 |
| **游离糖** | 减少摄入 |
| **盐** | 减少摄入（具体上限见 WHO 页面） |
| **能量平衡** | 摄入与消耗平衡，维持健康体重 |

**具体数值与适用条件见 [WHO 健康饮食页面](https://www.who.int/news-room/fact-sheets/detail/healthy-diet) [4]。**

**针对 HRT 期间的三条实用提示（本站整理，非上游原文）：**

| 提示 | 为什么 |
| --- | --- |
| **保证蛋白质摄入** | 肌肉量在下降，需要原料维持 |
| **注意钙与维生素 D** | 上游提到骨密度问题，见[骨密度与骨骼健康](/wiki/bone-density/) |
| **少饮酒** | 上游建议激素治疗期间「酌情饮酒」；酒精也影响肝脏代谢（见[肝功能指标怎么看](/wiki/liver-function/)） |

**上游在骨密度部分明确提到：青春期阻断期间「应适当补钙、补充维生素 D」[见 [GnRH 类似物](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/gnrha)]。**

## 五、体重与腰围怎么量

**一般人群的测量方式（NHS）[6]：**

| 指标 | 怎么量 |
| --- | --- |
| **体重** | 固定时间（如晨起空腹、排便后）、固定衣着，减少波动干扰 |
| **腰围** | 在肋骨下缘与髂骨上缘的中点水平绕一圈，正常呼气末测量，不要收腹 |
| **BMI** | 体重（kg）÷ 身高（m）² |

**⚠️ BMI 的局限：** 它不区分肌肉和脂肪，也不反映脂肪分布。**对 HRT 期间的人来说，腰围和体脂分布的变化比 BMI 更有信息量。**

**一般人群的肥胖判定标准与健康风险见 [NHS 肥胖页面](https://www.nhs.uk/conditions/obesity/) [7] 与 [WHO 肥胖与超重页面](https://www.who.int/news-room/fact-sheets/detail/obesity-and-overweight) [5]。**

## 六、记录建议

**如果你在管理体重，建议记录：**

| 字段 | 频率 |
| --- | --- |
| 体重 | 每周 1–2 次（不必每天） |
| 腰围 | 每 2–4 周 |
| 运动情况 | 每周（做了什么、多久） |
| 饮食变化 | 只在有明显调整时记 |
| **用药方案变化** | 每次调整时记（**因为 HRT 变化会影响体重**） |

**和激素记录放在一起，能看到更完整的趋势。** 见[用药记录怎么做](/wiki/hrt-log/)。

## 七、什么时候该找专业帮助

**⚠️ 本站没有找到针对跨性别者的体重管理医疗建议。** 以下是一般人群的常见判断：

| 情况 | 建议 |
| --- | --- |
| 体重在短期内明显变化（增加或减少） | 就诊，排查原因 |
| 无论怎么调整都不变化 | 就诊，排查甲状腺、血糖等问题 |
| 出现进食行为的明显改变（暴食、催吐、极端节食） | **尽快找专业帮助**，见[怎么找心理咨询](/wiki/finding-counselor/) |
| 因为体重产生持续的焦虑或低落 | 见[情绪管理](/wiki/emotion-management/) |

**关于进食障碍：** 跨性别群体中进食障碍的发生率高于一般人群，这与身体形象压力有关。**如果你在这方面有困扰，这不是「不够自律」，是需要专业支持的问题。**

## 八、一个提醒

**体重和体型的变化是 HRT 的一部分，不是失败。**

**同时，「控制体重」也不该变成新的焦虑来源。** 目标应该是**健康**，而不是某个具体的数字或外观标准。

**如果你发现自己每天多次称重、因为一顿饭而自责、或者回避社交场合**，那可能已经超出了「健康管理」的范围。**这时候需要的是支持，不是更强的意志力。**

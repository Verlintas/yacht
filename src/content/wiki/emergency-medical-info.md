<div class="notice">
<strong>这一页解决的问题</strong>
<p>
如果你因为事故、昏迷或急病被送到急诊，医生需要知道<b>你正在用什么药</b>——这会影响判断（例如血栓风险、电解质、药物相互作用）。
</p>
<p>
但那时你可能说不出话。<b>所以这件事需要提前准备。</b>
</p>
</div>

## 一、为什么这件事重要

**上游明确指出的几个关键点：**

| 用药 | 急诊时需要知道的原因 |
| --- | --- |
| **雌激素** | 增加静脉血栓风险；影响凝血相关指标 [2] |
| **醋酸环丙孕酮** | 肝毒性风险；可能诱发维生素 B12 缺乏；影响血糖 [2] |
| **螺内酯** | **可能影响血钾、钠、钙、镁等离子水平**；与利钾药物并用风险增大 [1] |
| **比卡鲁胺** | 肝毒性；**可能影响抗凝剂的疗效** [2] |

**还有一条特别重要的 [1]：**

> **建议术前一个月内停用雌、孕激素，术后卧床期间也应停用。**

**这意味着：如果你因为意外需要紧急手术，医生必须知道你在用激素。** 否则可能影响手术与术后管理的判断。

**另一条与急救直接相关 [2]：**

> **血栓是雌、孕激素的禁忌症之一。**

**如果你因疑似血栓症状就诊，医生必须知道你正在用激素。**

## 二、要准备的信息卡

**做一张卡片，放在钱包或手机锁屏可见的地方。**

**建议包含：**

| 字段 | 示例 |
| --- | --- |
| **我正在使用的药物** | 戊酸雌二醇（口服）、醋酸环丙孕酮 |
| **用药方式** | 口服，每日 |
| **是否有药物过敏** | — |
| **慢性病** | — |
| **紧急联系人** | 姓名 + 电话 |
| **备注** | 「跨性别者，正在接受激素治疗；如涉及手术或血栓评估请考虑用药影响」 |

**⚠️ 不需要写剂量。** 药名和方式就够医生判断。

**⚠️ 也不需要写诊断或就诊医院。** 那些属于隐私，且急救时用不上。

## 三、放在哪里

| 位置 | 优点 | 缺点 |
| --- | --- | --- |
| **钱包里的实体卡片** | 不依赖电量和网络 | 可能没带钱包 |
| **手机锁屏紧急信息** | 多数手机支持，急救人员可查看 | 需要提前设置 |
| **手机的「医疗急救卡」** | iPhone / Android 都有此功能 | 需要设置且对方知道去哪看 |
| **紧急联系人** | 有人能替你说 | 对方可能不知道你的用药 |
| **随身药物清单（纸质）** | 详细 | 需要更新 |

**建议至少做两个：实体卡片 + 手机锁屏。**

**iPhone：** 「健康」App → 「医疗急救卡」→ 开启「锁定时显示」
**Android：** 「设置」→ 「安全与紧急情况」→ 「医疗信息」

## 四、要不要告诉紧急联系人

**看情况。**

| 情况 | 建议 |
| --- | --- |
| **对方知道且支持** | 告诉对方你的用药情况，请对方在紧急时提供给医生 |
| **对方不知道** | **不必因此出柜。** 可以用「我在长期服用处方药，具体在卡片上」这样的说法 |
| **没有可信任的人** | 就依赖卡片和手机 |

**⚠️ 不要为了「万一」而向不安全的人出柜。** 日常的安全风险大于急救的准备价值。

**替代方案：** 把用药信息写在卡片上，并让一个信任的朋友知道「我的钱包里有一张医疗信息卡」。

## 五、如果你被送急诊而医生不知道

**可以做的事：**

| 情况 | 做法 |
| --- | --- |
| **你还能说话** | 直接说：「我在用雌激素和抗雄药物」——**不需要解释身份** |
| **你意识清醒但不想说身份** | 可以说「我在用处方药，卡片在钱包里」 |
| **你无法说话** | 依赖卡片、手机、或紧急联系人 |

**关键一句：「我在用雌激素和抗雄激素药物。」** 这句话是医疗信息，不是身份声明。**医生需要知道的是药物，不是你的身份。**

## 六、关于「要不要隐瞒」

**⚠️ 强烈不建议隐瞒。**

| 隐瞒的风险 | 说明 |
| --- | --- |
| **血栓判断错误** | 医生不会把血栓纳入考虑 |
| **电解质判断错误** | 螺内酯的影响可能被忽略 |
| **药物相互作用** | 急诊用药可能与 HRT 相互作用 |
| **手术管理错误** | 不知道你在用激素，可能影响围手术期安排 |

**上游的原话 [2]：**

> 如必须并用，请注意进行密切监测；并用期间出现任何不适或异常应随诊——**让医生知悉一切并对症下药，千万别瞒着！**

**这句话是针对药物相互作用的，但同样适用于急诊场景。**

**注意：** 上游的自我注射页面里有一些「怎么向医生隐瞒用药」的内容，**本站刻意不转录**——它会直接损害你的医疗安全。

## 七、关于「医疗信息卡会不会暴露身份」

**这是一个真实的顾虑。**

**可以这样降低暴露：**

| 做法 | 说明 |
| --- | --- |
| **只写药名，不写诊断** | 医生需要的是药物信息 |
| **不写「跨性别」这个词** | 写「长期使用以下处方药」即可 |
| **不写就诊医院** | 急救时用不上 |
| **卡片放在不显眼处** | 钱包内层，而不是透明卡位 |

**但要注意权衡：** 如果卡片完全不提激素治疗，医生可能不会立刻意识到需要评估血栓风险。**一个折中写法：**

> 长期使用处方药：戊酸雌二醇、醋酸环丙孕酮。
> 如有手术、血栓或电解质相关问题，请考虑上述用药。

**这样既提供了必要的医疗信息，又不需要写明身份。**

## 八、出差与旅行时

**如果在外地或国外：**

| 事项 | 说明 |
| --- | --- |
| **带药时保留原包装** | 便于识别 |
| **带处方或就诊记录复印件** | 见[药品储存与携带](/wiki/medication-storage/) |
| **卡片上写上药物通用名** | 不同地区的商品名不同 |
| **查清目的国对相关药物的规定** | 部分药物在其他国家属管制药品，见[护照与旅行证件](/wiki/travel-documents/) |
| **告知一位同行者** | 如果安全的话 |

## 九、现在就可以做的三件事

- [ ] **写一张卡片**（药名 + 方式 + 紧急联系人），放进钱包
- [ ] **设置手机医疗急救卡**，并开启锁屏显示
- [ ] **告诉一个可信任的人**「我的钱包里有一张医疗信息卡」

**这三件事加起来不到十分钟，但可能在关键时刻起作用。**

## 常见问题

**「一定要准备吗？」**
**建议准备。** 如果你因为事故、昏迷或急病被送到急诊，医生需要知道你在用什么药。

**「卡片上要写身份吗？」**
**不必。** 只写药名和方式就够医生判断。

**「会不会暴露身份？」**
**可以降低暴露：** 只写药名、不写诊断、不写「跨性别」这个词。

**「紧急联系人必须是家属吗？」**
**不必。** 朋友也可以。

**「对方不知道我的情况怎么办？」**
可以用「我在长期服用处方药，具体在卡片上」这样的说法。

**「可以隐瞒吗？」**
**强烈不建议。** 见下「关于要不要隐瞒」。

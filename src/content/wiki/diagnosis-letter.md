## 两种材料的区别

这两个词经常被混用，但它们在流程里承担的角色不同。搞混的代价是要多跑一趟。

| | 诊断证明 | 介绍信 |
| --- | --- | --- |
| 作用 | 说明诊断结论 | 把当事人转介给下一环（内分泌、手术科室） |
| 常见用途 | 办证、单位事务、部分报销 | 内分泌科接诊、手术科室受理 |
| 出具方 | 精神科 | 精神科 |
| 有效期 | 各家不同，可能要求近期出具 | 各家不同 |
| 是否写明用途 | 不一定 | 通常会写明建议的下一步 |

**上游有专门的[介绍信](https://mtf.wiki/zh-cn/docs/psyco/introletter)条目**，说明其用途与常见要求。诊断证明的相关说明分散在精神科资源与各医院条目里。

**具体格式、抬头、有效期，各医院要求不一致。** 这一页给的是大致框架，**真实要求请以上游对应条目和医院窗口为准**。

## 常见使用链条

```
精神科门诊
   ├─► 诊断证明 ──► 办证 / 单位 / 其他行政事务
   └─► 介绍信  ──► 内分泌科（HRT）
                     └─► 手术科室
```

**注意分支点：** 诊断证明与介绍信不是「升级关系」，而是**并行用途**。你需要哪一种，取决于下一步要办什么。

## 开材料时要问清的四件事

| 问题 | 为什么要问 |
| --- | --- |
| **这份材料叫什么名字？** | 后续环节可能明确要求「介绍信」或「诊断证明」中的一种 |
| **有效期多久？** | 部分环节要求材料在若干个月内出具，过期要重开 |
| **是否写明用途？** | 有些环节要求材料上写明「建议激素治疗」或「建议手术」 |
| **能不能补开？** | 补开是否需要重新挂号，还是可以直接找医生 |

**把答案记在手机备忘录里**，下次不用重新问。

## 材料不匹配时怎么办

**这是最常见的卡点。**

| 情况 | 处理 |
| --- | --- |
| 下一环要求特定表述，上一环没写 | 回上一环补开，**开材料时直接说明下一环的要求** |
| 材料过期 | 重新挂号开具 |
| 原件被收走，需要再要一份 | 提前多开一份，或问清补开流程 |
| 医院只给复印件 | 确认是否需要盖章；部分环节接受盖章复印件 |

**预防方法：开材料时就把下一环的要求说清楚。** 这能避免大部分往返。

## 关于盖章

**是否要盖医院公章，各院不同，各使用方要求也不同。**

- 有些环节只认原件加盖章
- 有些接受复印件
- 有些要求「骑缝章」

**办之前问清使用方：** 「需要原件还是复印件？要不要盖章？」

## 有效期为什么这么重要

**时间线上的错位是常见的返工原因：**

```
精神科开材料 →（间隔太久）→ 内分泌科受理
                    ↑
              材料可能已过期
```

**所以：** 拿到材料后尽快推进下一步；如果中间要等很久，先问清材料是否会过期。

## 隐私提醒

**依据：** 就诊记录属于个人医疗信息，医疗机构对其负有保密义务；**但你自己主动公开的内容不受此保护**。

诊断证明和介绍信含有诊断信息。**在公开场合（社群、社交平台、求职）分享时：**

- 遮掉诊断结论
- 遮掉医院名称
- 遮掉医生姓名
- 只保留「已具备相关材料」这个信息即可

**多数场合不需要你出示原件。** 见[安全与隐私基础](/wiki/safety-privacy/)与[材料与档案管理](/wiki/records-management/)。

## 关于「要不要主动多开几份」

**建议多开一份备用。**

理由：

- 有些环节收原件
- 补开需要重新挂号，可能还要等排期
- 丢失或损坏时不用重跑流程

**留存时注意加密**，见[材料与档案管理](/wiki/records-management/)。

## 本站的边界

**本站不提供材料模板，也不说明具体措辞。** 措辞由医院和医生决定，写错会影响后续所有环节。

需要了解具体格式要求时，看上游对应条目，或直接问医院窗口。

## 常见问题

**「一定要有介绍信吗？」**
**不是所有环节都要求。** 但某些医院开具诊断证明需要介绍信。**具体问目标医院。**

**「介绍信谁开？」**
上游：**全日制在校学生一般由学校开具、有工作时一般由工作单位开具**，若非在读学生且无全职工作则可能需要社区协助。

**「开介绍信会不会出柜？」**
**可能。** 上游提到「这种证明在很多 211 院校可以自助打印（甚至往往没有有效期限限制）从而避免向师长出柜」。

**「诊断证明和介绍信都要吗？」**
**看下一环要求。** 两者是并行用途，不是升级关系。

**「有效期多久？」**
**各家不同。** 部分环节要求材料在若干个月内出具。

**「材料不匹配怎么办？」**
**回上一环补开。** 开材料时直接说明下一环的要求，能避免大部分问题。

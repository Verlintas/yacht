这两个词经常被混用，但它们在流程里承担的角色不同。搞混的代价是要多跑一趟。

## 大致区别

| | 诊断证明 | 介绍信 |
| --- | --- | --- |
| 作用 | 说明诊断结论 | 把当事人转介给下一环（内分泌、手术科室） |
| 常见用途 | 办证、单位事务、部分报销 | 内分泌科接诊、手术科室受理 |
| 出具方 | 精神科 | 精神科 |
| 有效期 | 各家不同，可能要求近期出具 | 各家不同 |

**具体格式、抬头、有效期，各医院要求不一致。** 这一页给的是大致框架，真实要求请以上游对应条目和医院窗口为准。

## 常见使用链条

```
精神科门诊
   ├─► 诊断证明 ──► 办证 / 单位 / 其他行政事务
   └─► 介绍信  ──► 内分泌科（HRT）
                     └─► 手术科室
```

## 开材料时要问清的四件事

1. **这份材料叫什么名字**（「诊断证明」还是「介绍信」），后续环节要求的是哪一种。
2. **有效期多久**，会不会因为时间久了要重开。
3. **是否写明用途**，有些环节要求材料上写明「建议激素治疗」或「建议手术」。
4. **能不能补开**，如果要补开需要重新挂号还是可以直接找医生。

把答案记在手机备忘录里，下次不用重新问。

## 几个容易被卡住的点

- **材料上的措辞不匹配。** 下一环要求特定表述，上一环没写，就得回去补。开材料时直接说明下一环的要求，能避免大部分问题。
- **时间间隔太长。** 有的环节要求材料在若干个月内出具。
- **原件与复印件。** 有些环节收原件，办之前先问清楚，必要时多开一份。
- **盖章。** 是否要盖医院公章，各院不同。

## 隐私提醒

诊断证明和介绍信含有诊断信息。**在公开场合（社群、社交平台、求职）分享时，把诊断结论、医院名称、医生姓名遮掉**，只保留「已具备相关材料」这个信息即可。多数场合不需要你出示原件。

## 本站的边界

本站不提供材料模板，也不说明具体措辞。措辞由医院和医生决定，写错会影响后续所有环节。

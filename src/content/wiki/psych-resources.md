上游的[精神科医疗资源综述](https://mtf.wiki/zh-cn/docs/psyco/overview)是这一环最完整的资料，按城市分了子页面。

**本站不复制那份名单。** 名单更新频率高，复制过来就会变成过时信息。这一页讲的是**怎么用那份名单**。

## 那份名单的结构

| 层级 | 内容 |
| --- | --- |
| 综述页 | 总览、按城市的入口 |
| 城市页 | 该城市的医院与医生（例如[北京](https://mtf.wiki/zh-cn/docs/psyco/beijing)、[上海](https://mtf.wiki/zh-cn/docs/psyco/shanghai)） |
| 医院页 | 该院的具体流程、材料要求 |
| 医生页 | 单个医生的接诊情况、患者经验 |

**已收录的城市**（据上游目录）：北京、上海、广东（广州、深圳）、江苏（南京、无锡）、浙江（杭州、义乌、温州）、四川（成都）、山东（济南、青岛）、辽宁（大连）、湖北（武汉）、湖南（长沙）、重庆、云南（昆明）、山西（临汾）、江西（南昌）、广西（南宁）等。

## 名单怎么读

| 字段 | 怎么看 |
| --- | --- |
| 城市 / 医院 | 先按你实际能去的城市筛 |
| 医生姓名 | 用来挂号，不用来判断水平 |
| 页面备注 | 是否愿意接诊、是否要求家属、复诊间隔、开什么材料 |
| **更新时间** | **越新越好。超过一年的要打电话确认** |
| 患者经验 | 参考价值有限（样本量小），但能看出流程大概长什么样 |

**关键提醒：名单里的「接诊」状态会变。** 医生可能停诊、换科室、改变接诊政策。**不要拿着名单直接跑过去。**

## 去之前怎么确认

1. **打电话或看挂号平台**，确认医生当天出诊。
2. **问清挂号方式与放号时间**（不同医院差异很大：公众号、APP、电话、现场）。
3. **问清需要带的材料**（身份证、既往就诊记录、既往检查报告）。
4. **确认科室名称**（精神科 / 临床心理科 / 心理科，各院叫法不同）。
5. **如果医院有导诊台，可以先问「这方面该挂哪个科」**。

<div class="guide">
<strong>一个容易忽略的点</strong>
<p>有些医院的挂号系统里，医生的擅长方向不会写「跨性别」。名单上有的医生可能在不同院区、不同门诊类型出诊。</p>
<p>如果第一次挂错了，直接问医生「这方面该找谁」，通常能得到准确指引。</p>

## 去之前准备什么

**写下来，不要靠记。** 门诊时间有限：

1. **你要问的问题**（清单见下）
2. **你的情况怎么描述**（说感受、持续时间和影响，不用术语）
3. **要不要带人陪同**（允许，且能帮忙记医嘱）

**要问的问题：**

- 是否需要多次复诊？间隔多久？
- 会开出什么形式的材料？诊断证明还是介绍信？
- 这份材料能用于哪些后续环节（内分泌、手术、办证）？
- 下次复诊怎么挂号？
- 出现什么情况要立刻联系您？

更完整的清单见[就医前准备清单](/wiki/clinic-prep/)与[怎么跟医生说话](/wiki/doctor-communication/)。

## 关于「友好」这件事

**「友好」通常指：** 医生愿意接诊、不使用贬损措辞、按流程开具材料。

**它不等于医生会跳过必要的评估步骤。** 评估本身是流程要求，不是对你的质疑。见[诊断标准是什么](/wiki/diagnosis-criteria/)。

## 如果本地没有资源

| 方案 | 说明 |
| --- | --- |
| 邻省 | 看综述页的「其它地区」部分 |
| 线上初诊 + 线下复诊 | 部分医生支持，具体看条目说明 |
| 先做心理咨询 | 咨询师不能开材料，但能帮理清诉求并提供转介线索，见[怎么找心理咨询](/wiki/finding-counselor/) |
| 问社群 | 有人刚走过这条路，知道哪家最近还接，见[社群与互助](/wiki/community/) |
| 联系公益组织 | 上游的[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)名单有转介渠道 |

## 如果被拒绝了

**会发生。** 可能的原因：医生停诊、科室政策变化、医生个人不接、号挂错了。

**这不代表你没有资格获得医疗服务。** 换一家或换一位即可。

**处理顺序：**

1. 不要争辩，问清原因
2. 问替代方案（「这方面我应该找谁？」）
3. 记录：时间、医院、科室、医生、答复内容
4. 换人 / 换医院 / 换城市

详细应对见[被拒绝接诊怎么办](/wiki/psych-rejection/)。

## 本站的边界

本站：

- **不复述医生名单**（变化太快）
- **不评价医生**（主观且可能失准）
- **不复述具体接诊条件**（各院政策会变）

这些交给上游的社群维护更合适。

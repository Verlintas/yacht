## 为什么户籍是第一步

**身份证、学历、医保、护照的信息都以户籍登记为基础。** 户籍不改，后面每一步都会卡住。

```
医院相关证明
      │
      ▼
  户口本（户籍信息变更）  ← 你在这一步
      │
      ▼
   身份证
      │
      ▼
学历 · 医保 · 护照 · 银行 · 其余
```

**上游的[户口身份证变更指引](https://mtf.wiki/zh-cn/docs/srs/id-card)专门说明了这一步。**

## 办理地点与方式

| 项 | 说明 |
| --- | --- |
| 地点 | 户籍所在地的**派出所**或**政务服务中心的户籍窗口** |
| 是否需本人 | 多数情况需要本人到场 |
| 是否需预约 | 部分地区支持预约，建议先问 |
| 是否可异地 | **通常需要回户籍地**；部分业务已支持跨省通办，需咨询当地 |

## 可能需要的材料

- 户口本原件
- 身份证原件
- **医院出具的相关证明**（各地要求不同，可能要求特定格式或特定医院）
- 书面申请
- 部分地区要求公证材料

**以当地窗口要求为准。** 上游的[户口身份证变更指引](https://mtf.wiki/zh-cn/docs/srs/id-card)整理了各地经验。

**建议办之前打电话问清：** 需要哪些材料？要不要原件？要不要公证？办理周期多久？

## 关于「户主」这件事（最容易卡住的地方）

| 情况 | 说明 |
| --- | --- |
| **自己是户主** | 相对简单，本人办理即可 |
| **不是户主，户主是家人** | 变更户籍信息通常需要户主配合或提供户口本原件 |
| **家庭关系紧张** | 可能无法取得户口本，需要咨询窗口是否有替代方案 |

**如果卡在户口本拿不到这一步，可以：**

1. **先向户籍窗口咨询**是否有其他证明途径
2. **咨询公益组织**，看有没有类似情况的处理经验，见[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)
3. **涉及权益纠纷时**，参考上游的[常见法律问题](https://mtf.wiki/zh-cn/docs/useful-info/legal-faq)
4. **见[被拒绝后的申诉路径](/wiki/appeal-path/)**

## 变更完成后

- **户口本上会有变更记录**，建议**扫描留存**（加密保存，不要放公开云盘）
- **尽快办理身份证换领**，见[身份证性别信息变更](/wiki/id-card-change/)
- **之后按[实名信息变更总览](/wiki/real-name-overview/)的顺序逐项处理**
- **核对户口本上的其他信息**（姓名、出生日期、住址）是否也有需要更新的

## 常见问题

**「变更记录会留在户口本上吗？」**
户籍系统会保留历史变更记录。这是行政记录，不影响你正常使用证件。

**「能异地办理吗？」**
通常需要回户籍地。部分业务已支持跨省通办，**具体咨询当地窗口**。

**「办理要多久？」**
各地不同，从当场办结到数个工作日都有。

**「被拒绝怎么办？」**
问清依据、记录过程、换渠道尝试，见[身份证性别信息变更](/wiki/id-card-change/)里的「如果被拒」一节与[被拒绝后的申诉路径](/wiki/appeal-path/)。

**「家属会知道吗？」**
**这是需要提前考虑的。** 户籍变更可能涉及户主配合，家庭成员也可能通过其他渠道得知。**先做安全评估。**

**「变更后旧户口本复印件还有用吗？」**
有用。**建议保留一份变更前的复印件**（加密保存），用于证明身份沿革，见[材料与档案管理](/wiki/records-management/)。

## 隐私提醒

**户口本照片含有户号、住址、家庭成员信息。**

- **不要发给任何人**，包括看起来是「帮忙看材料」的陌生人
- **不要发到网上**，包括社群
- **需要提问时先打码**：遮掉户号、住址、家庭成员姓名、身份证号

见[安全与隐私基础](/wiki/safety-privacy/)。

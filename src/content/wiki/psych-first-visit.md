## 全流程

```
挂号 → 候诊 → 问诊 → 可能的量表 → 医生判断 → 开材料 / 约复诊
```

## 1. 挂号

| 事项 | 要点 |
| --- | --- |
| **先确认医生接诊** | 上游名单会标注，但名单会过期，**打电话或看挂号平台确认** |
| **选对科室** | 通常是精神科、临床心理科或心理科，各院名称不同 |
| **挂号方式** | 医院公众号、APP、电话、现场；放号时间各家不同 |
| **号源** | 热门医生号源紧张，可能需要提前抢 |

<div class="guide">
<strong>一个容易忽略的点</strong>
<p>有些医院的挂号系统里，医生的擅长方向不会写「跨性别」。名单上有的医生可能在不同院区、不同门诊类型出诊。</p>
<p>如果第一次挂错了，直接问医生「这方面该找谁」，通常能得到准确指引。</p>
</div>

**上游按城市整理了[精神科资源](https://mtf.wiki/zh-cn/docs/psyco/overview)，用法见[精神科资源怎么用](/wiki/psych-resources/)。**

## 2. 候诊

**带好材料**（清单见[就医前准备清单](/wiki/clinic-prep/)）。

候诊时可以：

- 再看一遍自己写的问题清单
- 把要出示的材料按顺序整理好
- 深呼吸，不用紧张——**你不需要「答对」任何问题**

## 3. 问诊

**医生会问的大致是：**

| 类别 | 具体问题 |
| --- | --- |
| 时间 | 什么时候开始有这样的感觉 |
| 内容 | 具体是什么样的感受 |
| 影响 | 对生活、情绪、工作学习造成了什么影响 |
| 家庭与社交 | 有没有告诉家人朋友，关系如何 |
| 病史 | 既往病史、用药史、过敏史、家族史 |
| 风险 | 有没有自伤或自杀的想法 |

**如实回答，包括让你不舒服的部分。** 医生需要真实信息才能判断。

**不确定的问题直接说「我不确定」。** 编答案会让医生判断失准。

**怎么描述见[怎么跟医生说话](/wiki/doctor-communication/)。**

## 4. 量表

有些医生会让你填量表。

**它的作用是帮你整理感受、帮医生了解你的状态，不是用来判定你是不是跨性别。**

见[自评量表的边界](/wiki/self-test-scales/)。

## 5. 医生判断

**可能的结果：**

| 结果 | 含义 | 常见程度 |
| --- | --- | --- |
| **直接开材料** | 已有较长就诊史时可能 | 相对少见 |
| **约复诊** | 需要观察一段时间，间隔数周到数月 | **最常见** |
| **建议先做咨询** | 有的医生会先建议心理支持 | 常见 |
| **不接诊** | 见下 | 会发生 |

**「需要复诊」是常规流程，不是对你的质疑。** 上游资料显示，多数人不是一次就能拿到材料。

**如果被拒绝接诊**，见[被拒绝接诊怎么办](/wiki/psych-rejection/)。

## 6. 开材料

**要问清楚：**

| 问题 | 为什么 |
| --- | --- |
| 开的是什么？诊断证明还是介绍信？ | 后续环节要求不同，见[诊断证明与介绍信](/wiki/diagnosis-letter/) |
| 能用于哪些后续环节？ | 避免下一环不认 |
| 有效期多久？要不要盖章？ | 过期要重开 |
| 下次什么时候来？怎么挂号？ | 复诊通常需要 |
| 出现什么情况要立刻联系您？ | 应急 |

## 出诊室之后立刻做三件事

1. **记医嘱。** 趁还记得，写下医生说的关键内容和下一步。
2. **扫描材料。** 加密保存，见[材料与档案管理](/wiki/records-management/)。
3. **记下窗口电话。** 下次预约或材料出问题时会用到。

## 常见担心

**「我表述不好会不会影响判断？」**
不会。你不需要用专业术语，说清楚感受就行。医生见过各种表述方式。

**「会不会被记录在案影响以后？」**
就诊记录属于医疗隐私，受保密义务约束。担心的话可以当面问医生记录的用途和范围。

**「家人会不会被通知？」**
成年且不涉及自伤/伤人风险时，通常不会。**可以在问诊时直接问清保密范围。**

**「一次要花多少钱？」**
挂号费加可能的量表费，通常不高。复诊次数多时累计会上去。

**「要准备多久？」**
**不要为了「准备充分」而拖几个月。** 挂上号、把问题写下来就可以去了。

**「如果我说得不够清楚，医生会不会觉得我不是？」**
评估看的是持续性、一致性和影响程度，不是表达水平。**如实说比说得漂亮重要。**

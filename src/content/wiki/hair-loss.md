## 为什么这件事要早处理

**已经萎缩的毛囊很难恢复。** 脱发是渐进过程，**越早干预，能保住的就越多**。

**上游在 HRT 效果表里把「脱发减少」列为「时间不定」** [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

**「不定」的含义：** 激素可能帮助减缓，但**不是确定效果，也不是主要治疗手段**。所以不能指望 HRT 解决脱发。

## 常见类型

| 类型 | 特点 | 常见原因 |
| --- | --- | --- |
| **雄激素性脱发** | 最常见。发际线后移、头顶稀疏 | 雄激素作用 + 遗传易感 |
| **休止期脱发** | 短期内大量掉发 | 压力、营养、疾病、产后、手术 |
| **斑秃** | 局部圆形脱发 | 自身免疫 |
| 其他 | — | 甲状腺问题、贫血、药物影响、牵拉性脱发 |

**先确认类型再治。** 不同类型处理方式完全不同。

## 常见治疗方向

上游的[脱发的治疗](https://mtf.wiki/zh-cn/docs/ffs/hair-loss-med)条目整理了主要方向：

| 方向 | 说明 |
| --- | --- |
| **抑制雄激素作用** | 通过 HRT 中的抗雄方案间接起效 |
| **外用制剂** | 部分外用药可促进毛发生长 |
| **口服药物** | 部分药物用于特定类型脱发 |
| **物理治疗** | 低能量激光等 |
| **植发** | 把后枕部毛囊移植到脱发区 |

**具体药物的适应症、用法与风险，看上游条目与说明书。本站不复述具体用法。**

## 关于植发

| 项 | 说明 |
| --- | --- |
| 前提 | **需要先控制住脱发进展**，否则移植的头发也会掉 |
| 供区 | 需要供区毛发充足 |
| 费用 | 较高，通常按毛囊单位计费 |
| 机构 | 要选正规医疗机构 |
| 时间 | 从取发到效果稳定需要数月 |

**上游把植发归在脱发治疗的框架下。** 具体适应症与流程，看上游条目与医生说明。

## 日常能做的

**以下是常见建议，没有权威来源支持，仅作参考：**

- 不要过度烫染，尤其在脱发期
- 不要用力拉扯头发（紧扎发型会加重牵拉性脱发）
- 保证营养与睡眠
- 减少压力（休止期脱发与压力明确相关）
- 避免频繁高温造型

**牵拉性脱发是可逆的**，如果长期扎紧发型，值得先改变习惯。

## 一个现实提醒

**头发对很多人来说是重要的心理支撑。** 如果你因为脱发感到焦虑，这是真实且合理的困扰，不需要觉得「这点小事也在意」。

**同时也要知道：发型、假发、发际线修饰都是有效的应对方式**，不是「放弃治疗」。有人用假发过得很好。

**如果脱发带来的焦虑持续影响生活**，值得找咨询师谈，见[怎么找心理咨询](/wiki/finding-counselor/)。

## 关于假发与修饰

**这是有效的应对方式，不是「放弃治疗」。**

| 方式 | 说明 |
| --- | --- |
| **假发** | 效果立即可见；选择上注意发际线与发色自然度 |
| **发际线粉/纤维** | 用于局部稀疏，应急效果好 |
| 发型设计 | 用刘海或层次掩盖稀疏区域 |
| 帽子、发带 | 日常可用 |
| **头皮遮瑕** | 用于局部露头皮 |

**有人用假发过得很好，也有人选择不做任何处理。** 这取决于你在意到什么程度。

**如果脱发带来的焦虑持续影响生活**，值得找咨询师谈，见[怎么找心理咨询](/wiki/finding-counselor/)。

## 常见问题

**「HRT 能治脱发吗？」**
**不能指望它。** 上游效果表把「脱发减少」列为「**时间不定**」——**不是确定效果，也不是主要治疗手段。**

**「已经掉的头发能长回来吗？」**
**已经萎缩的毛囊很难恢复。** 这也是要早处理的原因。

**「要早到什么程度？」**
**越早越好。** 脱发是渐进过程，早干预能保住的更多。

**「植发能解决吗？」**
**需要先控制住脱发进展**，否则移植的头发也会掉。

**「假发算不算放弃？」**
**不算。** 这是有效的应对方式，见下。

**「怎么判断是哪种脱发？」**
**需要医生判断。** 不同类型处理方式完全不同。

## 常见类型的详细对照

| 类型 | 特点 | 常见原因 | 是否可逆 |
| --- | --- | --- | --- |
| **雄激素性脱发** | 最常见。发际线后移、头顶稀疏 | 雄激素作用 + 遗传易感 | 早期可减缓，晚期难恢复 |
| **休止期脱发** | 短期内大量掉发 | 压力、营养、疾病、手术 | **通常可逆** |
| **斑秃** | 局部圆形脱发 | 自身免疫 | 可能自愈，可能反复 |
| **牵拉性脱发** | 发际线或特定区域 | 长期紧扎发型 | **早期可逆** |
| 其他 | — | 甲状腺问题、贫血、药物影响 | 视原因 |

**先确认类型再治。**

## 常见治疗方向的详细说明

| 方向 | 说明 | 注意 |
| --- | --- | --- |
| **抑制雄激素作用** | 通过 HRT 中的抗雄方案间接起效 | 效果有限，且不是主要手段 |
| **外用制剂** | 部分外用药可促进毛发生长 | 需长期使用，停用后可能回退 |
| **口服药物** | 部分药物用于特定类型脱发 | 有副作用，需医生评估 |
| **物理治疗** | 低能量激光等 | 效果因人而异 |
| **植发** | 把后枕部毛囊移植到脱发区 | 需要供区充足、先控制脱发 |

**具体药物的适应症、用法与风险，看上游的[脱发的治疗](https://mtf.wiki/zh-cn/docs/ffs/hair-loss-med)条目与说明书。本站不复述具体用法。**

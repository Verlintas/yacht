抗雄药物之间差别比很多人以为的大：**作用机制不同，风险类型也不同**。这一页帮你理解医生在权衡什么。剂量见[药物剂量速查](/wiki/medication-doses/)。

## 机制分类

| 类别 | 作用方式 | 代表药物 | 上游条目 |
| --- | --- | --- | --- |
| GnRH 类似物 | 作用于上游信号，抑制性腺激素分泌 | 多种 | [gnrha](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/gnrha) |
| 雄激素受体拮抗剂 | 阻断受体，不降低激素水平 | 比卡鲁胺 | [bicalutamide](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/bicalutamide) |
| 孕激素类 | 兼具抗促性腺作用 | 醋酸环丙孕酮 | [cyproterone](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/cyproterone) |
| 醛固酮受体拮抗剂 | 兼有抗雄作用 | 螺内酯 | [spironolactone](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/spironolactone) |
| 孕激素类（其他） | 抗促性腺作用 | 醋酸甲羟孕酮 | [medroxyprogesterone](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/medroxyprogesterone) |

**「阻断受体」和「降低激素水平」是两回事。** 这一点会影响监测指标怎么看——比如用受体拮抗剂时，激素水平可能仍然偏高，但不代表没有作用。这也是为什么监测方案要跟着具体药物走。

## 风险类型的差异

不同药物的风险关注点不同，常见的方向包括：

- **肝脏** — 部分药物需要关注肝功能指标
- **泌乳素** — 部分孕激素类药物需要关注
- **电解质与肾功能** — 部分利尿类抗雄药物需要关注
- **血栓** — 与雌激素联用时需要整体评估
- **情绪** — 个体差异较大，值得记录

**具体哪种药要关注哪些指标、多久查一次，看上游的[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)与[监测](https://mtf.wiki/zh-cn/docs/medicine/monitoring)条目，并遵医嘱。**

## 医生通常在权衡什么

1. 目标：是要降低激素水平，还是阻断作用？
2. 可获得性：本地能开到什么（这一点在国内影响很大）
3. 费用：GnRH 类似物通常明显更贵
4. 监测条件：能否按要求复查对应指标
5. 既往病史与用药史

## 常见误区

- **「抗雄药可以随便换」** — 不同机制的药，监测指标和风险都不同，换药需要医生评估。
- **「只用雌激素就够」** — 是否单用雌激素、是否加抗雄，取决于方案设计，由医生决定。
- **「剂量越大效果越好」** — 抑制过度会带来其他问题，且不会加速预期效果。

## 常见问题

**「哪种抗雄最好？」**
**上游的结论：任何抗雄激素方案之间没有特别明显的优劣之分，也缺乏直接比较的证据。**

**「螺内酯为什么不降睾酮？」**
它作用于雄激素受体（阻断作用），不抑制性腺分泌。所以**睾酮检查报告不能反映它的效果**（上游说明）。

**「比卡鲁胺为什么不能常规用？」**
上游：**用于 MtF 的记录很少，有待进一步研究，目前不宜用于常规 HRT**。

**「可以同时用两种抗雄吗？」**
**不建议自行组合。** 不同机制叠加的风险需要医生评估。

**「术后还要吃抗雄吗？」**
**上游说明：经手术切除睾丸（SRS）后，一般无需加用抗雄药物。**

**「色普龙吃多久要做影像检查？」**
**上游提示：服用 5 年以上，应接受脑部 CT 或磁共振（MRI）扫描。** 见[泌乳素升高怎么办](/wiki/prolactin/)。

## 四种抗雄的完整对照

| | CPA（色普龙） | MPA | 螺内酯 | 比卡鲁胺 |
| --- | --- | --- | --- | --- |
| **机制** | 孕激素类，抑制性腺 | 孕激素类 | 受体阻断（弱） | 受体阻断（强） |
| **是否降睾酮** | **是** | 是（较弱） | **否** | **否** |
| **一般剂量** | 10–12.5 mg/天 | 推算 30–100 mg/天 | 100–400 mg/天 | 25–50 mg/天 |
| **上游立场** | 常用 | CPA 的替代品 | 略不推荐 | **不推荐常规应用** |
| **主要风险** | 肝毒性、脑膜瘤、泌乳素 | 泌乳素 | **高钾血症** | 肝毒性 |
| **价格** | 较低 | 低 | 低 | **高** |

## 剂量的关键细节（CPA）

| 要点 | 内容 |
| --- | --- |
| **单药不能完全抑制睾酮** | 即使在最大推荐剂量（10～12.5 mg/d）下也不行，**只有与雌激素合用才行** |
| 建议剂量 | **10 ~ 12.5 mg/天** |
| 低剂量已足够 | **10 mg/天左右已可最大程度抑制睾酮，效果与高剂量一致** |
| 指南建议 | **WPATH SOC-8 亦建议 10 mg/天** |
| 超低剂量 | **每周两次 12.5 mg（等效约 3.5 mg/天）同样可实现充分抑制** |
| 减量 | 达到效果后**尽可能减至 5～6.25 mg/d**，暂不推荐减至 5 mg/d 以下 |
| 分药 | 可用切药器切为四片（每份 12.5 mg），**每 1 ~ 3 日一服** |
| **补充** | **建议适量补充维生素 B12** |
| 效果不佳时 | **首先检查雌激素血药浓度是否足够高** |

## 螺内酯的关键要求

| 要求 | 说明 |
| --- | --- |
| **禁忌症** | **高钾血症患者切勿服用** |
| **开始前** | **血钾应小于 5.0 mmol/L，肾功能应正常** |
| **服用期间** | 定期监测**血钾、肌酐和尿酸** |
| 肝功能不全（尤其肝硬化） | **慎用**，可能损害神经系统造成昏迷 |
| 服用含锂药物者 | 慎用，定期监测血锂 |
| **饮食** | 避免富钾食品：**香蕉、海带、含钾代用盐** |
| **药物** | **不得同时服用其它利钾药物** |
| 其他 | **多喝水** |
| **高风险人群** | **高年龄（超 45 岁）、肾功能不全、与其它利钾药物合用、钾补剂的服用** |

**剂量说明（上游）：** 「一般对 MtF 而言，和非注射途径的中等剂量雌二醇并用时，睾酮会有大幅下降，但仍高于女性正常范围；顺性别女性用于治疗雄激素相关症状时通常需要 50～200 mg/天，而 **MtF 可能需要更高剂量（如 100～300 mg/天，乃至 400 mg/天）** 方可阻断剩余的雄激素，但随之而来的尿频、高血钾等副作用可能会更严重。」

## 比卡鲁胺的关键要求

| 要求 | 说明 |
| --- | --- |
| **SOC-8 立场** | **现阶段不推荐将比卡鲁胺用于常规 GAHT 治疗** |
| **肝功能监测** | **开始前检测血清转氨酶，服药开始 6 个月内定期监测** |
| 肝损害 | **中、重度肝损害的病人应慎用** |
| **禁止服用人群** | 有遗传性半乳糖不耐受、Lapp 乳糖酶缺乏症或葡萄糖-半乳糖吸收障碍的患者 |
| **禁止联用** | **不可与特非那定、阿司咪唑或西沙必利联合使用** |
| **价格** | 原研康士得（50 mg × 28 片）挂网价 868.83 元；国产仿制 162.73–193 元 |

## 方案之间怎么比

**上游的结论：没有特别明显的优劣之分，也缺乏直接比较的证据。**

**但有一份可参考的资料：** 近期在北医三院进行的研究比较了「色普龙」和螺内酯的疗效，其中**乳房发育满意程度相近，但前者抑制勃起、促进体形女性化的作用更明显**。

## 关于「不推荐使用的」

| 药物 | 上游立场 |
| --- | --- |
| **非那雄胺**（5α-还原酶抑制剂） | 用于 MtF 的记录极其稀少；**现阶段不建议加用** |
| 螺内酯 | 上游标注为「略不推荐」 |
| 比卡鲁胺 | 上游标注为「不推荐常规应用」 |

## 一个辨认提醒

**「日色」是醋酸氯地孕酮（Chlormadinone Acetate），同样具有抗雄激素活性，但并非醋酸环丙孕酮，请不要误用。**

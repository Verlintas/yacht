## 先改变一个想法

**「出柜」常被想象成一次性的宣告：某一天，对所有人，全部说清楚。**

**实际上它更像是**一连串独立的决定**：对谁、什么时候、说多少、用什么词。**

**每一项都可以单独控制。** 把大事件拆成小决定，压力会小很多，风险也可控得多。

## 安全评估（最重要的一步）

**在告诉任何人之前，先回答这四个问题：**

| 问题 | 说明 |
| --- | --- |
| **1. 对方可能的反应是什么？** | **依据是过往言行，不是你的期望** |
| **2. 如果反应是最坏的那种，我会失去什么？** | 住处、经济来源、学费、工作、监护关系 |
| **3. 如果最坏的情况发生，我有什么退路？** | 能住哪、钱够不够、有没有人可以求助 |
| **4. 现在是不是必须说？** | 有没有可以推迟的余地 |

<div class="guide">
<strong>一条硬规则</strong>
<p>如果「失去住所或经济来源」的可能性真实存在，<b>先建立退路，再说</b>。</p>
<p>顺序反了代价很大。这不是不信任家人，是给自己留出从容的空间。</p>
</div>

## 分阶段的做法

| 阶段 | 对象 | 可控性 | 风险 |
| --- | --- | --- | --- |
| 1 | 一两个绝对信得过的人 | 最高 | 极低 |
| 2 | 社群、线上朋友 | 高 | 低 |
| 3 | 朋友、同学、同事中关系较近的 | 中 | 中 |
| 4 | 家人 | 低 | 高（涉及住所与经济） |
| 5 | 公开场合 / 所有人 | 最低 | **不可撤回** |

**不必按顺序走完。** 有人停在第二阶段也很正常。

**可以先在低风险阶段练习怎么开口**，等到面对高风险对象时会更从容。

## 关于家人

| 做法 | 说明 |
| --- | --- |
| **先选家里最可能支持的那一位** | 一次性面对全家，压力更大 |
| **准备好材料** | 有些人需要「有依据」才能接受 |
| **给时间** | 家人的接受过程可能以月甚至年计，**第一次谈话通常不是结论** |
| **设定边界** | 你有权不接受「你必须先证明给我看」这类要求 |
| **注意安全** | 如果遭遇强制「矫正」或限制人身自由，这是需要外部介入的情况 |

**详细应对见[家庭沟通](/wiki/family/)与[家人常见反应与应对](/wiki/family-reactions/)。**

## 信息控制

| 原理 | 说明 |
| --- | --- |
| **告诉一个人 = 告诉一个网络** | 除非明确要求保密，否则默认会扩散 |
| **可以先约定保密范围** | 「我还没准备好让更多人知道，请先别说」 |
| **不同场合用不同的信息量** | 职场只需要说称呼和代词，不需要交代病史 |
| **注意数字痕迹** | 改过的头像、昵称、旧发言都可能被关联 |

**见[安全与隐私基础](/wiki/safety-privacy/)。**

## 说不出口的时候

**很正常。** 可以：

| 替代方式 | 说明 |
| --- | --- |
| 写信或消息 | 比面对面容易 |
| 只对一个人说 | 降低压力 |
| 什么都不说，只是开始按自己的方式生活 | **这也是一种有效的策略** |
| 找咨询师练习 | 见[怎么找心理咨询](/wiki/finding-counselor/) |

**没有必须出柜的义务。** 选择不说，不是懦弱，是一种有效的策略。

## 关于「被动出柜」

**有时候不是你选择说，而是被别人发现或替你说出去。**

**如果发生：**

| 步骤 | 做法 |
| --- | --- |
| 1 | **先确认范围** —— 谁知道了、传到哪里了 |
| 2 | **评估风险** —— 有没有实际的安全或经济威胁 |
| 3 | **决定回应方式** —— 可以不回应、可以简短确认、可以说明边界 |
| 4 | **保留证据** —— 如果是他人恶意传播 |
| 5 | **见[网络暴力与取证](/wiki/online-harassment/)** |

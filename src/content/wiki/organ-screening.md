## 先说清楚这一页的边界

**跨性别者的器官筛查，取决于「有哪些器官」和「用了什么药」，而不是取决于身份。**

所以这一页按**器官**组织，而不是按「跨性别者应该查什么」。

**⚠️ 重要提醒：** 这一页里只有**乳腺**和**骨密度**两项有上游资料的明确表述。**其余部分属于一般人群筛查指南的适用范围，不是跨性别专属建议。具体做不做、多久做一次，必须问医生。**

## 一、乳腺（有上游依据）

**上游的明确表述 [2]：**

> 雌激素、孕激素可增长乳腺癌风险。**长年服用雌、孕激素应注意。**

**风险倍数 [2]：**

| 内容 | 说明 |
| --- | --- |
| **风险比较** | **接受性别肯定激素治疗的跨性别女性的乳腺癌风险是顺性别男性的 46 倍，但仍低于顺性别女性** |
| **筛查建议** | **对于接受激素治疗的跨性别者而言，遵循与顺性别者相同的筛查指南即可** |
| 家族史 | 有乳腺癌（尤其是携带 BRCA1/2 致病变异）家族史的个体风险将**显著增加** |
| 家族史者的策略 | **建议接受与近亲女性相同的乳腺健康状态监测策略** |
| 年龄因素 | **年龄较大的跨性别者可以考虑停止激素治疗，以降低患乳腺癌的风险** |

**上游把「乳腺扫描」列为可酌情监测项目，理由正是「长年服用雌、孕激素应注意」[1]。**

**延伸阅读：**[乳腺癌风险](https://tfsci.mtf.wiki/zh-cn/articles/breast-cancer/) [3]

**关键含义：** 「遵循与顺性别者相同的筛查指南」意味着——**你的筛查安排应该按女性标准来**，而不是按男性标准。这一点在就诊时可能需要主动向医生说明。

## 二、骨密度（有上游依据）

**上游的表述 [2]：**

> 雌二醇和睾酮均有利于维持骨密度，过低会导致骨质流失。**长期处于雌二醇、睾酮「双低」状态者应谨慎**（例如接受青春期阻断治疗，或不充分的激素治疗）。

**上游把骨密度列为可酌情监测项目 [1]。**

**北医三院的初诊检查里包含骨密度（基线检查，双能 X 线法或超声，检查部位是腰椎和髋关节）[见[各阶段的年龄门槛与家长要求](/wiki/age-thresholds/)引用的北医三院页面]。**

**哪些情况需要格外注意：**

| 情况 | 说明 |
| --- | --- |
| 长期单用抗雄制剂 | 上游不建议长期（一个月以上）单用抗雄 |
| 术后未继续用雌激素 | 上游：即使切除性腺后一般也需长期服用雌二醇 |
| 青春期阻断期间 | 上游明确提示注意骨密度变化 |

**详细说明见[骨密度与骨骼健康](/wiki/bone-density/)。**

## 三、前列腺

**如果你未做前列腺切除手术，前列腺仍然存在。**

**⚠️ 本站没有找到针对这一人群的前列腺筛查专属指南。** 上游资料里没有相关条目。

**所以：**

- **按一般人群的筛查建议**（通常与年龄和家族史相关）
- **就诊时主动告知医生你的 HRT 情况**——因为雌激素会影响前列腺相关指标（如 PSA）的解读
- **具体筛查安排问医生**

## 四、宫颈与子宫

**如果你未做过子宫切除手术，子宫颈和子宫仍然存在。**

**⚠️ 本站没有找到针对这一人群的筛查专属指南。** 上游资料里没有相关条目。

**一般原则：** 按一般人群的筛查建议（通常与年龄、性生活史相关）。**具体问医生。**

## 五、一般人群的常规筛查

**以下项目与性别认同无关，按年龄和风险因素常规进行：**

| 项目 | 说明 |
| --- | --- |
| **血压** | 常规测量，成本低，价值高 |
| **血糖** | HRT 期间属于可酌情监测项（见下） |
| **血脂** | 同上 |
| **体重与腰围** | HRT 后体重和体脂普遍增加，见下 |
| **视力、口腔** | 常规 |
| **疫苗** | 按当地接种建议 |

**上游把这些列为可酌情监测项目，理由见[治疗期间的监测](/wiki/monitoring-index/)：**

| 项目 | 上游的理由 |
| --- | --- |
| 空腹血糖和胰岛素 | 雌激素以及比卡鲁胺等部分抗雄药物**可影响糖耐量，使血糖升高** |
| 空腹血脂 | **雌激素可降低 LDL、提高甘油三酯**；**螺内酯、比卡鲁胺可提高 LDL** |
| 肾功能 | **肾功能不全者慎用螺内酯**；**慎用雌激素**（可能导致体液潴留） |
| 离子六项 | **螺内酯可能影响钾、钠、钙、镁等离子水平** |
| 血常规 | 雌激素可导致血小板计数增加；CPA、比卡鲁胺可导致红细胞计数减少 |
| 甲状腺功能 | **雌激素可刺激甲状腺素结合球蛋白分泌**，使甲状腺素再摄取减少 |
| 体重和体脂 | **MtF 群体中普遍可见接受 GAHT 以后体重和体脂增加的现象**。应定期测量体重 |

## 六、关于「不想去体检」

**这是一个真实存在的问题，值得正面处理。**

| 顾虑 | 可以怎么做 |
| --- | --- |
| **怕被问到身份** | 需要向医生说明用药情况，但**不必解释身份**。见[怎么跟医生说话](/wiki/doctor-communication/) |
| **怕被议论** | 选择正规机构，必要时换一家 |
| **怕检查项目涉及隐私部位** | 可以提前问清检查流程，也可以要求同性医护在场 |
| **怕结果** | 这是最常见的顾虑。但**早发现的处理空间远大于晚发现** |
| **觉得麻烦** | 把体检和复查合并安排，减少往返次数 |

**上游在监测页里给了一个实用的提示：**

> 中国大陆任何一家三甲医院均可进行激素和其它血液指标检查。挂号时，应挂内分泌科门诊，男科、妇科也能提供相关检查。**进行检查的理由可以如实坦白**，如果是相对保守的地区也可以用激素相关的疾病复查作为理由。

## 七、建议的记录方式

**建一张表，按「项目 + 上次检查时间 + 下次该查时间」管理：**

| 项目 | 频率 | 上次 | 下次 |
| --- | --- | --- | --- |
| 激素（E2/T/PRL） | 每 3 个月（第一年） | — | — |
| 肝功能 | 每 3 个月 | — | — |
| 血常规 / 生化 | 每 3 个月 | — | — |
| 骨密度 | 视医生建议 | — | — |
| 乳腺 | 按女性筛查指南 | — | — |
| 血压 / 体重 | 每次复诊 | — | — |

**这张表本身是敏感信息，要加密保存。** 见[材料与档案管理](/wiki/records-management/)与[用药记录怎么做](/wiki/hrt-log/)。

## 八、什么时候该主动就医（不必等筛查）

| 信号 | 说明 |
| --- | --- |
| 乳房出现肿块、皮肤改变、异常分泌物 | 尽快就诊 |
| 单侧肢体肿痛、胸痛、呼吸困难 | **紧急**，见[血栓风险与自我评估](/wiki/thrombosis-risk/) |
| 皮肤或眼白发黄、尿色变深 | 肝相关 |
| 心悸、肌肉无力 | 电解质相关 |
| 持续加重的头痛、视力变化 | 见[泌乳素升高怎么办](/wiki/prolactin/) |
| 轻微外力下骨折、身高变矮 | 骨密度相关 |

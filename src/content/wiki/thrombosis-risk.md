## 为什么总提血栓

**上游把静脉血栓列为雌激素最严重的不良反应之一，严重时可导致心肌梗塞与中风。**

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)

**但要注意剂量与途径的差别：**

| 途径 | 血栓风险 |
| --- | --- |
| **口服** | 相对最高（有肝脏首过效应） |
| 舌下 / 面颊含服 | 低于口服 |
| **贴片 / 凝胶（经皮）** | **最低** |
| 注射 | 同剂量下低于口服 |

**上游的明确表述：达到相同激素水平时，经口服的雌二醇静脉血栓风险大于含服、经皮、注射。**

**这是选择剂型时医生会考虑的因素之一。** 见[雌激素类药物对照](/wiki/estrogen-compare/)。

**上游还指出：口服雌二醇或人工合成雌激素（如炔雌醇）的这项风险更大。**

## 会推高风险的因素

| 因素 | 说明 |
| --- | --- |
| **吸烟** | **最常被医生追问的一项，与血栓风险明确相关** |
| 年龄 | 风险随年龄上升 |
| **既往血栓史** | 重要禁忌参考 |
| **家族史** | 直系亲属的血栓史会被问到 |
| 肥胖 | 相关因素 |
| 长期不动 | 长途旅行、术后卧床、久坐 |
| 部分合并疾病 | 心血管疾病、凝血相关疾病 |
| 部分合并用药 | 见[药物相互作用与合并用药](/wiki/drug-interactions/) |
| 偏头痛（尤其有先兆） | 会被问到 |

**这些因素不是「绝对不能用药」，而是需要医生评估、可能需要调整方案。**

## 就诊前先想清楚这几个问题

**医生大概率会问，提前想好回答会更顺：**

- [ ] 你吸烟吗？吸多少、多久了？
- [ ] 你或直系亲属有过血栓、肺栓塞、心梗、中风吗？
- [ ] 你做过手术吗？有没有术后并发症？
- [ ] 你目前在用哪些药（**包括保健品**）？
- [ ] 你平时的活动量如何？有没有长期久坐或久卧？
- [ ] 有没有偏头痛（尤其是有先兆的）？
- [ ] 有没有心血管疾病或相关病史？

**如实回答。隐瞒这些信息，风险落在你自己身上。**

## 怎么降低风险

| 做法 | 说明 |
| --- | --- |
| **不吸烟** | **上游明确建议激素治疗期间不要吸烟。这是最有效的一条** |
| **选择合适的剂型** | 和医生讨论经皮途径是否更适合你 |
| **按方案复查** | 见[治疗期间的监测](/wiki/monitoring-index/) |
| **避免长期不动** | 长途旅行时定时活动腿部、多喝水 |
| **术后严格按医嘱活动** | 见[术后护理与恢复](/wiki/surgery-recovery/) |
| **控制其他风险因素** | 体重、血压、血脂 |
| **不自行加用其他激素类药物** | — |

## 需要立刻就医的信号

**出现以下任一情况，尽快就医，并告知医生你正在使用激素：**

| 类型 | 表现 |
| --- | --- |
| **下肢血栓** | 单侧小腿或大腿肿胀、疼痛、发热 |
| **肺栓塞** | 突然的呼吸困难、胸痛、心跳加速、咳血 |
| **脑血管** | 突然的剧烈头痛、视力变化、言语不清、一侧肢体无力、面部歪斜 |
| **心梗** | 胸痛、胸闷、左臂或下颌疼痛 |

**这些是血栓与栓塞的典型信号，不要等。**

## 关于「长期安全性」

**上游提到：目前的研究表明，在专业医生的指导和风险把控下进行激素治疗是安全的**（见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)）。

**但本站不复述具体发生率数字**——数字需要跟着研究更新，且高度依赖个体情况。

**想了解当前认识，看上游的[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)条目与指南原文。延伸阅读：[雌激素与血栓](https://tfsci.mtf.wiki/zh-cn/articles/estrogens-blood-clots/)。**

## 常见问题

**「透皮途径真的更安全吗？」**
**上游的数据显示是。** 透皮雌二醇 ≤ 50 μg/天的风险率是 **0.9 倍**（低于未使用者），口服 > 1 mg/天是 1.4 倍。

**「不吸烟就不会有风险吗？」**
**不是。** 不吸烟能显著降低风险，但其他因素（年龄、既往史、家族史）仍然相关。

**「有血栓史还能用吗？」**
**上游：血栓是雌、孕激素的禁忌症之一。** 具体由医生评估。

**「手术前要停药吗？」**
**上游：建议术前一个月内停用雌、孕激素，术后卧床期间也应停用。**

**「腿肿了是不是血栓？」**
**不一定**，但**单侧**肿痛需要立刻就医。

**「怎么知道自己有没有风险？」**
**做凝血相关检查 + 如实告知病史。** 见下「就诊前要准备的问题」。

## 血栓相对风险率的完整数据（上游）

| 雌激素类型 | 血栓风险率 |
| --- | --- |
| **透皮雌二醇 ≤ 50 μg/天** | **0.9 倍** |
| 透皮雌二醇 > 50 μg/天 | 1.1 倍 |
| **口服雌二醇 ≤ 1 mg/天** | **1.2 倍** |
| 口服雌二醇 > 1 mg/天 | 1.4 倍 |
| 口服雌二醇约 1 mg/天合并孕激素 | 1.4–1.8 倍 |
| 口服结合雌激素 ≤ 0.625 mg/天 | 1.4 倍 |
| 口服结合雌激素 > 0.625 mg/天 | 1.7 倍 |
| 口服结合雌激素约 0.625 mg/天合并孕激素 | 1.5–2.4 倍 |
| **现代避孕药（如达英-35）** | **4.2 倍** |
| **早期避孕药（高剂量炔雌醇）** | **4–10 倍** |
| 高剂量聚磷酸雌二醇注射剂 | 2.1 倍 |
| **高剂量口服人工雌激素** | **5.7–10 倍** |
| 选择性雌激素受体调节剂 | 约 1.5–3 倍 |
| **单用高剂量醋酸环丙孕酮** | **3–5 倍** |

**这张表最值得注意的两点：**

1. **透皮途径（贴片、凝胶）的风险率低于 1** —— 相对未使用者没有增加，甚至略低
2. **人工合成雌激素与高剂量 CPA 的风险显著更高**

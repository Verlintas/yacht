## 为什么总提血栓

**上游把静脉血栓列为雌激素最严重的不良反应之一，严重时可导致心肌梗塞与中风。**

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)

**但要注意剂量与途径的差别：**

| 途径 | 血栓风险 |
| --- | --- |
| **口服** | 相对最高（有肝脏首过效应） |
| 舌下 / 面颊含服 | 低于口服 |
| **贴片 / 凝胶（经皮）** | **最低** |
| 注射 | 同剂量下低于口服 |

**上游的明确表述：达到相同激素水平时，经口服的雌二醇静脉血栓风险大于含服、经皮、注射。**

**这是选择剂型时医生会考虑的因素之一。** 见[雌激素类药物对照](/wiki/estrogen-compare/)。

**上游还指出：口服雌二醇或人工合成雌激素（如炔雌醇）的这项风险更大。**

## 会推高风险的因素

| 因素 | 说明 |
| --- | --- |
| **吸烟** | **最常被医生追问的一项，与血栓风险明确相关** |
| 年龄 | 风险随年龄上升 |
| **既往血栓史** | 重要禁忌参考 |
| **家族史** | 直系亲属的血栓史会被问到 |
| 肥胖 | 相关因素 |
| 长期不动 | 长途旅行、术后卧床、久坐 |
| 部分合并疾病 | 心血管疾病、凝血相关疾病 |
| 部分合并用药 | 见[药物相互作用与合并用药](/wiki/drug-interactions/) |
| 偏头痛（尤其有先兆） | 会被问到 |

**这些因素不是「绝对不能用药」，而是需要医生评估、可能需要调整方案。**

## 就诊前先想清楚这几个问题

**医生大概率会问，提前想好回答会更顺：**

- [ ] 你吸烟吗？吸多少、多久了？
- [ ] 你或直系亲属有过血栓、肺栓塞、心梗、中风吗？
- [ ] 你做过手术吗？有没有术后并发症？
- [ ] 你目前在用哪些药（**包括保健品**）？
- [ ] 你平时的活动量如何？有没有长期久坐或久卧？
- [ ] 有没有偏头痛（尤其是有先兆的）？
- [ ] 有没有心血管疾病或相关病史？

**如实回答。隐瞒这些信息，风险落在你自己身上。**

## 怎么降低风险

| 做法 | 说明 |
| --- | --- |
| **不吸烟** | **上游明确建议激素治疗期间不要吸烟。这是最有效的一条** |
| **选择合适的剂型** | 和医生讨论经皮途径是否更适合你 |
| **按方案复查** | 见[治疗期间的监测](/wiki/monitoring-index/) |
| **避免长期不动** | 长途旅行时定时活动腿部、多喝水 |
| **术后严格按医嘱活动** | 见[术后护理与恢复](/wiki/surgery-recovery/) |
| **控制其他风险因素** | 体重、血压、血脂 |
| **不自行加用其他激素类药物** | — |

## 需要立刻就医的信号

**出现以下任一情况，尽快就医，并告知医生你正在使用激素：**

| 类型 | 表现 |
| --- | --- |
| **下肢血栓** | 单侧小腿或大腿肿胀、疼痛、发热 |
| **肺栓塞** | 突然的呼吸困难、胸痛、心跳加速、咳血 |
| **脑血管** | 突然的剧烈头痛、视力变化、言语不清、一侧肢体无力、面部歪斜 |
| **心梗** | 胸痛、胸闷、左臂或下颌疼痛 |

**这些是血栓与栓塞的典型信号，不要等。**

## 关于「长期安全性」

**上游提到：目前的研究表明，在专业医生的指导和风险把控下进行激素治疗是安全的**（见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)）。

**但本站不复述具体发生率数字**——数字需要跟着研究更新，且高度依赖个体情况。

**想了解当前认识，看上游的[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)条目与指南原文。延伸阅读：[雌激素与血栓](https://tfsci.mtf.wiki/zh-cn/articles/estrogens-blood-clots/)。**

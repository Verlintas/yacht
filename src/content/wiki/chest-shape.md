## 内衣尺码：两个数字

**内衣尺码由两部分组成：下胸围 + 罩杯。**

| 数字 | 怎么量 | 说明 |
| --- | --- | --- |
| **下胸围**（如 75、80、85） | 乳房下缘绕一圈 | **这是最重要的数字** |
| **罩杯**（A、B、C…） | 胸围与下胸围的差值 | 差值决定字母 |

**⚠️ 最常见的错误是下胸围买大了。**

**下胸围不合身的后果：** 肩带会往下滑、后背会往上跑、承托力全靠肩带、穿久了肩颈疼。

**判断标准：** 扣好后，**后背的带子应该水平，能塞进两根手指**。

**⚠️ 不同品牌的内衣尺码差异很大，而且同一品牌不同款式也可能不同。** 具体以品牌的尺码表为准。

**MtF.wiki 有一个[胸围计算](https://mtf.wiki/zh-cn/cup-calculator)工具**，可以按测量值换算。

## 从无钢圈开始

| 类型 | 特点 | 适合 |
| --- | --- | --- |
| **无钢圈** | 舒适，门槛低 | 刚开始穿、日常 |
| **软钢圈** | 有一定承托 | 过渡 |
| **运动内衣** | 包裹感强、压平 | 运动、想弱化轮廓时 |
| **背心式** | 最简单 | 最不容易出错 |
| **有钢圈／聚拢** | 强调轮廓 | 需要时 |

**建议从无钢圈或背心式开始。** 钢圈位置不对会压到乳腺，不舒服。

## 义乳与垫胸

**⚠️ 以下为经验整理，非研究结论。**

| 方式 | 做法 | 特点 |
| --- | --- | --- |
| **加厚内衣** | 内衣自带胸垫 | 最简单，不用额外买 |
| **胸垫／硅胶垫** | 放进内衣罩杯内 | 可调大小，便宜 |
| **义乳** | 专门的硅胶制品 | 更接近真实重量与触感，价格较高 |
| **假体／填充物** | 丝袜、棉垫等自制 | 便宜，效果看手艺 |
| **整体式（背心带垫）** | 一体设计 | 不容易移位 |

**选择时看三点：**

- [ ] **重量** —— 太重的义乳会拉扯肩颈
- [ ] **贴合度** —— 移位会很明显
- [ ] **透气性** —— 长时间穿要透气

**⚠️ 夏天要注意透气与皮肤护理。** 长时间不透气可能引起皮肤问题。

## 束胸（binding）：安全边界

**⚠️ 束胸有明确的健康风险，这一节请认真看。**

**⚠️ 以下为经验整理，非研究结论。但风险部分不是「个人体验」，而是常见的医学提示。**

| 绝对不要做 | 原因 |
| --- | --- |
| **用绷带、胶带、保鲜膜** | 无法控制压力，会限制呼吸、损伤皮肤和肋骨 |
| **穿比自己小很多号的束胸** | 压力过大 |
| **束胸时运动** | 呼吸受限，风险叠加 |
| **束胸时睡觉** | 长时间不间断压迫 |
| **一次超过 8 小时** | 常见建议的上限 |
| **感冒、咳嗽、哮喘发作时束胸** | 呼吸功能已经受限 |
| **有肋骨、脊柱或呼吸系统疾病时束胸** | 风险显著增加 |

**出现以下情况立即停止：**

| 信号 | 说明 |
| --- | --- |
| **呼吸困难、喘不上气** | **立即解开** |
| **胸痛** | **立即解开** |
| **肋骨疼痛或压痛** | 停止 |
| **皮肤破损、起疹、变色** | 停止 |
| **咳嗽持续** | 停止 |
| **头晕** | 停止 |

**降低风险的做法（常见建议）：**

- [ ] 选专门设计的束胸，不要自制
- [ ] 从最松的档位开始
- [ ] 有休息日，不要每天穿
- [ ] 不用来运动
- [ ] 保持清洁干燥
- [ ] 注意姿势，不要含胸驼背

**⚠️ 本站不推荐任何具体品牌，也不给出「能压到多平」的标准。** 如果束胸是你目前唯一能承受的方案，**请优先保证安全参数，而不是效果。**

**如果束胸带来的身体损害已经出现，先停下来，并考虑就医。**

## 和身体的关系

| 心态 | 说明 |
| --- | --- |
| **用什么是你自己的选择** | 束胸、垫胸、什么都不做，都成立 |
| **不需要向任何人解释** | 包括家人、朋友、医生（除非涉及医疗安全） |
| **不是「作弊」** | 内衣、义乳和化妆、眼镜是同一类东西 |
| **不必永久依赖** | 很多人的选择会随时间和身体变化而改变 |
| **疼痛不是「应该忍」的** | 疼说明有问题 |

## 常见问题

**「一定要穿内衣吗？」**
**不必。** 有人穿，有人不穿，都是个人选择。

**「怎么知道尺码对不对？」**
**下胸围合身是第一位。** 后背带子水平、能塞进两根手指。

**「义乳会被看出来吗？」**
**选对重量和贴合度通常不容易。** 注意衣服的领口和面料。

**「束胸会不会影响乳房发育？」**
**本站没有找到关于这一问题的权威来源。** 上游的 HRT 效果表与监测页未涉及此项。

**「束胸会不会影响以后手术？」**
**本站没有找到关于这一问题的权威来源。** 如果你在考虑手术，**请在术前告知医生你有束胸习惯**。

**「HRT 之后还需要垫吗？」**
**看个人。** 发育程度、时间和个人偏好都不同。

**「运动时怎么办？」**
**运动内衣是更安全的选择。不要用束胸运动。**

## 内衣尺码换算的思路

**内衣尺码 = 下胸围 + 罩杯字母。**

| 下胸围（厘米） | 常见对应尺码 |
| --- | --- |
| 68–72 | 70 |
| 73–77 | 75 |
| 78–82 | 80 |
| 83–87 | 85 |
| 88–92 | 90 |

| 胸围 − 下胸围 | 常见罩杯 |
| --- | --- |
| 约 10 cm | A |
| 约 12.5 cm | B |
| 约 15 cm | C |
| 约 17.5 cm | D |

**⚠️ 这张表只是常见对应关系，不同品牌差异很大。** 有些品牌会做「姐妹尺码」（如 75B ≈ 80A），有些不会。

**⚠️ 下胸围偏大是普遍现象。** 如果量出 78，先试 75 和 80 两个尺码。

**试穿时检查三件事：**

- [ ] **后背带子水平** —— 不往上跑
- [ ] **能塞进两根手指** —— 不太紧也不太松
- [ ] **罩杯不空不压** —— 空杯说明罩杯大了或形状不合；压胸说明小了

**肩带的作用是微调，不是承托。** 如果全靠肩带撑着，说明下胸围大了。

## 什么时候需要重新量

| 时机 | 说明 |
| --- | --- |
| **HRT 开始后每几个月** | 乳房发育会改变胸围 |
| **体重明显变化后** | 下胸围也会变 |
| **换品牌时** | 尺码标准不同 |
| **穿起来总是不舒服时** | 说明尺码不对 |
| **肩颈开始酸痛时** | 常见于下胸围过大 |

**⚠️ 不要为了「看起来更大」而买小下胸围的款式。** 那会让整个白天都不舒服，而且影响健康。

## 选购渠道与预算

| 渠道 | 优点 | 缺点 |
| --- | --- | --- |
| **网购（支持退换）** | 不用面对人，选择多 | 尺码可能不对 |
| **实体店** | 能试穿 | 心理门槛 |
| **运动品牌** | 运动内衣选择多 | 款式偏中性 |
| **平价连锁** | 便宜 | 尺码标准不一 |
| **二手／换衣** | 成本低 | 卫生需注意 |

**⚠️ 本站不推荐任何具体品牌。**

**预算有限时的顺序：**

| 顺序 | 买什么 |
| --- | --- |
| **1** | 一两件无钢圈或背心式（日常够用） |
| **2** | 一件运动内衣（运动必需） |
| **3** | 一副可调胸垫（灵活调整） |
| **4** | 其他款式 |

## 护理与卫生

| 事项 | 说明 |
| --- | --- |
| **换洗频率** | 每天换或隔天换 |
| **手洗更好** | 保护形状与钢圈 |
| **不要用热水** | 会让面料变形 |
| **阴干** | 避免暴晒 |
| **义乳清洁** | 按产品说明，注意皮肤接触面 |
| **皮肤护理** | 长时间穿戴要注意透气 |

**⚠️ 如果皮肤出现红疹、破损或持续瘙痒，先停穿并检查尺码与材质。**

## 常见问题（补充）

**「为什么穿上还是不像？」**
**内衣的作用是承托和塑形，不是制造身体。** 发育程度、胸廓形状、体重都会影响效果。**不要用「像不像」来评价自己。**

**「可以穿一整天吗？」**
**普通内衣可以。束胸不可以，见上文安全部分。**

**「运动时穿什么？」**
**运动内衣。不要用束胸运动。**

**「旧内衣怎么处理？」**
**可以留、可以扔、可以送人。** 没有规定。

**「需要买很多件吗？」**
**两到三件换洗就够。** 先买够用的，再考虑款式。

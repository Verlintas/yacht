这一页是**导航用的速查表**，不是定义大全。

**要更细的解释，看上游的两份词表：**[缩写词语表](https://mtf.wiki/zh-cn/docs/useful-info/abbreviation)与[通俗用语表](https://mtf.wiki/zh-cn/docs/useful-info/colloquialism)。

**本页的词条定义是本站对上述来源的整理**，不是原始定义。

## 身份与人群

| 词 | 含义 |
| --- | --- |
| **MtF** | Male-to-Female，出生时被指派为男性、认同为女性的人 |
| **FtM** | Female-to-Male，方向相反 |
| **transfeminine** | 女性倾向跨性别者，比 MtF 更宽，包含非二元中的女性倾向者 |
| **AMAB / AFAB** | 出生时被指派为男性 / 女性（assigned male/female at birth） |
| **enby** | non-binary 的非正式写法，非二元 |
| **指派性别** | 出生时被登记或判定的性别 |
| **顺性别（cis）** | 性别认同与指派性别一致 |
| **非二元** | 认同不完全落在「男」或「女」两个点上，见[非二元是什么](/wiki/nonbinary/) |

## 医疗相关

| 词 | 含义 |
| --- | --- |
| **HRT** | Hormone Replacement Therapy，激素替代治疗 |
| **GAHT** | Gender-Affirming Hormone Therapy，性别肯定激素治疗，是 HRT 更中性的说法 |
| **抗雄** | 抗雄激素药物，用来降低雄激素作用 |
| **SRS / GRS** | 生殖器相关手术的两种常见叫法 |
| **FFS** | Facial Feminization Surgery，面部女性化手术 |
| **嗓音女性化** | 通过训练或手术改变声音的音高与音色 |
| **术前公证** | 部分手术前需要办理的公证材料，见[公证是什么](/wiki/notarization/) |
| **监测** | 用药期间按间隔做的血液检查，见[治疗期间的监测](/wiki/monitoring-index/) |
| **E2 / T / P4 / PRL** | 雌二醇 / 睾酮 / 孕酮 / 泌乳素 |
| **激素六项** | 常见的激素检查套餐，见[激素六项怎么看](/wiki/hormone-panel/) |
| **单药治疗** | 只用雌激素、不加抗雄的方案，通常只有注射途径可实现 |
| **双低** | 雌激素与雄激素都偏低的状态，见[骨密度与骨骼健康](/wiki/bone-density/) |
| **青春期阻断** | 用 GnRH 类似物暂时抑制性腺功能，见[青春期阻断](/wiki/puberty-blockers/) |

## 证件与制度

| 词 | 含义 |
| --- | --- |
| **诊断证明** | 精神科出具的证明材料，多数医疗与办证环节需要 |
| **介绍信** | 由精神科出具、用于转介到内分泌或手术环节的文书，见[诊断证明与介绍信](/wiki/diagnosis-letter/) |
| **实名信息变更** | 身份证、户口本等法定证件上的姓名与性别信息更新 |
| **ICD-11** | 世界卫生组织国际疾病分类第 11 版，见 [ICD-11 与去病理化](/wiki/icd11-depathologization/) |
| **DSM-5-TR** | 美国精神医学学会的诊断手册 |
| **户口本变更** | 户籍信息变更，通常是证件变更的第一步 |
| **曾用名** | 户籍系统保留的历史姓名记录 |

## 社群用语

| 词 | 含义 |
| --- | --- |
| **出柜** | 向他人公开自己的性别认同，见[出柜策略与安全评估](/wiki/coming-out/) |
| **passing** | 在日常生活中被他人按自己认同的性别看待 |
| **stealth** | 不向新认识的人公开跨性别经历 |
| **性别焦虑** | 因性别认同与身体或社会对待不一致而产生的痛苦，见[性别焦虑是什么](/wiki/gender-dysphoria/) |
| **吃糖** | 社群对 HRT 的非正式说法 |
| **国色 / 土色 / 新色** | 社群对不同产地醋酸环丙孕酮的叫法（中国大陆 / 土耳其 / 新西兰） |
| **日雌** | Progynon-Depot 的社群叫法，一种戊酸雌二醇针剂 |
| **补佳乐 / 克龄蒙** | 戊酸雌二醇片的常见商品名 |
| **诺坤复** | 雌二醇片的常见商品名 |

## 关于用语的三点说明

**1. 词会变。**

上游的[通俗用语表](https://mtf.wiki/zh-cn/docs/useful-info/colloquialism)就专门收录了社群内通行但与字面意思不同的说法。**这不是谁对谁错，是语言在动。**

**2. 别人怎么称呼你，以你自己的选择为准。**

**词表是给「看不懂」用的，不是给「应该怎么叫」用的。**

**3. 如果某份资料里的用词让你不舒服**

可以直接去看它的原始出处，或者换一份资料。**用词也是信息质量的一部分。**

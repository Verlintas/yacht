## 先说结论

**被拒绝是常见的，不代表你不够格。** 可能的原因很多，而且大多数和你本人无关。

## 可能的原因

| 原因 | 说明 |
| --- | --- |
| 医生个人不接 | 有医生明确不接这类来访者，这是他的选择 |
| 科室政策变化 | 医院可能调整过接诊范围 |
| 医生不熟悉 | 没经验，担心处理不好 |
| 号挂错了 | 挂到了不相关的科室或医生 |
| 医院层级限制 | 部分医院要求特定资质才能开具相关材料 |
| 你表达的方式 | 极少见，但如果医生误解了你的诉求也可能 |

**注意最后一条：不是要你反思自己。** 如果是因为沟通，那也只是沟通问题，换个人重说一遍就行。

## 现场怎么应对

1. **不要争辩。** 争论很少能改变结果，还会消耗你。
2. **问清原因。** 「能告诉我为什么吗？」「这方面我应该找谁？」有时医生会指向正确的人。
3. **问替代方案。** 「如果这里不行，您建议我去哪里？」
4. **记录。** 时间、医院、科室、医生、答复。这对后面的人和可能的维权都有用。
5. **正常结账离开。** 保留挂号凭证。

<div class="guide">
<strong>如果对方使用了贬损性说法</strong>
<p>你有权不接受。可以当场说明「请用专业的方式沟通」，也可以直接结束就诊。</p>
<p>如果涉及明确的侮辱或歧视，记录时间、地点、在场人，之后可以走投诉渠道。见[常见法律问题索引](/wiki/legal-faq-index/)。</p>
</div>

## 之后的替代路径

1. **换医生。** 上游名单里通常有多位，同一城市不同医院也可以试。
2. **换城市。** 邻省有时有接诊的医院。上游按城市整理了[精神科资源](https://mtf.wiki/zh-cn/docs/psyco/overview)。
3. **先做心理咨询。** 咨询师不能开材料，但可以帮你理清诉求，也能提供转介线索。
4. **问社群。** 有人刚走过这条路，知道哪家最近还接。见[社群与互助](/wiki/community/)。
5. **联系公益组织。** 上游的[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)页面有转介渠道。

## 关于「被拒记录」

- **挂号记录会留在医院系统里**，但这通常不影响你去其他医院就诊。
- **不同医院之间一般不共享门诊记录**，除非是同一医疗集团或你主动提供。
- 如果你担心，可以下次就诊时不主动提之前的经历。

## 情绪上的处理

被拒会有挫败感，这很正常。几件事值得记住：

- **这不是对你身份的否定。** 是流程和人的问题。
- **不要因此拖延。** 休息几天，然后换一家继续。
- **找人说说。** 社群里有大量相同经历的人。
- **如果情绪持续低落**，见[怎么找心理咨询](/wiki/finding-counselor/)或[社群与互助](/wiki/community/)里的危机资源。

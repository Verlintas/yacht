## 先说结论

**被拒绝是常见的，不代表你不够格。**

可能的原因很多，**而且大多数和你本人无关**。

## 可能的原因

| 原因 | 说明 | 是否和你有关 |
| --- | --- | --- |
| 医生个人不接 | 有医生明确不接这类来访者 | 无关 |
| 科室政策变化 | 医院可能调整过接诊范围 | 无关 |
| 医生不熟悉 | 没经验，担心处理不好 | 无关 |
| 号挂错了 | 挂到了不相关的科室或医生 | 流程问题 |
| 医院层级限制 | 部分医院要求特定资质才能开具相关材料 | 无关 |
| 你表达的方式 | 极少见，但如果医生误解了你的诉求也可能 | **沟通问题，不是身份问题** |

**注意最后一条：不是要你反思自己。** 如果是因为沟通，那也只是沟通问题，换个人重说一遍就行。

## 现场怎么应对

| 步骤 | 做法 |
| --- | --- |
| 1 | **不要争辩** —— 争论很少能改变结果，还会消耗你 |
| 2 | **问清原因** —— 「能告诉我为什么吗？」「这方面我应该找谁？」 |
| 3 | **问替代方案** —— 「如果这里不行，您建议我去哪里？」 |
| 4 | **记录** —— 时间、医院、科室、医生、答复 |
| 5 | **正常结账离开** —— 保留挂号凭证 |

<div class="guide">
<strong>如果对方使用了贬损性说法</strong>
<p>你有权不接受。可以当场说明「请用专业的方式沟通」，也可以直接结束就诊。</p>
<p>如果涉及明确的侮辱或歧视，记录时间、地点、在场人，之后可以走投诉渠道。见<a href="/wiki/legal-faq-index/">常见法律问题索引</a>。</p>
</div>

## 之后的替代路径

| 路径 | 说明 | 成本 |
| --- | --- | --- |
| **换医生** | 上游名单里通常有多位 | 低 |
| **换医院** | 同一城市不同医院也可以试 | 低到中 |
| **换城市** | 邻省有时有接诊的医院 | 中到高 |
| **先做心理咨询** | 咨询师不能开材料，但可以帮你理清诉求，也能提供转介线索 | 中 |
| **问社群** | 有人刚走过这条路，知道哪家最近还接 | 低 |
| **联系公益组织** | 上游的[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)名单有转介渠道 | 低 |

**建议的顺序：先从成本最低的开始。** 换医生通常比换城市划算得多。

## 关于「被拒记录」

| 问题 | 说明 |
| --- | --- |
| 挂号记录会留在医院系统吗 | 会，但**通常不影响你去其他医院就诊** |
| 不同医院之间共享记录吗 | **一般不共享**，除非是同一医疗集团或你主动提供 |
| 担心的话怎么办 | 下次就诊时不主动提之前的经历 |

## 情绪上的处理

**被拒会有挫败感，这很正常。** 几件事值得记住：

- **这不是对你身份的否定。** 是流程和人的问题。
- **不要因此拖延。** 休息几天，然后换一家继续。
- **找人说说。** 社群里有大量相同经历的人，见[社群与互助](/wiki/community/)。
- **允许自己生气或难过。** 不需要立刻「调整好心态」。
- **如果情绪持续低落**，见[怎么找心理咨询](/wiki/finding-counselor/)或[危机资源与紧急情况](/wiki/crisis-resources/)。

## 关于「要不要投诉」

**看情况。**

| 情况 | 建议 |
| --- | --- |
| 明确不接诊但没有不当言行 | **通常不值得投入**，换人更快 |
| 使用贬损性语言 | 可以投诉到医务科或卫健委 |
| 拒绝提供已挂号的服务 | 可以要求退费并投诉 |
| 涉及明确的歧视性行为 | 记录证据，见[被拒绝后的申诉路径](/wiki/appeal-path/) |

**评估成本。** 投诉需要时间与精力，而换一家可能当天就能解决。

## 常见问题

**「被拒是我自己的问题吗？」**
**不是。** 可能的原因很多，**大多数和你本人无关**。

**「被拒后还能去其他医院吗？」**
**可以。** 挂号记录通常不影响你去其他医院就诊。

**「不同医院会共享记录吗？」**
**一般不共享**，除非是同一医疗集团或你主动提供。

**「要休息多久再试？」**
**看你自己。** 休息几天然后换一家继续，通常比无限期拖延好。

**「要不要投诉？」**
**看情况。** 明确不接诊但没有不当言行，通常不值得投入；使用贬损语言或拒绝提供已挂号服务，可以投诉。

**「被拒多次了怎么办？」**
可以换城市、先做咨询、或问社群。见下「替代路径」。

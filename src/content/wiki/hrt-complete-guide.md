# 第一部分：基础

## 一、生理基础

### 1.1 内分泌轴

人体通过一条三级链条调节性激素 [1]：

```
下丘脑  →  垂体  →  性腺（睾丸 / 卵巢）
（指挥）   （派活）    （生产激素）
```

| 环节 | 作用 |
| --- | --- |
| **下丘脑** | 调节垂体，可理解为向班长下发作业的「班主任」 |
| **垂体** | 分泌促性腺激素（LH、FSH），指令性腺工作，可理解为「班长」 |
| **性腺** | 产生雄激素、雌激素、孕激素，可理解为做作业的「学生」 |

### 1.2 负反馈：HRT 的底层原理

**关键机制在这里：** 下丘脑和垂体会检测体内性激素的浓度，但**无法分辨激素是自体产生还是外源摄入的**。浓度足够高时，它们就会减少对性腺的指令，性腺的激素产量随之下降 [1]。

**这就是为什么外源雌激素能抑制睾酮分泌**——不是雌激素直接「对抗」睾酮，而是通过负反馈让性腺停工。

上游给出了具体的阈值：**当雌二醇水平上升到并维持于 200 pg/mL 以上时，睾酮水平被抑制到顺性别女性参考范围内（55 ng/dL 以下）** [2]。

**这解释了两件事：**

1. 为什么注射是唯一能实现单药治疗的途径（只有注射能稳定达到这个水平）
2. 为什么其他途径通常需要加用抗雄药物

**上游的进一步说明：** 从等效剂量表可知，无论何种途径都需要很高剂量来达到 200 pg/mL 的目标；除注射剂以外，不仅成本飙升，使用上的不便也会越发显著。**因此上游仅推荐将针剂用于雌二醇单药治疗** [2]。

### 1.3 肾上腺的本底值

**除了性腺，肾上腺皮质也会产生少量性激素。** 所以即使性腺被充分抑制、或者做了 SRS，**检查报告里也会有一定的睾酮本底值，这是正常现象** [2]。

**上游在监测部分进一步说明：** 睾丸切除后，睾酮主要来自于肾上腺皮质。如仍存在睾酮高于女性参考值上限，请咨询内分泌科医生 [3]。

## 二、三种性激素及其作用

### 2.1 雌二醇（E2）—— 最主要的雌激素

**主要作用 [2]：**

| 方向 | 具体 |
| --- | --- |
| 女性化 | 乳房发育、皮肤软化且更细腻、脂肪分布女性化 |
| 骨骼（青春期） | 引导骨骼生长女性化：锁骨形状、骨架较窄、髋骨较宽 |
| 骨骼（长期） | 维持骨密度、促进骨生成、减少骨吸收 |
| 大脑 | 影响认知、情绪和行为 |
| 其他 | 调节脂肪组织和骨骼等器官 [3] |

**上游的补充说明：** 雌二醇在男性体内作为睾酮的代谢产物同样存在，其血清浓度相当于绝经后的妇女。雌二醇与雌酮可相互转化 [3]。

### 2.2 孕酮（P4）—— 作用存疑

**上游的表述很直接：孕酮在女性化和青春期发育过程中没有明确的作用。** [2]

近期有研究表明孕酮可以改善受试者对乳房发育的满意程度，**但研究没有检查乳房情况，也没有披露孕酮是否确实改变了乳房发育的结果，所以仍不能判断孕酮作用如何** [2][3]。

**上游还提到：口服孕酮还会导致类似酒精的副作用（如镇静）** [3]。

### 2.3 睾酮（T）—— 最主要的雄激素

**主要作用 [2]：**

| 方向 | 具体 |
| --- | --- |
| 男性化 | 阴茎增大、肩膀及肋骨扩张、肌肉增加、声音低沉、体毛生长 |
| 阻断 | 阻止雌激素引导的乳房发育 |
| 骨骼 | 增加或维持骨密度和强度；青春期促进骨骼成熟与身高增长 |
| 大脑 | 影响认知、情绪和行为，包括性欲 |
| 其他 | 影响性欲、力量、免疫功能，并起到对抗骨质疏松症等功效 [3] |

**睾酮通过两个方式产生效用 [3]：**

1. 直接或以局部双氢睾酮 (DHT) 形式激活雄激素受体
2. 转化为雌二醇激活某些雌激素受体

**数量级参考：** 据统计，成年男性睾酮的分泌量约为成年女性的 20 倍，体内含量是成年女性的 7–8 倍 [3]。

### 2.4 「激素六项」是哪六项

| 缩写 | 全称 | 关注度 |
| --- | --- | --- |
| E2 | 雌二醇 | **重点** |
| T | 睾酮 | **重点** |
| PRL | 泌乳素 | **较重要** |
| LH | 促黄体激素 | 使用色普龙或青春期阻断时有参考意义 |
| FSH | 促卵泡激素 | 同上 |
| P4 | 孕酮 | 参考意义有限 |

**上游的表述：** 治疗期间应监测性激素六项，**其中雌二醇、睾酮、泌乳素较重要** [3]。

**上游在另一处的表述：** 重点观察雌二醇和睾酮；建议观察泌乳素；LH、FSH 仅建议在青春期阻断治疗期间观察；孕酮基本没有参考意义 [2]。

## 三、治疗目标

### 3.1 血液指标目标

| 人群 | 雌二醇目标 | 睾酮目标 | 来源 |
| --- | --- | --- | --- |
| 成年 | 100–200 pg/mL（367–734 pmol/L） | 低于 0.5 ng/mL（低于 1.7 nmol/L） | [1][4] |
| 尚未成年 | 50–60 pg/mL 左右 | — | [1] |
| 非二元方案 | 30–50 pg/mL | — | [1] |

**补充说明：**

- 多份医学指南推荐将雌二醇期望值设于 **100–200 pg/mL** 之间 [2][4]
- 短时处于卵泡期范围（30 pg/mL 以上）可以容忍，但**不宜一直处于低位** [2]
- 青春期人群的激素水平一般低于成年，**雌二醇期望值无需向成年靠拢** [2]

### 3.2 更细的目标区间（来自监测页）

**上游在监测页面给出了更细的谷值目标 [3]：**

| 途径 | 目标 |
| --- | --- |
| **除针剂外** | 平均值 100–200 pg/mL；**谷值（接近下次用药前）55–150 pg/mL，建议在 100 pg/mL 以上** |
| **针剂** | **谷值 200 pg/mL 以上** |

**注意「谷值」这个词：** 它指接近下一次用药前的水平，也就是整个给药周期里的最低点。**这也是采血时间点的要求所在。**

### 3.3 关于「高于 200 是否更好」

**上游的明确结论：已知除了对促性腺激素、以及睾酮的产生有抑制作用以外，雌二醇水平高于 200 pg/mL 不会带来更强的女性化作用** [2]。

### 3.4 参考范围

来自 LabCorp [5]，经上游引用。**可能与你的报告单不同，以报告单为准。**

| 指标 | 单位一 | 单位二 |
| --- | --- | --- |
| 雌二醇（卵泡期） | 30–100 pg/mL | 110–367 pmol/L |
| 雌二醇（黄体期） | 70–300 pg/mL | 257–1100 pmol/L |
| 雌二醇（男性） | 8–35 pg/mL | 29–128 pmol/L |
| 睾酮（绝经前女性） | 0.10–0.55 ng/mL | 0.35–1.91 nmol/L |
| 睾酮（男性） | 2.64–9.16 ng/mL | 9.15–31.76 nmol/L |
| 泌乳素（女性） | 4.79–23.3 ng/mL | — |
| FSH（绝经前女性，卵泡/黄体期） | 1.8–11.2 mIU/mL | — |
| LH（绝经前女性） | 卵泡期 2.0–9.0 mIU/mL；黄体期 2.0–11.0 mIU/mL | — |

**上游的重要提醒：** 国内尚无完整的、统一的妇产科内分泌性激素测定值，且由于各种试剂的来源、测定的方法、数据的计算、采用的单位不同，**即使同一激素标本，各实验室所得结果也不完全相同。因此上述数据仅供参考** [3]。

**单位换算的公式可以从分子量推导**，见[激素换算工具](/wiki/hormone-converter/)。

# 第二部分：药物

## 四、雌激素：为什么只用雌二醇

**上游的立场很明确：临床上仅推荐运用雌二醇作为 GAHT 的雌激素来源** [2]。

### 4.1 为什么不建议用其他雌激素

| 类型 | 问题 |
| --- | --- |
| **炔雌醇**（Ethinyl Estradiol） | 血栓风险远高于天然的雌二醇 [2][6] |
| **结合雌激素**（Conjugated Estrogens） | 同上 |
| 雌酮 | 无法取代雌二醇 |
| 雌三醇 | 效力较弱；仅对特定用途有效（如绝经后阴道萎缩管理），转化率极其有限 [2] |

**含这些成分的常见药物：** 达英-35 / Diane-35 等以女性避孕为主的制剂。**现有跨性别医学指南不建议为 GAHT 运用这些雌激素** [4]。

### 4.2 雌二醇 vs 戊酸雌二醇：化学上的区别

**这是最容易混淆的一点。**

| 药物 | 化学性质 | 效力 |
| --- | --- | --- |
| **戊酸雌二醇** | 由雌二醇经**戊酸酯化**而成；进入体内后快速经**酯酶水解**为雌二醇，从而发挥雌激素活性（酯酶多见于肝脏，也见于血液等各组织） | 剂量比雌二醇大 33% |
| **雌二醇（半水合物）** | 不同于戊酸雌二醇，**效力和内源性雌二醇完全相当** | 基准 |

**来源：**[戊酸雌二醇片](https://mtf.wiki/zh-cn/docs/medicine/estrogen/estradiol-valerate) [6] · [雌二醇片](https://mtf.wiki/zh-cn/docs/medicine/estrogen/estradiol) [7]

**换算提醒：2 mg 戊酸雌二醇 = 1.5 mg 雌二醇** [1][2]。

**上游关于贴片的说明：** 目前在中国大陆尚未被正式批准，且缺乏使用记录（多见于海外）；尽管如此，在中国各大电商平台均已有进口贴片产品在售，也有社群伙伴证实了其有效性 [8]。

**上游关于凝胶的购买提醒：** 发现市面上存在一些**宣称**为雌二醇凝胶的保健品及消毒用品，购买时应该注意甄别，**简而言之国内请认准国药准字** [9]。

## 五、给药途径详解

### 5.1 口服

| 项 | 说明 |
| --- | --- |
| 一般剂量 | 2～6 mg/天 [1] |
| 利用率 | 5% [1] |
| 用药间隔 | 1～2 次/天 |
| 血栓风险 | **相对最高**（有肝脏首过效应）[2] |
| 获取难度 | 低（药店和医院）[1] |
| 是否需合用抗雄 | 需要 [1] |

**注意：** 口服剂基本都允许舌下或面颊含服 [2]。

### 5.2 舌下 / 面颊含服

| 项 | 说明 |
| --- | --- |
| 一般剂量 | 1～3 mg/天 [1] |
| 利用率 | 10～20% [1] |
| 用药间隔 | 2 次/天 |
| 血栓风险 | 低于口服 [2] |
| 是否需合用抗雄 | 需要 [1] |

**上游提到的含服要领 [1]：** 先舔掉包衣；药丸到位后尽量避免张口或移动舌头；含服时可能不断流口水，尽量忍耐；面颊处含服刺激较小、口水较少。

**缺点 [2]：** 吸收率易受唾液、进食、饮水、说话影响；持续时间较短，一日内或需多次含服。

**延伸阅读：** [舌下雌二醇](https://tfsci.mtf.wiki/zh-cn/articles/sublingual-e2-transfem/) [26]

### 5.3 外用贴片

| 项 | 说明 |
| --- | --- |
| 一般剂量 | 约 100 µg/天 [1] |
| 利用率 | 约 10% [1] |
| 更换周期 | 2～3.5 天轮换一次（不同品牌不同）[1] |
| 血栓风险 | **最低** [2] |
| 获取难度 | 较低（线上，需改搜索关键词）[1] |
| 是否需合用抗雄 | 需要 [1] |

**上游给出的具体疗效数据 [8]：**

| 产品 | 规格 | 理论疗效（雌二醇测定） |
| --- | --- | --- |
| Estramon | 100 µg/天 | 平均 81 pg/mL，最高 118 pg/mL |
| Estrana Tapes（久光） | 0.72 mg | 平均 52.0～53.8 pg/mL |

**上游的说明：** 可经皮肤吸收，使用方便，**且可完全避免肝脏的首过效应，安全性更高** [8]。

**注意事项 [1]：** 可能引起皮肤反应；如果贴附紧密，洗澡和游泳不会影响贴片，不慎掉落可立即贴回原位。

### 5.4 外用凝胶

| 项 | 说明 |
| --- | --- |
| 一般剂量 | 约 2.5 g/天 [1] |
| 利用率 | 约 10% [1] |
| 用药间隔 | 约 1 次/天 |
| 血栓风险 | **最低** [2] |
| 获取难度 | 较低（医院，少数连锁药店可预订）[1] |
| 是否需合用抗雄 | 需要 [1] |

**上游的注意事项 [1]：**

- 可能引起皮肤反应
- **涂抹处 2 小时内不得碰水**
- 衣物剐蹭、洗澡和游泳可能影响吸收
- **不得涂抹于乳房处**
- 各部位吸收率不同（手掌等角质较厚处、外阴等较薄处除外，基本在 10% 上下浮动）
- 外阴处吸收率高（约 2～5 倍），但安全性尚有争议
- 宜搭配电子秤（0.01 g 精度）计量使用

**上游的说明：** 可经皮肤吸收，**完全避免肝脏的首过效应，安全性更高。不过总体开销较大** [9]。

**另有专家共识：** 上游提到存在《雌二醇凝胶临床应用指导建议》这一专家共识 [9]。

### 5.5 注射

| 项 | 说明 |
| --- | --- |
| 一般剂量 | 10 mg / 十天左右，或 5 mg / 七天左右 [1] |
| 利用率 | 100% [1] |
| 用药间隔 | 7 天以上 |
| 血栓风险 | 同剂量下低于口服 [2] |
| 获取难度 | 高（线下交易）[1] |
| 是否需合用抗雄 | **不需要** [1] |

**上游列出的优点 [2]：** 唯一可实现单药治疗的途径；雌二醇水平高，可同时抑制睾酮；给药持久（一周以上），用药间隔长；综合成本较低。

**上游列出的缺点 [2]：** 注射瞬间有痛感，部分人可能晕针；可能引起注射部位反应；因注射技术等条件不同，效果不确定性较大；获取较困难。

**峰值数据：** 以「日雌」（戊酸雌二醇 10 mg）为例，注射后预计雌二醇最高可达 590 pg/mL，实际可能更高 [2][25]。

### 5.7 等效剂量对照

同一雌激素水平可以用不同途径达到。下表由 Aly 推算 [24]：

| 途径 | 低剂量 | 中等剂量 | 高剂量 | 超高剂量 |
| --- | --- | --- | --- | --- |
| 口服（以雌二醇计） | 2 mg/天 | 4 mg/天 | 8 mg/天 | 12 mg/天 |
| 舌下或面颊含服 | 0.5–1 mg/天 | 1–2 mg/天 | 2–4 mg/天 | 3–6 mg/天 |
| 透皮贴片 | 50–100 µg/天 | 100–200 µg/天 | 200–400 µg/天 | 300–600 µg/天 |
| 透皮凝胶 | 1.5 mg/天 | 3 mg/天 | 6 mg/天 | 9 mg/天 |
| 肌肉或皮下注射 | 1 mg/周 | 2 mg/周 | 4 mg/周 | 6 mg/周 |

**上游的提醒：** 达到相同激素水平时，**经口服的雌二醇静脉血栓风险大于含服、经皮、注射** [1][2]。

## 六、注射操作的安全原则

**上游有一篇非常详细的[自我注射](https://mtf.wiki/zh-cn/docs/medicine/estrogen/injection/at-home-injection/at-home-injection)教程 [11]。** 本页不复制完整步骤，只列出**最关键的安全原则**——这些是出错代价最大的部分。

### 6.1 肌肉注射还是皮下注射

| | 肌肉注射 | 皮下注射 |
| --- | --- | --- |
| 适用 | 长效药物通常使用 | 简单、易行 |
| 吸收 | 肌肉血液供应好，吸收较快较稳定 | 释放更平缓，水平波动稍小 |
| 容量 | **单点尽量不超过 3 mL** | **单点尽量不超过 1.5 mL** |
| 疼痛 | 不易发生局部疼痛 | 药液较多时可能疼痛 |
| 过敏 | 不易产生较重过敏反应，且消退较快 | 对载剂油过敏时清除慢，可能导致较长时间的痒、肿 |
| 部位 | 较大的肌肉（臀大肌、股外侧肌等） | — |

**上游的建议 [11]：**

- **如果这是你的第一次注射，可以选择皮下注射**
- **如果你信任自己的能力，或属于过敏体质，最好选择肌肉注射**
- **如果被发现将带来人身安全危险，那你只应选择肌肉注射**

**「如果被发现将导致人身安全危险」这条出现了两次** [11] —— 上游把它作为选择注射方式的一个考量因素。

### 6.2 卫生原则

**这几条是最重要的，出错代价最大 [11]：**

| 原则 | 说明 |
| --- | --- |
| **消毒不能替代洗手** | 用肥皂和流水洗手，这是预防感染很重要的一步 |
| **消毒后自然风干** | 皮肤或橡胶塞用酒精消毒后，应让其**自然风干约 30 秒**；**不要吹干、擦干、或摇扇** |
| **消毒后不可触摸** | 消毒后的表面和皮肤不能用手触摸；若意外触碰，需重新消毒并等待完全干燥 |
| **针头不得接触非无菌表面** | 使用时若发生，需要整套弃置 |
| **用过的器材不可再接触药物** | 在人体中使用后，或其它方式污染后的器材，不能再次接触药物或穿刺橡胶塞，**无论是否更换针头** |
| **一次性耗材不可复用** | 注射器、针头、针管均为一次性；若怀疑被污染，或在人体中使用完后，**必须立即整套弃置，不可复用，即使更换针头也不例外** |

**上游同时引用了 WHO 与 CDC 的卫生与感染安全资料作为参考** [11]。

### 6.3 注射器与针头型号

**上游列出的常见规格 [11]：**

| 用途 | 规格 |
| --- | --- |
| 胰岛素针（低死腔） | 1 mL，0.8–1.2 cm / 0.35–0.5 mm；针头不可替换 |
| **肌肉注射** | 需要 **6 号以上**针头 |
| BMI 很大时 | 可能需要 3.2 cm 的 **7–8 号**针头 |
| 多次性药瓶 + 肌肉注射 | 需要 1 mL 针管，丢弃附带的 4.5 号针头，换上 6–8 号针头 |

**「死腔」**指困在针管和针头连接处的空间。**低死腔注射器**专门设计得减少这个空间里浪费掉的药液 [11]。

### 6.4 药品储存（注射相关）

- 多次使用的瓶子可以用塑料袋装好，**放回冰箱冷藏储存**，不用把盖子重新盖上 [11]
- 具体储存条件看说明书，见[药品储存与携带](/wiki/medication-storage/)

**完整的操作步骤见上游教程 [11] 与[自我注射安全](/wiki/self-injection/)。**

## 七、抗雄激素药物

### 7.1 为什么需要抗雄

**对于尚留有性腺的 MtF，一般建议将一种抗雄激素药物与雌激素合用** [2]。

原因可以用数字说明 [2]：

- 雌二醇低于 200 pg/mL 时，**不能完全阻止**来自性腺的睾酮分泌
- 「色普龙」本身最多能抑制 **50–70%**
- **二者合用时，睾酮可减少 95%**，落入女性范围内

**经手术切除睾丸（SRS）后，一般无需加用抗雄药物** [2]。

### 7.2 醋酸环丙孕酮（CPA / 色普龙）

**上游有一篇很详细的[色普龙条目](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/cyproterone) [15]。**

| 项 | 说明 |
| --- | --- |
| 类型 | 孕激素药物；具有极强的孕激素作用，抑制卵巢功能 |
| 其他用途 | 男性前列腺癌治疗；女性因高雄激素引起的痤疮、脱发；复方避孕药（如达英-35） |
| 地位 | **现为女性化激素治疗中使用最多的抗雄药物之一** |
| 服用方式 | 口服（无明显味道） |

**剂量要点 [15]：**

| 要点 | 内容 |
| --- | --- |
| **单药不能完全抑制睾酮** | **CPA 单药治疗时，即使在最大推荐剂量（10～12.5 mg/d）下，也不能实现睾酮水平的完全抑制；只有在和雌激素合用时方可实现** |
| 建议剂量 | **10 ~ 12.5 mg/天** |
| 低剂量已足够 | 多项研究发现，在与雌二醇同时使用时 **10 mg/天左右剂量已可最大程度抑制睾酮，且效果与高剂量一致** |
| 指南建议 | **WPATH SOC-8 亦建议 10 mg/天的剂量** |
| 超低剂量 | 进一步研究发现，**每周两次 12.5 mg（等效约 3.5 mg/天）的超低剂量同样可以实现睾酮水平的充分抑制** |
| 减量 | **在推荐剂量达到效果后，尽可能减少用量至 5～6.25 mg/d。由于研究资料有限，暂不推荐减至 5 mg/d 以下** |
| 分药 | 可用切药器切为四片（即每份 12.5 mg），**每 1 ~ 3 日一服** |
| 剂量与风险 | 超出建议剂量会有更大的副作用与健康风险；低于建议剂量可能会使睾酮抑制效果不显著 |
| 效果不佳时 | 若在推荐剂量（10 mg/天）下血清睾酮水平仍较高，**请首先检查雌激素血药浓度是否足够高** |
| 补充 | **建议适量补充维生素 B12** |
| 停药 | **停药时须逐步减药** |

**副作用 [15]：**

| 类别 | 内容 |
| --- | --- |
| **脑膜瘤风险** | 可能诱发脑膜瘤，**风险与剂量和使用时长正相关**。建议尽可能以更小剂量服用；**如累积剂量已很大（高于 10 g），建议进行核磁共振扫描（MRI）** |
| **精神疾病** | 可能导致抑郁风险升高。主要原因是抗雄激素和潜在的糖皮质激素作用，**并可能诱发维生素 B12 缺乏**，而 B12 缺乏与多种精神/情绪状况的改变有关，包括抑郁 |
| **高血压与高血糖** | 可能提高体内胰岛素抗性，从而引起血糖偏高。**糖尿病患者应慎用**；并发血管病变时禁用 |
| **血栓与乳腺癌** | 与雌激素合用时可一定程度提高其风险；**也有色普龙单药引起更高血栓风险之报告** |
| **高泌乳素水平** | **可明显增加泌乳素水平，且随剂量上升**，严重时可引起**垂体泌乳素瘤**。应定期检查泌乳素水平 |
| **肝毒性** | **色普龙最严重的副作用**，与剂量相关，表现为肝转化酶水平升高；严重时可引起**肝衰竭甚至死亡**。使用前应当检查肝功能，使用时定期检查 |
| 暂未明确 | **过早导入色普龙（尤其高剂量）可能造成乳房发育不良** |

### 7.4 螺内酯

| 项 | 说明 |
| --- | --- |
| 类型 | 保钾利尿药和醛固酮的特异性拮抗剂 |
| 抗雄机制 | **阻断雄激素受体**，但**本身不会使睾酮降低**，其阻断效力较弱，需服用较大剂量方可充分起效 |
| 一般剂量 | **每天 100–400 mg，分多次服用** [1] |

**上游关于剂量的详细说明 [16]：**

> 一般对 MtF 而言，和非注射途径的中等剂量雌二醇并用时，睾酮会有大幅下降，但仍高于女性正常范围；顺性别女性用于治疗雄激素相关症状时通常需要 50～200 mg/天，而 **MtF 可能需要更高剂量（如 100～300 mg/天，乃至 400 mg/天）方可阻断剩余的雄激素**，但随之而来的尿频、高血钾等副作用可能会更严重。

**⚠️ 禁忌症与监测要求 [16]：**

| 要求 | 说明 |
| --- | --- |
| **高钾血症患者切勿服用** | 明确的禁忌症 |
| **开始前** | **血钾应小于 5.0 mmol/L，肾功能应正常** |
| **服用期间** | 定期监测**血钾、肌酐和尿酸** |
| 肝功能不全（尤其肝硬化） | **慎用**，因为螺内酯可能损害神经系统，造成昏迷 |
| 服用含锂药物（如碳酸锂）者 | 慎用，应定期监测血锂 |
| **饮食** | 避免过多食用富钾食品，如**香蕉、海带、含钾代用盐**等 |
| **药物** | **不得同时服用其它利钾药物** |
| 其他 | **多喝水** |

**副作用 [16]：**

| 副作用 | 说明 |
| --- | --- |
| **高钾血症** | **最严重的副作用，可导致住院甚至死亡** |
| 尿频 | 常见 |
| 血压、血容积过低 | — |
| 低钠血症 | **慎重与可能影响血钠的药物并用**（例如三环类、SSRI 类抗抑郁药）。必要时应监测血钠 |
| 头晕 | — |

**高钾血症风险人群 [4]：** **高年龄（超 45 岁）、肾功能不全、与其它利钾药物合用、钾补剂的服用**等，须格外注意。

**关键特点：它并不会将睾酮水平压下去，睾酮还有可能继续「捣乱」** [2]。

**延伸阅读：** [螺内酯与睾酮](https://tfsci.mtf.wiki/zh-cn/articles/spiro-testosterone/) [30]

### 7.5 比卡鲁胺

| 项 | 说明 |
| --- | --- |
| 类型 | **非甾体类**抗雄激素制剂，作用于雄激素受体，阻断其与雄激素的结合 |
| 强度 | **拮抗作用远强于螺内酯**，故可采用更低的剂量 |
| 一般剂量 | 口服，每日 25~50 mg [1] |
| 其他用途 | 广泛用于男性前列腺癌治疗 |

**⚠️ 上游的明确立场 [14]：** 据现行 WPATH SOC-8 所述，**出于现有 MtF 相关研究资料较少的缘故，现阶段不推荐将比卡鲁胺用于常规 GAHT 治疗。**

**注意事项 [14]：**

| 项 | 说明 |
| --- | --- |
| 肝损害 | **中、重度肝损害的病人应慎用** |
| **肝功能监测** | **在开始使用前应当检测血清转氨酶水平，并在服药开始 6 个月内定期监测** |
| **禁止服用人群** | 有遗传性半乳糖不耐受、Lapp 乳糖酶缺乏症或葡萄糖-半乳糖吸收障碍的患者 |
| **禁止联用** | **不可与特非那定、阿司咪唑或西沙必利联合使用** |

**价格参考 [14]：** 康士得（原研，50 mg × 28 片）挂网价 868.83 元（深圳）；国产仿制药（上海朝晖 50 mg × 14 片）162.73 元（深圳）、（浙江海正 50 mg × 28 片）193 元（上海）。**价格上大幅高于色普龙、螺内酯等常规用药。**

**关键特点：同样不会压制睾酮水平。** 对于单用比卡鲁胺而未使用雌激素的个体，可能出现睾酮与雌二醇水平较前上升 [2]。

### 7.6 GnRH 类似物

**上游有一篇详细的 [GnRH 类似物条目](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/gnrha) [13]。**

| 药物 | 常见规格 | 用法 |
| --- | --- | --- |
| 亮丙瑞林 | 1.88、3.75、11.25 mg | 常用 3.75，每月注射一次 |
| 戈舍瑞林 | 3.6、10.8 mg | 常用 3.6，每月注射一次 |
| 曲普瑞林 | 3.75 mg | 每月注射一次 |

**机制 [13]：** 分为激动剂和拮抗剂两种，作用于脑垂体 GnRH 受体；**虽然激动剂治疗初期激素水平上升，但持续治疗后，二者疗效相当，均控制激素在青春期前范围内。**

**中国大陆目前尚无 GnRH 受体拮抗剂上市** [1]。

**「青春期的暂停键」[13]：**

> 在跨性别儿童中，该治疗被比喻为「青春期的暂停键」，使青春期第二性征的发育暂停（如暂停乳房发育、阴毛生长、月经来潮，暂停阴茎阴囊增长和勃起，骨架女性化/男性化发育等），使未成年跨性别者有更多时间去探索自我、更加成熟地思考心理上的认同性别。**若成年后仍希望进行性别转变，则可接以性别肯定激素治疗；若决定不进行转变，停药后原有青春期会重新启动。**

**上游列出的关键事实 [13]：**

| 事实 | 说明 |
| --- | --- |
| 可逆性与安全性 | 常规可应用于性早熟儿童的治疗，**具有良好的可逆性和安全性** |
| 心理效果 | 国外研究显示，**该治疗可以改善跨性别青少年的性别焦虑相关心理健康** |
| **无改变认同的作用** | **其并无直接改变性别认同的作用**，对其他原发的心理病症也无直接缓解或治疗作用 |
| **无逆转作用** | **对部分已经发育的第二性征如喉结、嗓音、骨骼无逆转作用** |
| 时机 | **建议在首次表现出青春期的身体变化后开始青春期激素抑制** |
| 结局 | **与在青春期的初期阶段之后很久才开始性别肯定治疗相比，青春期早期进行青春期抑制会带来更好的心理和身体结局** |
| 前置条件 | 对于未成年跨性别者，**可以在心理科医生评估后且监护人同意的情况下使用** |

**作为抗雄药物的用途 [13]：**

> 对于完成了部分或全部青春期发育进程的跨性别女性，仍可将其作为抗雄药物使用，但无法起到逆转已经完成的发育进程的效果。
>
> **其优点在于一次用药的作用时间长，相对于醋酸环丙孕酮（CPA）不易引起包括但不限于：肝功能异常、泌乳素升高、抑郁、累积剂量过高导致的垂体瘤。**
>
> 唯须自行衡量是否值得，**因其同周期费用可能为其它抗雄药物的数十倍**，而又已经没有了「青春期阻断」这一特殊效果。

**副作用 [13]：**

| 类别 | 说明 |
| --- | --- |
| **骨量** | 应用期间影响骨量的累积，**骨密度较同龄同性别人群偏低**，且身高增长减缓；文献报道停药后该效应可逐渐消失（如随后激素治疗不够理想，骨密度仍可能会偏低）。**为此应适当补钙、补充维生素 D** |
| **手术影响** | 抑制阴囊阴茎的继续生长，**可能会对未来手术治疗产生潜在影响**（该部位皮瓣面积不及一般人群） |
| 脑发育 | 对脑发育的未知影响；**近期研究认为认知能力未受到明显影响** |
| 其他 | 敏感、易怒、躁动、注射部位疼痛、痤疮、皮疹、头痛、体重增加等 |

**价格参考 [13]：** 国内亮丙瑞林注射剂集采中标价介乎 **907.13～1650 元（中位数 1349.68 元）**。

### 7.7 不推荐使用的

| 药物 | 上游立场 |
| --- | --- |
| **非那雄胺**（5α-还原酶抑制剂） | 用于 MtF 的记录极其稀少；不清楚在睾酮被充分抑制的情况下使用有何收益；**现阶段不建议加用** [2][4] |
| 螺内酯 | 上游标注为「略不推荐」 [2] |
| 比卡鲁胺 | 上游标注为「不推荐常规应用」 [2]；SOC-8 亦不推荐 [14] |

### 7.8 方案之间怎么比

**上游的结论：任何抗雄激素方案之间没有特别明显的优劣之分，也缺乏直接比较的证据** [2]。

**但有一份可参考的资料：** 近期在北医三院进行的研究比较了「色普龙」和螺内酯的疗效，其中**乳房发育满意程度相近，但前者抑制勃起、促进体形女性化的作用更明显** [2]。

## 八、孕激素

### 8.1 上游的立场

**孕激素药物用于 MtF 的记录较少，且存在争议** [4]。

**一般来讲，除非有抗雄这样的特别需要，否则无需加用孕激素** [2]。

### 8.2 争议在哪

| 支持 | 反对 |
| --- | --- |
| 有研究显示口服孕酮、注射 MPA 等可改善对乳房发育的满意程度，且可能和精神状态改善有关 [2][3] | 口服孕酮被认为效果较差，不足以促进乳腺增生 [2] |
| — | 有人认为在 HRT 中过早引入孕激素可能导致乳房发育不理想 [2] |

**上游的评价：研究没有检查乳房情况，也没有披露孕酮是否确实改变了乳房发育的结果，所以仍不能判断孕酮作用如何** [2]。

**关于口服孕酮：** 已知口服孕酮与类似于酒精的神经甾体副作用有关；**非口服孕酮无任何已知副作用** [4]。**延伸阅读：**[口服孕酮的低水平问题](https://tfsci.mtf.wiki/zh-cn/articles/oral-p4-low-levels/) [31]

### 8.3 临床使用的孕激素

| 药物 | 说明 |
| --- | --- |
| 孕酮 | 天然的孕激素 |
| 醋酸甲羟孕酮（MPA） | 更多作为抗雄药物使用 |
| 醋酸环丙孕酮（CPA） | 同上 |

**上游不建议采用其他人工孕激素制剂：** 虽然理论上均可作为替代，但临床上缺乏用于跨性别者的经验或记载，副作用可能更为严重，或者成本较高 [2]。

**延伸阅读：**[孕激素与乳房发育](https://tfsci.mtf.wiki/zh-cn/articles/progestogens-breast-dev/) [32]

## 九、选择性雌激素受体调节剂（SERM）

**这一节主要针对非二元性别认同者和暂时不想引起乳房发育者。进行常规 HRT 的人不需要使用这类药物** [18]。

### 9.1 先看一份乳房发育的研究

**上游引用的研究结论 [18]：**

> 乳房发育程度基本和年龄之类的外界因素无关，**不同的 HRT 方案只影响发育速度，不影响最终结果**（从 4.1±2.9cm 增加到一年后的 7.9±3.1cm）。

### 9.2 SERM 的机制

**SERM 是一类作用于雌激素受体（ER）的药物 [18]：**

> 由于每一种 SERM 分子都具有不同的结构和特征，且不同组织中 ERα/β（雌激素核受体的两种亚型）的 mRNA 经过不同的选择性剪切，不同的 SERMs 在与不同的 ERs 结合后，可以诱导其产生不同的独特构象，使其与各种辅激活因子 / 辅抑制因子表现出不同的亲和度，从而**选择性地在一些方面表现出雌激素作用，而在另一些方面表现出抗雌激素作用**。

**临床上，SERMs 被用于 ER+ 乳腺癌的治疗、乳腺癌的预防、和绝经后女性中骨质疏松的预防** [18]。

**一句话总结：SERMs 可以抑制乳房发育，而在其他方面表现出雌激素作用** [18]。

### 9.3 雷洛昔芬

| 项 | 说明 |
| --- | --- |
| 受体作用 | **ERα 的部分激动剂、ERβ 的完全拮抗剂、GPER 的激动剂** |
| 雌激素作用部位 | 肝脏代谢、皮肤、骨骼、脂肪分布 |
| 抗雌激素作用部位 | **乳房发育、阴道干燥、潮热** |
| **关键特点** | **无抗促性腺激素作用** |
| 常规用途 | 顺性别女性中用于绝经后骨质疏松和乳腺癌的预防 |
| **用量** | **每日 60 mg** |

**来源：**[雷洛昔芬](https://mtf.wiki/zh-cn/docs/medicine/SERMs/raloxifene) [19]

**⚠️ 一个重要限制 [19]：**

> 值得注意的是，**不同于雌二醇，雷洛昔芬无抗促性腺激素作用，因此其不可与孕激素联合来充分降低雄激素水平**。而单独使用孕激素只可降低睾酮水平约 50%-70%，且长期使用下睾酮水平会发生一定程度的回升；螺内酯不能有效拮抗高水平的雄激素。**该方案下，一般的抗雄激素疗法（CPA 或螺内酯，皆需与雌激素合用）不适用。**

**不良反应与禁忌 [19]**（临床试验主要在绝经后顺性别女性中进行，仍有参考价值）：

| 类别 | 说明 |
| --- | --- |
| **血栓与中风** | 增加血栓和中风的风险。**在患有房颤、高血压、吸烟和有中风历史的患者中应当慎用** |
| **肝脏损伤** | 在有肝损伤的患者中应谨慎使用；是临床显著的肝损伤的**可能罕见原因** |
| **潮热** | 增加潮热发生率。在骨质疏松预防试验中，**接受雷洛昔芬治疗的志愿者中大约有 1/4 经历了潮热症状，而对照组中为 1/6** |
| **腿部痉挛** | 增加腿部痉挛发生率。骨质疏松治疗试验中为 **7.0% vs 3.7%**（雷洛昔芬 vs 安慰剂）；预防试验中为 5.9% vs 1.9% |
| **睾酮上升** | 雷洛昔芬减少肝脏合成的 IGF-1，从而反馈性地导致 GH 水平增加，且拮抗雌激素的抗促性腺激素作用，**最终导致有睾丸者体内睾酮水平的上升** |

**其他 SERM：** 中国大陆可用的还有他莫昔芬（10、20 mg，每日口服 10 mg）[1]。

# 第三部分：监测与风险

## 十、治疗期间的监测

### 10.1 复查频次

| 阶段 | 频次 |
| --- | --- |
| 开始前 | 一次全面检查，排查疾病问题 [1] |
| 用药第一年 | **每三个月**（或遵医嘱）复查一次激素 [2][4] |
| 稳定后 | 每年复查激素与其它常规**至少一次** [2][4] |
| **肝功能** | **治疗开始前检查一次，治疗期间每三个月一次** [3] |
| **肝功能（用 CPA / 比卡鲁胺时）** | **前六个月内每个月检查一次** [3] |

**依检查结果和身体反应，可能需酌情增加复查频率** [4]。

### 10.2 采血时间点

**上游的明确要求 [3]：**

> 应当在**接近下一次用药前**进行抽血检查，**不要在服用药物之后立即进行激素检查**。可以在完全六项检查之后一段时间里，只检查所关注的几项。是否空腹抽血请遵医嘱。

**⚠️ 一个具体的坑（透皮药物）[3]：**

> 如果您正在使用任何透皮类的雌激素药物，请确保您在**采血前没有在采血的手臂使用药物**，否则测出的结果将会异常偏大且没有参考价值，甚至超出仪器最大量程（有编者曾测出 E2 > 19856.78 pmol/L）。

### 10.3 检查项目

**上游列出的监测项目（分为「应监测」与「可酌情监测」）[3]：**

**应监测：**

| 项目 | 说明 |
| --- | --- |
| **性激素六项** | 其中雌二醇、睾酮、泌乳素较重要 |
| **肝功能** | 见上表的频次要求 |

**可酌情监测：**

| 项目 | 为什么 |
| --- | --- |
| **空腹血糖和胰岛素** | **雌激素以及比卡鲁胺等部分抗雄药物可影响糖耐量，使血糖升高**。血糖控制异常或有糖尿病者应谨慎，可能需增加降血糖药剂量 |
| **空腹血脂**（尤其 LDL 和甘油三酯） | **雌激素可降低低密度脂蛋白水平，提高甘油三酯水平**；**部分抗雄制剂（如螺内酯、比卡鲁胺）可提高低密度脂蛋白水平**。高甘油三酯水平与罕见的胰腺炎有关——**有相关既往史的慎用雌激素，密切监测** |
| **骨密度** | 雌二醇和睾酮均有利于维持骨密度，过低会导致骨质流失。**长期处于雌二醇、睾酮「双低」状态者应谨慎** |
| **肾功能** | **肾功能不全者慎用螺内酯**，其可能加剧高钾血症；**慎用雌激素**，其可能导致体液潴留 |
| **离子六项** | **螺内酯可能影响血液钾、钠、钙、镁等离子水平**，有相关风险者应密切监测。与其它可能影响上述离子的药物并用时格外注意 |
| **凝血功能** | **雌激素、孕激素可增强凝血，增加静脉血栓风险**。**建议术前一个月内停用雌、孕激素，术后卧床期间也应停用**；对醋酸环丙孕酮（本质是人工合成孕激素）也应酌情调整用药或主动咨询医生 |
| **血常规**（尤其红细胞和血小板） | **雌激素可导致血小板计数增加**，这与凝血功能增强有关；**醋酸环丙孕酮、比卡鲁胺等可导致红细胞计数减少**，严重者可引起贫血 |
| **甲状腺功能** | **雌激素可刺激甲状腺素结合球蛋白 (TBG) 分泌**，使甲状腺素再摄取减少。如正在或需要进行甲状腺素替代治疗，考虑监测，且可能需增加剂量 |
| **乳腺扫描** | 雌激素、孕激素可增长乳腺癌风险。**长年服用雌、孕激素应注意** |
| **脑部 MRI** | **长年、高剂量服用醋酸环丙孕酮，应注意脑膜瘤风险，一经发现须立即停药** |
| **体重和体脂** | 睾酮水平降低将使得脂肪组织增加，而雌激素可促进前体脂肪细胞成熟和分化；因此 MtF 群体中普遍可见接受 GAHT 以后体重和体脂增加的现象。**应定期测量体重，适当运动，控制饮食，避免超重** |

**其他相关指标 [3]：**

- **甲状旁腺功能不全者使用雌激素，可能导致血钙偏低**，考虑同时监测甲状旁腺素 (PTH)
- **无机磷和 PTH 水平呈负相关**，也和雌二醇水平呈负相关
- **血清铁在有贫血、肝病可能时可辅助鉴别诊断**

### 10.4 各项指标怎么看

**上游给出的判读框架（此处「正常范围」指医院给出的顺性别参考值）[3]：**

**未手术：**

| 指标 | 目标 |
| --- | --- |
| 雌二醇 | 维持女性正常范围 |
| 睾酮 | **如使用色普龙（醋酸环丙孕酮），维持女性正常范围附近** |
| FSH & LH | **如使用色普龙，低于正常范围** |
| 泌乳素 | **如使用色普龙，过高请注意** |

**睾丸移除或 SRS 后：**

| 指标 | 目标 |
| --- | --- |
| 雌二醇 | 维持女性正常范围 |
| FSH & LH | 维持女性正常范围附近。**睾丸切除后一段时间内，该项指标会偏高，如果过高，可能存在雌二醇用量不足** |

**其它指标：维持于正常参考范围之内。**

### 10.5 逐项详解

**雌二醇 (E2) [3]：**

- 是 GAHT 的指标中较为重要的内容
- 是主要的雌性激素，负责调节女性特征，促进乳腺导管系统的产生；除生殖和性功能以外，还影响脂肪组织和骨骼等器官
- 一般建议于**下一次用药前**进行检测
- **参考值：** 除针剂外——平均值 100–200 pg/mL，谷值 55–150 pg/mL，建议在 100 pg/mL 以上；针剂——谷值 200 pg/mL 以上

**睾酮 (T) [3]：**

| 用药情况 | 参考价值 |
| --- | --- |
| **使用螺内酯片** | **并不会显著降低睾酮水平，故此项的参考价值不大** |
| **使用比卡鲁胺片** | **并不会显著降低睾酮水平，部分使用者甚至会出现血清睾酮升高现象，故此项参考价值不大** |
| **使用色普龙等孕激素** | 会降低睾酮水平。**没有必要将睾酮降得过低，达到 0.55 ng/mL 以下即可，如睾酮过低可考虑减少用量** |
| 睾丸切除后 | 睾酮主要来自于肾上腺皮质。**如仍存在睾酮高于女性参考值上限，请咨询内分泌科医生** |

**FSH 与 LH [3]：**

| 情况 | 变化 |
| --- | --- |
| 使用色普龙等孕激素 | 使该项水平降低，**甚至低于检出值** |
| 使用高浓度雌二醇降雄 | 使该项水平降低，**甚至低于检出值** |
| 睾丸切除后 | **该项指标会偏高，如果过高，可能存在雌二醇用量不足** |

**泌乳素 (PRL) [3]：**

- **外源性雌、孕激素会使该项水平升高，其中色普龙（醋酸环丙孕酮）的提升作用显著**；超标时可考虑减少用量
- 此外，**精神压力、刺激乳房、某些 D2 受体拮抗药物（如部分抗精神病药、促胃肠动力药）等因素也可能使泌乳素升高**
- 女性参考范围：4.79–23.3 ng/mL
- **如果泌乳素高于正常值三倍或以上，应密切观察，酌情降低雌/孕激素剂量、换药或排查泌乳素瘤（复查脑部 MRI）**

**肝功能 (LFT) [3]：**

> 多数药物的代谢均依赖于肝脏，雌激素、抗雄制剂也不例外。其中，**比卡鲁胺、醋酸环丙孕酮已有服药期间出现急性肝衰竭（可致命）的报告**。另外，**重度肝脏疾病（如肝功能不全及肝肿瘤）也是雌激素、醋酸环丙孕酮等药的禁忌症**。

- 治疗开始前应检查一次，治疗期间每三个月检查一次
- **特别是醋酸环丙孕酮、比卡鲁胺治疗期间前六个月内，每个月检查一次**
- 尤其应关注**转氨酶水平**
- 如肝功能指标出现异常，应慎重考虑用药剂量，对症治疗，密切监视，直至恢复正常

### 10.6 去哪里查

**上游的说明 [3]：**

> 中国大陆任何一家三甲医院均可进行激素和其它血液指标检查。挂号时，应挂**内分泌科**门诊，**男科、妇科**也能提供相关检查。进行检查的理由可以如实坦白，如果是相对保守的地区也可以用激素相关的疾病复查作为理由。

### 11.4 抗雄药物：肝毒性数据

**上游引用的加拿大安全性评估结果 [4]：**

> 尽管类固醇类和非类固醇类抗雄激素药物都与肝毒性相关，但这些不良反应的发生频率及其临床特征，在不同药品间似乎有所不同。例如，观察性研究结果显示，**使用氟他胺的患者出现肝毒性事件的发生频率高于那些使用醋酸环丙孕酮的患者（15.3% 比 9.5%，p=0.034）**。
>
> 此外，这项研究发现在**严重的肝毒性（定义为肝酶水平升高大于 6 倍正常值上限）事件中，使用氟他胺者占 4.8%，使用醋酸环丙孕酮者占 3.8%**。在严重肝毒性事件中，使用比卡鲁胺和尼鲁米特者罕有报告。

### 11.5 抗雄药物：脑膜瘤的监管限制

**上游引用的欧盟限制 [4]：**

> 现有数据并未表明含有 **1 或 2 毫克的低剂量环丙孕酮与炔雌醇或雌二醇联用**治疗痤疮、多毛症、避孕或激素替代疗法的风险。然而，作为预防措施，**这些药物不应用于脑膜瘤患者或有脑膜瘤病史者**。含高剂量环丙孕酮的药物已有该限制。

### 11.6 雌激素：EMA 关于高强度雌二醇乳膏

**上游引用 [4]：**

> PRAC 审查了关于高强度雌二醇乳膏用于治疗绝经期妇女阴道萎缩症状的安全性和有效性的现有数据。这些数据表明，绝经后妇女使用这些乳膏后，**血液中的雌二醇水平高于正常绝经后的水平**。PRAC 的结论是，雌二醇在血液中的吸收值得关注，可能导致与激素替代疗法 (HRT) 相似的副作用……**基于这些原因，PRAC 建议这些乳膏一个疗程最多只能使用 4 周。**

| 类型 | 表现 |
| --- | --- |
| **血栓** | 单侧肢体肿痛、胸痛、呼吸困难、剧烈头痛、视力变化 |
| **肝损伤** | 皮肤或眼白发黄、尿色变深、持续恶心、右上腹痛 |

## 十二、药物相互作用

**上游有一整节专门讨论这个 [4]，并给出警告：**

> 如需服用 GAHT 以外的任何药物，务必就药物相互作用问题咨询医师，并查阅说明书相关内容！

**上游同时说明：** 诸 GAHT 药物之间以及与其它药物之间的相互作用非常复杂，且强度不一，需要海量资料来建立其关系；目前只能通过各药品的说明书内容和药代动力学研究资料来做大致判断。**考虑到 MtF 当中精神疾病的流行率较高，此处会特别指明与精神药品的关系** [4]。

### 12.1 肝酶代谢关系

**这是理解相互作用的基础。主要 GAHT 用药均依赖或影响肝酶代谢 [4]：**

| 药物 | 与肝酶的关系 |
| --- | --- |
| 雌二醇、雌二醇酯 | **依赖 CYP3A4 代谢** |
| 醋酸环丙孕酮 | **依赖 CYP3A4 代谢** |
| 醋酸甲羟孕酮 | **依赖 CYP3A4 代谢** |
| **螺内酯** | **有诱导 CYP3A4 的作用**；另可能抑制其它 CYP3A 酶系和 CYP2C11 |
| 比卡鲁胺 | (S)-对映体经 CYP3A4 代谢，(R)-对映体部分经此代谢；**有抑制 CYP3A4 的潜力**，但体内研究表明作用不明显 |
| GnRH 类似物 | 曲普瑞林**很少被肝酶代谢** |

**「依赖 CYP3A4 代谢」意味着什么：** 抑制剂会使其代谢减慢（血药浓度升高）；诱导剂会使其代谢加快、疗效减弱 [4]。

### 12.2 GAHT 用药之间的相互作用

**上游列出「可能存在相互作用的情况包括但不限于」[4]：**

| 组合 | 说明 |
| --- | --- |
| **雌二醇与螺内酯** | 现有文献评述中，螺内酯单药用于顺性别男性时，雌二醇水平不变或小幅增加，雌激素尿排出量增加 |
| **雌二醇与比卡鲁胺** | 由于比卡鲁胺使睾酮增加，而睾酮可被芳香化成为雌二醇，使雌二醇同步增加，故**难以判断比卡鲁胺是否会抑制雌二醇代谢** |
| **人工孕激素与比卡鲁胺** | 理论上比卡鲁胺会抑制人工孕激素代谢。**不建议并用** |
| **GnRH 类似物与人工孕激素** | 据曲普瑞林说明书，由于高泌乳素血症可导致 GnRH 受体减少，故不建议将其与可诱发高泌乳素水平的药物并用。**实际上，在已使用 GnRH 类似物的情况下，是无需采取额外抗雄手段的** |

### 12.3 与其它药物的相互作用

| 组合 | 说明 |
| --- | --- |
| **螺内酯与升高血钾的药物** | 二者并用导致**高钾血症的风险增大** |
| **螺内酯与部分精神药品** | **抑制锂剂排出，锂毒性可能增加**；与**三环类、SSRI 类抗抑郁药**并用可能导致**低钠血症**；另外可能影响经 CYP3A4 和 CYP2C11 代谢的药物 |
| **比卡鲁胺与部分药品** | 可能影响经 CYP3A4 代谢的药物；**可能影响抗凝剂的疗效** |
| **雌二醇、人工孕激素与影响肝酶的药品** | 代谢可能受到 CYP3A4 抑制剂或诱导剂的影响 |
| **螺内酯、人工孕激素与血浆蛋白** | 这两种抗雄制剂均与血浆白蛋白高度结合，**不能排除其会跟其它强结合药物竞争白蛋白的可能**。并用时二者的游离血药浓度均可能增加，导致作用和副作用增强。可能需要降低其中一种强结合药物的剂量。**这类药物包括抗抑郁药舍曲林** |
| **雌二醇与血浆蛋白** | 生理水平下的雌二醇绝大部分与血浆蛋白结合（多数结合于白蛋白，少数结合于 SHBG）。虽然会受到竞争白蛋白的其它药物影响，但由于雌二醇也会引起 SHBG 增加，故游离浓度变数可能较大 |
| **共用 CYP3A4 代谢途径的药品** | 剂量较大时，相关副作用发生的风险可能增大。**应以最低有效剂量服药** |
| **酒精** | **已知酒精可降低醋酸环丙孕酮的效力** |

# 第四部分：特殊情况与法规

## 十三、预期效果与时间线

**资料来自北医三院和多份医学指南** [1][2]。

| 作用效果 | 出现时间 | 稳定时间 |
| --- | --- | --- |
| 乳房发育 | 3–6 月 | 2–5 年 |
| 体脂重新分布 | 3–6 月 | 2–5 年 |
| 肌肉质量、力量降低 | 3–6 月 | 1–2 年 |
| 皮肤变软、油性减少 | 3–6 月 | 未知 |
| 肢端毛发生长减少 | 6–12 月 | ≥ 3 年 |
| 脱发减少 | 不定 | 不定 |
| 性欲减退 | 1–3 月 | 1–2 年 |
| 自发勃起减少 | 1–3 月 | 3–6 月 |
| 睾丸体积减小 | 3–6 月 | 2–3 年 |
| 男性性功能障碍 | 未知 | 2 年 |
| 精子产量减少 | 不定 | 不定 |
| **声音改变** | **无** | — |

**声音一栏标注为「无」，可以寻求[嗓音训练](https://mtf.wiki/zh-cn/docs/vocal-therapy/overview)或[声带手术](https://mtf.wiki/zh-cn/docs/vocal-surgery/overview)来改变声音** [1][2]。

**注意「出现」和「稳定」是两回事。** 详细说明见 [HRT 会改变什么、不会改变什么](/wiki/hrt-effects/)。

## 十四、特殊情况

### 14.1 青春期阻断

见第七章 7.6 节的完整说明，另见[青春期阻断](/wiki/puberty-blockers/)。

**核心要点：** 在 Tanner II～III 期介入；成本高；注意监测骨密度；国内尚无 GnRH 受体拮抗剂上市；**青春期早期进行抑制会带来更好的心理和身体结局** [1][13]。

### 14.2 非二元方案

**目标：去男性化，但同时仅引入一部分女性化效果** [1]。

| 方案 | 思路 |
| --- | --- |
| **SERM + 抗雄** | 用雷洛昔芬等维持骨密度，同时避免乳房发育；**抗雄仍需要**，但注意雷洛昔芬方案下常规抗雄疗法不适用，见第九章 [1][19] |
| **低剂量雌激素 + 抗雄** | 沿用常规方案但减少雌激素用量，目标雌二醇 30～50 pg/mL [1] |

详见[非二元是什么](/wiki/nonbinary/)与上游的[非二元方案说明](https://tfsci.mtf.wiki/zh-cn/articles/nonbinary-transfem-overview/) [34]。

### 14.3 生育力保存

**上游的明确表述 [2]：**

> 长期 HRT 会减弱性功能、使生育力受损。如希望**保存生育力**，建议在 HRT 开始前进行。即使已接受 HRT，**停药后数月内生育力也会缓慢恢复**——但停药反应，尤其是精神上的不适可能较明显，需谨慎安排。

**效果表中的相关条目：** 精子产量减少——出现时间「不定」、稳定时间「不定」[2]。

详见[生育力保存](/wiki/fertility/)。

### 14.4 围手术期

**上游关于凝血的明确要求 [3]：**

> 长年服用高剂量雌、孕激素，或者**接受手术前**，应格外注意；**建议术前一个月内停用雌、孕激素，术后卧床期间也应停用**，对于醋酸环丙孕酮（本质是人工合成孕激素）也应酌情调整用药或主动咨询专业医生。

**已完成嗓音女性化手术者：** 全身麻醉手术涉及气管插管，**请务必术前与麻醉科医师确认风险** [35]。

详见[术前准备与公证](/wiki/surgery-prep/)。

## 十五、用药原则与常见误区

### 15.1 上游给出的原则

1. **应用激素应当逐步加量，停药应当逐步减量** [2]
2. **用药的原则是在维持效果的情况下尽量减少用量** [2]
3. **不宜同时出现雌激素和雄激素「双低」** —— 长此以往将引起骨质疏松、盗汗等一系列更年期症状；要保持骨密度，需至少确保其中一种激素居于主导 [2]
4. **如不存在血栓风险等特殊情况，一般需长期服用雌二醇**；即使切除了性腺（SRS）以后亦然 [2]
5. **除青春期阻断之外，一般不建议长期（一个月以上）单用抗雄制剂** [2]
6. **激素治疗期间请勿吸烟，酌情饮酒，适量运动** [2]
7. **睾酮下降需要数日方可完成**，用药初期不宜操之过急 [2]
8. **应在开始治疗前认真阅读说明书**，尤其是药物相互作用部分；治疗期间不时回顾 [4]
9. **如必须并用其他药物，密切监测；出现任何不适随诊，千万别瞒着医生** [4]

### 15.2 常见误区

| 误区 | 事实 | 来源 |
| --- | --- | --- |
| 「吃药能改变骨架/身高/声音」 | 骨骼在成年后基本定型；效果表明确标注「声音改变：无」 | [1][2] |
| 「剂量越大效果越好」 | 高于 200 pg/mL 不会带来更强的女性化作用 | [2] |
| 「可以自己换方案」 | 不同机制的药物，监测指标和风险都不同 | [1] |
| 「验血没必要」 | 指标异常大部分没有体感 | [2] |
| 「注射更省事」 | 省的是给药频率，多的是时间点管理和操作要求 | [2][25] |
| 「CPA 可以单药」 | **单药即使在最大推荐剂量下也不能完全抑制睾酮**，只有与雌激素合用才行 | [15] |
| 「螺内酯能降睾酮」 | **不会**。它阻断受体，所以睾酮检查参考价值不大 | [3][16] |
| 「比卡鲁胺也是常规选项」 | **SOC-8 不推荐用于常规 GAHT** | [14] |
| 「乳房发育取决于方案」 | 研究表明**不同 HRT 方案只影响发育速度，不影响最终结果** | [18] |

## 十六、法规与获取

**2022 年 11 月 30 日**，国家药监局发布《药品网络销售禁止清单（第一版）》，将**环丙孕酮**与**雌二醇**列为「用药风险较高的品种」及「其他禁止通过网络零售的药品」 [36]。

**2023 年 7 月 10 日**，国家药监局综合司在复函中强调，禁止含雌二醇单方的复合包装产品经网络销售，所涉产品含「克龄蒙」 [37]。

**这意味着这些药物在国内无法通过正规网络渠道零售。** 本站不建议任何形式的私下交易。

**上游提到的现实情况 [1]：**

| 剂型 | 获取难度 |
| --- | --- |
| 口服 | 低（药店和医院） |
| 贴片 | 较低（线上，需改搜索关键词；搜索示例「更年期贴片」「荷尔蒙贴片」） |
| 凝胶 | 较低（医院，少数连锁药店可预订） |
| 注射 | 高（线下交易） |

**获取途径的现实情况见**[HRT 医疗资源怎么用](/wiki/hrt-resources/)与[中介与骗局识别](/wiki/scam-awareness/)。

## 十七、常见问题

**「什么时候开始都不晚吗？」**
上游的原话：**HRT 介入的最佳时机是十年前和现在；任何时候用药都不晚** [1]。诚然大龄能改变的地方有限。

**「为什么一定要雌二醇？」**
见第四章。其他雌激素要么效力较弱，要么血栓风险远高于雌二醇 [1][2]。

**「可以换用另一种途径吗？」**
可以。等效剂量对照见 5.7 节 [1]。

**「雌二醇高于 200 pg/mL 会更好吗？」**
不会。除抑制促性腺激素与睾酮外，不会带来更强的女性化作用 [2]。

**「漏服怎么办？」**
**不要自行加倍补注。** 记录后联系医生，见[漏服、停药与调整](/wiki/missed-dose/)。

**「想停药怎么办？」**
**应当逐步减量。不要自己突然停**，见[漏服、停药与调整](/wiki/missed-dose/)。

**「需要加孕激素吗？」**
一般不需要，除非有抗雄等特别需要 [2]。

**「抗雄药哪种最好？」**
上游：**没有特别明显的优劣之分，也缺乏直接比较的证据** [2]。

**「CPA 吃多少？」**
**上游与 SOC-8 建议 10 mg/天**；研究显示这个剂量已可最大程度抑制睾酮。**减量可至 5～6.25 mg/d，暂不推荐减至 5 mg/d 以下** [15]。

**「为什么 CPA 要补维生素 B12？」**
因为 CPA 可能诱发 B12 缺乏，而 B12 缺乏与包括抑郁在内的多种精神/情绪状况改变有关 [15]。

**「螺内酯要注意什么？」**
**高钾血症患者切勿服用**；开始前血钾应小于 5.0 mmol/L 且肾功能正常；期间定期监测血钾、肌酐和尿酸；避免富钾食品；不得同时服用其它利钾药物；多喝水 [16]。

**「比卡鲁胺要注意什么？」**
**开始前检测血清转氨酶，服药开始 6 个月内定期监测**；**不可与特非那定、阿司咪唑或西沙必利联用**；中重度肝损害慎用 [14]。

**「用透皮药物采血要注意什么？」**
**不要在采血的手臂使用药物**，否则结果会异常偏大、没有参考价值 [3]。

**「能自己买药吗？」**
跳过了监测环节，风险最大。且在国内属违规渠道 [36][37]。

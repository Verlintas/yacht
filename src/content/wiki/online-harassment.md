## 先保安全，再谈维权

**如果涉及现实威胁（有人知道你的住址、说要来找你、有人跟踪），优先处理人身安全：**

- 告诉可信任的人你的处境
- 必要时报警
- 暂时调整出行路线与作息
- 检查社交账号的定位与个人信息暴露

## 第一时间：取证

**这是最容易被忽略、也最不可逆的一步。** 内容会被删除、账号会被注销。

**要截什么：**

- [ ] 发布内容本身（含时间戳、账号 ID、浏览量）
- [ ] 发布者的主页（用户名、ID、头像、简介）
- [ ] 评论区（含点赞数）
- [ ] 私信与威胁信息
- [ ] 转发与扩散情况
- [ ] 你的账号主页（证明被攻击的对象是你）

**怎么截：**

- **不要只截内容，要带上平台界面与网址**，证明来源
- **滚动截图或录屏**，避免被指为拼接
- **多个设备备份**（本地 + 加密云盘）
- **可以的话做时间戳固定**（例如通过区块链存证平台或公证处）

<div class="guide">
<strong>一个常见错误</strong>
<p>很多人气头上直接对骂、或者立刻注销账号——这两件事都会让取证变难。</p>
<p>正确顺序是：<b>先静默取证，再决定怎么回应。</b></p>
</div>

## 平台渠道

1. **举报与投诉** —— 各平台的举报入口，选择「人身攻击 / 泄露隐私 / 骚扰」
2. **要求删除** —— 明确要求平台下架内容并保留证据
3. **保留平台回复** —— 平台的处理结果与时间也是证据

**平台不作为时**，可以向网信部门举报。**具体举报入口以各平台与主管部门公布的信息为准**，本站不复述渠道名称与号码。

## 法律渠道

| 情形 | 可能涉及 |
| --- | --- |
| 侮辱、诽谤 | 可能涉及名誉权纠纷；情节严重的可能构成犯罪 |
| 公开你的身份信息 | 可能涉及个人信息权益、隐私权 |
| 威胁、恐吓 | 视情节可能构成违法或犯罪 |
| 传播你的照片 | 可能涉及肖像权、隐私权 |

**上表是常见分类，不是法律意见。具体定性与可主张的赔偿，需要咨询律师。** 上游的[常见法律问题](https://mtf.wiki/zh-cn/docs/useful-info/legal-faq)条目讨论了类似情形，另见[常见法律问题索引](/wiki/legal-faq-index/)。

## 该不该回应

**没有标准答案。** 两种做法都有代价：

| 做法 | 风险 |
| --- | --- |
| 公开回应 | 可能扩大传播；个人信息进一步暴露 |
| 完全不回应 | 攻击可能持续；也可能被当成默认 |

**如果决定回应：**

- 只陈述事实，不做情绪化反击
- 不透露更多个人信息
- 把证据准备好，说明已保存并将走法律渠道
- 回应一次即可，不参与持续对骂

**如果决定不回应：**

- 关闭评论、设置隐私
- 暂时离开那个平台
- 找人支持自己，不要独自消化

## 心理上的处理

网络暴力会造成真实的心理伤害。**这不是「玻璃心」。**

- 暂时离开屏幕，减少反复查看
- 找信得过的人说说
- 如果持续失眠、情绪低落、出现自伤想法，见[社群与互助](/wiki/community/)里的危机资源
- **不要用对方的恶意来评价自己**

## 关于平台责任

**平台对用户发布的内容通常负有管理义务。**

| 你可以要求的 | 说明 |
| --- | --- |
| **下架侵权内容** | 通过举报入口 |
| **提供发布者信息** | **通常需要司法机关介入**，个人无法直接获取 |
| **保留证据** | 平台通常有义务在一定期限内保留日志 |
| **处理结果告知** | 保留平台的回复作为记录 |

**如果平台不作为**，可以向网信部门举报。

**具体举报入口与流程以各平台与主管部门公布的信息为准**，本站不复述渠道名称与号码。

**涉及诉讼时，需要律师协助调取平台数据。** 见[常见法律问题索引](/wiki/legal-faq-index/)。

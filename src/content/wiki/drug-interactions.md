## 上游的原话

来自 [MtF.wiki《HRT 全面指南》](https://mtf.wiki/zh-cn/docs/medicine/overview)：

> **如需服用 HRT 以外的任何药物，务必就药物相互作用问题咨询医师，并查阅说明书相关内容！**

## 「任何药物」包括哪些

**「任何药物」是字面意思。** 下面这些类别属于**常见合并用药**：

| 类别 | 例子 |
| --- | --- |
| 感冒药 / 退烧药 | 含对乙酰氨基酚、伪麻黄碱的复方制剂 |
| 止痛药 | 非甾体抗炎药 |
| 胃药 | 部分质子泵抑制剂 |
| 抗生素 | 部分经同一肝酶代谢 |
| 抗抑郁药 / 精神科药物 | 可能影响泌乳素或代谢 |
| **保健品** | 圣约翰草、大豆异黄酮等 |
| **中药 / 中成药** | 成分复杂，相互作用难以评估 |
| 外用药 | 部分经皮吸收 |
| 酒 | 影响肝脏代谢 |

**具体相互作用需查说明书或咨询药师。**

## 为什么这件事重要

上游把药物相互作用列为[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)的一部分，并要求查阅说明书。

| 原因 | 说明 |
| --- | --- |
| **肝脏代谢通道共享** | 两种药走同一个酶，可能互相影响浓度 |
| **激素类药物本身需肝脏代谢** | 见[肝功能指标怎么看](/wiki/liver-function/) |
| **部分组合会叠加风险** | 例如影响凝血、泌乳素、电解质 |
| **保健品不是「没有作用」** | 有作用就可能有相互作用 |

**本站不逐条列出具体的相互作用对。** 因为这类信息必须依据具体药品的说明书，而不同厂家的说明书可能不同。

**请查你手上药品的说明书，或咨询药师。**

## 实际做法

**就诊时主动提供一份「正在使用清单」：**

- [ ] 全部处方药
- [ ] 非处方药（**包括偶尔吃的**）
- [ ] 保健品、维生素
- [ ] 中药 / 中成药
- [ ] 外用药

**写法：药名 + 剂型 + 使用频率。** 不必写剂量，但如果你知道，写上更清楚。

<div class="guide">
<strong>买药前问一句</strong>
<p>在药店或网上买任何药之前，说清楚「我正在用雌激素和抗雄药物」，请药师确认有没有相互作用。</p>
<p><b>看医生时同理</b>——不管是看什么科，都要主动提。</p>

## 特别提醒

| 提醒 | 说明 |
| --- | --- |
| **不要自行加用其他激素类产品** | 包括某些「丰胸」「调经」类保健品，成分可能含激素或类激素物质 |
| **不要同时使用多种来源不明的药物** | — |
| **饮酒要酌情** | 上游建议激素治疗期间不吸烟、酌情饮酒 |
| **葡萄柚汁** | 会影响部分药物代谢（这是药品说明书上常见的提示项），具体问药师 |
| **手术前** | 需要停用部分药物，由医生安排，见[术前准备与公证](/wiki/surgery-prep/) |

## 出现这些情况要考虑相互作用

| 信号 | 说明 |
| --- | --- |
| 开始用新药后出现明显不适 | — |
| 激素水平异常波动，但方案没变 | — |
| 肝功能指标突然变化 | — |
| 睡眠、情绪、性欲明显改变 | — |
| 泌乳素升高 | 部分药物会影响，见[泌乳素升高怎么办](/wiki/prolactin/) |

**带全部药物清单去找医生，比自己排查有效。**

## 关于「中药/中成药」

**这是最容易被忽略的一类。**

| 问题 | 说明 |
| --- | --- |
| 成分复杂 | 往往含多种成分，相互作用难以评估 |
| 说明书信息有限 | 部分中成药的相互作用信息不完整 |
| 容易被当成「温和的」 | 但「有作用」和「有相互作用」是同一件事的两面 |

**服用任何中成药前，告诉医生或药师你正在使用的全部药物。**

## 常见问题

**「感冒药算吗？」**
**算。** 上游说的是「任何药物」，包括非处方药。

**「保健品算吗？」**
**算，而且是最容易被忽略的一类。** 有作用就可能有相互作用。

**「中药算吗？」**
**算。** 成分复杂，相互作用难以评估。

**「偶尔吃一次要紧吗？」**
**可能要紧。** 具体取决于药物与剂量。**不确定时问药师。**

**「医生没问，我需要主动说吗？」**
**需要。** 主动提供「正在使用清单」。

**「怎么查两种药有没有相互作用？」**
上游提到：如果懂一些英语，可以在 **Drugs.com** 查询两种药品（英文名称）之间是否存在相互作用。

**「发现相互作用了怎么办？」**
**不要自己停药或改药。** 联系医生或药师。

## 肝酶代谢关系（上游整理）

**这是理解相互作用的基础：**

| 药物 | 与肝酶的关系 |
| --- | --- |
| 雌二醇、雌二醇酯 | **依赖 CYP3A4 代谢** |
| 醋酸环丙孕酮 | **依赖 CYP3A4 代谢** |
| 醋酸甲羟孕酮 | **依赖 CYP3A4 代谢** |
| **螺内酯** | **有诱导 CYP3A4 的作用**；另可能抑制其它 CYP3A 酶系和 CYP2C11 |
| 比卡鲁胺 | (S)-对映体经 CYP3A4 代谢，(R)-对映体部分经此代谢；**有抑制 CYP3A4 的潜力** |
| GnRH 类似物 | 曲普瑞林**很少被肝酶代谢** |

**含义：** 抑制剂会使其代谢减慢（血药浓度升高）；诱导剂会使其代谢加快、疗效减弱。

## GAHT 用药之间的相互作用（上游整理）

| 组合 | 说明 |
| --- | --- |
| **雌二醇与螺内酯** | 螺内酯单药用于顺性别男性时，雌二醇水平不变或小幅增加，雌激素尿排出量增加 |
| **雌二醇与比卡鲁胺** | 比卡鲁胺使睾酮增加，而睾酮可被芳香化成为雌二醇，使雌二醇同步增加，故**难以判断比卡鲁胺是否会抑制雌二醇代谢** |
| **人工孕激素与比卡鲁胺** | 理论上比卡鲁胺会抑制人工孕激素代谢。**不建议并用** |
| **GnRH 类似物与人工孕激素** | 不建议与可诱发高泌乳素水平的药物并用。**实际上，已使用 GnRH 类似物时无需额外抗雄** |

## 与其它药物的相互作用（上游整理）

| 组合 | 说明 |
| --- | --- |
| **螺内酯与升高血钾的药物** | **高钾血症的风险增大** |
| **螺内酯与锂剂** | **抑制锂剂排出，锂毒性可能增加** |
| **螺内酯与三环类、SSRI** | 可能导致**低钠血症** |
| **比卡鲁胺与抗凝剂** | **可能影响抗凝剂的疗效** |
| **螺内酯、人工孕激素与舍曲林** | 均与血浆白蛋白高度结合，**可能竞争白蛋白**，导致作用和副作用增强 |
| **共用 CYP3A4 代谢途径的药品** | 剂量较大时副作用风险增大。**应以最低有效剂量服药** |
| **酒精与醋酸环丙孕酮** | **酒精可降低其效力** |

## 上游的实用建议

- **应在开始治疗之前认真阅读说明书**，尤其是药物相互作用部分；治疗期间不时回顾
- 如果懂一些英语，可以在 **Drugs.com** 查询
- **如必须并用，请注意密切监测**；并用期间出现任何不适或异常应随诊
- **让医生知悉一切并对症下药，千万别瞒着！**

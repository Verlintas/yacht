## 上游的原话

> **如需服用 HRT 以外的任何药物，务必就药物相互作用问题咨询医师，并查阅说明书相关内容！**

「任何药物」是字面意思，包括下面这些容易被忽略的：

| 类别 | 例子 |
| --- | --- |
| 感冒药 / 退烧药 | 含对乙酰氨基酚、伪麻黄碱的复方制剂 |
| 止痛药 | 非甾体抗炎药 |
| 胃药 | 部分质子泵抑制剂会影响其他药物代谢 |
| 抗生素 | 部分经同一肝酶代谢 |
| 抗抑郁药 / 精神科药物 | 可能影响泌乳素或代谢 |
| 保健品 | 圣约翰草、大豆异黄酮等 |
| 中药 / 中成药 | 成分复杂，相互作用难以评估 |
| 外用药 | 部分经皮吸收 |
| 酒 | 影响肝脏代谢 |

## 为什么这件事重要

1. **肝脏代谢通道是共享的。** 两种药走同一个酶，可能互相影响浓度。
2. **激素类药物本身需要肝脏代谢。** 见[肝功能指标怎么看](/wiki/liver-function/)。
3. **部分组合会叠加风险。** 例如影响凝血、影响泌乳素、影响电解质。
4. **保健品不是「没有作用」的意思。** 有作用就可能有相互作用。

## 实际做法

**就诊时主动提供一份「正在使用清单」：**

- 全部处方药
- 非处方药（包括偶尔吃的）
- 保健品、维生素
- 中药 / 中成药
- 外用药

**写法：药名 + 剂型 + 使用频率。** 不必写剂量，但如果你知道，写上更清楚。

<div class="guide">
<strong>买药前问一句</strong>
<p>在药店或网上买任何药之前，说清楚「我正在用雌激素和抗雄药物」，请药师确认有没有相互作用。</p>
<p>看医生时同理——不管是看什么科，都要主动提。</p>
</div>

## 特别提醒

- **不要自行加用其他激素类产品。** 包括某些「丰胸」「调经」类保健品，成分可能含激素或类激素物质。
- **不要同时使用多种来源不明的药物。**
- **饮酒要酌情。** 上游建议激素治疗期间不吸烟、酌情饮酒。
- **葡萄柚汁**会影响部分药物代谢，具体问药师。

## 出现这些情况要考虑相互作用

- 开始用新药后出现明显不适
- 激素水平异常波动，但方案没变
- 肝功能指标突然变化
- 睡眠、情绪、性欲明显改变

**带全部药物清单去找医生，比自己排查有效。**

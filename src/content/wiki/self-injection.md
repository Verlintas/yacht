## 这一页的定位

**本站不写操作步骤。** 注射涉及无菌操作、部位选择、进针角度和并发症处理，文字描述不足以替代演示。

**正确的学习顺序：**

1. 让医生或护士**当面演示一次**
2. 在对方观察下**自己操作一次**
3. 之后按上游教程复习细节

上游的[自我注射](https://mtf.wiki/zh-cn/docs/medicine/estrogen/injection/at-home-injection/at-home-injection)条目有详细图文说明，**那是操作依据，本页不是**。

## 注射与其他途径的关键区别

上游在[雌激素药物](https://mtf.wiki/zh-cn/docs/medicine/estrogen)部分列出了各途径的对比。注射的独特之处：

| 特点 | 说明 |
| --- | --- |
| **利用率 100%** | 不经肝脏首过效应，也不受皮肤吸收率影响 |
| **可单药治疗** | 上游说明：注射是**唯一可实现单药治疗**的途径 |
| **给药间隔长** | 一周以上 |
| **波动大** | 峰谷差明显，采血时间点尤其关键 |
| **需要专业操作** | 上游标注为「需专业操作使用」 |

**「唯一可单药治疗」的原因：** 上游解释，雌二醇水平达到并维持 200 pg/mL 以上时，可对促性腺激素形成负反馈，从而几乎中止性腺的睾酮分泌。其他途径要达到这个水平，成本与不便都会显著上升。

## 需要提前确认的事

| 事项 | 为什么重要 |
| --- | --- |
| **是肌注还是皮下** | 两种操作的部位、针具、角度都不同，不能混用 |
| **针具规格** | 与注射方式、药液黏度相关，不能通用 |
| **药品的储存条件** | 上游指出部分针剂对温度与避光有要求 |
| **注射部位轮换** | 长期同一部位注射可能造成硬结 |
| **废弃针具的处理** | 避免扎伤，尤其是有同住者或儿童时 |
| **出现异常怎么办** | 提前知道该联系谁 |

**具体规格与储存条件看药品说明书**，不同产品差异很大（上游[针剂](https://mtf.wiki/zh-cn/docs/medicine/estrogen/injection)条目说明了不同产品的包装与用法差异）。

## 无菌原则（概括）

以下是**原则**，不是操作步骤：

- 操作前洗手，操作区域清洁
- 药液按说明保存，注意有效期与开封期限
- 一次性针具不重复使用
- 不与他人共用任何器具
- 注射部位消毒后等干再进针
- 针具与药液避免接触非无菌表面

**具体手法看上游教程与医护演示。**

## 采血时间点：注射方案尤其要注意

**注射的峰谷差比口服和经皮都大**，所以采血时间点的要求更严格。

以「日雌」（戊酸雌二醇 10 mg）为例，上游提到注射后预计雌二醇峰值可达 590 pg/mL（见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)）。

**这意味着：**

- 「下次给药前抽血」的要求必须遵守
- 不同时间点抽的血，数值可以差好几倍
- **不能拿注射后的峰值去和其他途径的谷值比较**

见[激素六项怎么看](/wiki/hormone-panel/)与[治疗期间的监测](/wiki/monitoring-index/)。

## 需要尽快就医的情况

**出现以下任一情况，尽快就医，并告知医生你正在使用激素：**

| 类型 | 表现 |
| --- | --- |
| **局部感染** | 注射部位明显红肿、发热、剧痛或化脓 |
| **过敏反应** | 皮疹、面部或喉部肿胀、呼吸困难 |
| **血栓信号** | 单侧肢体肿痛、胸痛、呼吸困难、剧烈头痛、视力变化 |
| **药液异常** | 药液明显浑浊、变色或有颗粒（**此时不要注射**） |

**血栓信号与注射途径没有直接关系，但与雌激素使用有关**，见[血栓风险与自我评估](/wiki/thrombosis-risk/)。

## 常见问题

**「可以自己换注射部位吗？」**
轮换部位是常规做法，但**具体哪些部位可用、怎么轮换，要问医生或护士**。不是所有部位都适合。

**「针头可以重复使用吗？」**
不可以。一次性针具重复使用会增加感染、断针与组织损伤风险。

**「漏了一次注射怎么办？」**
**不要自行加倍补注。** 先记录，然后联系医生。见[漏服、停药与调整](/wiki/missed-dose/)。

**「可以带着针剂出门或坐飞机吗？」**
可以，但要注意储存条件与运输规定。见[药品储存与携带](/wiki/medication-storage/)。

**「晕针怎么办？」**
上游把晕针列为注射的注意事项之一。**如果晕针，注射途径可能不适合你**——可以和其他剂型比较，见[雌激素类药物对照](/wiki/estrogen-compare/)。

**「注射后多久能洗澡？」**
**按医生或说明书的要求。** 本站不给出时间建议。

## 与监测的配合

注射同样需要按方案复查，**而且时间点要求更严**。复查项目包括激素、肝功能、血常规等，见[治疗期间的监测](/wiki/monitoring-index/)。

**注射不等于「更省事」。** 它省的是给药频率，多的是时间点管理和操作要求。

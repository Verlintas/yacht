## 一般路径

身份证上的性别信息**依据户籍信息**。所以顺序通常是：

```
1. 先变更户籍信息（户口本）  ← 见 household-register
2. 再换领身份证
```

**反过来办不通**，因为公安系统里的身份证信息来自户籍登记。

## 常见材料

各地要求不同，通常会涉及：

- 户口本
- 原身份证
- **医院出具的相关证明**（常见是手术证明，具体要求各地不同）
- 书面申请
- 近期证件照

**具体清单以当地派出所或政务服务中心的要求为准。** 上游的[户口身份证变更指引](https://mtf.wiki/zh-cn/docs/srs/id-card)有更细的整理，也记录了各地实际办理的经验。

## 常见卡点

| 卡点 | 说明 |
| --- | --- |
| **医院证明的格式** | 各地对证明的内容与格式要求不同，可能要求特定表述 |
| **证明的出具医院** | 有的地方要求指定级别或指定医院 |
| **是否要求手术** | 各地口径不一，且可能变化 |
| **窗口不熟悉流程** | 一线工作人员可能没办过这类业务，需要耐心沟通或换窗口 |
| **异地办理** | 通常需要回户籍地办理 |
| **办理周期** | 换领身份证本身有制证周期，要留出时间 |
| **姓名与性别同时变更** | 顺序问题，见[改名流程](/wiki/name-change/) |

## 如果被拒

1. **问清依据。** 「请问是需要补充什么材料，还是不予受理？能给我书面说明吗？」
2. **记录。** 记下办理时间、窗口、经办人、答复内容。不是为了对抗，是为了下次不重复解释。
3. **换渠道。** 政务服务中心、上级公安机关、政务服务热线都可以尝试。
4. **找参考。** 上游指引里可能有其他人遇到相同情况的处理经验。
5. **寻求协助。** 涉及权益问题时，可以联系公益组织，见[常见法律问题](https://mtf.wiki/zh-cn/docs/useful-info/legal-faq)。

**完整的申诉路径见[被拒绝后的申诉路径](/wiki/appeal-path/)。**

## 办理时的实用建议

| 建议 | 原因 |
| --- | --- |
| **提前打电话问清材料** | 避免白跑 |
| **带齐材料的原件和复印件** | 部分窗口收原件，部分收复印件 |
| **多复印几份关键材料** | 窗口可能收走 |
| **避开月初和月末** | 办事高峰，等待时间长 |
| **记下窗口电话** | 后续查询进度用得上 |
| **如果第一次没办成，换个时间或窗口再试** | 不同经办人熟悉程度不同 |

## 变更之后

身份证更新完，还有一串东西要跟着改：

| 类别 | 项目 |
| --- | --- |
| **金融** | 银行卡、信用卡、证券、支付账户 |
| **通信** | 手机号实名、宽带 |
| **学历** | 学籍、学历（见[学籍与学历变更](/wiki/education-records/)） |
| **社会保障** | 医保、社保、公积金（见[医保与社保](/wiki/healthcare-insurance/)） |
| **出行** | 护照、港澳台通行证、驾驶证（见[护照与旅行证件](/wiki/travel-documents/)） |
| **工作** | 劳动合同、人事系统、工牌 |
| **生活** | 房产、车辆、会员卡、各类实名账号 |

**顺序框架见[实名信息变更总览](/wiki/real-name-overview/)。**

## 常见问题

**「身份证能直接改性别吗？」**
不能。**必须先改户籍信息**，身份证依据户籍登记。

**「换领需要多久？」**
有制证周期，各地不同。**换领期间旧证可能被收回**，所以要提前规划出行与办事安排。

**「可以代办吗？」**
多数情况需要本人到场（涉及人像采集）。**具体问当地窗口。**

**「照片要重新拍吗？」**
换领通常需要重新采集人像，见[证件照拍摄](/wiki/id-photos/)。

**「变更记录会显示在身份证上吗？」**
身份证上不显示变更记录。户籍系统内部保留历史记录。

## 隐私提醒

**不要把自己的证件照片、变更材料、办理回执发到公开平台。**

这类图片含有完整身份信息。需要在社群里提问时，**把姓名、证件号、住址、具体窗口名称全部遮掉**。

见[安全与隐私基础](/wiki/safety-privacy/)与[个人信息与隐私保护](/wiki/privacy-law/)。

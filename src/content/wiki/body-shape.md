## 先说前提

**HRT 会改变体脂分布，但需要时间**（3–6 月开始，2–5 年稳定）——见 [HRT 效果表](https://mtf.wiki/zh-cn/docs/medicine/overview)与[HRT 会改变什么](/wiki/hrt-effects/)。

**在等待期间，着装是最快见效、完全可逆的方式。**

## 三个关键比例

| 目标 | 做法 |
| --- | --- |
| **提高腰线** | 高腰裤/裙，把视觉腰线上移 |
| **柔化肩线** | 落肩、插肩袖、V 领、船领；**避免垫肩、硬挺肩线** |
| **增加下半身量感** | A 字裙、阔腿裤、百褶；**避免紧身直筒** |

**核心逻辑：让上下半身的宽度差变小。**

**不是「遮住」，是「改比例」。** 这两者的区别在于：前者容易显得臃肿，后者看起来自然。

## 版型比尺码重要

| 要点 | 说明 |
| --- | --- |
| **不要只看尺码标签** | 不同品牌尺码差异很大，试穿为准 |
| **合身 > 宽松** | 过度宽松反而显壮 |
| **面料垂坠感很重要** | 硬挺面料容易撑出棱角 |
| **注意长度** | 裙长、裤长、袖长都会影响视觉比例 |

## 颜色与图案

| 做法 | 效果 |
| --- | --- |
| 上深下浅 | 弱化上半身量感 |
| 竖向线条 | 拉长视觉 |
| 小图案 | 比大图案更柔和 |
| **避免横条纹、大面积亮色在上身** | 会强调肩宽 |

**不必把自己限制在「女性化颜色」里。** 黑、灰、深蓝一样可以穿出想要的效果。

## 配饰与细节

| 配饰 | 作用 |
| --- | --- |
| **围巾** | 增加颈部与胸前层次，柔化肩颈线条 |
| **项链** | V 形垂坠可拉长颈部视觉 |
| **腰带** | 强调腰线位置 |
| **鞋** | 跟高不必高，2–3 cm 已经能改变站姿与比例 |
| **内衣** | 合适的支撑与形态调整可以明显改变轮廓 |

## 体型与姿态

**姿态对观感的影响常被低估：**

- 收下巴、肩胛骨微收、挺胸
- 避免含胸驼背
- 走路时重心稳定，步幅适中

**这一条同时有健康意义**（减少腰背负担），见 [NHS 健康身体](https://www.nhs.uk/live-well/healthy-body/)。

**详细说明见[仪态与肢体语言](/wiki/posture-mannerisms/)。**

## 分阶段的做法

| 阶段 | 建议 |
| --- | --- |
| **刚开始** | 先换一两件基础款（高腰裤、A 字裙、落肩外套） |
| **有感觉后** | 整理出适合的版型与颜色，建立「自己的模板」 |
| **长期** | 按 HRT 后的体型变化重新调整 |

**不必一次换完整个衣柜。** 可逆的事，慢慢试。

**建议：** 试穿时拍全身照（正面 + 侧面），比照镜子更容易看出效果。

## 关于「要不要做手术改变体型」

**HRT 不会改变骨架。** 肩宽、肋廓、身高在青春期后基本固定。

**想改变这些需要手术**（见[手术五类导览](/wiki/surgery-overview/)），但**着装与体态调整通常能解决大部分日常观感问题**，而且零风险。

**先试非手术的方式，再考虑是否需要手术。**

## 一个提醒

**外表不是资格。**

**不需要先穿成什么样才能开始过自己的生活，也没有「穿对了」的标准。**

**着装是工具，用多少、怎么用，由你决定。** 有人很在意，有人完全不在意，都正常。

**如果着装让你更焦虑而不是更自在**，那就先放一放。**舒服比「正确」重要。**

## 常见问题

**「需要买很贵的衣服吗？」**
**不需要。** 版型和比例比价格重要。**基础款 + 对的版型通常比贵的错版型效果好。**

**「一定要穿裙子吗？」**
**不必。** 高腰阔腿裤、落肩外套一样能改变轮廓。**颜色也不限于「女性化颜色」。**

**「HRT 后体型会变吗？」**
会。**体脂重新分布 3–6 月开始，2–5 年稳定。** 但**骨架不会变**，见[HRT 会改变什么](/wiki/hrt-effects/)。

**「要不要等 HRT 效果出来再买衣服？」**
**不必。** 着装是可逆的，可以边试边调整。**等 HRT 稳定再重新调整更实际。**

**「身高/肩宽能靠着装改变吗？」**
**视觉上可以改善，实际尺寸不会变。** 见下「三个关键比例」。

**「为什么我穿什么都不好看？」**
**大概率是版型或尺码问题，不是你的问题。** 建议：试穿、拍照、对比不同版型。

## 三个关键比例的详细做法

| 目标 | 做法 | 避免 |
| --- | --- | --- |
| **提高腰线** | 高腰裤/裙、把上衣扎进裤子、用腰带 | 低腰裤、长上衣盖过臀部 |
| **柔化肩线** | 落肩、插肩袖、V 领、船领、有垂坠感的面料 | 垫肩、硬挺肩线、方领、横条纹 |
| **增加下半身量感** | A 字裙、阔腿裤、百褶、有体积感的下装 | 紧身直筒、上宽下窄 |

## 一、常见的创伤来源

**跨性别者可能遇到的创伤，有些是共通的，有些是特定的：**

| 类型 | 具体情形 |
| --- | --- |
| **校园霸凌** | 言语侮辱、排挤、肢体冲突、网络霸凌 |
| **家庭暴力** | 打骂、限制人身自由、经济控制、强迫「矫正」 |
| **被公开身份** | 未经同意被他人公开（outting），尤其在危险环境中 |
| **医疗创伤** | 被拒诊、被贬损、被要求额外条件、隐私被泄露 |
| **性暴力** | 与身份相关的性暴力发生率更高 |
| **职场歧视** | 被辞退、被排挤、被威胁 |
| **亲密关系暴力** | 被伴侣以身份相要挟 |
| **制度性羞辱** | 办证、就医、办事过程中的反复刁难 |
| **长期否定** | 从小到大反复被否定「你不对」 |

**⚠️ 重要：这些经历造成的影响是真实的，不是「想太多」。**

## 二、创伤反应可能长什么样

**一般人群的常见创伤反应（NHS）[1]：**

| 类别 | 表现 |
| --- | --- |
| **闪回** | 反复出现创伤场景的画面、声音或感觉 |
| **噩梦** | 与创伤相关的梦 |
| **回避** | 回避与创伤相关的人、地点、话题 |
| **过度警觉** | 容易受惊、时刻紧张、难以放松 |
| **易怒** | 情绪爆发、难以控制 |
| **睡眠问题** | 难以入睡、睡眠浅、易惊醒 |
| **麻木** | 感觉不到情绪，与人对不上 |
| **身体反应** | 头痛、肠胃问题、心悸、疼痛 |
| **自我评价** | 自责、羞耻、觉得是自己的错 |
| **信任** | 难以信任他人 |

**具体诊断标准与建议见 [NHS 创伤后应激障碍页面](https://www.nhs.uk/mental-health/conditions/ptsd-post-traumatic-stress-disorder/) [1]。**

**⚠️ 有这些反应不等于「得了 PTSD」。** 诊断需要专业人员做。但**如果有这些反应且影响生活，就值得找帮助**。

## 三、几个特别值得说的情形

### 3.1 被公开身份（outting）

**这可能是最常见、也最容易被低估的创伤来源。**

| 反应 | 说明 |
| --- | --- |
| **安全感崩塌** | 你不知道还有谁知道、还会传到哪里 |
| **持续的警惕** | 见到人就紧张，担心被认出来 |
| **愤怒与羞耻交织** | 气对方，也气自己 |
| **对社群的失望** | 如果是社群里的人做的，打击更大 |

**可以做的事：**

| 步骤 | 做法 |
| --- | --- |
| 1 | **先确认范围** —— 谁知道了、传到哪里了 |
| 2 | **评估实际风险** —— 有没有安全、经济、工作上的威胁 |
| 3 | **保留证据** —— 如果是恶意传播，见[网络暴力与取证](/wiki/online-harassment/) |
| 4 | **不需要向所有人解释** —— 你没有义务回应 |
| 5 | **找人支持** —— 不要独自消化 |

### 3.2 医疗创伤

**被医生贬损、被拒诊、被要求与诊疗无关的条件——这些会留下印记。**

**常见的后续影响：**

| 影响 | 说明 |
| --- | --- |
| **回避就医** | 明知该去也不想去 |
| **就诊时高度紧张** | 心率血压异常，影响检查结果 |
| **不敢如实说明** | 影响医生判断 |

**可以做的事：**

| 做法 | 说明 |
| --- | --- |
| **换机构** | 上游的名单通常不止一家 |
| **带人陪同** | 见[就医陪同](/wiki/hospital-companion/) |
| **提前说明紧张** | 医生可以给你更多时间 |
| **出示日常测量记录** | 上游提到：若因紧张导致心率血压异常，可出示可穿戴设备或自行测量的近期记录代替 |
| **保留记录** | 时间、地点、对话内容，必要时用于投诉 |

**⚠️ 如果回避就医已经影响到必要的治疗，这本身值得找专业帮助。**

### 3.3 家庭内的暴力与控制

**这些是明确的越界行为，不是「家人关心你」：**

- 限制人身自由（锁门、没收手机、禁止出门）
- 强迫就医或强迫「矫正」
- 经济胁迫（以学费、生活费为条件）
- 暴力或暴力威胁
- 强制要求断绝与朋友、社群的来往

**处理顺序：**

| 步骤 | 做法 |
| --- | --- |
| 1 | **先离开或降低风险** |
| 2 | **联系可信任的人** |
| 3 | **必要时报警** |
| 4 | **见[常见法律问题索引](/wiki/legal-faq-index/)** |
| 5 | **见[危机资源与紧急情况](/wiki/crisis-resources/)** |

## 四、可以做的事

**一般人群的自助方向（NHS）[2]：**

| 方向 | 说明 |
| --- | --- |
| **不回避谈论** | 与可信任的人谈论创伤，通常比压着好 |
| **保持规律作息** | 睡眠、饮食、活动稳定对情绪有直接作用 |
| **减少酒精** | 酒精会加重创伤反应，也会影响睡眠质量 |
| **重建安全感的日常** | 固定的作息、熟悉的环境、可预测的安排 |
| **身体层面的调节** | 规律运动、呼吸练习、放松训练 |
| **给自己时间** | 创伤反应不是「快点好起来」的问题 |

**完整的自助资源见 [NHS 心理健康自助指南](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/) [2]。**

**⚠️ 自助方法的作用是「撑过一段时间」，不能替代专业帮助。**

## 五、什么时候必须找人

| 信号 | 行动 |
| --- | --- |
| **出现伤害自己的想法或行为** | **紧急情况**，见[危机资源与紧急情况](/wiki/crisis-resources/) |
| 闪回或噩梦频繁影响生活 | 找咨询师或精神科 |
| 持续回避必要的活动（如就医、上学、工作） | 尽快就诊 |
| 用酒精或药物缓解 | 尽快找专业帮助 |
| 持续两周以上的低落或焦虑 | 见[焦虑与抑郁](/wiki/anxiety-depression/) |

**创伤相关的心理治疗是有证据支持的**，具体形式与适用见 [NHS 页面](https://www.nhs.uk/mental-health/conditions/ptsd-post-traumatic-stress-disorder/) [1] 与 [WPATH SOC-8](https://project-trans.org/SOC-8/) [8]。

## 六、一个提醒

**创伤反应不是软弱，也不是「过不去」。**

**它是身体和大脑对超出承受范围的事件做出的正常反应。** 治疗是有效的，很多人确实会好转。

**你不需要先「变得坚强」才能开始治疗。**

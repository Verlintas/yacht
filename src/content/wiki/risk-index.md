## 怎么读这一页

风险讨论容易走两个极端：要么被说成「完全安全」，要么被说成「非常危险」。**两种都不准确。**

实际的情况是：**风险类型明确，风险大小因人而异，且大部分可以通过监测和调整来管理。**

**上游的原话：** 发现任何健康问题，请立即就医 [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

## 按类型索引

### 1. 静脉血栓

| 项 | 内容 |
| --- | --- |
| 上游定性 | **雌激素最严重的不良反应之一**，严重时可导致心肌梗塞与中风 |
| 风险更高的情形 | 口服雌二醇、使用人工合成雌激素（如炔雌醇） |
| 相关因素 | 吸烟、年龄、既往血栓史、家族史、长期不动 |
| 剂型差异 | **同剂量下经口服的风险大于含服、经皮、注射** |
| 监测手段 | 凝血相关项目、病史询问 |
| 需要就医的信号 | 单侧肢体肿痛、呼吸困难、胸痛、剧烈头痛、视力变化 |

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview) · [用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)

**详细说明见[血栓风险与自我评估](/wiki/thrombosis-risk/)。延伸阅读：[雌激素与血栓](https://tfsci.mtf.wiki/zh-cn/articles/estrogens-blood-clots/)。**

### 2. 肝功能

| 项 | 内容 |
| --- | --- |
| 上游定性 | 部分药物经肝脏代谢；**色普龙与比卡鲁胺需格外注意** |
| 具体风险 | 色普龙：肝毒性、良性与恶性肝脏肿瘤（可能引起致命性腹内出血） |
| | 比卡鲁胺：肝毒性、肝衰竭 |
| 监测手段 | 肝功能指标（ALT、AST 等），治疗初期尤其重要 |
| 需要就医的信号 | 皮肤或眼白发黄、尿色变深、持续恶心、右上腹痛、异常乏力 |

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview) · [比卡鲁胺片](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/bicalutamide) · [色普龙](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/cyproterone)

**详细说明见[肝功能指标怎么看](/wiki/liver-function/)。**

### 3. 泌乳素相关

| 项 | 内容 |
| --- | --- |
| 上游定性 | 部分孕激素类药物需要关注 |
| 相关药物 | 醋酸环丙孕酮、醋酸甲羟孕酮 |
| 特别提示 | **色普龙服用 5 年以上，应接受脑部 CT 或磁共振（MRI）扫描以排除肿瘤** |
| 监测手段 | 泌乳素（PRL） |
| 需要就医的信号 | 持续加重的头痛（尤其晨起）、视力变化、异常分泌 |

**来源：**[色普龙](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/cyproterone) · [醋酸甲羟孕酮](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/medroxyprogesterone) · [治疗期间的监测](https://mtf.wiki/zh-cn/docs/medicine/monitoring)

**详细说明见[泌乳素升高怎么办](/wiki/prolactin/)。延伸阅读：[醋酸环丙孕酮与脑膜瘤风险](https://tfsci.mtf.wiki/zh-cn/articles/cpa-meningioma/)。**

### 4. 电解质与肾功能

| 项 | 内容 |
| --- | --- |
| 相关药物 | 螺内酯 |
| 上游定性 | 最常见不良反应为**高钾血症**、胃肠道反应；最严重为**高钾血症（高风险者可引起猝死）** |
| 监测手段 | 血钾、肾功能；肾功能不全时尤其注意 |
| 需要就医的信号 | 心悸、肌肉无力、心律异常 |

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview) · [螺内酯片](https://mtf.wiki/zh-cn/docs/medicine/antiandrogen/spironolactone)

### 5. 乳腺癌

| 项 | 内容 |
| --- | --- |
| 上游定性 | 雌激素最严重的不良反应之一 |
| 风险更高的情形 | 口服雌二醇或人工合成雌激素 |
| 相关因素 | **家族成员有乳腺癌病史的须注意** |
| 监测手段 | 按医生建议进行自检与筛查 |

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview) · [HRT 简明指南](https://mtf.wiki/zh-cn/docs/medicine/zero-to-hrt)

**延伸阅读：[乳腺癌风险](https://tfsci.mtf.wiki/zh-cn/articles/breast-cancer/)。**

### 6. 骨密度

| 项 | 内容 |
| --- | --- |
| 上游定性 | **不宜同时出现雌激素和雄激素「双低」**，长此以往将引起骨质疏松、盗汗等更年期症状 |
| 相关情形 | 长期单用抗雄制剂、术后未继续用雌激素、青春期阻断期间 |
| 监测手段 | 骨密度（视医生判断） |

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)

**详细说明见[骨密度与骨骼健康](/wiki/bone-density/)。**

### 7. 常见但通常较轻的反应

| 类型 | 上游表述 |
| --- | --- |
| 雌激素 | 乳房紧张/乳房疼痛、腹痛、水肿与头痛 |
| 孕激素 | 口服孕酮与类似于酒精的神经甾体副作用有关；**非口服孕酮无任何已知副作用** |
| 色普龙 | 体重增加或减轻、抑郁、性欲降低、勃起功能障碍、精子产量减少（**停药后可逆**） |
| 比卡鲁胺 | 男性乳房发育、潮热、疼痛、乏力、便秘、感染、恶心、外周性水肿、呼吸急促、腹泻、尿血、遗尿、贫血 |
| 螺内酯 | 高钾血症、胃肠道反应（恶心、呕吐、胃痉挛、腹泻） |

**来源：**[HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)

## 影响风险大小的因素

| 因素 | 说明 |
| --- | --- |
| **吸烟** | 上游明确建议激素治疗期间不要吸烟 |
| **年龄** | 部分风险随年龄上升 |
| **既往病史** | 血栓、心血管疾病、肝肾疾病、偏头痛 |
| **家族史** | 血栓、乳腺癌、心血管疾病 |
| **合并用药** | 包括保健品与中药 |
| **剂型与给药方式** | 口服的血栓风险相对更高 |
| **是否按监测方案复查** | **直接决定问题能否被早发现** |

## 怎么降低风险

1. **在医生指导下用药，不要自行调整。**
2. **按方案复查。** 这是最有效的一条。
3. **如实告知病史与用药史**，包括吸烟、饮酒、其他药物与保健品。
4. **选择风险更低的剂型**（如适用），和医生讨论。
5. **不吸烟。**
6. **出现异常及时联系医生。**
7. **不要叠加来源不明的药物。**

## 关于「长期安全性」

这是合理的关切，也是上游资料和指南都在持续更新的部分。

**上游提到：目前的研究表明，在专业医生的指导和风险把控下进行激素治疗是安全的** [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

**本站不复述具体发生率数字**——数字需要跟着研究更新，且高度依赖个体情况。想了解当前认识，看上游条目与指南原文。

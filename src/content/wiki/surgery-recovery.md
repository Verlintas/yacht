## 这一页的定位

**本站不写具体护理操作。** 术后护理高度依赖术式、医院方案和个体情况，文字描述不足以替代医嘱和护士的当面指导。

**正确的做法是：**

1. 出院前把医嘱问清、记下来
2. 按医院给的复诊时间表复查
3. **有疑问直接联系手术医院**，不要自己上网找答案
4. 需要操作细节时，看上游的[术后护理](https://mtf.wiki/zh-cn/docs/srs/care)条目——部分医院的条目里有非常具体的流程（如[上海四一一医院的术后护理页](https://mtf.wiki/zh-cn/docs/srs/china/sh411/postoperative-care)）

## 恢复期的分阶段节奏

不同术式差别很大，但通常都会经历这几个阶段：

| 阶段 | 特点 | 你要做的 |
| --- | --- | --- |
| **住院期** | 以卧床和观察为主 | 让医护教你护理方法，把医嘱记下来 |
| **出院初期** | 需要有人帮忙，活动受限 | 重点防感染；按医嘱用药与清洁 |
| **恢复中期** | 逐步恢复日常活动 | 仍避免剧烈运动；按计划复查 |
| **稳定期** | 基本恢复日常 | 继续按计划复查；注意长期注意事项 |

**具体时间以医生给的时间表为准。** 不要拿别人的恢复速度要求自己。

**上游的医院条目里通常会有分阶段的说明**（例如上海四一一医院的条目包含住院流程与术后护理两页），值得在术前就读一遍。

## 需要立刻联系医生的情况

| 类别 | 表现 |
| --- | --- |
| **感染** | 发热；伤口红肿、渗液异常、明显疼痛加重 |
| **出血** | 出血量增加或持续不止 |
| **排尿** | 排尿困难或明显异常 |
| **血栓** | 单侧肢体肿痛、呼吸困难、胸痛 |
| **心理** | 情绪严重低落，或出现伤害自己的想法 |

**不确定算不算异常的时候，打电话问。多问一次没有代价。**

血栓信号与手术、卧床、雌激素使用都有关，见[血栓风险与自我评估](/wiki/thrombosis-risk/)。

## 复查

- **按医院给的复诊时间表走**，不要自行调整。
- **异地手术的话，提前问清复查能不能在当地做**、需要带什么材料。
- **保留全部出院材料和检查报告**，后续办证、复诊都可能用到，见[材料与档案管理](/wiki/records-management/)。
- **术后仍需按医嘱使用雌激素**（如适用）。上游明确指出：即使切除了性腺，一般也需长期服用雌二醇 [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

## 恢复期的生活安排

| 事项 | 建议 |
| --- | --- |
| **请假** | 提前申请。学生可以说「医疗原因」，不必交代细节，见[请假与考试](/wiki/leave-exam/) |
| **陪护** | 出院初期一个人会比较吃力，见[就医陪同](/wiki/就医陪同/) |
| **住处** | 优先选离医院近的，方便复查与应急 |
| **衣物** | 准备宽松衣物 |
| **饮食** | 易消化的食物；具体忌口问医生 |
| **运动** | **不要急着恢复运动**，什么时候可以恢复问医生 |
| **通勤** | 恢复期避免长时间颠簸与久坐 |
| **药物** | 按医嘱使用，包括止痛、抗感染等；**不要自行加用其他药物**，见[药物相互作用与合并用药](/wiki/drug-interactions/) |

## 关于扩张（如适用）

**部分术式需要长期扩张。** 具体要求（频率、时长、持续多久）**由医生决定**，且与术式相关。

**上游的[手术技术](https://mtf.wiki/zh-cn/docs/srs/tech)与[术后护理](https://mtf.wiki/zh-cn/docs/srs/care)条目有说明。**

**本站不给出扩张方案。** 频率与时长是个体化的，照抄别人的方案可能有害。

## 心理上的准备

**恢复期是情绪最容易出问题的阶段，原因很具体：**

| 原因 | 说明 |
| --- | --- |
| 身体不适 | 疼痛、活动受限、睡眠受影响 |
| 孤立感 | 独处时间变长，与外界接触减少 |
| 期待落差 | 术后早期的外观与功能通常不是最终结果 |
| 激素波动 | 围手术期的用药调整可能影响情绪 |
| 后悔情绪 | 术后短期内出现怀疑是**已知的现象**，不代表决定错了 |

**可以做的是：**

- **提前安排支持。** 让至少一个人知道你的恢复期安排。
- **不要用术后早期的状态评价手术结果。** 稳定需要时间，问医生大概多久。
- **找人说话。** 社群里有经历过同样过程的人，见[社群与互助](/wiki/community/)。
- **如果情绪持续低落或出现自伤想法，立刻求助**，见[危机资源与紧急情况](/wiki/crisis-resources/)与[怎么找心理咨询](/wiki/finding-counselor/)。
- **允许自己慢慢来。** 恢复期不是效率竞赛。

## 关于「术后后悔」

**上游在 HRT 部分提到：有证据表明，成年跨性别者采取激素治疗后出现反悔意愿的几率非常低** [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

**但术后短期内出现情绪波动、怀疑、甚至后悔的想法是常见的**，通常与恢复期的身体状态和心理压力有关。

**如果这种想法持续存在，值得找咨询师谈，而不是独自消化。** 见[怎么找心理咨询](/wiki/finding-counselor/)。

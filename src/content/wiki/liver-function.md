## 为什么肝要单独查

**部分药物经肝脏代谢**，所以肝功能是监测的常规项目。上游的[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)把肝功能列为独立的风险方向。

尤其是用**醋酸环丙孕酮**和**比卡鲁胺**时，上游明确提示要格外注意肝功能。

## 报告单上常见的项目

| 缩写 | 中文 | 说明 |
| --- | --- | --- |
| ALT | 谷丙转氨酶 | 最常看的指标之一 |
| AST | 谷草转氨酶 | 常与 ALT 一起看 |
| GGT | γ-谷氨酰转肽酶 | 与胆汁淤积、饮酒相关 |
| ALP | 碱性磷酸酶 | 与胆道、骨骼相关 |
| TBIL / DBIL | 总胆红素 / 直接胆红素 | 黄疸相关 |
| ALB | 白蛋白 | 反映肝脏合成功能 |

**参考范围各实验室不同，以报告单上的范围为准。**

## 怎么理解「异常」

**轻度升高不等于肝损伤。** 影响因素很多：

- 熬夜、疲劳、剧烈运动
- 饮酒
- 近期感冒或其他感染
- 其他合并用药
- 脂肪肝

**重要的是趋势和幅度：**

| 情况 | 通常的处理 |
| --- | --- |
| 轻度升高，无症状 | 医生可能建议复查、观察 |
| 明显升高 | 需要评估是否调整用药 |
| 升高伴乏力、食欲差、黄疸 | 尽快就医 |

<div class="guide">
<strong>不要自己解读「箭头」</strong>
<p>报告单上的箭头只表示超出参考范围，不代表临床意义。是否要紧，取决于升高幅度、变化趋势、有没有症状、以及你正在用什么药。</p>
<p>把报告带给开药的医生，比自己查资料可靠。</p>
</div>

## 需要立刻就医的信号

- 皮肤或眼白发黄
- 尿色明显变深（像浓茶）
- 持续恶心、呕吐、食欲明显下降
- 右上腹持续疼痛
- 异常乏力

**出现这些不要等到下次复查。**

## 怎么降低风险

1. **按方案复查**，尤其是开始用药的头几个月。
2. **不饮酒，或尽量少饮。** 上游建议激素治疗期间不要吸烟、酌情饮酒。
3. **不自行加用其他药物或保健品。** 很多成分也经肝代谢，见[药物相互作用](/wiki/drug-interactions/)。
4. **如实告知医生既往肝病史。**
5. **保持规律作息。** 熬夜会直接影响指标，也会干扰对报告的判断。

## 关于「长期安全性」

这是合理的关切。上游资料和指南都在持续更新这部分内容，**本站不复述具体数据**——数字需要跟着研究更新。

想了解当前认识，看上游的[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)条目与指南原文。

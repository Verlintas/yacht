## 一、为什么这两个更常见

**跨性别群体中焦虑与抑郁的发生率高于一般人群。**

**但原因不是「因为是跨性别」，而是：**

| 原因 | 说明 |
| --- | --- |
| **少数群体压力** | 长期面对歧视、偏见、被否定 |
| **隐瞒的负担** | 长期隐藏身份需要持续的精力 |
| **家庭冲突** | 被拒绝、被威胁、失去支持 |
| **医疗流程的阻力** | 挂号难、被拒诊、排期长 |
| **社会环境的敌意** | 媒体、政策、日常遭遇 |
| **身体与身份的不一致** | 性别焦虑本身带来的痛苦 |

**这个区分很重要：** 如果把它理解成「跨性别导致抑郁」，就会得出「不做跨性别就好了」的错误结论。**实际上，压力来源是社会环境，不是身份本身。**

**所以减少歧视与增加支持，是有效的干预。** 这也是[给家人、伴侣与朋友的指南](/wiki/for-family-friends/)存在的原因。

## 二、抑郁：识别信号

**一般人群的常见信号（NHS）[2]：**

| 类别 | 表现 |
| --- | --- |
| **情绪** | 持续低落、空虚、绝望、易哭 |
| **兴趣** | 对以前喜欢的事失去兴趣 |
| **精力** | 持续疲乏，做小事也费力 |
| **睡眠** | 入睡困难、早醒、睡不醒 |
| **食欲** | 明显减少或增加，体重变化 |
| **注意力** | 难以集中、难以做决定 |
| **身体** | 不明原因的疼痛、头痛、消化问题 |
| **社交** | 回避与人接触 |
| **自我评价** | 自责、无价值感 |
| **最严重** | **出现伤害自己的想法** |

**⚠️ 关键的判断标准不是「有没有某一条」，而是：**

| 标准 | 说明 |
| --- | --- |
| **持续时间** | 大多数日子、持续两周以上 |
| **功能影响** | 影响到工作、学习、社交或日常生活 |

**具体诊断标准与自助建议见 [NHS 抑郁页面](https://www.nhs.uk/mental-health/conditions/depression/) [2]。**

**注意：** 诊断需要专业人员做，**上面这张表不是诊断工具**。见[自评量表的边界](/wiki/self-test-scales/)。

## 三、焦虑：识别信号

**一般人群的常见信号（NHS）[3]：**

| 类别 | 表现 |
| --- | --- |
| **心理** | 持续的担心、难以控制的忧虑、预感坏事会发生 |
| **身体** | 心悸、出汗、颤抖、肌肉紧张、头晕、肠胃不适 |
| **行为** | 回避某些场合、反复确认、难以放松 |
| **睡眠** | 难以入睡、睡眠浅 |
| **注意力** | 难以集中，容易烦躁 |

**具体分类与自助建议见 [NHS 广泛性焦虑障碍页面](https://www.nhs.uk/mental-health/conditions/generalised-anxiety-disorder/) [3]。**

**⚠️ 注意区分：**

| 类型 | 说明 |
| --- | --- |
| **焦虑情绪** | 面对具体压力时的正常反应，通常随压力源消失而缓解 |
| **焦虑障碍** | 持续存在、与压力源不成比例、影响功能 |
| **激素相关的情绪波动** | 可能与 HRT 水平变化有关，见下 |

## 四、一个重要区分：是不是激素引起的

**上游提到性激素会影响认知、情绪和行为** [见 [HRT 全面指南](https://mtf.wiki/zh-cn/docs/medicine/overview)]。

**所以情绪变化可能有几个来源：**

| 来源 | 特征 | 怎么办 |
| --- | --- | --- |
| **激素水平变化** | 常在开始用药、调整剂量、漏服或停药后出现 | **带记录找医生，不要自行停药** |
| **性别焦虑本身** | 与身体或社会对待相关 | 见[性别焦虑是什么](/wiki/gender-dysphoria/) |
| **外部压力** | 与具体事件相关（被拒诊、家庭冲突） | 见[情绪管理](/wiki/emotion-management/) |
| **独立的心理问题** | 持续存在，与上述都不明显相关 | 找咨询师或精神科 |

**⚠️ 不要自行判断是哪种。** 把记录带给医生，由专业人员判断。见[用药记录怎么做](/wiki/hrt-log/)。

**特别是：不要因为「觉得是药的问题」而自己停药。** 见[漏服、停药与调整](/wiki/missed-dose/)。

## 五、可以做的事

**一般人群的自助方法（NHS）[4]：**

| 方法 | 说明 |
| --- | --- |
| **保持规律作息** | 睡眠、饮食、活动的稳定对情绪有直接影响 |
| **规律运动** | 见[体重、饮食与运动](/wiki/weight-nutrition/) |
| **减少酒精** | 酒精会加重抑郁与焦虑 |
| **与人保持联系** | 哪怕只是简单聊天 |
| **把任务拆小** | 抑郁时「做完一件事」比「做对」重要 |
| **写下来** | 把担心的事写下来，比在脑子里循环好 |
| **限制信息摄入** | 尤其是社群里的负面信息与比较 |

**完整的自助资源见 [NHS 心理健康自助指南](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/) [4]。**

**⚠️ 自助方法的作用是「撑过一段时间」，不能替代专业帮助。** 如果两周以上没有改善，或者情况在恶化，请找人。

## 六、什么时候必须找人

**出现以下情况，不要等：**

| 信号 | 行动 |
| --- | --- |
| **出现伤害自己的想法或行为** | **紧急情况**，见[危机资源与紧急情况](/wiki/crisis-resources/) |
| 持续两周以上的低落或焦虑 | 找咨询师或精神科 |
| 无法工作或学习 | 尽快就诊 |
| 睡眠、食欲明显改变 | 就诊 |
| 用酒精或药物来缓解情绪 | 尽快找专业帮助 |

**求助路径：**

| 选项 | 说明 |
| --- | --- |
| **找咨询师** | 见[怎么找心理咨询](/wiki/finding-counselor/) |
| **找精神科** | 如需药物干预，只有精神科医师可以开药 |
| **找社群** | 见[社群与互助](/wiki/community/) |
| **找朋友** | 「我最近不太好」就够了 |
| **危机资源** | 见[危机资源与紧急情况](/wiki/crisis-resources/) |

## 七、关于「要不要告诉医生」

**在精神科评估时，焦虑与抑郁是会被问到的内容。**

**如实回答不会让你「失去资格」。** 相反：

| 情况 | 说明 |
| --- | --- |
| 有抑郁或焦虑 | 医生会评估是否需要同时处理 |
| 正在用精神科药物 | 需要注意药物相互作用，见[药物相互作用与合并用药](/wiki/drug-interactions/) |
| 有过自伤史 | 医生需要知道，以便评估风险与安排支持 |
| **隐瞒** | 可能导致评估失准，也可能漏掉必要的支持 |

**上游提到「考虑到 MtF 当中精神疾病的流行率较高」，因此在用药风险页特别说明了与精神药品的相互作用 [见 [用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk)]。**

**这说明医生对这类情况是有预期的，不是罕见情况。**

## 八、一个提醒

**焦虑和抑郁不是你「不够坚强」的证据。**

**它们是可治疗的状况，而且治疗手段是有效的。** 找专业帮助，和骨折了去医院是一样的。

**也不要把「撑住」当成目标。** 撑住是暂时的，好转才是目标。

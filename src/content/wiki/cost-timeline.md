## 先说三件事

**1. 所有数字都会变。** 价格随政策、集采、医院调整而变；时间随号源、排期、窗口效率而变。**这一页只是量级参考。**

**2. 本站不复述「某个医院收多少」。** 除了上游明确给出数字的，本页不补。

**3. 隐形成本容易被低估。** 交通、住宿、请假、误工——这些通常不在「医疗费用」里，但实际占比不小。

## 一、精神科阶段

**⚠️ 上游没有给出精神科就诊的费用数据。** 本站不补。

**可以确认的构成：**

| 项目 | 说明 |
| --- | --- |
| 挂号费 | 各院不同，通常不高 |
| 可能的量表费 | 视医院 |
| 复诊次数 | **多数人不是一次就能拿到材料**，见[诊断证明与介绍信](/wiki/diagnosis-letter/) |
| **时间成本** | 上游列出的三种模式中，**「设置半年至两年的观察期」**是最常见的一种，见[精神科资源怎么用](/wiki/psych-resources/) |

**时间上的现实预期：** 从首次就诊到拿到可用于 HRT 的病历，**常见是数月**；拿到可用于手术的诊断证明，**可能更久**。

## 二、HRT 阶段

### 2.1 初诊检查

**北医三院的明确数据 [1]：**

> 总花费介于 **1000 - 2000** 之间。

**包含的项目 [1]：** 血常规、凝血七项（含 D-Dimer）、血生化、糖化血红蛋白、甲功三项、甲状旁腺素、2,5-羟维生素 D、空腹胰岛素、性激素六项、腹部超声、乳腺超声、骨密度、染色体检查（可选）。

**时间 [1]：**

| 项目 | 时间 |
| --- | --- |
| 血液检查 | 很快出报告，最晚次日可取 |
| 超声 | **排期较长，可能需要等待 3 个工作日以上** |
| 骨密度 | 可能当天，也可能约在另一天 |
| **染色体检查** | **需要整整 30 天**；第三方检查约 15 天且可提前做 |

**省时间的做法 [1]：** 外地人士可在当地做完相关检查后携带报告前往，**检查有效期三个月**。

**省钱的做法 [1]：** 在当地三甲医院完成检查（可用当地医保），一般内分泌科医生熟悉这些项目。

### 2.2 长期用药

**⚠️ 上游没有给出常规 HRT 药物的价格数据**（除了下面的特殊情况）。本站不补。

**可以确认的是费用构成：**

| 构成 | 说明 |
| --- | --- |
| 药物本身 | 各剂型差异大，见下 |
| **定期复查** | **每三个月一次**，见[治疗期间的监测](/wiki/monitoring-index/) |
| 挂号费 | 每次复诊 |
| 交通与时间 | 如果医院在外地，这部分可能超过药费 |

**剂型成本差异（上游对「日均成本」的评价）[见[给药途径详解](/wiki/hrt-complete-guide/)]：**

| 途径 | 上游评价 |
| --- | --- |
| 口服 | 较低 |
| 舌下 / 含服 | 较低 |
| 贴片 | **高** |
| 凝胶 | **高**（上游另指出「总体开销较大」） |
| 注射 | 较高（但综合成本较低，因为给药间隔长） |

### 2.3 几种特殊的费用数据

**这些是上游给出明确数字的：**

| 项目 | 数据 | 来源 |
| --- | --- | --- |
| **GnRH 类似物（亮丙瑞林）** | 国内集采中标价 **907.13～1650 元（中位数 1349.68 元）** | [3] |
| **GnRH 类似物的相对成本** | 上游：**同周期费用可能为其它抗雄药物的数十倍** | [3] |
| **比卡鲁胺（原研康士得，50 mg × 28 片）** | 挂网价 **868.83 元**（深圳） | [4] |
| **比卡鲁胺（国产仿制，上海朝晖 50 mg × 14 片）** | **162.73 元**（深圳） | [4] |
| **比卡鲁胺（国产仿制，浙江海正 50 mg × 28 片）** | **193 元**（上海） | [4] |

**上游对比卡鲁胺的说明 [4]：** 「价格上则大幅高于色普龙、螺内酯等常规用药。」

**关于雷洛昔芬：** 上游提到它是「易维特」「贝邦」等品牌，**未给出价格数字** [5]。

## 三、手术阶段

### 3.1 SRS（生殖器相关手术）

**上游给出的中位数预期 [2]：**

> **费用预期：中位数预期为 60000 CNY。**

**⚠️ 这只是手术费用本身。** 不含：

| 额外成本 | 说明 |
| --- | --- |
| **术前公证** | 部分医院要求，见[公证是什么](/wiki/notarization/) |
| 术前检查 | 各院要求不同 |
| 住院与药费 | 视医院 |
| **交通与住宿** | 如果是异地手术，可能不是小数目 |
| **陪护成本** | 有人陪同意味着对方也要请假 |
| **恢复期误工 / 休学** | 见[请假与考试](/wiki/leave-exam/) |
| **术后复查** | 多次，且可能涉及异地往返 |
| 可能的二次修整 | 见[手术评价与技术选择](/wiki/surgery-evaluation/) |

**时间上的现实预期：**

| 环节 | 说明 |
| --- | --- |
| **前置条件** | 「对性别重置的要求至少持续 5 年以上」+ 满 18 岁，见[各阶段的年龄门槛与家长要求](/wiki/age-thresholds/) |
| **排期** | 通常以月计 |
| **住院** | 视术式 |
| **恢复期** | 需要一段无法正常学习工作的时间 |

### 3.2 FFS（面部女性化手术）

**⚠️ 上游未在综述中给出费用数字。** 上游说明「费用因项目数、医院、医生差异很大，需要直接咨询机构」。

**可以确认的是：** **国内基本不纳入医保**，见[FFS 面部女性化手术](/wiki/ffs-overview/)。

### 3.3 隆乳、嗓音、脱毛

**⚠️ 上游未给出这几类的费用数字。** 本站不补。

**可以确认的结构性差异：**

| 项目 | 特点 |
| --- | --- |
| 隆乳 | 按术式与假体计算 |
| 嗓音手术 | 通常要求先做训练 |
| **脱毛** | **需要多次疗程，累计费用可能不低**；电解按小时计费，见[脱毛方式对比](/wiki/hair-removal/) |
| 植发 | 通常按毛囊单位计费 |

## 四、证件阶段

**⚠️ 上游没有给出证件办理的费用数据。** 本站不补。

**可以确认的构成：**

| 项目 | 说明 |
| --- | --- |
| 证件工本费 | 各证件不同 |
| **公证费** | 按公证类型与标的额计算，见[公证是什么](/wiki/notarization/) |
| 交通与误工 | 逐项办理，多次往返 |
| **时间** | **跨几个月很正常**，见[实名信息变更总览](/wiki/real-name-overview/) |

## 五、隐形成本：最容易被低估的部分

**这一节是本站整理，不是上游原文。**

| 成本类型 | 说明 |
| --- | --- |
| **交通** | 如果接诊医院在外地，每次复诊都要跑 |
| **住宿** | 异地手术与复查 |
| **请假** | 学生可能影响学业，在职可能影响收入 |
| **误工** | 恢复期无法工作 |
| **时间** | 挂号、排队、等待排期——这些不花钱，但消耗大量时间 |
| **情绪成本** | 被拒、被刁难、反复往返 |

**建议：把「交通 + 住宿 + 请假」单独列一栏做预算。** 这部分经常比药费高。

## 六、怎么做规划

**一个实用的做法：**

| 步骤 | 做法 |
| --- | --- |
| 1 | **列出所有阶段**（精神科 → HRT → 手术 → 证件） |
| 2 | **每个阶段标出「已知费用」和「未知费用」** |
| 3 | **未知的部分打电话问医院**，不要靠网上估算 |
| 4 | **把隐性成本单独列一栏** |
| 5 | **按时间排序，看哪些可以并行**（例如证件流程可以提前了解） |
| 6 | **预留缓冲**——实际花费通常高于预算 |

**关于医保：** 与跨性别医疗相关的项目是否纳入报销范围，各地医保目录不同，**必须向当地医保部门确认**，见[医保与社保](/wiki/healthcare-insurance/)与[保险与理赔](/wiki/insurance-claims/)。

## 七、关于「钱不够怎么办」

**⚠️ 本站不提供筹款或借贷建议。** 但可以说几条原则：

| 原则 | 说明 |
| --- | --- |
| **不要为了医疗而借高利贷** | 债务压力会严重影响心理健康，而心理健康影响整个过渡过程 |
| **不要因此自行购买来源不明的药物** | 见[中介与骗局识别](/wiki/scam-awareness/) |
| **优先做「投入小、见效快、可逆」的事** | 见[日常入门的顺序](/wiki/daily-basics/) |
| **分阶段做，不必一次全做** | 手术类都是独立的决定 |
| **问清有没有低费或公益资源** | 上游的[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)可能有线索 |

**经济约束是现实，不是你的失败。** 慢慢来也可以。

## 量表能做什么

| 用途 | 说明 |
| --- | --- |
| **整理感受** | 有些感受难以用语言描述，量表提供了一套现成的描述框架 |
| **发现被忽略的方面** | 你可能只关注了身体，量表会问到社交、情绪、日常功能 |
| **准备就诊** | 把填完的结果带去门诊，比临场组织语言更容易说清楚 |
| **提供参照** | 知道「不只是我这样」本身有价值 |

## 量表不能做什么

| 不能 | 原因 |
| --- | --- |
| **不能诊断** | 诊断需要专业人员结合访谈、病史和多方面信息来判断 |
| **不能决定你是不是跨性别** | 没有任何量表是为「判定身份」设计的 |
| **不能预测满意度** | 这类因果关系量表无法给出 |
| **不能作为说服他人的证据** | 医生、家人、单位都不会因为一张量表改变判断 |

## 为什么有人会被量表误导

量表通常有**阈值**和**得分区间**。这容易造成一种错觉：分数够高就是，不够就不是。

**实际上：**

| 问题 | 说明 |
| --- | --- |
| 测的是当下状态 | 会随情绪、睡眠、生活事件波动 |
| 编制目的不同 | 有的用于筛查，有的用于研究，**没有一个是用来判定身份的** |
| 常模可能不适用 | 跨性别群体的得分分布和其他群体不同，用通用阈值解释可能失真 |
| 总分信息量有限 | **具体条目比总分更有信息量** |

## 一个健康的使用方式

| 步骤 | 做法 |
| --- | --- |
| 1 | **填之前先问自己：我填这个是为了什么？** 如果答案是「想让人告诉我我是不是」，量表给不了 |
| 2 | **如实填**，不要为了「拿高分」而选答案 |
| 3 | **看具体条目而不是总分** —— 哪几条让你有反应，比总分更有信息量 |
| 4 | **当成一份自我观察笔记**，而不是一份证明 |

<div class="guide">
<strong>一个判断标准</strong>
<p>填完之后，如果你的第一反应是「我该拿这个分数去证明什么」，那说明量表被用错了地方。</p>
<p>如果你的第一反应是「原来这几条我特别有共鸣」，那它起作用了。</p>
</div>

## 就诊时怎么用

**带上填写结果，但不要以「我测出来符合」作为开场。**

**更有效的说法是：**

> 我整理了一些自己的感受，有几条我特别有共鸣，想和您确认一下。

**把主动权交给医生，同时你也有材料可讲。**

**不要做的事：**

- 不要用分数反驳医生的判断
- 不要用「网上都说这个分数就够了」施压
- 不要把量表当成「通过评估」的工具

见[怎么跟医生说话](/wiki/doctor-communication/)。

## 关于「评估会不会用这些量表」

**精神科评估可能包含量表，但不依赖量表。** 评估的常规内容见[诊断标准是什么](/wiki/diagnosis-criteria/)。

**医生关注的是：** 持续性、一致性、影响程度、鉴别诊断、知情程度、支持系统。

**量表只是其中一个信息源。**

## 如果填写过程让你不适

**停下来。** 量表不是必须完成的任务。

有些问题可能触发强烈的情绪反应。如果出现这种情况：

- 停下来，做点别的事
- 找人说说
- 需要时找咨询师，见[怎么找心理咨询](/wiki/finding-counselor/)
- **如果情绪严重低落或出现自伤想法**，见[危机资源与紧急情况](/wiki/crisis-resources/)

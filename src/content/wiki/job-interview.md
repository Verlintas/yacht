## 面试时要不要说

**通常不必。你没有义务在录用前公开。**

| 情况 | 建议 |
| --- | --- |
| **证件信息与外观一致** | 不需要主动说 |
| **证件信息尚未变更** | 视情况，通常可以入职后单独与 HR 沟通 |
| **岗位涉及客户或公众形象** | 评估风险，但不等于必须说 |
| **公司有明显歧视记录** | **重新考虑这家公司** |

**如果决定说，越简短越好：**

> 有一件事需要提前说明：我的证件信息和日常称呼不一致，入职时我会单独和 HR 沟通处理。

**只说事实，不说病史。**

## 体检

| 事项 | 说明 |
| --- | --- |
| **常规入职体检** | 通常不涉及相关项目 |
| **遇到额外要求** | 可以问清：这是岗位必需的吗？谁有权查看？保密范围是什么？ |
| **结果保密** | 体检结果属于个人医疗信息，**用人单位有保密义务** |
| **不要隐瞒影响岗位安全的问题** | 这不属于隐私，属于安全 |

## 背调

**背调可能联系前雇主。需要提前准备：**

| 准备项 | 做法 |
| --- | --- |
| **确认前雇主会说什么** | 如果前一段经历不愉快，可以找一位愿意为你说话的同事作为证明人 |
| **准备中性的说法** | 例如「因为个人发展原因离开」，不必解释细节 |
| **前雇主可能泄露你的身份信息** | 这属于侵权，见[个人信息与隐私保护](/wiki/privacy-law/) |
| **注意时间线** | 履历中的空档期可以如实说明（休学、治疗、调整期），不必详细解释 |

## 简历上的姓名

| 情况 | 做法 |
| --- | --- |
| **证件已变更** | 直接用新名字 |
| **证件未变更** | 可以用常用名投递，入职时说明情况 |
| **担心被追问** | 附一句简短说明，或面试时口头说明 |

**有些公司接受「常用名」投递。具体看招聘流程。**

**关于名字的选择，见[名字的选择](/wiki/choosing-name/)。**

## 入职后

| 事项 | 做法 |
| --- | --- |
| **人事信息** | 与 HR 单独沟通，**请对方注意保密** |
| **工牌、邮箱、通讯录** | 确认是否能用你选择的名字 |
| **社保、公积金** | 跟随身份证信息 |
| **同事关系** | 只需要说称呼和代词，不必交代病史 |

**详细做法见[与 HR 沟通](/wiki/hr-communication/)。**

## 遇到歧视

| 阶段 | 说明 |
| --- | --- |
| **招聘阶段** | 歧视较难举证，但聊天记录、邮件可以留 |
| **录用后被辞退或调岗** | 性质不同，见[就业歧视与劳动权益](/wiki/employment-discrimination/) |
| **证据** | 保留全部证据：招聘沟通、录用通知、劳动合同、绩效记录 |

## 关于「空档期」

**如果履历中有空档期（休学、治疗、调整期）：**

| 说法 | 说明 |
| --- | --- |
| 「个人原因」 | 最常用，通常不会再追问 |
| 「健康原因，已恢复」 | 如果被追问，这个说法通常足够 |
| 「家庭原因」 | — |

**你没有义务说明具体是什么健康问题。** 「已恢复、不影响工作」是完整的回答。

## 常见问题

**「面试时必须说吗？」**
**通常不必。你没有义务在录用前公开。**

**「不说的话，入职时会不会出问题？」**
入职需要提供身份证。**可以在拿到 offer 后、入职前单独和 HR 沟通**，请对方注意保密。

**「简历上可以用常用名吗？」**
可以。**证件未变更时用常用名投递，入职时说明情况**是常见做法。有些公司接受「常用名」投递，具体看招聘流程。

**「背调会暴露吗？」**
取决于前雇主说什么。**可以提前确认**，必要时换一位愿意为你说话的证明人。见[职场](/wiki/workplace/)。

**「体检会被查出来吗？」**
**常规入职体检通常不涉及相关项目。** 遇到额外要求，可以问清用途与保密范围。

**「空档期怎么解释？」**
「个人原因」「健康原因，已恢复」通常足够。**你没有义务说明具体是什么健康问题。**

**「入职后发现被歧视怎么办？」**
保留证据，见[就业歧视与劳动权益](/wiki/employment-discrimination/)。

## 不同公司类型的差异

**⚠️ 以下为经验整理，非上游资料。**

| 公司类型 | 一般情况 | 注意事项 |
| --- | --- | --- |
| **外企 / 跨国公司** | 通常有明确的多元化政策 | 政策与实际执行可能不同，看它过去怎么处理 |
| **互联网 / 科技公司** | 相对宽松 | 仍取决于团队文化 |
| **国企 / 事业单位** | 流程规范，但可能更保守 | 人事环节较多，保密范围需要明确 |
| **体制内（公务员、编制）** | 审查环节多 | **需要单独了解具体要求** |
| **中小企业** | 差异最大 | 取决于老板个人态度 |
| **客户导向行业**（销售、服务） | 可能更看重形象 | 评估岗位实际需求 |
| **技术岗位** | 通常更看重能力 | 但团队氛围仍重要 |

**判断方法：看这家公司过去怎么处理类似问题，而不是看它的口号。**

## 面试时被问到私人问题

**有些问题不该被问，但实际会发生。**

| 被问 | 可以怎么回应 |
| --- | --- |
| 「你结婚了吗？有孩子吗？」 | 「这个和岗位有关吗？」 |
| 「你的性别认同是……」 | 「这和我的工作能力有关吗？」 |
| 「你身体有什么问题吗？」 | 「我能胜任岗位要求。」 |
| 「你为什么不男不女？」 | 「请用专业的方式沟通。」 |
| 反复追问私人生活 | **可以中止面试。** 这说明这家公司不合适 |

**你有权不回答与岗位无关的问题。** 如果对方持续追问，这本身就是关于这家公司的信息。

## 入职前的准备清单

- [ ] **确认 offer 与合同条款**（岗位、薪资、试用期、社保）
- [ ] **确认入职需要哪些材料**
- [ ] **想好怎么和 HR 沟通**（如果证件信息不一致），见[与 HR 沟通](/wiki/hr-communication/)
- [ ] **确认体检项目**（如有疑问，提前问清用途）
- [ ] **准备背调的说法**（如果需要）
- [ ] **确认工牌、邮箱、通讯录能否用你选择的名字**
- [ ] **想好同事问起时怎么回应**（「这个我不太想聊」是完整的回答）

## 关于「职业发展」

**这是真实的顾虑，不必否认。**

| 可能的影响 | 应对 |
| --- | --- |
| 客户关系 | 视行业而定；部分行业影响很小 |
| 晋升机会 | 取决于公司文化，**观察它过去的做法** |
| 背调与跳槽 | 提前准备说法 |
| 行业圈子小 | 在特定行业里信息传播更快 |

**同时：** 长期隐瞒也会消耗精力。**没有零成本的选项，只有你更能接受哪一种。**

**如果某份工作因为身份问题而失去，那不是你的能力问题。** 见[就业歧视与劳动权益](/wiki/employment-discrimination/)。

## 年龄是第一条线：16 周岁

**中国劳动法框架下，16 周岁是一条明确的分界线。**

| 年龄 | 身份 | 说明 |
| --- | --- | --- |
| **未满 16 周岁** | 属于**童工** | 用人单位**禁止招用**；仅文艺、体育和特种工艺单位经审批可有例外 |
| **已满 16 周岁、未满 18 周岁** | **未成年工** | 可以就业，但受**特殊保护** |
| 已满 18 周岁 | 成年劳动者 | 一般规定 |

**⚠️ 上面的表述是框架性的。** 具体条文以[国家法律法规数据库](https://flk.npc.gov.cn/)为准。

**如果你还未满 16 周岁**，合法打工的路径非常有限。**任何招你去打工的地方都在违法，而且你没有任何法律保护。**

## 未成年工的特殊保护（框架）

**未成年工可以就业，但用人单位负有额外义务。** 框架性的内容包括：

| 保护 | 说明 |
| --- | --- |
| **禁止从事特定劳动** | 矿山井下、有毒有害、国家规定的第四级体力劳动强度等 |
| **定期健康检查** | 用人单位应按规定安排 |
| **工作时间限制** | 不得安排加班和夜班等（框架性规定） |
| **登记备案** | 用人单位需按规定办理 |

**⚠️ 如果你已经在打工，且被安排做重体力、夜班或危险作业，这是可以主张权利的情形。**

**遇到这种情况：** 保留证据（排班表、聊天记录、工资记录），咨询律师或当地劳动保障监察部门。

## 常见的学生工作类型

**⚠️ 以下为经验整理，非研究结论。**

| 类型 | 特点 | 注意 |
| --- | --- | --- |
| **餐饮／奶茶店** | 招人多，门槛低 | 站立时间长；排班灵活 |
| **便利店／超市** | 相对稳定 | 可能涉及夜班 |
| **家教／辅导** | 收入相对高 | 需要学科能力 |
| **线上兼职**（设计、剪辑、写作、翻译） | 时间灵活 | **诈骗高发，见下** |
| **活动／展会临时工** | 短期 | 结算要确认 |
| **宠物照看／遛狗** | 门槛低 | 需要信任基础 |
| **二手交易** | 不需要雇主 | 见下 |
| **校内勤工助学** | 最安全 | 名额有限 |

**⚠️ 本站不推荐任何具体平台或雇主。**

## 找工作的安全边界

**⚠️ 学生群体是诈骗的重点目标。**

| 红旗 | 说明 |
| --- | --- |
| **要求先交钱**（押金、服装费、培训费、保证金） | **正规招聘不会先收钱** |
| **要求提供身份证原件** | 只提供复印件并注明用途 |
| **要求办银行卡／手机卡交给他** | **绝不。可能涉及违法犯罪** |
| **要求「帮忙转账」「帮忙取现」** | **绝不。可能构成帮信罪** |
| **要求提供人脸／手持身份证照片** | **绝不** |
| **高薪但要求低、门槛模糊** | 典型诈骗结构 |
| **只通过私人聊天沟通，没有公司信息** | 谨慎 |
| **要求签空白合同** | 拒绝 |
| **催你「马上决定」** | 典型话术 |

**⚠️ 「帮忙转账」「帮忙取现」「借银行卡」这几类，可能让你成为犯罪链条的一部分，后果远大于赚到的钱。**

**见[常见骗局与识别](/wiki/scam-awareness/)与[安全与隐私](/wiki/safety-privacy/)。**

## 打工时的隐私问题

**打工意味着进入一个新的人际环境。**

| 情况 | 说明 |
| --- | --- |
| **证件信息与外观不一致** | 入职登记时可能被看到 |
| **同事问私人问题** | 见[职场](/wiki/workplace/) |
| **打卡／工牌上的名字** | 可以问能否用你选择的名字 |
| **工资卡与实名** | 需要实名，可能暴露旧信息 |
| **社保记录** | 见[医保与社保](/wiki/healthcare-insurance/) |

**可以做的：**

- [ ] **提前想好怎么和 HR 沟通** —— 见[面试与求职](/wiki/job-interview/)
- [ ] **只提供办理该事项所需的材料**
- [ ] **「这个我不太想聊」是完整的回答**
- [ ] **不需要向同事解释你的身份**

## 攒钱：把它变成一件看得见的事

**⚠️ 以下为经验整理，非研究结论。**

| 做法 | 说明 |
| --- | --- |
| **单开一个账户** | 和日常花销分开 |
| **设定一个具体目标** | 「攒 X 元」比「多存点」有效 |
| **每月固定转入** | 金额不重要，固定更重要 |
| **记录支出** | 知道钱去哪了 |
| **区分「想要」和「需要」** | 不苛责自己，但要有意识 |
| **不要放在家人能看到的账户** | 隐私考虑 |
| **不要为了攒钱牺牲吃饭和健康** | 见[进食障碍](/wiki/eating-disorders/) |

**⚠️ 关于「放在哪里」：** 未成年人开立账户、以及账户是否会被监护人知晓，**规则和实际情况各地不同，需要你自己了解。**

## 常见问题

**「我 15 岁，能打工吗？」**
**法律上不行。** 见上文「16 周岁」一节。**未满 16 周岁打工没有任何法律保护。**

**「家里不支持，我想自己攒钱做医疗，可以吗？」**
**经济独立是一个过程，不是开关。** 见[小城市与县城](/wiki/small-city/)与[家人反对时怎么办](/wiki/family-reactions/)。**先保证安全和学业。**

**「打工会不会影响学习？」**
**会，取决于时长。** 学业是长期资产，**不要为了短期收入放弃它。**

**「怎么和 HR 说我的名字？」**
**见[面试与求职](/wiki/job-interview/)。** 证件未变更时，可以入职后单独沟通。

**「打工时被认出来怎么办？」**
**见[安全与隐私](/wiki/safety-privacy/)。** 提前想好说法，不必主动解释。

**「网上兼职可靠吗？」**
**诈骗高发。** 见上文红旗清单，**任何先交钱或要求借银行卡的都是危险信号。**

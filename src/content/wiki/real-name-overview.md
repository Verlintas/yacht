## 核心原则：顺序比材料重要

多数证件之间存在**引用关系**——后办的要看先办的。顺序错了，就要重跑一遍。

![证件与信息变更顺序](/images/wiki/document-order.svg)

<div class="guide">
<strong>办之前先问窗口三件事</strong>
<p>1. 改名和性别信息变更能不能一起办？</p>
<p>2. 各自需要哪些材料，要不要原件、要不要公证？</p>
<p>3. 先办哪个？</p>
<p>这三句话能省掉大部分往返。各地口径不一样，甚至同一城市不同窗口也不同。</p>
</div>

```
医院手术证明
      │
      ▼
  户口本（户籍信息变更）
      │
      ▼
   身份证（依据户籍）
      │
      ├──► 学历 / 学籍
      ├──► 医保 / 社保
      ├──► 护照 / 旅行证件
      ├──► 银行 / 手机号 / 各类实名账号
      └──► 驾驶证、房产、婚姻登记等
```

**先户籍，后身份证，再其余。** 这是一般规律，具体以当地窗口要求为准。

## 各地口径不一样

这是最需要提前知道的一点：**同一项业务，不同城市的执行要求可能不同**，甚至同一城市不同窗口也不一样。可能变化的包括：

- 是否需要手术证明
- 是否要求指定级别的医院
- 是否需要公证
- 材料格式与有效期
- 是否接受异地办理

**所以「别人能办」不代表「你也能办」，「别人被拒」也不代表你不行。** 办之前先打电话问当地窗口，是最省时间的做法。

## 办之前问清的五件事

1. 需要哪些材料，是否需要原件
2. 材料是否需要公证或指定格式
3. 受理窗口、办公时间、是否需要预约
4. 办理周期多久
5. 如果材料被退回，补办流程是什么

## 一个实用建议

**把所有变更记录成一张表**：项目、办理日期、所需材料、窗口电话、办理状态、下一步。证件变更往往跨几个月，靠记忆容易乱。

这份记录属于个人隐私，不要公开发布。

## 本站的边界

本站只提供顺序框架和上游链接。**具体材料要求、办理条件、政策细节，一律以当地窗口和上游指引为准。** 政策会变，二手总结跟不上。

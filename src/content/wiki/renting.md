## 找房时的证件问题

**租房通常需要身份证。** 如果证件信息尚未变更：

| 情况 | 说明 |
| --- | --- |
| 证件与外观不一致 | 中介或房东可能多问几句。**不需要解释** |
| 不想暴露 | 优先选择正规中介、连锁公寓，流程标准化程度更高 |
| 证件已变更 | 正常流程，无需特别处理 |

**签约时用的是证件上的名字。** 这和日常称呼可以不一致，**不影响合同效力**。

## 合租的风险点

**合租是信息暴露风险较高的场景**，因为同住者会看到你的日常。

**降低风险的做法：**

| 做法 | 说明 |
| --- | --- |
| **优先选独立卫浴的房间** | 减少公共空间接触 |
| **优先选室友作息规律的房源** | — |
| **看房时观察室友的态度** | 比看房子本身更重要 |
| **不必主动说明** | 但也不要刻意隐瞒到紧张 |
| **可以先短租** | 月租、季租，再决定长租 |

## 签约要注意的

- [ ] 合同上的出租方信息与房产证一致
- [ ] **押金与退还条件写清楚**
- [ ] 水电燃气网络费用的承担方式
- [ ] 维修责任划分
- [ ] 提前退租的条件
- [ ] 是否允许转租
- [ ] 保留一份合同原件或清晰照片

**押金纠纷是最常见的租房问题。**

**入住时拍照记录房屋现状**（含已有损坏、水电表读数），退租时用得上。

## 遇到房东或室友的歧视

**租房属于民事合同关系。**

| 情况 | 说明 |
| --- | --- |
| **已签约，房东想赶你走** | 房东不能单方面因身份原因解除合同，需要看合同条款 |
| **室友的态度** | 不是房东解约的合法理由 |
| **被强制要求搬离** | 保留证据（聊天记录、通知），咨询律师 |
| **还没签约** | **不必纠缠，换一家。效率比争理更重要** |

**涉及具体法律问题时，见[常见法律问题索引](/wiki/legal-faq-index/)。**

## 安全考虑

**如果担心住址被知晓：**

| 做法 | 说明 |
| --- | --- |
| 快递收件地址用驿站或快递柜 | 不写具体门牌 |
| 外卖备注放门口 | — |
| 社交平台不发窗外景色、门牌、小区标志 | — |
| 不实时发布行程 | — |

**如果遇到跟踪、骚扰等现实威胁：**

| 步骤 | 做法 |
| --- | --- |
| 1 | **优先处理人身安全** |
| 2 | 告知可信任的人 |
| 3 | 必要时报警 |
| 4 | 见[网络暴力与取证](/wiki/online-harassment/) |

## 关于「要不要和室友出柜」

**没有义务。** 合租是居住安排，不是亲密关系。

| 选择 | 说明 |
| --- | --- |
| **决定说** | 简洁说明称呼与代词即可，不必展开 |
| **不说** | 保持基本的室友礼仪（作息、卫生、噪音）通常比说明身份更能维持关系 |

## 换房与搬家

**如果决定换房：**

- 提前规划时间（避免押金和租期的双重压力）
- 搬家公司或朋友帮忙（**搬家时留意不要泄露新地址给不想告知的人**）
- 更新收件地址、账单地址
- 通知必要的机构（银行、社保等，如涉及）

## 关于押金纠纷

**押金是最常见的租房纠纷。**

| 预防做法 | 说明 |
| --- | --- |
| **入住时拍照记录现状** | 含已有损坏、水电表读数、家具状态 |
| 合同写清退还条件 | 什么情况扣押金、扣多少 |
| 保留缴费凭证 | 转账记录、收据 |
| **退租时再拍一次** | 对比用 |
| 要求书面说明 | 如果被扣押金，要求写明理由 |

**如果发生纠纷：**

1. 保留全部证据（合同、聊天记录、照片、转账记录）
2. 先协商，要求书面说明
3. 协商不成可以向法院起诉（**标的额小，程序相对简单**）
4. 涉及具体法律问题，见[常见法律问题索引](/wiki/legal-faq-index/)

## 常见问题

**「证件信息不一致能租到房吗？」**
**通常可以。** 签约时用证件上的名字，这和日常称呼可以不一致，**不影响合同效力**。

**「必须出柜吗？」**
**没有义务。** 合租是居住安排，不是亲密关系。

**「房东能因为身份赶我走吗？」**
**已签约的情况下不能单方面解除。** 需要看合同条款。**具体问题咨询律师。**

**「室友反对怎么办？」**
室友的态度不是房东解约的合法理由。**如果还没签约，换一家更快。**

**「押金被扣了怎么办？」**
保留证据、协商、必要时起诉。见下。

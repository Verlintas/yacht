## 先做减法

**新手最容易犯的错是一次上太多步骤**，结果又花时间又不自然。

**建议顺序：底妆 → 眉毛 → 唇 → 其他。**

## 第一步：底妆

| 产品 | 作用 | 注意 |
| --- | --- | --- |
| 妆前乳 | 修饰毛孔与肤色 | 可选 |
| **粉底** | 均匀肤色 | **选贴近颈部肤色的，不要选白的** |
| 遮瑕 | 遮盖痘印、黑眼圈、胡青 | 胡青用偏橘色系 |
| 定妆 | 控油、持久 | 干皮可只定 T 区 |

**最关键的一条：粉底色号要贴合脖子，不是贴合脸。** 太白的粉底会让面部和颈部明显脱节。

**关于胡青：** 这是很多人最在意的部分。橘色/蜜桃色遮瑕 + 粉底通常能明显改善。

**长期方案是[脱毛](/wiki/hair-removal/)**——护肤和化妆只能遮盖，不能消除。

**如果面部有痤疮，先处理痤疮再考虑妆容**，见 [AAD 痤疮页面](https://www.aad.org/public/diseases/acne)与[护肤：有证据的部分](/wiki/skincare-advanced/)。

## 第二步：眉毛

**眉毛对整体观感的影响被严重低估。** 修整眉形、填补空隙，往往比浓妆更有效。

| 要点 | 说明 |
| --- | --- |
| 眉形 | 以**自然、稍有弧度**为宜，不要过细或过挑 |
| 工具 | **用眉粉比眉笔更自然**，尤其新手 |
| 颜色 | 选比发色浅一号 |
| 修眉 | **从少量开始**，一次修太多很难补救 |
| 对称 | 不必追求完全对称，自然的不对称更真实 |

## 第三步：唇

| 要点 | 说明 |
| --- | --- |
| 打底 | 润唇膏打底 |
| 色号 | **选接近自己唇色的**，比大胆色号更自然 |
| 唇形 | 想要饱满可以用唇线笔轻轻描边 |
| 日常妆 | **不必追求「显色」**，日常唇通常很淡 |

## 第四步之后：其他

| 项目 | 何时考虑 | 难度 |
| --- | --- | --- |
| 腮红 | 提气色，位置在颧骨偏上 | 低 |
| 眼线 / 眼影 | 熟练底妆后再学 | 中到高 |
| 睫毛 | **夹翘比涂睫毛膏更自然** | 低 |
| 修容 | 影响大但难度高 | 高 |

## 买什么、不买什么

**新手三件就够：** 粉底（或 BB 霜）、眉粉、润唇膏。

**不要一上来买：** 全套刷具、十几个色号的彩妆盘、专业修容产品。

**预算优先级：** 底妆 > 其他。**便宜的粉底和贵的差别通常比眉粉、唇膏更大。**

## 卸妆比上妆重要

| 要点 | 说明 |
| --- | --- |
| **必须卸干净** | 残留会堵塞毛孔 |
| 眼唇 | 用专门的眼唇卸妆液 |
| 之后 | 正常清洁、保湿 |
| **不要带妆睡觉** | 最伤皮肤的习惯之一 |

**卸妆产品也要按肤质选。** 卸妆油对干皮友好，卸妆水对油皮更清爽。

## 护肤是基础

**妆容建立在皮肤状态上。** 基础三步（清洁、保湿、防晒）做好，妆容会更服帖。

**上游的 HRT 效果表提到皮肤会变软、油性减少**，所以用药后妆容的服帖度可能变化，需要调整产品。

见[护肤：有证据的部分](/wiki/skincare-advanced/)。

## 一个提醒

**化妆不是义务。** 有人化，有人不化，都正常。**它只是工具之一。**

**也不要因为「化不好」而否定自己。** 这是纯熟能生巧的技能，练几个月就会有明显变化。

**如果化妆让你更焦虑而不是更自在**，那就先放一放。**状态比技巧重要。**

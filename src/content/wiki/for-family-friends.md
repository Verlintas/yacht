下面的内容没有权威来源逐条支持，属于常见的经验整理，<b>请当作参考而不是依据</b>。
</p>

## 先说三句最重要的话

**1. 这不是你的错，也不是你哪里做错了。**
性别认同不是教育出来的，也不是被谁「带坏」的。它不由你的养育方式决定。

**2. 你不需要马上完全理解，才能开始尊重。**
「我不太懂，但我尊重你」是一个完全成立的立场。**理解可以慢慢来，尊重现在就能给。**

**3. 你需要时间，这很正常。**
你的感受也是真实的。接受需要时间，这不代表你不爱对方。

## 你可能会经历什么

**这不是每个人都会走的顺序，但你可能会认出自己：**

| 阶段 | 可能的感受 | 常见的想法 |
| --- | --- | --- |
| **震惊** | 麻木、不知所措 | 「我完全没想到」 |
| **否认** | 觉得这是阶段性的 | 「过一阵就好了」 |
| **愤怒或自责** | 怪对方、怪自己、怪网络 | 「是不是我害的」 |
| **讨价还价** | 想设定条件 | 「先别告诉别人行不行」 |
| **低落** | 为「失去的那个孩子/伴侣」难过 | 「我好像失去他了」 |
| **接受** | 开始把它当成事实 | 「那我们接下来怎么办」 |

**「为失去而难过」是常见的，而且不丢人。** 你确实失去了某种预期中的未来。这份难过和接纳对方并不矛盾。

**这些阶段会反复。** 今天接受了，明天可能又退回去。

## 可以说的话

| 说法 | 为什么有用 |
| --- | --- |
| **「谢谢你告诉我。」** | 出柜需要勇气，这句话承认了这一点 |
| **「我需要一点时间，但我不会走。」** | 诚实，而且给了对方安全感 |
| **「我希望用你选择的名字和代词。」** | 具体的支持，比抽象的表态有力 |
| **「我不太懂，你愿意跟我讲讲吗？」** | 把「不懂」变成了沟通的起点 |
| **「我可能还会犯错，你提醒我一下。」** | 提前为失误留了空间 |
| **「你希望我怎么做？」** | 把主动权交给对方 |

## 不该说的话

| 说法 | 为什么伤人 |
| --- | --- |
| **「你确定吗？会不会只是一时冲动？」** | 对方通常已经想了很久 |
| **「你是不是被网上带坏了？」** | 把对方当成没有判断力的人 |
| **「那你以后怎么办？」** | 表达的是担忧，听起来是否定 |
| **「你考虑过我们的感受吗？」** | 把焦点从对方转到了自己 |
| **「我能接受，但别告诉亲戚。」** | 可以谈条件，但不要用「接受」当交换 |
| **「你以前不也……」** | 用过去的行为否定现在的陈述 |
| **「那你要做手术吗？」** | 这是私人医疗事务，不该成为第一个问题 |
| **「你还年轻，以后会变的。」** | 用年龄否定对方的判断 |

**如果你说了上面某句——不用自责，但可以补一句「抱歉，我不该那么说」。**

## 你可以做的实际的事

| 事项 | 说明 |
| --- | --- |
| **用对名字和代词** | 这是最直接的支持，也是最容易被低估的 |
| **私下纠正自己，公开纠正别人** | 说错了就改，不用大张旗鼓道歉；但别人说错时，帮忙纠正 |
| **不要替对方出柜** | **这是最重要的一条**。告知谁、什么时候、说多少，由对方决定 |
| **陪着去一次医院** | 见[就医陪同](/wiki/hospital-companion/) |
| **了解基本流程** | 读一遍[全流程地图](/wiki/full-path-map/)，你就知道对方在经历什么 |
| **不要急着给建议** | 先问「你想听我的想法吗」 |
| **照顾自己的情绪** | 你也可以找人聊，见下 |

## 关于「名字和代词」

**这可能是你能做的最有力的事。**

| 情况 | 做法 |
| --- | --- |
| 一时叫错 | 简单纠正，继续说话。**不用长篇道歉**——那会把注意力转到你的愧疚上 |
| 当着外人 | **如果对方还没公开，先按旧的方式称呼**，事后问对方希望怎么做 |
| 家人不接受 | 你可以是那个坚持用对的人 |
| 觉得别扭 | 会有一个适应期，这是正常的。**练几次就顺了** |

**「我还不习惯」是事实，但不是不做的理由。** 习惯是练出来的。

## 不要替对方出柜

**这是最容易犯、后果最严重的错误。**

| 不要 | 为什么 |
| --- | --- |
| 告诉亲戚、邻居、同事 | 对方可能因此面临实际的危险或损失 |
| 在群里「求助」 | 群成员会变，截图会流出 |
| 发社交平台 | 一旦发出就收不回 |
| 告诉对方的同学或同事 | 可能影响学业或工作 |
| 告诉医生以外的人 | 医疗信息属于隐私 |

**如果你需要找人倾诉**，可以找：**不含对方可识别信息的**支持渠道、心理咨询师（保密义务）、或者明确约定保密的亲友。

**「我需要找人说说」是合理的需求，但不能以对方的隐私为代价。**

## 如果你担心安全

**有些担心是真实的，需要处理，而不是回避。**

| 情况 | 可以怎么做 |
| --- | --- |
| 担心对方被歧视 | 一起了解应对方法，见[被拒绝后的申诉路径](/wiki/appeal-path/) |
| 担心对方的情绪 | 见下「关于心理健康」 |
| 担心医疗风险 | 一起了解，见 [HRT 完整指南](/wiki/hrt-complete-guide/)，并把问题带给医生 |
| 家里其他成员强烈反对 | 见[家庭沟通](/wiki/family/)与[家人常见反应与应对](/wiki/family-reactions/) |

**如果你自己出现了强烈的负面情绪（愤怒、抑郁、无法入睡），也值得找专业帮助。** 见[怎么找心理咨询](/wiki/finding-counselor/)。

## 关于心理健康

**跨性别者的焦虑、抑郁与自伤风险高于一般人群，这不是「因为跨性别」，而是因为歧视、排斥和压力。**

**所以你的支持是真实有效的干预。** 被家人接纳的跨性别者，心理健康状况显著更好。

**需要警惕的信号：**

- 持续两周以上的低落
- 睡眠、食欲明显改变
- 无法工作或学习
- 出现伤害自己的想法

**出现这些，不要等。** 见[危机资源与紧急情况](/wiki/crisis-resources/)与[怎么找心理咨询](/wiki/finding-counselor/)。

**如果对方说「我不想活了」，认真对待。** 不要当成气话，也不要说「你想太多了」。陪着对方，帮忙找资源，必要时去医院急诊。

## 最后一句

**你不需要成为专家，也不需要立刻想通所有事。**

**你只需要让对方知道：你没有走。** 这一条，比任何理解都重要。

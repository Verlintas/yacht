## 请假：说多少

**「就医」两个字通常足够。**

| 做法 | 说明 |
| --- | --- |
| **病假条** | 写「就诊」「治疗」「手术」都可以，**不需要写科室** |
| **辅导员追问细节** | 「个人医疗事务，不便详述」 |
| **这属于隐私范围** | 你有权不展开 |

**需要长期请假时**（例如手术恢复期），可能需要：

- 医院出具的证明（**写「建议休息 X 天」即可，不必写手术名称**）
- 家长知情（未成年人通常需要）
- 院系审批

## 需要多次就诊怎么安排

**复诊间隔可能是几周甚至几个月，不要每次都重新解释一遍。**

| 步骤 | 做法 |
| --- | --- |
| 1 | **一次性说明情况** —— 「我有一段时间需要定期复诊，会提前报备。」 |
| 2 | **提供一次证明**，后续按流程走 |
| 3 | **固定一个沟通人**（通常是辅导员），避免每次面对不同的人 |
| 4 | **保留全部请假记录** |

## 考试

| 情况 | 处理 |
| --- | --- |
| **与考试时间冲突** | 提前申请缓考或补考 |
| **术后恢复期撞上考试** | 提前申请，通常可以延期 |
| **需要特殊安排** | 向教务处说明，询问可选项 |
| **长期缺课影响平时分** | 提前和任课老师沟通 |

**关键：提前申请，不要事后补。** 事后的流程通常麻烦得多。

**如果因为缺课导致无法参加考试**，越早沟通越好，不要等到考试前一天。

## 休学与复学

**如果需要较长的恢复期，休学是一个正式选项。**

**考虑：**

| 事项 | 说明 |
| --- | --- |
| 休学时长 | 通常以学年为单位 |
| 复学流程与材料 | 提前问清 |
| 对学籍的影响 | 保留学籍的条件 |
| 对奖学金、助学贷款的影响 | 可能影响 |
| 对毕业时间的影响 | 顺延 |
| 对住宿的影响 | 休学期间通常不能住校 |

**这些要提前和学籍管理部门问清，不要自己猜。**

## 哪些信息不必交代

| 不必说明 | 学校有权知道的 |
| --- | --- |
| 具体诊断 | 你需要请假/休学这个事实 |
| 具体用药 | 建议休息的时长 |
| 具体手术内容 | 是否有影响考试或集体活动的限制 |
| 主治医生与医院 | — |

<div class="guide">
<strong>一个实用说法</strong>
<p>「医生建议我休息 X 天 / 需要定期复诊。这是医院的证明。具体病情我不太想展开。」</p>
<p>这句话既满足流程要求，又划清了隐私边界。</p>
</div>

## 如果遇到刁难

| 步骤 | 做法 |
| --- | --- |
| 1 | **要求书面依据** —— 「请问是哪条规定要求我提供这个？」 |
| 2 | **逐级反映** —— 院系 → 学工部门 → 教务 → 教育主管部门 |
| 3 | **保留记录** —— 时间、地点、对话内容 |
| 4 | **寻求支持** —— 见[被拒绝后的申诉路径](/wiki/appeal-path/)与[常见法律问题索引](/wiki/legal-faq-index/) |

## 关于「老师会不会告诉别人」

**教职员工对学生的个人信息负有保密义务。**

**但实际操作中，信息可能通过非正式渠道扩散。** 降低风险的做法：

- 固定一个沟通人（减少知情人数）
- 明确说明「不希望被扩散」
- 尽量用书面沟通（留下记录）

**如果被泄露**，见[个人信息与隐私保护](/wiki/privacy-law/)。

## 常见问题

**「请假会被追问吗？」**
可能会，但**你没有义务展开**。「个人医疗事务，不便详述」是完整的回答。

**「病假条上要写什么？」**
**写「就诊」「治疗」「手术」都可以，不需要写科室。** 需要长期休息时，医生通常写「建议休息 X 天」——**也不必写手术名称**。

**「学校要求我提供具体诊断怎么办？」**
**学校有权知道「需要请假」这个事实，无权知道具体诊断。** 可以问清依据：「请问是哪条规定要求我提供这个？」

**「可以事后补请假吗？」**
可以，但流程通常麻烦得多。**尽量提前申请。**

**「缺课影响平时分怎么办？」**
**提前和任课老师沟通。** 越早说越好，不要等期末。

**「休学会影响毕业吗？」**
会顺延毕业时间。**具体影响要问学籍管理部门**，不要自己猜。

**「休学期间能住校吗？」**
**通常不能。** 需要提前安排住处。

**「复学需要什么材料？」**
各校不同。**提前问清**，避免到期才发现材料不齐。

## 不同时长的请假处理

| 时长 | 通常需要 | 注意 |
| --- | --- | --- |
| **单次就诊（半天到一天）** | 口头报备或简单假条 | 最常见 |
| **多次定期就诊（几周至几个月）** | 一次性说明 + 一次证明 | 固定沟通人，减少重复解释 |
| **短期住院（几天到两周）** | 医院证明 + 院系审批 | 提前和任课老师沟通 |
| **长期恢复期（一个月以上）** | 可能涉及休学 | 见下 |
| **休学（一学期或一学年）** | 正式申请 + 医院证明 + 家长知情（未成年人） | 提前问清全部流程 |

## 休学与复学的完整考虑

**如果医生建议较长恢复期，休学是正式选项。**

**需要提前问清的：**

- [ ] **休学时长**（通常以学年为单位，能否申请延长？）
- [ ] **申请材料**（医院证明的具体要求）
- [ ] **复学流程与时限**（什么时候申请复学？需要什么材料？）
- [ ] **学籍保留条件**（什么情况下会被取消学籍？）
- [ ] **对奖学金、助学贷款的影响**
- [ ] **对毕业时间的影响**
- [ ] **对住宿的影响**（休学期间通常不能住校）
- [ ] **对已修学分的影响**
- [ ] **医保与社保的处理**

**⚠️ 这些问题要问学籍管理部门，不要问辅导员，也不要自己猜。**

## 与老师沟通的方式

**⚠️ 以下为经验整理。**

| 对象 | 说什么 | 不必说 |
| --- | --- | --- |
| **辅导员** | 请假事由、时长 | 具体诊断、用药 |
| **任课老师** | 缺课情况、补课或补考安排 | 同上 |
| **学籍管理部门** | 休学/复学的正式流程 | 同上 |
| **体育部** | 需要调整的原因（身体情况） | 同上 |
| **校心理咨询中心** | 想谈的内容 | 由你决定 |

**一个实用做法：把关键信息写成一页纸。** 每次需要说明时直接出示，减少口头解释的负担。

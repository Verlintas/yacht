## 常见反应阶段

不是每个人都会走完，顺序也可能不同。

| 阶段 | 表现 | 你可以做的 |
| --- | --- | --- |
| **否认** | 「你只是一时想不开」「是被网上带坏了」 | 不辩论。重复说明这是长期的、认真的 |
| **愤怒** | 指责、争吵、威胁 | 停止对话，等情绪平复。保护自己的安全 |
| **讨价还价** | 「先别告诉别人」「等毕业再说」「先去看心理医生治好」 | 可以答应部分，但明确哪些是你的底线 |
| **低落** | 沉默、回避、自责 | 给空间，但不放弃沟通。可以留文字资料 |
| **接受** | 开始询问、尝试用新称呼 | 给正反馈。耐心，这个阶段可能反复 |

**「反复」是常态。** 今天接受了，明天可能又退回去。这不是失败。

## 具体应对

**「你是不是学坏了 / 被人骗了？」**
> 不是。我很久以前就有这种感觉，只是以前不知道怎么描述。

**「你考虑过我们吗？」**
> 考虑过，所以我想了很久才说。

**「你能不能先别做任何改变？」**
> 我可以给你时间，但我也需要能按自己的方式生活。我们可以商量一个节奏。

**「你要去做手术吗？」**
> 这是我的私人医疗事务。我现在需要的是你们先知道这件事。

**「亲戚问起来我怎么说？」**
> 这是你的课题。你可以说「她有自己的安排」，不需要替我解释。

## 什么情况下停止沟通

**以下情况，安全优先于沟通：**

- 限制人身自由（锁门、没收手机、禁止出门）
- 强迫就医或强迫「矫正」
- 经济胁迫（以学费、生活费为条件）
- 暴力或暴力威胁
- 强制要求断绝与朋友、社群的来往

**处理顺序：**

1. **先离开或降低风险**
2. **联系可信任的人**
3. **必要时报警**
4. **寻求外部支持**，见[常见法律问题索引](/wiki/legal-faq-index/)与[社群与互助](/wiki/community/)

**这些行为是越界的，不是「家人关心你」。**

## 如果家人愿意了解

- **邀请他们一起见医生。** 有第三方在场，对话通常更理性。
- **家长互助群存在。** 有些家长通过与其他家长交流接受得更快。上游的[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations)可能有线索。
- **给具体的小事让他们参与**（比如新名字怎么念），比抽象讨论有效。

## 如果一直不被接受

这是可能发生的。你能做的：

- **降低期待。** 不是所有家庭都能走到理解，但可以维持基本关系。
- **建立自己的支持网络。** 朋友、社群、伴侣可以替代部分家庭功能。
- **保持经济独立。** 这是最实际的保护。
- **允许自己难过。** 不被家人接受是真实的损失，不需要假装不在意。
- **不把责任归到自己身上。** 接受需要时间，而时间不是你能控制的。

## 常见问题

**「家人完全不接受怎么办？」**
**可能发生。** 可以做的：降低期待、建立自己的支持网络、保持经济独立、允许自己难过。见下。

**「要给他们多久？」**
**没有标准。** 有人几周，有人几年，有人一直不接受。**时间不是你能控制的。**

**「要不要主动提这件事？」**
**看安全评估。** 如果可能引发暴力或失去住所，先建立退路。见[出柜策略与安全评估](/wiki/coming-out/)。

**「家人要求我先别告诉别人怎么办？」**
**可以答应一部分，但明确哪些是你的底线。**

**「家人说要带我去看医生『治好』怎么办？」**
**说明这不是需要治的问题。** 可以一起去见医生（让专业人士解释）。**如果涉及强制或「矫正」，见下。**

**「亲戚问起来怎么办？」**
**这是家人的课题。** 他们可以说「她有自己的安排」，不需要替你解释。

## 需要警惕的情况（安全优先）

**以下情况，安全优先于沟通：**

| 情况 | 行动 |
| --- | --- |
| **限制人身自由**（锁门、没收手机、禁止出门） | 先离开或降低风险 |
| **强迫就医或强迫「矫正」** | 同上 |
| **经济胁迫**（以学费、生活费为条件） | 建立独立收入 |
| **暴力或暴力威胁** | **必要时报警** |
| **强制要求断绝与朋友、社群的来往** | 同上 |
| **被赶出家门** | 见下 |

**处理顺序：**

| 步骤 | 做法 |
| --- | --- |
| 1 | **先离开或降低风险** |
| 2 | **联系可信任的人** |
| 3 | **必要时报警** |
| 4 | **见[常见法律问题索引](/wiki/legal-faq-index/)** |
| 5 | **见[危机资源与紧急情况](/wiki/crisis-resources/)** |

**这些行为是越界的，不是「家人关心你」。**

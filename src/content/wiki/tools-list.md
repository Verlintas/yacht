## 记录类

**没有现成的完美工具，建议自己建表。** 需要记录两类：

| 类型 | 字段 | 参考 |
| --- | --- | --- |
| 用药与检查记录 | 日期、药名、E2、T、PRL、肝功能、感受 | [用药记录怎么做](/wiki/hrt-log/) |
| 办事进度表 | 项目、状态、材料、窗口电话、下一步 | [材料与档案管理](/wiki/records-management/) |

**工具选择：**

- **加密笔记软件** —— 随手记，手机可用
- **本地表格软件** —— 好筛选、好算趋势
- **不要用公开的在线表格** —— 数据属于敏感医疗信息

## 加密类

| 需求 | 方案 |
| --- | --- |
| 加密文件与扫描件 | 系统自带的加密磁盘映像（macOS 磁盘工具 / Windows BitLocker） |
| 跨平台加密容器 | VeraCrypt |
| 密码管理 | 密码管理器（生成并保存强密码） |
| 加密笔记 | 支持端到端加密的笔记应用 |

**不要用「压缩包加密码」。** 那类加密容易被破解，而且很多人把密码写在文件名里。

## 常见问题

**「有现成的工具吗？」**
**部分有**（换算类、量表类），**但记录类通常要自己建。** 见下。

**「用什么记比较好？」**
**加密笔记软件或本地表格。不要用公开的在线表格。**

**「怎么加密？」**
用系统自带的加密磁盘映像，或跨平台加密容器。**不要用压缩包加密。**

**「在哪查医师执业信息？」**
国家卫健委官网或当地卫健委。

**「在哪查医保目录？」**
当地医保局官网 / 公众号 / 热线。

**「在哪查药品说明书？」**
药监局数据库，或 [Transfeminine Science 译文站](https://tfsci.mtf.wiki/)收录的说明书。

## 换算类

| 工具 | 用途 | 链接 |
| --- | --- | --- |
| 激素换算 | 雌二醇 / 睾酮的单位换算 | [mtf.wiki/zh-cn/converter](https://mtf.wiki/zh-cn/converter) |
| 胸围计算 | 估算工具（受测量方式影响大） | [mtf.wiki/zh-cn/cup-calculator](https://mtf.wiki/zh-cn/cup-calculator) |

**换算结果只用于理解量级**，是否达标交给医生判断。见[激素换算工具](/wiki/hormone-converter/)。

## 记录类

**没有现成的完美工具，建议自己建表。** 需要记录两类：

| 类型 | 字段 | 参考 |
| --- | --- | --- |
| 用药与检查记录 | 日期、药名、E2、T、PRL、肝功能、感受 | [用药记录怎么做](/wiki/hrt-log/) |
| 办事进度表 | 项目、状态、材料、窗口电话、下一步 | [材料与档案管理](/wiki/records-management/) |

**工具选择：**

- **加密笔记软件** —— 随手记，手机可用
- **本地表格软件** —— 好筛选、好算趋势
- **不要用公开的在线表格** —— 数据属于敏感医疗信息

## 加密类

| 需求 | 方案 |
| --- | --- |
| 加密文件与扫描件 | 系统自带的加密磁盘映像（macOS 磁盘工具 / Windows BitLocker） |
| 跨平台加密容器 | VeraCrypt |
| 密码管理 | 密码管理器（生成并保存强密码） |
| 加密笔记 | 支持端到端加密的笔记应用 |

**不要用「压缩包加密码」。** 那类加密容易被破解，而且很多人把密码写在文件名里。

## 查询类

| 需求 | 渠道 |
| --- | --- |
| 医师执业信息 | 国家卫健委官网或当地卫健委 |
| 医疗机构许可 | 同上 |
| 医保目录与报销 | 当地医保局官网 / 公众号 / 热线 |
| 政策文件 | [中国政府网](https://www.gov.cn/) |
| 药品说明书 | 药监局数据库、或 [Transfeminine Science 译文站](https://tfsci.mtf.wiki/)收录的说明书 |

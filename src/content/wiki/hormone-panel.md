## 六项分别是什么

「激素六项」通常指：

| 缩写 | 全称 | 关注度 |
| --- | --- | --- |
| E2 | 雌二醇 | **重点** |
| T | 睾酮 | **重点** |
| PRL | 泌乳素 | 建议观察 |
| LH | 促黄体激素 | 青春期阻断时才有参考意义 |
| FSH | 促卵泡激素 | 同上 |
| P4 | 孕酮 | 参考意义有限 |

## 只有两项是重点

上游说得很直接：**重点观察雌二醇和睾酮**，建议观察泌乳素；LH、FSH 只在青春期阻断治疗期间才有直接参考意义；孕酮基本没有参考意义。

所以拿到报告先看两个数：

| 指标 | 目标（成年） | 来源 |
| --- | --- | --- |
| 雌二醇 | 100–200 pg/mL（367–734 pmol/L） | WPATH SOC-8 |
| 睾酮 | 低于 0.5 ng/mL（低于 1.7 nmol/L） | WPATH SOC-8 |

完整参考范围见[药物剂量速查](/wiki/medication-doses/)里的表格。

## 单位换算

同一份血样，不同实验室可能用不同单位，数字看起来差很多。**这是单位不同，不是结果不同。**

| 指标 | 常见两种单位 |
| --- | --- |
| 雌二醇 | pg/mL ↔ pmol/L |
| 睾酮 | ng/mL ↔ nmol/L |

换算用上游的[激素换算工具](https://mtf.wiki/zh-cn/converter)。**不要凭记忆乘系数。**

## 采血时间点为什么重要

**结果和「上次给药到现在多久」直接相关。** 所以：

- 医生要求空腹就空腹
- 要求「下次给药前抽血」就按那个时间点去
- 注射方案的波动比口服大，时间点尤其关键
- **不要自行改时间**，否则数据没法解释

<div class="guide">
<strong>拿到报告先做这三件事</strong>
<p>1. <b>看采血时间</b>是否符合要求——不符合的话，数字再好看也没意义。</p>
<p>2. <b>看单位</b>，和上一次的报告对齐。</p>
<p>3. <b>看趋势而不是单次数值</b>——一两次波动很正常，连续几次同方向才值得调整。</p>
</div>

## 数值不在目标区间怎么办

**不要自己调药。** 正确的顺序是：

1. 确认采血时间点和单位有没有问题
2. 带着报告找开药的医生
3. 由医生判断是调整剂量、换剂型，还是继续观察

**常见情况：**

| 情况 | 可能的方向 |
| --- | --- |
| 雌二醇偏低 | 调整剂量或剂型；检查依从性 |
| 雌二醇偏高 | 减量；检查采血时间点 |
| 睾酮没压下去 | 评估抗雄方案；确认依从性 |
| 睾酮过低 | 评估是否抑制过度 |
| 泌乳素升高 | 密切随访，见[泌乳素升高怎么办](/wiki/prolactin/) |

## 还要一起查什么

激素六项之外，通常还要看：

- **肝功能** — 见[肝功能指标怎么看](/wiki/liver-function/)
- **血常规与凝血相关** — 血栓风险相关
- **肾功能与电解质** — 部分抗雄药物相关

完整清单见[治疗期间的监测](/wiki/monitoring-index/)。

## 记录建议

建一张表，每次复查填一行：日期、E2、T、PRL、肝功能关键项、当时用药方案（写药名即可）、身体感受。

**复诊时带着，医生能更快判断趋势。** 这份记录属于隐私，不要公开发布。

## 关于趋势判断

**单次数值的信息量有限，趋势才是关键。**

| 情况 | 通常的意义 |
| --- | --- |
| 连续两次同方向变化 | 值得和医生讨论 |
| 单次波动，前后都正常 | 可能只是采血时间或个体波动 |
| 数值达标但体感差 | **体感与数据不一致本身是信息**，要说出来 |
| 数值不达标但体感好 | 同样要说出来，由医生判断 |

**建议至少连续记录三次，再判断趋势。** 见[用药记录怎么做](/wiki/hrt-log/)。

**不要拿两次不同时间点的报告直接比较**，除非采血时间点相同（见[治疗期间的监测](/wiki/monitoring-index/)）。

## 常见问题

**「六项都要查吗？」**
**上游的表述：重点观察雌二醇和睾酮；建议观察泌乳素；LH、FSH 仅建议在青春期阻断治疗期间观察；孕酮基本没有参考意义。**

**「只查三项可以吗？」**
**可以。** 上游提到：「可以在完全六项检查之后一段时间里，只检查所关注的几项。」

**「单位不一样怎么看？」**
**先看单位，再比较数值。** 同一指标存在多种单位，见[激素换算工具](/wiki/hormone-converter/)。

**「数值不在目标区间怎么办？」**
**不要自己调药。** 带报告找医生，见下。

**「采血时间点有多重要？」**
**非常关键。** 结果和「上次给药到现在多久」直接相关。

**「透皮药物有什么要注意的？」**
**不要在采血的手臂使用药物**，否则结果会异常偏大且没有参考价值。

## 六项的详细对照

| 缩写 | 全称 | 上游的关注度 | 备注 |
| --- | --- | --- | --- |
| **E2** | 雌二醇 | **重点** | GAHT 的指标中较为重要 |
| **T** | 睾酮 | **重点** | 是否达标取决于用药方案 |
| **PRL** | 泌乳素 | **较重要 / 建议观察** | 部分孕激素类药物相关 |
| LH | 促黄体激素 | 青春期阻断时有参考意义 | 术后会偏高 |
| FSH | 促卵泡激素 | 同上 | 同上 |
| P4 | 孕酮 | **参考意义有限** | — |

## 治疗目标与参考值

| 指标 | 目标（成年） | 来源 |
| --- | --- | --- |
| 雌二醇 | 100–200 pg/mL（367–734 pmol/L） | WPATH SOC-8 |
| 睾酮 | 低于 0.5 ng/mL（低于 1.7 nmol/L） | WPATH SOC-8 |

**更细的谷值目标（上游监测页）：**

| 途径 | 目标 |
| --- | --- |
| **除针剂外** | 平均值 100–200 pg/mL；**谷值 55–150 pg/mL，建议在 100 pg/mL 以上** |
| **针剂** | **谷值 200 pg/mL 以上** |

**参考范围（LabCorp）见[药物剂量速查](/wiki/dose/)的表格。**

## 睾酮的解读（按用药方案）

**上游的明确表述：**

| 用药情况 | 参考价值 |
| --- | --- |
| **使用螺内酯片** | **并不会显著降低睾酮水平，故此项的参考价值不大** |
| **使用比卡鲁胺片** | **并不会显著降低睾酮水平，部分使用者甚至会出现血清睾酮升高现象，故此项参考价值不大** |
| **使用色普龙等孕激素** | 会降低睾酮水平。**没有必要将睾酮降得过低，达到 0.55 ng/mL 以下即可，如睾酮过低可考虑减少用量** |
| 睾丸切除后 | 睾酮主要来自于肾上腺皮质。**如仍存在睾酮高于女性参考值上限，请咨询内分泌科医生** |

## FSH 与 LH 的解读

| 情况 | 变化 |
| --- | --- |
| 使用色普龙等孕激素 | 使该项水平降低，**甚至低于检出值** |
| 使用高浓度雌二醇降雄 | 使该项水平降低，**甚至低于检出值** |
| **睾丸切除后** | **该项指标会偏高，如果过高，可能存在雌二醇用量不足** |

**上游的判读框架：**

| 状态 | FSH / LH 目标 |
| --- | --- |
| 未手术，使用色普龙 | **低于正常范围** |
| 术后 | 维持女性正常范围附近 |

## 泌乳素的解读

| 要点 | 说明 |
| --- | --- |
| **影响因素** | **外源性雌、孕激素会使该项水平升高，其中色普龙（醋酸环丙孕酮）的提升作用显著** |
| 其他影响因素 | 精神压力、刺激乳房、某些 D2 受体拮抗药物（如部分抗精神病药、促胃肠动力药） |
| 参考范围（女性） | 4.79–23.3 ng/mL |
| **处理阈值** | **如果泌乳素高于正常值三倍或以上，应密切观察，酌情降低雌/孕激素剂量、换药或排查泌乳素瘤（复查脑部 MRI）** |

**详细说明见[泌乳素升高怎么办](/wiki/prolactin/)。**

上游的[校园指南](https://mtf.wiki/zh-cn/docs/campus)是这一块的主要资料，本站补充几条原则与操作细节。

## 在校期间优先办的事

**学籍信息变更。**

**在读期间办，通常比毕业后办容易得多。** 详细说明见[学籍与学历变更](/wiki/education-records/)。

**如果还在读书，这一项值得优先处理。**

## 各类事项找谁

| 事项 | 找谁 | 说明 |
| --- | --- | --- |
| **学籍信息** | 学籍管理部门 / 教务处 | **不是辅导员** |
| **档案** | 学生档案管理部门 | 容易被忽略 |
| **宿舍安排** | 学工部门 / 宿管中心 | 可以申请调整，理由不必细说 |
| **体育课 / 体测** | 体育部 / 教务处 | 各校处理方式不同 |
| **请假就医** | 辅导员 / 教务 | 说明「就医」即可 |
| **校园系统显示名** | 信息中心 / 教务处 | 教务、图书馆、门禁可能各自独立 |
| **校园卡** | 后勤 / 卡务中心 | — |
| **心理支持** | 校心理咨询中心 | **注意保密范围** |

**「找对人」比「说对话」重要。** 辅导员通常没有学籍变更的权限。

## 学校无权替你做决定的事

| 无权 | 说明 |
| --- | --- |
| **公开你的身份** | 是否向班级、宿舍公开，**由你决定** |
| **要求你先「证明」什么** | 比如要求家长同意书（成年学生） |
| **因性别认同给予处分** | 如果发生，保留证据并逐级反映 |
| **替你通知家长** | 成年学生通常不适用 |
| **强制调换宿舍或班级** | 调整应经你同意 |

**如果发生这些情况，见下「如果遇到问题」。**

## 心理咨询的保密边界

**校心理咨询中心通常有保密义务，但存在例外**（例如自伤或伤人风险）。

**咨询前可以直接问清：**

- 什么情况下你会告知学校或家长？
- 咨询记录会不会进档案？
- 谁有权限查看？

**如果担心，可以考虑校外的咨询资源**，见[怎么找心理咨询](/wiki/finding-counselor/)。

## 请假与就医

**需要多次就诊时，请假理由写「就医」通常足够，不需要说明科室。**

如果辅导员追问：

> 个人医疗事务，不便详述。

**这属于隐私范围。**

**长期请假与考试的安排见[请假与考试](/wiki/leave-exam/)。**

## 如果遇到问题

| 步骤 | 做法 |
| --- | --- |
| 1 | **保留证据** —— 聊天记录、通知、邮件、书面文件 |
| 2 | **书面提交** —— 口头沟通容易没有记录 |
| 3 | **逐级反映** —— 院系 → 学校学生工作部门 → 教育主管部门 |
| 4 | **寻求外部支持** —— 公益组织、法律援助 |
| 5 | **见[被拒绝后的申诉路径](/wiki/appeal-path/)** |

## 一个现实提醒

**学校环境相对封闭，信息传播快。**

**在确认安全之前，控制知情范围比争取「公开支持」更重要。**

**等毕业或转学后，约束会小很多。** 有些事不必在学校期间解决。

## 关于「要不要公开」

**没有义务向任何人公开。** 包括班级、宿舍、社团。

**如果决定说：** 简洁说明称呼与代词即可，不必展开。

**如果不说：** 保持基本的人际礼仪通常比说明身份更能维持关系。

上游的[校园指南](https://mtf.wiki/zh-cn/docs/campus)是这一块的主要资料，本站只补充几条原则。

## 在校期间优先办的事

**学籍信息变更**。在读期间办，通常比毕业后办容易得多。具体见[学籍与学历](/wiki/education-records/)。

## 常见事项与沟通对象

| 事项 | 找谁 | 说明 |
| --- | --- | --- |
| 学籍信息 | 学籍管理部门 / 教务处 | 不是辅导员 |
| 宿舍安排 | 学工部门 / 宿管中心 | 可以申请调整，理由不必细说 |
| 体育课 / 体测 | 体育部 / 教务处 | 各校处理方式不同 |
| 请假就医 | 辅导员 / 教务 | 说明「就医」即可，不必交代细节 |
| 校园系统显示名 | 信息中心 / 教务处 | 教务、图书馆、门禁可能各自独立 |
| 心理支持 | 校心理咨询中心 | 注意保密范围，见下 |

## 学校无权替你做决定的事

- **无权公开你的身份。** 是否需要向班级、宿舍公开，由你决定。
- **无权要求你先「证明」什么才提供服务。** 比如要求家长同意书（成年学生）。
- **无权因性别认同给予处分。** 如果发生，保留证据并逐级反映。

## 心理咨询的保密边界

校心理咨询中心通常有保密义务，但**存在例外**（例如自伤或伤人风险）。咨询前可以直接问清：「什么情况下你会告知学校或家长？」

如果担心，可以考虑校外的咨询资源，见[怎么找心理咨询](/wiki/finding-counselor/)。

## 请假与就医

需要多次就诊时，请假理由写「就医」通常足够，不需要说明科室。如果辅导员追问，可以说「个人医疗事务，不便详述」。**这属于隐私范围。**

## 如果遇到问题

1. **保留证据**：聊天记录、通知、邮件、书面文件
2. **书面提交**：口头沟通容易没有记录
3. **逐级反映**：院系 → 学校学生工作部门 → 教育主管部门
4. **寻求外部支持**：公益组织、法律援助，见[常见法律问题](https://mtf.wiki/zh-cn/docs/useful-info/legal-faq)

## 一个现实提醒

学校环境相对封闭，信息传播快。**在确认安全之前，控制知情范围**比争取「公开支持」更重要。等毕业或转学后，约束会小很多。

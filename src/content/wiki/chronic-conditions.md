## 这一页怎么用

**有慢性病不等于不能做 HRT**，但意味着**需要更密切的监测、可能需要调整方案**。

**这一页分两部分：**

| 部分 | 内容 |
| --- | --- |
| **上游有明确表述的** | 直接引用上游原话，可作为依据 |
| **上游没有专门说明的** | 给出一般人群的疾病背景（引用 NHS 等来源），**并明确标注「本站没有找到这一人群的专属建议」** |

**⚠️ 无论哪一部分，都必须在医生指导下用药。** 这一页的作用是让你知道**该问医生什么**。

# 第一部分：上游有明确表述的

## 一、糖尿病与血糖异常

**上游的明确表述 [1]：**

> 雌激素以及比卡鲁胺等部分抗雄药物**可影响糖耐量，使血糖升高**。血糖控制异常、或有糖尿病者应谨慎，**可能需增加降血糖药的剂量**。

**关于醋酸环丙孕酮 [3]：**

> 色普龙可能会提高体内胰岛素抗性，从而引起血糖偏高。**糖尿病患者应慎用**，用药时抗糖尿病制剂或胰岛素的需求可能改变；**并发血管病变时禁用**。

**要点：**

| 事项 | 说明 |
| --- | --- |
| 影响机制 | 影响糖耐量、提高胰岛素抗性 |
| 需要做什么 | **监测空腹血糖和胰岛素**（上游列为可酌情监测项） |
| 可能的结果 | 抗糖尿病制剂或胰岛素的**需求可能改变** |
| **明确禁用情况** | **并发血管病变时禁用醋酸环丙孕酮** |

**一般人群的糖尿病背景：** 见 [NHS · 2 型糖尿病](https://www.nhs.uk/conditions/type-2-diabetes/) [8]

## 二、肝功能异常与肝病

**上游的明确表述 [2]：**

> **重度肝脏疾病（如肝功能不全及肝肿瘤）也是雌激素、醋酸环丙孕酮等药的禁忌症。**

> 其中，**比卡鲁胺、醋酸环丙孕酮已有服药期间出现急性肝衰竭（可致命）的报告。**

**监测要求 [1]：**

| 阶段 | 要求 |
| --- | --- |
| 治疗开始前 | 检查一次肝功能 |
| 治疗期间 | **每三个月**检查一次 |
| **用 CPA / 比卡鲁胺时** | **前六个月内每个月检查一次** |

**要点：**

- **重度肝病是明确的禁忌症**
- 用 CPA 或比卡鲁胺时监测频率更高
- 尤其关注**转氨酶水平**
- 如肝功能指标出现异常，应慎重考虑用药剂量，对症治疗，密切监视，直至恢复正常

**详细说明见[肝功能指标怎么看](/wiki/liver-function/)。**

## 三、肾功能异常

**上游的明确表述 [1]：**

> **肾功能不全者慎用螺内酯**，其可能加剧高钾血症；**慎用雌激素**，其可能导致体液潴留；应密切监测，直至肾功能恢复。

**螺内酯的具体要求 [4]：**

| 要求 | 说明 |
| --- | --- |
| **开始前** | **血钾应小于 5.0 mmol/L，肾功能应正常** |
| **服用期间** | 定期监测**血钾、肌酐和尿酸** |
| 高风险人群 | **高年龄（超 45 岁）、肾功能不全、与其它利钾药物合用、钾补剂的服用** |

## 四、电解质异常

**上游的明确表述 [1]：**

> **螺内酯可能影响血液钾、钠、钙、镁等离子水平**，有相关风险者在治疗期间应密切监测。与其它可能影响上述离子的药物并用时，应格外注意。

**具体注意事项见[螺内酯的说明](/wiki/antiandrogen-compare/)。**

## 五、血栓风险与心血管疾病

**上游的明确表述 [2]：**

> **有血栓、心血管疾病、肝/肾疾病或既往史的，要格外注意。家族成员有乳腺癌病史的亦须注意。**

**关于凝血 [1]：**

> **雌激素、孕激素可增强凝血，增加静脉血栓风险。血栓是雌、孕激素的禁忌症之一。**

**要点：**

| 事项 | 说明 |
| --- | --- |
| 明确禁忌 | **血栓是雌、孕激素的禁忌症之一** |
| 需要告知医生 | 既往血栓史、心血管疾病史、**直系亲属的血栓史** |
| 剂型选择 | 透皮途径的血栓风险低于口服，见[雌激素类药物对照](/wiki/estrogen-compare/) |
| 围手术期 | **建议术前一个月内停用雌、孕激素，术后卧床期间也应停用** |

**详细说明见[血栓风险与自我评估](/wiki/thrombosis-risk/)。**

## 六、甲状腺疾病

**上游的明确表述 [1]：**

> **雌激素可刺激甲状腺素结合球蛋白 (TBG) 分泌**，使甲状腺素再摄取减少。**如正在或需要进行甲状腺素替代治疗，考虑监测之，且可能需增加甲状腺素剂量。**

**另有相关提示 [1]：**

> 甘油三酯水平和甲状腺功能呈负相关。如其中一项异常，考虑同时监测二者。

**一般人群的甲状腺功能减退背景：** 见 [NHS · 甲状腺功能减退](https://www.nhs.uk/conditions/underactive-thyroid-hypothyroidism/) [10]

## 七、甲状旁腺功能与血钙

**上游的明确表述 [1]：**

> **甲状旁腺功能不全者使用雌激素，可能导致血钙偏低。** 考虑同时监测甲状旁腺素 (PTH)。

> 无机磷和 PTH 水平呈负相关，也和雌二醇水平呈负相关。必要时同时监测 PTH。

## 八、偏头痛

**上游把偏头痛列为需要告知医生的信息之一 [见[血栓风险与自我评估](/wiki/thrombosis-risk/)]。**

**雌激素与偏头痛的关系：**

- 偏头痛（尤其**有先兆的偏头痛**）与卒中风险相关，因此是医生评估 HRT 时会重点询问的一项
- 戊酸雌二醇片的说明书把**偏头痛**列为「罕见」不良反应 [2]

**要点：** 就诊时如实说明有无偏头痛、是否有先兆（如视觉异常、闪光、麻木）。**不要自行判断「不严重就不说」。**

## 九、乳腺癌家族史

**上游的明确表述 [2]：**

> 有乳腺癌（尤其是携带 BRCA1/2 致病变异）家族史的个体罹患乳腺癌的风险将**显著增加**。

> 跨性别者如果因家族遗传倾向而增加患乳腺癌的风险，**建议接受与近亲女性相同的乳腺健康状态监测策略。**

**来源：[HRT 简明指南](https://mtf.wiki/zh-cn/docs/medicine/zero-to-hrt) [6] 与[用药风险](https://mtf.wiki/zh-cn/docs/medicine/risk) [2]**

**详细说明见[器官筛查与定期体检](/wiki/organ-screening/)。**

## 十、肥胖

**上游把体重和体脂列为可酌情监测项目 [1]，但未把肥胖列为禁忌症。**

**上游的表述 [1]：**

> 睾酮水平降低将使得脂肪组织（尤其是皮下脂肪）增加，而雌激素可促进前体脂肪细胞成熟和分化，并减少皮下脂肪的分解；因此，**MtF 群体中普遍可见接受 GAHT 以后体重和体脂增加的现象**。应定期测量体重，适当运动，控制饮食，避免超重。

**注意：** 上游提到「如果你的体重指数很大，可能需要 3.2 cm 的 7-8 号针头」——即**肥胖会影响注射的针具选择**。

**关于体重管理的具体方法，见[体重、饮食与运动](/wiki/weight-nutrition/)。**

# 第二部分：上游没有专门说明的

**以下情况的处理，本站没有找到针对跨性别者的专属建议。** 只给出一般人群的背景与「该问医生什么」。

## 十一、自身免疫性疾病

**背景：** 部分自身免疫性疾病在女性中更常见，而雌激素可能影响免疫系统活动。

**⚠️ 本站没有找到这一人群的 HRT 专属建议。**

**该问医生的问题：**

- 我的疾病和激素水平有关吗？
- HRT 会不会影响病情活动？
- 需要调整我现在的免疫抑制治疗吗？
- 需要增加哪些监测项目？

## 十二、精神科疾病

**背景：** 上游提到「考虑到 MtF 当中精神疾病的流行率较高」，因此特别说明了与精神药品的相互作用 [2]。

**上游有明确表述的部分：** 药物相互作用（见下）。

**上游对精神药品的相互作用提示 [2]：**

| 组合 | 说明 |
| --- | --- |
| 螺内酯与部分精神药品 | **抑制锂剂排出，锂毒性可能增加**；与三环类、SSRI 类抗抑郁药并用可能导致**低钠血症** |
| 螺内酯、人工孕激素与血浆蛋白 | 均与血浆白蛋白高度结合，**可能跟其它强结合药物竞争白蛋白**。**这类药物包括抗抑郁药舍曲林** |
| CYP3A4 诱导剂/抑制剂 | 见[药物相互作用与合并用药](/wiki/drug-interactions/) |

**⚠️ 上游没有专门说明「精神科疾病患者能否用 HRT」。** 该问医生的问题：

- 我的精神科用药和 HRT 有相互作用吗？
- 需要调整剂量吗？
- 需要增加哪些监测？

## 十三、癫痫

**⚠️ 本站没有找到这一人群的 HRT 专属建议。**

**可以确认的相关点：** 部分抗癫痫药（如卡马西平、苯妥英、苯巴比妥）是 **CYP3A4 诱导剂**，会加快雌二醇代谢、减弱疗效 [2]。

**该问医生的问题：**

- 我的抗癫痫药和 HRT 有相互作用吗？
- 需要调整 HRT 剂量吗？

## 十四、残障与慢性疼痛

**⚠️ 本站没有找到这一人群的 HRT 专属建议。**

**可以确认的相关点：** 长期活动受限（久坐、久卧）是血栓的风险因素之一 [见[血栓风险与自我评估](/wiki/thrombosis-risk/)]。

**该问医生的问题：**

- 我的活动受限程度会不会增加血栓风险？
- 有没有更适合我的剂型？
- 需要额外的监测吗？

---

## 十五、一个通用的就诊准备

**如果你有慢性病，就诊时带上这些：**

- [ ] **完整的用药清单**（含慢性病用药、保健品、中药）
- [ ] **慢性病的诊断与病程**
- [ ] **最近的检查报告**（血糖、血压、肝肾功能、甲状腺等）
- [ ] **专科医生的联系方式**（可能需要会诊）
- [ ] **你正在用的监测设备记录**（血糖仪、血压计、可穿戴设备的数据）
- [ ] **问题清单**

**上游提到一个实用做法 [1]：** 如果因为情绪紧张或赶时间导致现场测出的心率血压异常，**可以出示可穿戴设备记录的近期数据，或近期数次自行测量的记录**来代替。

**见[就医前准备清单](/wiki/clinic-prep/)与[怎么跟医生说话](/wiki/doctor-communication/)。**

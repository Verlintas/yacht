## 为什么单看评价容易被带偏

手术评价是**样本量为 1 的个人体验**，受很多因素影响：

| 影响因素 | 说明 |
| --- | --- |
| 术式不同 | 不同技术路线的结果本来就不一样 |
| 恢复阶段不同 | 术后三个月和术后三年的评价可能完全不同 |
| 期望不同 | 期待「看起来正常」和期待「功能完整」评价标准不同 |
| 个体条件不同 | 组织条件、既往手术史都会影响结果 |
| 表达动机不同 | 有人倾向于只讲好的一面，有人倾向于只讲问题 |

**所以评价要看，但要看很多条，并且看具体描述而不是结论。** 上游的[手术评价方法](https://mtf.wiki/zh-cn/docs/srs/compraise)条目专门讲了怎么读这类信息。

## 怎么读评价

1. **看时间点。** 术后多久写的？恢复早期的评价参考价值有限。
2. **看具体描述。** 「很好」没有信息量；「术后 X 个月，日常坐姿无不适，但骑自行车还不行」才有。
3. **看它回答了哪些问题。** 有人关心外观，有人关心功能，有人关心并发症。确认对方关心的是不是你关心的。
4. **看有没有提并发症。** 完全不提问题的评价，通常不是全面的评价。
5. **看多篇。** 同一术式至少看十几篇不同来源的，再找共同点。
6. **注意发布平台。** 中介、机构号发的「评价」要打个折扣。

## 技术路线

不同术式的差异主要在几个方面：

- 使用的组织与材料
- 术后是否需要长期扩张及频率
- 感觉与功能的保留程度
- 外观结果
- 并发症类型与发生率
- 是否需要二次修整

**具体每种技术的原理、优缺点与适用情况，看上游的[手术技术](https://mtf.wiki/zh-cn/docs/srs/tech)与[基本概念](https://mtf.wiki/zh-cn/docs/srs/terminology)条目。**

本站不复述技术细节：这类信息需要专业背景才能准确转述，而且各医院的实际做法会随医生经验变化。

## 问医生的问题清单

去咨询时，把这些问题问清楚并记录下来：

- 您通常采用哪种术式？为什么？
- 这种术式需要长期扩张吗？频率如何？
- 感觉与功能的预期是怎样的？
- 常见并发症有哪些？您这里的发生率大概什么量级？
- 需要二次修整的比例大概多少？
- 如果结果不理想，修复方案是什么？
- 术前需要停用哪些药物？提前多久？
- 住院多久？完全恢复需要多久？

**「大概什么量级」比「有没有风险」更有用。** 任何手术都有风险，关键是概率和可处理性。

## 一个提醒

**不要为了「做完就算完成」而急着决定。** 这一项是不可逆的，而排期可以等。等到自己真的想清楚了再排，比排完再犹豫好。

如果有人催你、或者用「错过这个时机就没了」这类说法推动你决定，先停下来。

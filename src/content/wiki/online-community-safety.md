## 先保护自己，再参与

**最重要的一条：不要用你的主账号。**

| 分层 | 用途 | 建议 |
| --- | --- | --- |
| **主账号** | 工作、家人、现实朋友 | **不加入任何相关社群** |
| **社群账号** | 只用于相关社群 | 独立邮箱、独立头像、**不关联手机通讯录** |
| **匿名账号** | 提问、查资料 | 一次性或低频使用 |

**原因：** 群成员会变，群会解散，截图会流出。

**你在群里说过的话，可能在任何时间出现在任何地方。**

## 怎么判断一个群安不安全

| 观察点 | 安全信号 | 危险信号 |
| --- | --- | --- |
| **入群要求** | 基本管理，不索取敏感信息 | **要求提供证件、病历、私密照片** |
| **隐私规则** | 明确禁止外传 | 没有规则，或鼓励发照片 |
| **讨论氛围** | 允许不同选择 | 逼人「证明自己」、攻击未做医疗的人 |
| **商业行为** | 不推销 | 频繁推荐特定机构、药品渠道、付费「指导」 |
| **管理** | 会处理骚扰 | 对骚扰视而不见，或管理员本身在骚扰 |
| **信息质量** | 会引用来源 | 大量「听说」「内部消息」 |
| **活跃度** | 正常讨论 | 长期只有几个人在推销 |

**任何要求你提供证件、就诊记录、私密照片才能加入的群，直接退出。**

## 具体做法

| 不要 | 说明 |
| --- | --- |
| 发可定位的照片 | 窗外景色、门牌、小区标志 |
| 发证件、检查单、处方 | 属于敏感信息 |
| 透露具体住址、学校、单位 | — |
| 连续发布同一地点的内容 | 等于公开活动范围 |
| 直接发未处理的提问截图 | **先脱敏**（遮掉姓名、证件号、医院、医生） |
| 用同一头像跨平台 | 会被关联 |

**线下见面按[社群与互助](/wiki/community/)里的安全做法来。**

## 关于「被要求证明」

**群里有时会有人质疑「你是不是真的跨性别」。**

**你没有义务证明。** 可以：

| 选项 | 说明 |
| --- | --- |
| 简单说明，然后不再回应 | 通常最有效 |
| 直接无视 | 完全合理 |
| 退出该群 | 如果氛围持续不好 |

**不要为了「通过」而提供敏感材料。这是最容易被利用的地方。**

## 哪里找社群

**上游整理了两份入口：**

| 入口 | 说明 |
| --- | --- |
| [公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations) | 有实体或长期运营的机构 |
| [友情链接](https://mtf.wiki/zh-cn/docs/friendship) | 相关站点与社群 |

**优先选择有公开主体、有长期记录的组织**，比来历不明的群可靠。

## 遇到骚扰

| 步骤 | 做法 |
| --- | --- |
| 1 | **退出或拉黑** —— 不需要解释 |
| 2 | **保存证据** —— 截图（含账号 ID 与时间） |
| 3 | **向平台举报** |
| 4 | **如果涉及威胁或人肉** —— 见[网络暴力与取证](/wiki/online-harassment/) |
| 5 | **提醒群管理或其他成员**（如果安全的话） |

## 关于「社群也会让人受伤」

**社群不是避风港，也会有冲突、排挤、小圈子、观点之争。** 这很常见，不代表你哪里不对。

| 提醒 | 说明 |
| --- | --- |
| 不必参与所有讨论 | — |
| 不必认同所有人的观点 | — |
| 可以随时退出任何群组 | — |
| **找到两三个真正能说话的人，比待在十个大群里更有用** | — |

## 常见问题

**「用主账号加群会怎样？」**
**风险很高。** 群成员会变，群会解散，截图会流出。**你在群里说过的话，可能在任何时间出现在任何地方。**

**「群主要求提供证件才能加入怎么办？」**
**直接退出。** 任何要求提供证件、就诊记录、私密照片才能加入的群，都不值得进。

**「群里有人质疑我身份怎么办？」**
**你没有义务证明。** 可以简单说明、无视、或退出。

**「线下见面安全吗？」**
**取决于怎么做。** 公共场所、告知他人、手机有电、随时能离开——见下。

**「被骚扰了怎么办？」**
退出、拉黑、保存证据、向平台举报。涉及威胁或人肉的，见[网络暴力与取证](/wiki/online-harassment/)。

**「社群里的信息可信吗？」**
**不一定。** 上游资料比社群发言更可靠。社群的价值在于经验和陪伴，不在于权威性。

**「怎么找靠谱的社群？」**
优先选有公开主体、有长期记录的组织。见[资料库与社群地图](/wiki/resource-map/)。

## 具体做法清单

**不要发：**

- [ ] 可定位的照片（窗外景色、门牌、小区标志）
- [ ] 证件、检查单、处方
- [ ] 具体住址、学校、单位
- [ ] 连续同一地点的内容
- [ ] 未处理的提问截图（**先脱敏**）
- [ ] 跨平台相同的头像

**脱敏时遮掉：**

- [ ] 姓名
- [ ] 证件号
- [ ] 医院名称
- [ ] 医生姓名
- [ ] 具体日期
- [ ] 任何二维码

## 线下见面的安全做法

| 做法 | 说明 |
| --- | --- |
| **第一次约在公共场所** | 白天，人多的地方 |
| **告诉一个信得过的人** | 时间、地点、对方信息 |
| **手机保持有电** | 随时可以离开 |
| **不喝离开过视线的饮料** | — |
| **需要过夜时自己订住处** | — |
| **直觉不对就走** | **不用找理由** |
| **设定退出信号** | 给朋友发约定消息，让对方打个电话给你 |
| **不透露具体住址** | 包括打车目的地 |

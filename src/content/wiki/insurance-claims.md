## 医保：能报什么

**医保报销与「费用项目」有关，与性别信息无关。** 医保体系的基本结构与查询方式见上游的[医保系统简易介绍](https://mtf.wiki/zh-cn/docs/useful-info/healthcare-quickguide)。

关键在于项目是否在医保目录内：

| 项目 | 通常情况 |
| --- | --- |
| 门诊挂号、检查、化验 | 一般可按规定报销 |
| 药物 | 在医保目录内的可报；目录外自费 |
| 住院 | 按比例报销，有起付线与封顶线 |
| 手术 | 视项目与适应症，各地目录不同 |

**与跨性别医疗相关的项目是否纳入报销范围，各地医保目录不同。** 上游没有整理统一的报销清单，**这个问题必须向当地医保部门确认，本站无法给出结论**。

**查询方式：**

- 当地医保局官网或公众号
- 医保服务热线
- 就诊医院的医保窗口

## 异地就医

跨省就医通常需要**先备案**（见上游[医保系统简易介绍](https://mtf.wiki/zh-cn/docs/useful-info/healthcare-quickguide)）。

- 通过官方医保渠道办理（具体入口以当地医保部门公布为准）
- 备案后按参保地政策报销
- **证件信息变更后，备案信息可能需要更新**

**异地手术前务必确认备案是否办妥**，否则可能无法直接结算。

## 商业保险

**这部分条款差异很大，需要逐份看合同。**

| 关注点 | 说明 |
| --- | --- |
| 既往症条款 | 投保前已存在的情况可能不在保障范围内 |
| 免责条款 | 明确列出不赔的情形 |
| 等待期 | 投保后一段时间内出险不赔 |
| 如实告知义务 | **投保时需要如实告知** |

<div class="guide">
<strong>关于「如实告知」</strong>
<p>投保时如果被问到相关健康状况，应当如实回答。隐瞒可能导致理赔被拒。</p>
<p>但<b>告知的范围限于保险公司明确询问的内容</b>。没有被问到的，不需要主动展开。</p>
<p>具体如何回答，可以咨询保险经纪人或律师。</p>
</div>

## 理赔被拒怎么办

1. **要求书面拒赔通知。** 上面应当写明拒赔理由与依据条款。
2. **核对合同条款。** 拒赔理由是否真的对应合同约定？
3. **向保险公司申诉。** 提交补充材料，要求重新审核。
4. **向监管部门投诉。** 银行保险监督管理机构。
5. **诉讼。** 涉及金额较大时，咨询律师。
6. **见[常见法律问题索引](/wiki/legal-faq-index/)。**

## 信息变更后要更新

证件信息变更后，以下需要同步：

- [ ] 医保电子凭证
- [ ] 社保卡（部分情况需重新制卡）
- [ ] 商业保险合同上的投保人信息
- [ ] 异地就医备案信息
- [ ] 单位人事系统（在职人员）

见[医保与社保](/wiki/healthcare-insurance/)。

## 一个现实提醒

**商业保险对跨性别相关医疗的覆盖通常有限或明确排除。** 投保前务必看清条款，不要基于「应该能报」的假设做决定。

**医保部分则取决于当地目录。** 值得直接打电话问，因为各地差异很大。

## 关于异地就医报销

| 事项 | 说明 |
| --- | --- |
| **先备案** | 跨省就医通常需要，见[医保与社保](/wiki/healthcare-insurance/) |
| 备案渠道 | 官方医保渠道（具体入口以当地公布为准） |
| 报销比例 | 按参保地政策，可能低于本地就医 |
| **证件信息变更后** | **备案信息可能需要更新** |
| 直接结算 | 备案后通常可以，未备案可能需要先垫付再回参保地报销 |
| **手术类** | 提前确认项目是否在目录内、是否需要额外审批 |

**异地手术前务必确认备案是否办妥**，否则可能无法直接结算。

**具体政策各地不同，必须向参保地医保部门确认。**

## 常见问题

**「医保能报 HRT 吗？」**
**取决于项目是否在当地医保目录内。** 各地不同，**必须向当地医保部门确认**。

**「手术能报吗？」**
**与跨性别医疗相关的项目是否纳入报销范围，各地医保目录不同。** 上游没有整理统一的报销清单。

**「异地就医怎么报？」**
**跨省就医通常需要先备案。** 见下。

**「商业保险能报吗？」**
**条款差异很大，需要逐份看合同。** 对跨性别相关医疗的覆盖通常有限或明确排除。

**「理赔被拒了怎么办？」**
要求书面拒赔通知、核对条款、申诉、向监管部门投诉、必要时诉讼。

**「投保时要告知吗？」**
**投保时如果被问到相关健康状况，应当如实回答。** 隐瞒可能导致理赔被拒。**但告知的范围限于保险公司明确询问的内容。**

## 异地就医的完整流程

| 步骤 | 做法 |
| --- | --- |
| 1 | **提前备案** —— 通过官方医保渠道办理 |
| 2 | **确认备案生效** —— 建议出发前再查一次 |
| 3 | **在定点医院就诊** —— 确认医院是否支持异地直接结算 |
| 4 | **直接结算或垫付后报销** —— 备案后通常可以，未备案可能需要先垫付 |
| 5 | **证件信息变更后** —— **备案信息可能需要更新** |

**⚠️ 异地手术前务必确认备案是否办妥**，否则可能无法直接结算。

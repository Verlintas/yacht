## 核心判断：说，还是不说

**没有通用答案，取决于三件事：**

| 判断项 | 说明 |
| --- | --- |
| **岗位性质** | 是否依赖客户关系或公众形象 |
| **公司实际环境** | **看它过去怎么处理类似问题，而不是看它的口号** |
| **你的退路** | 如果结果是负面的，你能承受多久的过渡期 |

**如果退路不足，先找工作、先攒钱，再考虑公开。**

**顺序可以调整，但没必要硬扛。**

## 如果决定说

| 对象 | 说什么 | 注意 |
| --- | --- | --- |
| **直属上级** | 称呼与代词的变化，以及时间点 | 通常最先需要知道的人 |
| **HR** | 需要更新的人事信息、社保信息 | **强调保密要求** |
| **同事** | 只需要称呼和代词 | 不必交代病史 |
| **客户 / 外部** | 视岗位而定 | 通常不需要主动说 |

**信息最小化：多数人只需要知道怎么称呼你，不需要知道你做了什么医疗决定。**

**详细做法见[与 HR 沟通](/wiki/hr-communication/)。**

## 需要同步更新的东西

- [ ] 人事系统里的姓名、性别
- [ ] 社保、公积金信息（见[医保与社保](/wiki/healthcare-insurance/)）
- [ ] 工牌、邮箱、内部通讯录、门禁
- [ ] 劳动合同（如需变更姓名，一般签补充协议）
- [ ] 名片（如有）
- [ ] 各类业务系统账号

## 如果遇到问题

**先确认事实：** 是明确的辞退、降薪、调岗，还是氛围上的排挤？**性质不同，处理方式不同。**

**处理顺序：**

| 步骤 | 做法 |
| --- | --- |
| 1 | **保留证据** —— 书面通知、聊天记录、邮件、绩效记录 |
| 2 | **要求书面说明** —— 辞退需要合法理由和书面文件 |
| 3 | **了解自己的权利** —— 见上游的[常见法律问题](https://mtf.wiki/zh-cn/docs/useful-info/legal-faq) |
| 4 | **咨询专业人士** —— **劳动仲裁有期限，尽早咨询** |
| 5 | **评估成本** —— 维权要花时间和精力，也可能影响背调 |

**「绩效突然变差」的时间点如果和出柜重合，这本身就是线索。** 把出柜时间点与前后绩效记录整理出来。

**详细说明见[就业歧视与劳动权益](/wiki/employment-discrimination/)。**

## 求职时

| 环节 | 注意事项 |
| --- | --- |
| **简历与证件信息不一致** | 可以提前和 HR 沟通，说明情况，**请对方保密** |
| **背调** | 可能联系前雇主。提前准备说法，见[面试与背调](/wiki/job-interview/) |
| **体检** | 常规入职体检通常不涉及相关项目。**遇到额外要求，先问清用途与保密范围** |
| **要不要在面试时主动说** | **通常不必。没有义务在录用前公开** |

## 同事关系

| 情况 | 建议 |
| --- | --- |
| **不需要对每个人解释自己** | — |
| **被问到私人问题** | 「这个我不太想聊」是完整的回答 |
| **遇到骚扰或歧视性言论** | 记录时间、地点、在场人 |
| **想找支持** | 找到一两个可以说话的同事，工作体验会好很多 |
| **不想参加集体活动** | 可以礼貌拒绝，不必解释理由 |

## 关于「会不会影响职业发展」

**这是真实的顾虑，不必否认。**

| 可能的影响 | 应对 |
| --- | --- |
| 客户关系 | 视行业而定；部分行业影响很小 |
| 晋升机会 | 取决于公司文化，**观察它过去的做法** |
| 背调与跳槽 | 提前准备说法 |
| 行业圈子小 | 在特定行业里信息传播更快 |

**同时：** 长期隐瞒也会消耗精力。**没有零成本的选项，只有你更能接受哪一种。**

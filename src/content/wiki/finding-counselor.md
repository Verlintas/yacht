## 先分清两件事

| | 精神科诊断 | 心理咨询 |
| --- | --- | --- |
| 目的 | 出具材料，走医疗流程 | 处理情绪、关系、压力 |
| 产出 | 诊断证明 / 介绍信 | 谈话本身 |
| 频次 | 按流程要求复诊 | 通常固定频率、较长周期 |
| 资质 | 精神科医师 | 心理咨询师 / 治疗师 |
| 能否开药 | 可以 | 不可以 |

**不需要为了开材料而做长期咨询，也不需要为了咨询而先拿诊断。** 两件事可以分开进行，也可以同时进行。

**重要区别：** 咨询师**不能**开药、不能出具诊断材料（除非同时具备精神科医师资质）。见[诊断证明与介绍信](/wiki/diagnosis-letter/)。

## 咨询能帮什么

| 方向 | 具体情形 |
| --- | --- |
| 情绪 | 身份确认过程中的焦虑、抑郁、失眠 |
| 关系 | 家庭冲突、出柜的时机与方式、亲密关系 |
| 压力 | 职场或校园压力、歧视经历 |
| 决策 | 在决定要不要做某个医疗步骤时理清顾虑 |
| 创伤 | 过往的暴力、霸凌、被否定经历 |
| 支持 | 有一个稳定的、不必解释自己的说话对象 |

**咨询不是「治病」，也不要求你有病才去。** 它更像是有专业训练的对话。

## 怎么筛选咨询师

第一次见面就可以用这几个问题筛：

| 问题 | 你想听到的 |
| --- | --- |
| 你接触过跨性别来访者吗？ | 不需要是「专家」，但要有基本了解 |
| 你的取向是「探索」还是「矫正」？ | 前者是陪你理清，后者是试图改变你 |
| 你会不会要求我先做某些决定？ | 好的咨询师不会替你定方向 |
| 保密范围是什么？ | 明确说明什么情况下会告知第三方 |
| 如果我中途想停，怎么处理？ | 正常的咨询关系允许你终止 |
| 你用什么流派/方法？ | 能说清楚，且不宣称「唯一有效」 |

## 如果遇到这些，换人

- 试图说服你「其实不是跨性别」
- 用「先试试看当男生/女生」当治疗手段
- 要求你带家属来「一起纠正」
- 把跨性别本身当作需要治愈的问题
- 打探与咨询目标无关的隐私
- 推销课程、产品或其他付费项目
- 承诺确定性（「几次就能好」）
- 用恐惧推动决策

**这些是明确的红线，不是「风格不同」。**

## 怎么找

上游有一份[跨性别友好医生（心理咨询）](https://mtf.wiki/zh-cn/docs/psyco/friendly)名单，按城市整理。此外：

| 渠道 | 说明 |
| --- | --- |
| 公立医院心理科 / 临床心理科 | 部分医生接诊跨性别来访者 |
| 高校心理咨询中心 | 在校生可用，**注意保密范围** |
| 公益组织转介 | 见[公益组织](https://mtf.wiki/zh-cn/docs/useful-info/organizations) |
| 线上咨询平台 | 便利，但资质差异大，需自行核实 |
| 精神科医生转介 | 就诊时可以直接问 |

**核实资质的方法：** 询问受训背景、是否有督导、所属机构。**正规从业者不会回避这类问题。**

## 第一次见面会怎样

通常包括：

1. **了解你的情况**（为什么来、想解决什么）
2. **说明设置**（频率、时长、费用、保密范围）
3. **商量目标**（不一定第一次就定下来）
4. **你可以问问题**

**第一次的主要作用是互相评估。** 不合适就换，这很正常，不需要有心理负担。

## 费用与频次

**各渠道差异很大：**

| 渠道 | 大致情况 |
| --- | --- |
| 公立医院心理科 | 相对低，但号源紧张、时长可能较短 |
| 高校心理咨询中心 | 在校生通常免费或低价，次数可能有限 |
| 社会机构 / 私人执业 | 价格差异大，与资历、城市相关 |
| 线上平台 | 通常低于线下面询 |

**常见频次是每周一次，每次 50 分钟左右**，但不同流派与设置不同。

**如果费用有压力：** 可以问是否有低费名额、公益名额，或缩短频次。**很多机构有这类安排，但不会主动说。**

## 保密范围

**咨询内容通常保密，但有例外：**

- 自伤或伤人的风险
- 涉及未成年人的虐待
- 法律要求披露的情况

**第一次见面直接问清：** 「什么情况下你会告知第三方？」**这是合理的问题，不需要不好意思。**

## 校内咨询的特别注意

高校心理咨询中心通常有保密义务，但**与学校的行政关系可能影响保密边界**。

**建议提前问清：** 「咨询记录会不会进档案？」「什么情况下会通知辅导员或家长？」

如果担心，可以考虑校外资源。见[校园](/wiki/campus/)。

## 如果聊不下去

**这不是你的问题。** 咨询关系本身是重要变量，不匹配很常见。

- 可以直接说「我觉得我们不太匹配」
- 可以要求转介
- 可以换机构
- **不需要解释理由**

## 常见问题

**「咨询和诊断是一回事吗？」**
**不是。** 见下对照表。

**「咨询师能开药吗？」**
**不能。** 只有精神科医师可以开药。

**「咨询师能出诊断证明吗？」**
**不能**（除非同时具备精神科医师资质）。

**「第一次见面要聊什么？」**
见下「第一次见面会怎样」。

**「不合适怎么办？」**
**换人。** 不需要有心理负担。

**「多久一次？」**
**常见是每周一次，每次 50 分钟左右**，但不同流派与设置不同。

**「费用高怎么办？」**
**可以问是否有低费名额、公益名额，或缩短频次。** 很多机构有这类安排，但不会主动说。

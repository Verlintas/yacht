## 为什么这一行骗子多

三个原因：

1. **需求真实且迫切** —— 着急的人更容易被推动决策
2. **信息不对称** —— 大多数人第一次走这条路，不知道正常流程长什么样
3. **羞于求助** —— 遇到问题不愿声张，骗子正是靠这一点

## 五类常见套路

### 1. 药物私下交易

| 话术 | 问题 |
| --- | --- |
| 「医院开不到，我这有渠道」 | 来源不明，无法确认真伪与储存条件 |
| 「群里都在用，放心」 | 群里的推荐不构成质量保证 |
| 「便宜，比医院省一半」 | 省下的钱换的是没有监测的用药风险 |

**2022 年起，环丙孕酮与雌二醇已被列入网络禁售清单。** 正规渠道买不到，私下渠道买到的就更需要警惕。见[药物剂量速查](/wiki/medication-doses/)里的法规部分。

### 2. 手术中介

- 收取高额「服务费」，实际只是帮你发邮件
- 承诺「包成功」「包满意」——任何手术都不可能
- 用别人的术后照片冒充自己的案例
- 收钱后失联，或到当地后发现安排与承诺不符

**上游有专门的[中介信息](https://mtf.wiki/zh-cn/docs/srs/thailand/intermediary)页面，说明了怎么辨别。** 自己直接联系医院通常比通过中介更可靠。

### 3. 假医生与假机构

- 「专家坐诊」但查不到执业信息
- 诊所没有医疗机构执业许可证
- 要求先付款、不给正规发票
- 地址在居民楼、酒店房间

**核实方法**：在国家卫健委官网或当地卫健委查询医师执业注册信息与机构许可。

### 4. 假社群

- 入群要求提供证件、就诊记录、私密照片
- 群里频繁推荐特定渠道、特定「老师」
- 管理员对骚扰视而不见
- 用恐惧推动决策（「不这样会出事」）

**任何要求你提供敏感材料才能加入的社群，直接退出。**

### 5. 「矫正」类骗局

- 声称可以「改变」你的性别认同
- 收费昂贵、疗程漫长、承诺「治好」
- 常用手段包括隔离、羞辱、强迫行为

**这类做法没有证据支持，且被国际指南明确反对。** 遇到直接远离。

## 统一的识别方法

不管哪种套路，都符合这几条里的一条以上：

1. **要求先付款**，且不给正规凭证
2. **承诺确定性**（一定、百分百、包）
3. **制造紧迫感**（名额只剩一个、今天不定就涨价）
4. **阻止你核实**（「不方便说」「你不懂」「别人都没问」）
5. **要求保密**（「别告诉别人」「说出去对你不利」）
6. **索要敏感信息**（证件、病历、私密照片）
7. **只能通过私人渠道联系**，没有可查证的主体

## 已经被骗了怎么办

1. **立刻停止付款。**
2. **保存全部证据**：聊天记录、转账记录、对方账号、承诺内容。
3. **报警。** 涉及金额较大时，诈骗是刑事犯罪。
4. **联系发卡行或支付平台**，尝试止付。
5. **告诉社群。** 这能帮到后面的人，也不该被羞耻感阻止。
6. **需要法律帮助时**，看[常见法律问题索引](/wiki/legal-faq-index/)。

## 关于二手交易平台

**药物和手术相关服务在二手平台上出现时，风险更高。**

| 红旗 | 说明 |
| --- | --- |
| 卖家无法提供来源凭证 | 药品来源不明 |
| 价格明显低于市场 | 可能是假货或过期品 |
| **要求私下转账**（不走平台） | 失去平台保障 |
| 催促快速决定 | 制造紧迫感 |
| 拒绝提供实物照片 | 可能没有货 |
| 「代购」「渠道货」等模糊说法 | 无法追溯 |

**注意：2022 年起，环丙孕酮与雌二醇已被列入网络禁售清单**，见 [HRT 完整指南](/wiki/hrt-complete-guide/)的法规部分。

**如果已经被骗**，按本页「已经被骗了怎么办」处理，**不要因为羞耻感而不报警**。

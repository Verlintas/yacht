## 一、为什么值得单独写一页

**残障或慢性疼痛与跨性别身份的交叉，会带来叠加的障碍：**

| 障碍类型 | 说明 |
| --- | --- |
| **就医障碍** | 交通不便、需要无障碍设施、长时间候诊困难 |
| **评估障碍** | 精神科评估依赖访谈与量表，可能未考虑认知、语言或精神状况的差异 |
| **被质疑** | 「你自己都照顾不了，还想做这些」——这类说法常见，但不成立 |
| **决策能力被否定** | 残障者常被默认「没有能力做决定」，这是偏见 |
| **药物相互作用** | 慢性病用药与 HRT 的相互作用，见[慢性病与 HRT](/wiki/chronic-conditions/) |
| **活动受限** | 长期久坐久卧是血栓风险因素 |
| **经济压力** | 残障与慢性病本身就有额外支出 |
| **社会支持更少** | 可能同时面临残障歧视与跨性别歧视 |

**关键一句：残障不取消你做医疗决定的权利。** 需要的是**无障碍的支持**，不是替你决定。

## 二、就医时可能遇到的具体问题

### 2.1 交通与场地

**可以提前做的：**

| 事项 | 做法 |
| --- | --- |
| **确认无障碍设施** | 提前打电话问：是否有电梯、无障碍卫生间、轮椅通道 |
| **确认候诊条件** | 能否坐着等、是否有优先通道 |
| **安排陪同** | 见[就医陪同](/wiki/hospital-companion/) |
| **选择人少的时段** | 减少等待与消耗 |
| **预约制医院** | 优先选需要预约的（可控性更高） |

**上游提到：** 北医三院「跨性别相关内容……均需预约挂号。**无特殊情况，不予现场加号**」[见[各阶段的年龄门槛与家长要求](/wiki/age-thresholds/)引用的北医三院页面]。

**这意味着：如果现场加号对你来说更容易（例如临时身体状态不允许提前预约），需要提前和医院沟通。**

### 2.2 检查环节

**部分检查对特定残障者可能不适用或需要调整：**

| 检查 | 可能的障碍 |
| --- | --- |
| 骨密度（双能 X 线） | 需要保持特定体位一段时间 |
| 超声 | 需要配合呼吸或体位 |
| 采血 | 血管条件、晕针、需要平卧 |
| 长时间空腹 | 部分慢性病或用药不允许 |

**可以做的：** 提前告知医生你的情况，问是否可调整。**这不是「麻烦别人」，是合理的需求。**

### 2.3 精神科评估

**上游列出的问诊内容与量表 [见[诊断标准是什么](/wiki/diagnosis-criteria/)] 可能没有考虑：**

| 情况 | 可能的困难 |
| --- | --- |
| 沟通方式差异（如语言、听力、自闭谱系） | 访谈形式的评估可能不适用 |
| 认知差异 | 量表解释可能失真 |
| 精神状态波动 | 不同时间的描述可能差异大 |
| 长期被医疗系统对待的经历 | 就诊本身可能引发强烈反应 |

**可以做的：**

| 做法 | 说明 |
| --- | --- |
| **提前说明你的情况** | 「我需要更长时间回答问题」「我需要书面形式」 |
| **带书面材料** | 把感受和经历写下来，减少临场表达压力 |
| **带陪同** | 有人可以帮你补充 |
| **如果评估过程让你不适** | 可以要求暂停，或换医生 |

## 三、关于「能力」这件事

**⚠️ 这是最需要正面回应的偏见。**

**常见的错误说法：**

| 说法 | 为什么错 |
| --- | --- |
| 「你自己都照顾不了自己」 | 照顾能力与决策能力是两件事 |
| 「你可能是被影响了」 | 这个质疑对任何人都可以用，但通常只用在残障者身上 |
| 「等你身体好了再说」 | 可能是无限期推迟 |
| 「你家人替你做决定吧」 | 成年人有自己的决定权，除非法律另有规定 |
| 「你可能理解不了后果」 | 应当通过无障碍的信息提供来支持理解，而不是否定权利 |

**⚠️ 本站不提供法律意见。** 如果你的决定权被否定，见[常见法律问题索引](/wiki/legal-faq-index/)。

## 四、一些实际的应对

**⚠️ 以下为本站整理。**

| 场景 | 建议 |
| --- | --- |
| **需要书面沟通** | 提前发邮件或带书面说明，减少口头解释的负担 |
| **需要重复解释** | 把关键信息写成一页纸，每次直接出示 |
| **需要无障碍信息** | 要求大字版、语音版，或请人读给你听 |
| **需要更多时间** | 就诊前说明，或分次就诊 |
| **需要固定医生** | 减少重复解释，见[HRT 医疗资源怎么用](/wiki/hrt-resources/) |
| **活动受限** | 和医生讨论血栓风险与剂型选择，见[血栓风险与自我评估](/wiki/thrombosis-risk/) |
| **慢性疼痛影响情绪** | 疼痛与抑郁焦虑互相加重，见[焦虑与抑郁](/wiki/anxiety-depression/) |
| **经济压力** | 见[费用与时间规划](/wiki/cost-timeline/) |

## 五、关于「疼痛与情绪」

**慢性疼痛与抑郁、焦虑高度相关，而且是双向的。**

| 方向 | 说明 |
| --- | --- |
| 疼痛 → 情绪 | 长期疼痛会导致低落、易怒、社交回避 |
| 情绪 → 疼痛 | 焦虑和抑郁会放大疼痛感受 |

**⚠️ 这不是「心理作用」。** 疼痛是真实的，情绪的影响是生理机制，不是「想开点就好了」。

**可以做的：**

- 疼痛管理本身要找专业医生，不要只靠忍
- 情绪问题也要单独处理，见[焦虑与抑郁](/wiki/anxiety-depression/)
- **两件事可以同时处理**，不需要「先解决一个」

## 七、一个提醒

**你不需要先「变得健康」才能开始做自己。**

**无障碍不是特殊照顾，是基本条件。** 要求合理的调整，不是麻烦别人。

**如果你在就医过程中因为残障被拒绝或被贬损**，这属于需要记录和投诉的情况，见[被拒绝后的申诉路径](/wiki/appeal-path/)。

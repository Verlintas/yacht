门诊时间通常只有几分钟。**准备过的和没准备的，能问到的信息量差好几倍。** 这份清单可以直接抄进备忘录。

**这一页是一份操作清单**，内容整理自上游资料（见上方来源）与常见就诊经验。

## 一、出发前（提前几天）

### 确认事项

- [ ] 确认医生当天出诊（打电话或看挂号平台）
- [ ] 确认挂号方式与放号时间
- [ ] 确认科室名称（精神科 / 临床心理科 / 心理科，各院叫法不同）
- [ ] 确认需要带的材料清单
- [ ] 确认是否要求空腹或特定时间
- [ ] 确认医院位置与交通（部分医院有多个院区）

### 要带的材料

- [ ] 身份证
- [ ] 医保卡 / 医保电子凭证
- [ ] 既往就诊记录
- [ ] 既往检查报告（**尤其是近期的肝功能、血常规、激素水平**）
- [ ] 正在使用的药物清单（**药名即可，写纸上或手机里**）
- [ ] 既往手术记录（如有）
- [ ] 过敏史记录
- [ ] 已开过的诊断证明或介绍信（如有）

### 随身物品

- [ ] 纸笔或手机备忘录（**用来记医嘱**）
- [ ] 充电宝（排队时间长）
- [ ] 水和小食（尤其需要空腹抽血时，抽完可以吃）
- [ ] 口罩（部分医院要求）
- [ ] 一个文件夹或文件袋（装材料，避免折损）

## 二、要问的问题

### 关于材料（精神科）

- 这次能开什么材料？诊断证明还是介绍信？
- 能用于哪些后续环节？
- 有效期多久？要盖章吗？
- 如果后续环节不认可，怎么补？

### 关于流程

- 需要复诊几次？间隔多久？
- 下次怎么挂号？
- 如果我要换城市，材料还能用吗？
- 出现什么情况要立刻联系您？

### 关于用药（如适用）

- 我这种情况适合哪种剂型？
- 需要查哪些项目？多久查一次？
- 采血时间点有什么要求？
- 出现什么情况要立刻联系您？
- 药物在本地能买到吗，还是必须来医院开？

### 关于手术（如适用）

- 需要哪些前置材料？有效期多久？
- 是否需要公证？在哪办、要多久？
- 排期大概多久？
- 住院几天？恢复期多长？
- 常见并发症有哪些，出现时怎么处理？
- 如果结果不满意，有没有修复空间？
- 总费用多少，包含哪些、不包含哪些？

**把问题写下来带去。** 门诊时间短，临场容易忘。

## 三、怎么描述自己的情况

**不需要背术语，也不需要「答对」。说清楚三件事就够：**

| 要素 | 怎么讲 |
| --- | --- |
| **感受** | 从什么时候开始，具体是什么样的困扰 |
| **影响** | 对日常生活、情绪、工作学习造成了什么影响 |
| **诉求** | 你希望得到什么帮助 |

**一个可以照抄的开场：**

> 我长期觉得自己应该是女性，从（某时候）开始明显。这件事影响到了我的（睡眠 / 学习 / 情绪 / 社交）。
> 我希望得到（诊断证明 / 激素治疗 / 手术相关的建议）。
> 我想知道下一步该怎么做，以及需要准备什么。

**如果被问到不确定的问题，直接说「我不确定」比编答案好。** 编答案会让医生判断失准。

见[怎么跟医生说话](/wiki/doctor-communication/)。

## 四、候诊时

- [ ] 再看一遍问题清单
- [ ] 整理好要出示的材料（按顺序放，避免翻找）
- [ ] 如果需要填表，如实填，不确定的问导诊台
- [ ] 记下叫号，别错过

## 五、出诊室之后（立刻做）

**趁还记得，做三件事：**

1. **记医嘱。** 写下医生说的关键内容、开的材料、下一步安排。
2. **记时间和方式。** 下次复诊什么时候？怎么挂号？
3. **扫描材料。** 加密保存，见[材料与档案管理](/wiki/records-management/)。

**如果医生给了纸质材料：**

- [ ] 检查姓名、日期是否正确
- [ ] 检查是否有盖章
- [ ] 拍照备份（加密）
- [ ] 原件单独存放

## 六、记下这些信息

| 字段 | 例子 |
| --- | --- |
| 就诊日期 | 2026-09-21 |
| 医院 / 科室 | — |
| 医生 | — |
| 结论 / 开的材料 | — |
| 下一步 | 什么时候、做什么 |
| 花费 | — |
| 需要补的材料 | — |
| 窗口 / 科室电话 | — |

**这张表本身也是敏感信息，要加密保存。**

## 七、关于带人陪同

**多数医院允许。** 陪同的好处：

- 帮忙记医嘱（门诊信息量大，一个人容易漏）
- 情绪上更稳
- 遇到不友好情况时有人见证

**陪同的人不需要是家属，朋友也可以。** 详细说明见[就医陪同](/wiki/hospital-companion/)。

## 隐私提醒

- **诊室里说的话属于医疗隐私。** 医生有保密义务。
- **但你自己主动公开的不受保护。** 不要把病历、处方、检查单拍照发到公开平台。
- **需要向学校或单位提交时，只提交办理该事项所需的那一页。**
- **不要在社群里贴出医院名称 + 医生姓名 + 具体日期**的组合，这足以定位到人。

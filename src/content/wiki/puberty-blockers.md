## 它做什么

青春期阻断用 GnRH 类似物**暂时抑制性腺功能**，从而：

- 推迟青春期的开始，或
- 中断正在进行的青春期（上游提到一般不晚于 Tanner 三期）

**它是「暂停」，不是「改变」。** 停药后青春期会继续。

## 为什么有意义

**青春期带来的很多变化是不可逆的**：骨骼结构、声音、身高。青春期阻断的价值在于**争取时间**——让当事人在身体发生不可逆变化之前，有更多时间确认自己的需要。

上游的[青春期阻断剂综述](https://tfsci.mtf.wiki/zh-cn/articles/puberty-blockers/)有更详细的说明。

## 介入时机

**一般在 Tanner II–III 期介入**，之后经过一段过渡时间，转为常规激素治疗。

**太晚介入意义会下降**，因为不可逆的变化已经发生。

## 药物与用法

上游列出了中国大陆上市的三种 GnRH 受体激动剂：

| 药物 | 常见规格 | 用法 |
| --- | --- | --- |
| 亮丙瑞林 | 1.88、3.75、11.25 mg | 常用 3.75，每月注射一次 |
| 戈舍瑞林 | 3.6、10.8 mg | 常用 3.6，每月注射一次 |
| 曲普瑞林 | 3.75 mg | 每月注射一次 |

**中国大陆目前尚无 GnRH 受体拮抗剂上市。**

## 现实限制

| 限制 | 说明 |
| --- | --- |
| 成本高 | 上游明确指出「成本高，需结合自身经济能力考虑」 |
| 医院少 | 国内只有少数提供跨性别序列治疗的医院能开展 |
| 需要家庭支持 | 未成年人就医通常需要监护人同意 |
| 需监测骨密度 | 上游把骨密度监测列为注意事项 |
| 年龄限制 | 需要医生评估发育阶段 |

上游提到的国内机构包括[北京大学第三医院](https://mtf.wiki/zh-cn/docs/hrt/puth)与上海[复旦大学附属儿童医院](https://mtf.wiki/zh-cn/docs/hrt/shanghai/fudan-ch)。

## 年龄门槛与家长要求

**这一环的家长要求最明确：需监护人同意。** 完整的年龄门槛对照见[各阶段的年龄门槛与家长要求](/wiki/age-thresholds/)。

## 需要家庭支持这件事

这是最现实的障碍。**未成年人就医通常需要监护人同意**，这意味着：

- 需要先和家人沟通，见[家庭沟通](/wiki/family/)
- 家人可能不理解，需要时间与资料
- 如果家庭不支持，这条路会非常难走

## 如果已经错过时机

**青春期阻断有时机窗口，但 HRT 没有。** 上游的原话是：**HRT 介入的最佳时机是十年前和现在；任何时候用药都不晚。**

已经发生的骨骼与声音变化，可以通过其他方式应对（见[HRT 会改变什么](/wiki/hrt-effects/)），或者接受。**这不是「错过了就没有意义」。**

## 常见问题

**「阻断会永久影响发育吗？」**
**它是「暂停」，不是「改变」。停药后青春期会继续。** 上游的表述见[青春期阻断剂综述](https://tfsci.mtf.wiki/zh-cn/articles/puberty-blockers/)。

**「必须家长同意吗？」**
**未成年人就医通常需要监护人同意。** 这是最现实的障碍。

**「费用大概多少？」**
**上游明确指出「成本高，需结合自身经济能力考虑」**，本站不复述具体数字。

**「哪些医院能做？」**
**上游提到国内只有少数提供跨性别序列治疗的医院能开展**，已收录的包括[北京大学第三医院](https://mtf.wiki/zh-cn/docs/hrt/puth)与上海[复旦大学附属儿童医院](https://mtf.wiki/zh-cn/docs/hrt/shanghai/fudan-ch)。

**「错过时机怎么办？」**
**青春期阻断有时机窗口，但 HRT 没有。** 见[HRT 会改变什么](/wiki/hrt-effects/)。

## 常见问题

**「阻断会永久影响发育吗？」**
**它是「暂停」，不是「改变」。** 上游：「若决定不进行转变，**停药后原有青春期会重新启动**。」

**「必须家长同意吗？」**
**是。** 上游：「可以在**心理科医生评估后且监护人同意的情况下**使用。」

**「什么时候开始最好？」**
**上游建议：在首次表现出青春期的身体变化后开始。** 太晚介入意义会下降。

**「费用大概多少？」**
上游明确指出「成本高，需结合自身经济能力考虑」。**国内亮丙瑞林注射剂集采中标价 907.13～1650 元（中位数 1349.68 元）。**

**「哪些医院能做？」**
**上游提到国内只有少数提供跨性别序列治疗的医院能开展。** 已收录的包括北医三院与上海复旦大学附属儿童医院。

**「阻断能改变性别认同吗？」**
**不能。** 上游：「其并无直接改变性别认同的作用，对其他原发的心理病症也无直接缓解或治疗作用。」

**「已经发育的还能逆转吗？」**
**不能。** 上游：「对部分已经发育的第二性征如喉结、嗓音、骨骼无逆转作用。」

## 它做什么

**用 GnRH 类似物暂时抑制性腺功能，从而：**

- 推迟青春期的开始，或
- **中断正在进行的青春期**（上游提到一般不晚于 Tanner 三期）

**它是「暂停」，不是「改变」。** 停药后青春期会继续。

## 为什么有意义

**青春期带来的很多变化是不可逆的：骨骼结构、声音、身高。**

**青春期阻断的价值在于争取时间**——让当事人在身体发生不可逆变化之前，有更多时间确认自己的需要。

**上游引用的两条关键结论：**

> - 与在青春期的初期阶段之后很久才开始进行性别肯定治疗相比，**青春期早期进行青春期抑制会带来更好的心理和身体结局**
> - **建议在首次表现出青春期的身体变化后开始青春期激素抑制**

**上游还提到：** 国外研究显示，**该治疗可以改善跨性别青少年的性别焦虑相关心理健康**。

## 药物与用法

| 药物 | 常见规格 | 用法 |
| --- | --- | --- |
| 亮丙瑞林 | 1.88、3.75、11.25 mg | 常用 3.75，每月注射一次 |
| 戈舍瑞林 | 3.6、10.8 mg | 常用 3.6，每月注射一次 |
| 曲普瑞林 | 3.75 mg | 每月注射一次 |

**中国大陆目前尚无 GnRH 受体拮抗剂上市。**

**机制：** 分激动剂和拮抗剂两种，作用于脑垂体 GnRH 受体；**虽然激动剂治疗初期激素水平上升，但持续治疗后，二者疗效相当。**

## 作为抗雄药物的用途

**上游的表述：**

> 对于完成了部分或全部青春期发育进程的跨性别女性，仍可将其作为抗雄药物使用，但无法起到逆转已经完成的发育进程的效果。

**优点与缺点（上游明确对比）：**

| 优点 | 缺点 |
| --- | --- |
| **一次用药的作用时间长** | **同周期费用可能为其它抗雄药物的数十倍** |
| **相对 CPA 不易引起：肝功能异常、泌乳素升高、抑郁、累积剂量过高导致的垂体瘤** | 已没有「青春期阻断」这一特殊效果 |

## 副作用（完整）

| 类别 | 说明 |
| --- | --- |
| **骨量** | 应用期间影响骨量的累积，**骨密度较同龄同性别人群偏低**，身高增长减缓；文献报道停药后该效应可逐渐消失（如随后激素治疗不够理想，骨密度仍可能会偏低）。**应适当补钙、补充维生素 D** |
| **未来手术** | 抑制阴囊阴茎的继续生长，**可能会对未来手术治疗产生潜在影响**（该部位皮瓣面积不及一般人群） |
| **脑发育** | 对脑发育的未知影响；**近期研究认为认知能力未受到明显影响** |
| **其他** | 敏感、易怒、躁动、注射部位疼痛、痤疮、皮疹、头痛、体重增加等 |

## 现实限制

| 限制 | 说明 |
| --- | --- |
| **成本高** | 上游：同周期费用可能为其它抗雄药物的数十倍 |
| **医院少** | 国内只有少数医院能开展 |
| **需要家庭支持** | **未成年人就医通常需要监护人同意** |
| **需监测骨密度** | 上游明确提示 |
| **年龄窗口** | 需要医生评估发育阶段 |
| **可逆性不等于无影响** | 骨密度与身高增长会受影响 |

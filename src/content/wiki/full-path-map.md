这一页只讲一件事：**每一步产出什么、下一步依赖它什么**。具体要带什么材料、找哪位医生，看上游对应条目。

![医疗与证件流程总览](/images/wiki/flow-overview.svg)

<div class="guide">
<strong>只有五分钟？看这三条</strong>
<p>1. 医疗链条是串行的：<b>精神科 → 诊断证明 → HRT → 手术</b>，跳过前一步会在后一步被退回。</p>
<p>2. 证件链条也是串行的：<b>医院证明 → 户口本 → 身份证 → 其余</b>，顺序错了要重跑。</p>
<p>3. 两条链条的节奏不一样。医疗链条受排期影响，证件链条受窗口口径影响。</p>
</div>

## 主链条

```
精神科评估 ──► 诊断证明 / 介绍信 ──► 内分泌科 / HRT ──► 手术
     │                                        │
     └──────────────► 证件与信息变更 ◄────────┘
```

### 1. 精神科评估

| 项目 | 说明 |
| --- | --- |
| 产出 | 诊断证明、或用于后续步骤的介绍信 |
| 依赖 | 无，通常是第一步 |
| 耗时 | 各家不同，从一次门诊到多次复诊都有 |
| 卡点 | 医生是否接诊、是否需要家属知情、复诊间隔 |

上游按城市整理了[精神科资源](https://mtf.wiki/zh-cn/docs/psyco/overview)，并标注了哪些医生对跨性别友好。这份名单是社群维护的，比搜索引擎里的广告可靠得多。详细用法见[精神科资源怎么用](/wiki/psych-resources/)。

### 2. HRT

| 项目 | 说明 |
| --- | --- |
| 产出 | 处方与用药方案，以及后续的血液监测安排 |
| 依赖 | 多数医疗机构要求先有精神科材料 |
| 耗时 | 开药本身不慢，慢在挂号和排队 |
| 卡点 | 内分泌科是否愿意接、监测项目与频率 |

剂量见[药物剂量速查](/wiki/medication-doses/)，那一页每个数字都附来源，状态标为草稿。

### 3. 手术

| 项目 | 说明 |
| --- | --- |
| 产出 | 手术本身，以及用于证件变更的手术证明 |
| 依赖 | 通常要求精神科材料 + 一定时长的 HRT + 年龄与家属条件 |
| 耗时 | 排期是主要变量 |
| 卡点 | 术前公证、排期、术后护理安排 |

手术类别差异很大（生殖器、颌面、隆乳、嗓音、脱毛），每一项的门槛和风险都不同，分开看。

### 4. 证件与信息变更

| 项目 | 说明 |
| --- | --- |
| 产出 | 身份证、户口本、学历学籍、医保社保、旅行证件上的信息更新 |
| 依赖 | 通常需要医院出具的手术证明，各地要求不一 |
| 耗时 | 逐项办，顺序错了要重跑 |
| 卡点 | 各地执行口径不同，且会变 |

**顺序比材料更重要**，见[实名信息变更总览](/wiki/real-name-overview/)。

## 三条容易踩的坑

1. **以为材料可以后补。** 多数环节是串行的，前一步的纸质证明是后一步的入场券。
2. **只看网上的二手总结。** 医院要求、办证口径都会变，上游的医院条目和官方窗口才是准的。
3. **把可逆和不可逆的步骤混在一起决定。** 社会层面的调整（称呼、着装、社交）几乎都可逆；医疗步骤的可逆性各不相同，值得分开评估。

## 时间线怎么想

不同人的节奏差得很远，不要拿别人的时间表要求自己。真正值得提前规划的是**需要排期和需要材料链的部分**：挂号、公证、手术排期、办证窗口的受理周期。

## 两条链条的节奏差异

**医疗链条和证件链条的「慢」来源不同：**

| 链条 | 主要瓶颈 | 你能加速的部分 |
| --- | --- | --- |
| **医疗** | 号源、复诊间隔、手术排期 | 提前研究放号时间、材料一次备齐、把问题写好 |
| **证件** | 窗口口径、材料要求、制证周期 | **提前打电话问清**、多复印几份、记录窗口电话 |

**医疗链条的节奏主要由医疗资源决定，个人努力空间有限。**

**证件链条的节奏有相当一部分取决于信息准备是否充分** —— 这是投入产出比最高的地方。

**两条链条可以并行推进**，不必等医疗走完再开始了解证件流程。

## 常见问题

**「一定要按这个顺序吗？」**
**医疗链条基本是串行的**（精神科 → 诊断 → HRT → 手术）。**证件链条也是**（户籍 → 身份证 → 其余）。但**两条链条可以并行推进**。

**「可以跳过精神科吗？」**
**多数机构要求先有精神科材料。** 具体要求看医院条目。

**「可以只做其中一部分吗？」**
**可以。** 每一步都是独立的决定，没有「必须全做完」。

**「HRT 要多久才能手术？」**
**上游未给出统一时长要求。** 法规要求的是「对性别重置的要求至少持续 5 年以上」，见[各阶段的年龄门槛与家长要求](/wiki/age-thresholds/)。

**「证件变更必须等手术吗？」**
**多数地区需要医院出具的手术证明。** 具体口径各地不同，见[身份证性别信息变更](/wiki/id-card-change/)。

**「可以边用药边办证件吗？」**
可以。**两条链条并行推进**，不必等一条走完。

## 每一步的产出与依赖

| 步骤 | 产出 | 下一步依赖什么 |
| --- | --- | --- |
| **精神科评估** | 诊断证明 / 介绍信 | 无（通常是第一步） |
| **内分泌科 / HRT** | 处方与用药方案、血液监测记录 | 精神科材料 |
| **手术** | 手术本身、手术证明 | 精神科材料 + HRT 时长 + 年龄与家属条件 |
| **证件变更** | 更新后的证件 | 医院出具的手术证明 |

**「产出」这一列是关键：** 每一步的产出都是下一步的入场材料。**所以顺序错了要重跑。**

## 两条链条的节奏差异

| 链条 | 主要瓶颈 | 你能加速的部分 |
| --- | --- | --- |
| **医疗** | 号源、复诊间隔、手术排期 | 提前研究放号时间、材料一次备齐、把问题写好 |
| **证件** | 窗口口径、材料要求、制证周期 | **提前打电话问清**、多复印几份、记录窗口电话 |

**医疗链条的节奏主要由医疗资源决定，个人努力空间有限。**

**证件链条的节奏有相当一部分取决于信息准备是否充分** —— 这是投入产出比最高的地方。

## 三条容易踩的坑

| 坑 | 说明 | 怎么避免 |
| --- | --- | --- |
| **以为材料可以后补** | 多数环节是串行的，前一步的纸质证明是后一步的入场券 | 每一步拿到材料就尽快推进下一步 |
| **只看网上的二手总结** | 医院要求、办证口径都会变 | 上游的医院条目和官方窗口才是准的 |

## 时间线怎么想

**不同人的节奏差得很远，不要拿别人的时间表要求自己。**

**真正值得提前规划的是「需要排期」和「需要材料链」的部分：**

| 事项 | 为什么要提前 |
| --- | --- |
| **挂号** | 号源紧张，热门医生可能需要提前抢 |
| **公证** | 需要几个工作日到两周 |
| **手术排期** | 通常以月计 |
| **染色体检查** | 需要 30 天 |
| **办证窗口** | 受理周期，且可能需要补材料 |
| **异地就医备案** | 需要提前办 |

**这些「等待时间」可以并行安排** —— 例如在等排期时先了解证件流程。

## 关于「社会层面」

**社会层面的调整（称呼、着装、社交）不需要等流程。**

| 可以做 | 说明 |
| --- | --- |
| 称呼与代词 | 在安全的圈子里先开始 |
| 着装与外观 | 见[日常入门的顺序](/wiki/daily-basics/) |
| 声音训练 | 完全自主，越早开始收益越大 |
| 社群与支持 | 见[社群与互助](/wiki/community/) |

**医疗流程会慢，但这些可以自己推进。**

这一页只讲一件事：**每一步产出什么、下一步依赖它什么**。具体要带什么材料、找哪位医生，看上游对应条目。

## 主链条

```
精神科评估 ──► 诊断证明 / 介绍信 ──► 内分泌科 / HRT ──► 手术
     │                                        │
     └──────────────► 证件与信息变更 ◄────────┘
```

### 1. 精神科评估

| 项目 | 说明 |
| --- | --- |
| 产出 | 诊断证明、或用于后续步骤的介绍信 |
| 依赖 | 无，通常是第一步 |
| 耗时 | 各家不同，从一次门诊到多次复诊都有 |
| 卡点 | 医生是否接诊、是否需要家属知情、复诊间隔 |

上游按城市整理了精神科资源，并标注了哪些医生对跨性别友好。这份名单是社群维护的，比搜索引擎里的广告可靠得多。

### 2. HRT

| 项目 | 说明 |
| --- | --- |
| 产出 | 处方与用药方案，以及后续的血液监测安排 |
| 依赖 | 多数医疗机构要求先有精神科材料 |
| 耗时 | 开药本身不慢，慢在挂号和排队 |
| 卡点 | 内分泌科是否愿意接、监测项目与频率 |

剂量见[药物剂量速查](/wiki/medication-doses/)，那一页每个数字都附来源，状态标为草稿。

### 3. 手术

| 项目 | 说明 |
| --- | --- |
| 产出 | 手术本身，以及用于证件变更的手术证明 |
| 依赖 | 通常要求精神科材料 + 一定时长的 HRT + 年龄与家属条件 |
| 耗时 | 排期是主要变量 |
| 卡点 | 术前公证、排期、术后护理安排 |

手术类别差异很大（生殖器、颌面、隆乳、嗓音、脱毛），每一项的门槛和风险都不同，分开看。

### 4. 证件与信息变更

| 项目 | 说明 |
| --- | --- |
| 产出 | 身份证、户口本、学历学籍、医保社保、旅行证件上的信息更新 |
| 依赖 | 通常需要医院出具的手术证明，各地要求不一 |
| 耗时 | 逐项办，顺序错了要重跑 |
| 卡点 | 各地执行口径不同，且会变 |

**顺序比材料更重要**，见[实名信息变更总览](/wiki/real-name-overview/)。

## 三条容易踩的坑

1. **以为材料可以后补。** 多数环节是串行的，前一步的纸质证明是后一步的入场券。
2. **只看网上的二手总结。** 医院要求、办证口径都会变，上游的医院条目和官方窗口才是准的。
3. **把可逆和不可逆的步骤混在一起决定。** 社会层面的调整（称呼、着装、社交）几乎都可逆；医疗步骤的可逆性各不相同，值得分开评估。

## 时间线怎么想

不同人的节奏差得很远，不要拿别人的时间表要求自己。真正值得提前规划的是**需要排期和需要材料链的部分**：挂号、公证、手术排期、办证窗口的受理周期。

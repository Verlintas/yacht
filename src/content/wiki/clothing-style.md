## 先说一件重要的事

**没有任何衣服是「跨性别专属」或「跨性别禁忌」的。**

**你不需要先变成某个样子才能穿某件衣服，也不需要为了「像」而穿某种风格。**

**如果某个建议让你觉得别扭、不自在、像在演别人——那条建议对你就是错的。**

## 尺码：先量四个数

**买衣服之前先量一次，记在手机里。**

| 部位 | 怎么量 | 用途 |
| --- | --- | --- |
| **胸围** | 乳头水平绕一圈 | 上衣、内衣 |
| **下胸围** | 乳房下缘绕一圈 | 内衣尺码 |
| **腰围** | 肚脐上方最细处 | 裤子、裙子 |
| **臀围** | 臀部最宽处 | 裤子、裙子 |

**上衣通常看胸围，裤子裙子看腰围和臀围。**

**⚠️ 女装尺码在不同品牌之间差异很大。** 同一件 M 码，不同牌子可能差一个号。**以具体品牌的尺码表为准，不要认「M/L」这两个字母。**

## 常见版型问题与处理

**⚠️ 以下为经验整理，非研究结论。**

| 情况 | 常见做法 |
| --- | --- |
| **肩宽显得明显** | 避免一字领、垫肩、紧身针织；选落肩、V 领、有垂坠感的面料 |
| **腰线不明显** | 用高腰下装、腰带、收腰剪裁制造腰线位置 |
| **上半身偏长** | 高腰下装 + 短上衣，视觉上提高腰线 |
| **腿偏粗** | A 字裙、直筒裤、阔腿裤比紧身裤更友好 |
| **想遮住喉结** | 立领、高领、围巾、V 领的反向搭配 |
| **手臂线条** | 五分袖、七分袖、宽松长袖 |

**核心思路是「用剪裁改变视觉比例」，不是「藏起来」。**

## 面料比款式更重要

| 面料 | 特点 | 适合 |
| --- | --- | --- |
| **垂坠感强的**（雪纺、醋酸、天丝） | 顺着身体走，不强调轮廓 | 想弱化肩、臂线条 |
| **挺括的**（牛仔、西装料） | 有结构感 | 想制造线条 |
| **针织** | 贴身，强调身体轮廓 | 看具体厚度 |
| **棉** | 中性，日常 | 通用 |
| **亮面／反光** | 视觉放大 | 想强调的部位 |

**「垂坠」是穿搭里最常被低估的一个词。** 同样的剪裁，垂坠面料和硬挺面料的效果差别很大。

## 颜色

| 原则 | 说明 |
| --- | --- |
| **深色收缩，浅色放大** | 视觉原理 |
| **同色系搭配** | 不容易出错，显高 |
| **避免上下都花** | 一个重点就够 |
| **肤色偏冷／偏暖** | 影响适合的色系，但**不必当铁律** |
| **黑白灰** | 最不容易出错的底色 |

**先买基础色，再买喜欢的花色。**

## 从哪开始买

**建议的顺序：**

| 顺序 | 买什么 | 为什么 |
| --- | --- | --- |
| **1** | 一件合身的下装（直筒裤或 A 字裙） | 影响整体比例最大 |
| **2** | 一件基础色上衣 | 能搭很多件 |
| **3** | 一件外套 | 决定整体风格 |
| **4** | 鞋 | 影响站姿和走路 |
| **5** | 配饰 | 最后加 |

**不要一次买一堆。** 先买一两件穿一段时间，知道自己喜欢什么再买。

## 试穿与网购

| 渠道 | 优点 | 缺点 |
| --- | --- | --- |
| **实体店试穿** | 能看实际效果 | 需要面对店员 |
| **网购** | 不用面对人 | 尺码可能不对 |
| **网购 + 支持退换** | 折中，最常用 | 需要处理退货 |

**实体店的心理门槛是真实的。** 几个常见做法：

- [ ] 挑人少的时段去
- [ ] 提前想好要买什么，进去直接找
- [ ] 需要的话请朋友一起
- [ ] 店员问「买给谁」时，「自己穿」是完整的回答，不必解释更多
- [ ] **你不需要向店员证明什么**

**网购时：** 优先选支持七天无理由退换的店。**尺码不对就退，不要凑合。**

## 关于内衣与体形修饰

**这部分内容较多，单独放在[内衣与体形修饰](/wiki/chest-shape/)。**

**核心提示：** 内衣最重要的是**下胸围合身**，不是罩杯数字好看。

## 和身体的关系

**⚠️ 以下为经验整理，非研究结论。**

| 心态 | 说明 |
| --- | --- |
| **衣服是工具，不是考试** | 它服务于你，不是你服务于它 |
| **不必等「身材够了」再穿** | 那个时刻不会自己到来 |
| **不喜欢照镜子很正常** | 可以先从自己看着舒服的局部开始 |
| **换风格需要时间** | 前几次会觉得「不像自己」，这很常见 |
| **别人未必在看你** | 大多数人注意不到你担心的那些细节 |
| **不必扔掉旧衣服** | 留着也没关系 |

**如果穿衣服这件事持续带来强烈痛苦**，值得看看[身体意象](/wiki/body-shape/)与[情绪管理](/wiki/emotion-management/)。

## 常见问题

**「怎么知道什么适合我？」**
**试。** 没有别的方法。试穿是唯一的判断标准。

**「一定要穿裙子吗？」**
**不必。** 裤子、中性风格、任何风格都成立。

**「买衣服会被看出来吗？」**
**通常不会。** 别人在店里买什么，店员不关心。

**「尺码总是不对怎么办？」**
**先量好四个数，再按具体品牌的尺码表选。** 不同品牌差异很大。

**「HRT 之后要重新买吗？」**
**可能会。** 体脂分布变化后，原来的尺码和版型可能不再合适。

**「预算有限怎么办？」**
**先买一件最影响比例的下装。** 二手和换衣活动也是选项。

## 按场合分：先解决必须面对的

**⚠️ 以下为经验整理，非研究结论。**

| 场合 | 优先级 | 建议 |
| --- | --- | --- |
| **每天上学／上班** | 最高 | 先解决这一套，因为它占据你大部分时间 |
| **见家人** | 高 | 可能需要在「舒服」和「安全」之间权衡 |
| **出门买东西** | 中 | 最容易练手的场合 |
| **见朋友** | 中 | 容错率最高 |
| **正式场合**（面试、证件照） | 低 | 见[面试与求职](/wiki/job-interview/)与[证件照](/wiki/id-photos/) |
| **运动** | 低 | 见[宿舍与体育课](/wiki/dorm-sports/) |

**一次只解决一个场合。** 想把所有场合同时换掉，通常做不到。

## 按季节分

| 季节 | 优势 | 注意 |
| --- | --- | --- |
| **秋冬** | **最容易过渡** —— 外套、围巾、厚衣物天然遮挡 | 层次多，反而好搭配 |
| **春天** | 折中 | 薄外套是关键单品 |
| **夏天** | **最难** | 面料薄、暴露多；可以先解决秋冬 |
| **梅雨／潮湿** | 面料贴身 | 选速干、不易贴身的面料 |

**一个实用建议：如果你想尝试新的穿着方式，从秋冬开始。** 外套、围巾、高领都是很好的过渡单品。

## 鞋

| 类型 | 特点 |
| --- | --- |
| **平底鞋／小白鞋** | 最通用，不挑搭配 |
| **乐福鞋** | 中性偏正式 |
| **短靴** | 秋冬好搭 |
| **厚底鞋** | 视觉上拉长腿 |
| **高跟鞋** | **不是必需品**，且长时间穿对脚不好 |
| **运动鞋** | 日常首选 |

**⚠️ 鞋合不合脚比好不好看重要得多。** 不合脚的鞋会影响走路姿态，反而更显别扭。

**尺码注意：** 不同品牌鞋码差异大；**脚宽的人要选宽楦版本**。

## 配饰：小成本、大效果

| 配饰 | 作用 | 成本 |
| --- | --- | --- |
| **围巾** | 遮颈部、加层次 | 低 |
| **耳饰** | 影响整体观感 | 低到中 |
| **项链** | 改变视线落点 | 低 |
| **包** | 影响整体风格 | 中 |
| **帽子** | 遮发际线、改变轮廓 | 低 |
| **腰带** | 制造腰线 | 低 |
| **眼镜框** | 改变面部观感 | 中 |

**⚠️ 配饰是性价比最高的一类。** 同一套衣服，换一副眼镜框或一条围巾，整体观感会明显不同。

**如果还没打耳洞：** 夹式耳饰同样可用，不必为了配饰做身体改动。

## 衣柜的整理思路

**⚠️ 以下为经验整理，非研究结论。**

| 步骤 | 做法 |
| --- | --- |
| **1. 清点** | 把现在有的全部拿出来 |
| **2. 分类** | 常穿／偶尔穿／不穿 |
| **3. 找出共同点** | 常穿的那几件有什么共性？版型？颜色？面料？ |
| **4. 按共性买** | 下次买衣服时照着这个共性挑 |
| **5. 留出空间** | 不必一次扔掉旧衣服 |

**「我常穿的那几件有什么共性」这个问题，比任何穿搭指南都有用。**

## 关于「被看出来」

| 担心 | 实际情况 |
| --- | --- |
| **衣服会不会暴露我的身份** | 衣服本身不会。**大多数人注意的是整体观感，不是细节** |
| **尺码不对会不会被笑** | 很少有人在街上注意别人的尺码 |
| **风格会不会太明显** | 取决于场合；**日常场合的容错率比你想的高** |
| **熟人会不会觉得我变了** | 可能会注意到，但**注意到 ≠ 反对** |

**⚠️ 真正的风险不在于衣服，而在于信息环境。** 见[安全与隐私](/wiki/safety-privacy/)。

## 一个长期视角

| 阶段 | 特点 |
| --- | --- |
| **刚开始** | 会觉得别扭、不自在、像在演 |
| **几个月后** | 有几套固定的、自己觉得舒服的搭配 |
| **再之后** | 不再刻意想这件事，穿衣服变回日常 |
| **可能的变化** | 风格会变，尺码会变（HRT 后），偏好会变 |

**「像在演」这个阶段是正常的，它不代表你选错了路。** 新习惯在成为习惯之前，都会有这个阶段。

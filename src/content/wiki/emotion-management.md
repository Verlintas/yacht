## 几种常见的情绪

| 情境 | 常见情绪 |
| --- | --- |
| 还没确定自己 | 困惑、焦虑、怕「不够格」 |
| 等待挂号 / 排期 / 审批 | 焦躁、无力感、觉得被困住 |
| 被医生或窗口拒绝 | 挫败、愤怒、自我怀疑 |
| 出柜后 | 解脱与后悔并存、反复波动 |
| HRT 初期 | 情绪波动、期待与现实的落差 |
| 术后恢复期 | 低落、孤立感、身体不适带来的情绪 |
| 长期 | 疲惫、「什么时候是个头」 |

**这些是正常反应，不是你不够坚强。**

## 一个核心区分：能控制的 vs 不能控制的

**大部分情绪耗竭来自试图控制不能控制的事。**

| 不能控制 | 能控制 |
| --- | --- |
| 挂号号源 | 提前研究放号时间 |
| 排期 | 把材料准备好 |
| 医生接不接诊 | 找下一个 |
| 窗口口径 | 打电话问清楚 |
| 家人的接受速度 | 自己的边界和节奏 |
| 别人的看法 | 自己怎么对待自己 |

**把注意力放在右列。** 这不是鸡汤——这是减少无效消耗的实际做法。

## 几个具体方法

**1. 把「流程」和「生活」分开记**

- 流程清单：下一步办什么、卡在哪
- 生活清单：想试什么、想见谁

流程会慢，但生活清单可以自己推进。

**2. 设定「信息边界」**

不要每天泡在社群里看别人的进度。**对比是焦虑的主要来源之一。**

**3. 允许自己有不处理的时刻**

不是所有情绪都要立刻解决。有时候就是难受一会儿，然后继续过日子。

**4. 记录变化**

写下来会发现问题没有想象中那么多。见[用药记录怎么做](/wiki/hrt-log/)。

**5. 保持基本的生活结构**

睡眠、吃饭、运动。听起来像废话，但情绪低落时最先崩的就是这三样，而它们崩了情绪会更差。

## 什么时候该找专业帮助

**出现以下情况，建议尽快找咨询师或医生：**

- 持续两周以上的低落
- 睡眠、食欲明显改变
- 无法工作或学习
- 对以前感兴趣的事完全失去兴趣
- 出现伤害自己的想法

**这不是「撑不住」，是需要对的工具。** 见[怎么找心理咨询](/wiki/finding-counselor/)与[危机资源与紧急情况](/wiki/crisis-resources/)。

## 关于「是不是激素引起的」

**有可能。** 激素水平变化会影响情绪，尤其是：

- 刚开始用药时
- 调整剂量后
- 漏服或停药后

**如果是这种情况，带记录去找医生，不要自己停药。** 见[漏服、停药与调整](/wiki/missed-dose/)。

## 一个提醒

**你不需要等到「过渡完成」才配得上好心情。**

生活不是等所有条件齐了才开始。现在就可以有好的部分。

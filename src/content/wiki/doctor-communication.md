## 核心原则：说感受，说需求，不辩论

门诊通常只有几分钟。**把时间花在医生能用来帮你的事情上。**

| 有效 | 无效 |
| --- | --- |
| 说具体的感受和持续时间 | 背诵术语和分类学 |
| 说清楚你要什么 | 试图说服医生「跨性别不是病」 |
| 说清楚你不要什么 | 拿网上的资料和医生争论 |
| 问下一步怎么做 | 反复解释自己的身份 |

## 一个可以照抄的开场

> 我长期觉得自己应该是女性，从（某时候）开始明显。这件事影响到了我的（睡眠 / 学习 / 情绪 / 社交）。
> 我希望得到（诊断证明 / 激素治疗 / 手术相关的建议）。
> 我想知道下一步该怎么做，以及需要准备什么。

**三句话，把感受、影响、诉求说完了。** 剩下的时间留给医生提问。

**这段开场是本站整理的操作建议**，不是上游原文。上游对就诊流程的说明见[精神科医疗资源综述](https://mtf.wiki/zh-cn/docs/psyco/overview)。

## 医生可能问什么

下面这些问题来自精神科评估的常规内容（参见上游[精神科资源综述](https://mtf.wiki/zh-cn/docs/psyco/overview)与 [WPATH SOC-8](https://project-trans.org/SOC-8/) 对评估环节的说明）。提前想一遍，回答会顺很多：

- 什么时候开始有这种感觉？
- 这种感觉具体是什么样的？
- 对日常生活造成了什么影响？
- 有没有告诉家人或朋友？
- 有没有做过什么让自己好受一些的事？
- 有没有自伤或自杀的想法？（**如实回答。** 这关系到风险评估与医生怎么帮你，不是评判你）
- 既往病史、用药史、家族史

**不确定的问题直接说「我不确定」。** 编答案会让医生判断失准。

## 怎么问问题

**把问题写下来带去。** 门诊时间短，临场容易忘。

一次问一两个，问完记下来。医生说的听不懂就当场问：「这句我没听懂，能再说一遍吗？」

**要问的三类问题：**

1. **关于这次**：这次能开什么材料？什么时候能拿到？
2. **关于下一步**：下次什么时候来？怎么挂号？要带什么？
3. **关于边界**：出现什么情况要立刻联系您？

## 遇到不友好的医生

会发生。可能的表现：

- 使用贬损称呼
- 反复质疑你的动机
- 要求你做与诊疗无关的事
- 明确表示不接诊

**这时的处理：**

1. **不需要当场争辩。** 你是来获得服务的，不是来上课的。
2. **问清结论和依据。** 「所以您的意思是不接诊吗？能告诉我原因吗？」记录下来。
3. **换人。** 上游的名单里通常不止一位。
4. **记录。** 哪家医院、哪个科室、什么时间、什么理由。对后来的人有用。

**被一位医生拒绝，不代表你没有资格获得医疗服务。**

## 带个人一起去

多数医院允许。有人陪同的好处：

- 帮忙记医嘱（门诊信息量大，一个人容易漏）
- 情绪上更稳
- 遇到不友好情况时有人见证

陪同的人不需要是家属，朋友也可以。

## 隐私提醒

- **诊室里说的话属于医疗隐私。** 医生有保密义务。
- **但你自己主动公开的不受保护。** 不要把病历、处方、检查单拍照发到公开平台。
- 需要向学校或单位提交时，只提交办理该事项所需的那一页。

## 复诊时的沟通

**复诊比初诊更短，但信息更集中。**

| 准备 | 说明 |
| --- | --- |
| **带上上次的材料与记录** | 检查报告、用药记录，见[用药记录怎么做](/wiki/hrt-log/) |
| **说明变化** | 用药后的身体与情绪变化（关键词即可） |
| **说明问题** | 哪里不舒服、哪里不确定 |
| **说明依从性** | 有没有漏服、有没有自行调整 |
| **带问题清单** | 复诊同样需要 |

**如果医生说「继续观察」，可以追问：** 「观察到什么程度需要调整？」

**如果指标异常但你感觉良好，或指标正常但你感觉不好**，都要说出来——**体感和数据不一致本身就是信息。**

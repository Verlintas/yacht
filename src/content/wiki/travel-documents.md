## 三种主要旅行证件

| 证件 | 用途 | 换发依据 |
| --- | --- | --- |
| 中华人民共和国护照 | 出国 | 身份证 |
| 往来港澳通行证 | 港澳 | 身份证 |
| 往来台湾通行证 | 台湾 | 身份证 |

**信息变更通常以身份证为基础**，所以顺序是：

```
户籍 → 身份证 → 旅行证件
```

上游的[中国大陆旅行证件](https://mtf.wiki/zh-cn/docs/useful-info/document-updates/name-change)条目专门说明了这一块。

## 关键：换发而非修改

**已签发的旅行证件一般不能直接改信息，需要申请换发。**

| 事项 | 说明 |
| --- | --- |
| 办理方式 | 换发（不是「变更」） |
| 旧证件处理 | 通常会被注销或剪角 |
| 办理周期 | 有制证时间，换发期间无法使用旧证出行 |
| 材料 | 身份证、原证件、申请表、照片 |

**「换发期间不能出行」这一点要提前规划。** 如果近期有出行计划，先排好顺序。

## 签证失效这个坑（最容易吃亏）

**换发护照后，旧护照上的签证一般不再有效。**

| 情况 | 后果 |
| --- | --- |
| 有有效签证，换了新护照 | 通常需重新申请签证 |
| 有多年多次签证 | 同样可能失效 |
| 已订机票 | 可能无法登机 |

**所以顺序应该是：**

1. 先确认出行计划
2. 再决定什么时候换护照
3. **如果已有签证，换发前先确认该签证能否转移或保留**（以目的国使领馆规定为准）

**不同国家的规定不同。** 有些国家允许持新旧两本护照一起使用，有些不允许。**必须查目的国的官方说明。**

## 办理要点

- [ ] 身份证已更新（**这是前提**）
- [ ] 确认是换发还是补发（两者材料不同）
- [ ] 原证件是否需要交回
- [ ] 有效期与办理周期
- [ ] 已有签证的处理方式
- [ ] 是否需要预约（多数地区需要）

**具体材料与流程以当地出入境管理部门的要求为准。** 本站不复述具体材料清单，因为各地执行细节会变。

## 出入境时的实际情况

| 情况 | 说明 |
| --- | --- |
| 证件信息已更新，但外貌与照片差异大 | 边检可能多问几句，属正常核验 |
| 旧护照上有有效签证 | 一般需重新申请，以目的国规定为准 |
| 部分国家的历史入境记录 | 可能保留旧信息，以目的国规定为准 |
| 第三国转机 | 以转机国规定为准 |
| 证件与本人相符性核验 | 保持平静，配合核验即可 |

**不需要主动解释身份。** 出示证件、配合核验即可。如果被问，回答「是本人」通常足够。

## 海外证件

如果你持有其他国家的证件，**规则完全不同**。

上游的[海外证件信息修改](https://mtf.wiki/zh-cn/docs/useful-info/document-updates)按国家分类（目前有德国、芬兰等条目）。

**常见差异点：**

| 差异点 | 说明 |
| --- | --- |
| 是否要求手术 | 部分国家要求，部分不要求 |
| 是否要求本国机构文件 | 可能不承认境外医疗材料 |
| 是否需要法院程序 | 部分国家需要 |
| 办理周期与费用 | 差异很大 |
| 是否需要居住证明 | 部分国家要求 |

**查对应国家的部分，或该国官方说明。**

## 出境就医要考虑什么

有人会考虑到境外做医疗。**需要考虑的不只是医疗本身：**

| 类别 | 要考虑的 |
| --- | --- |
| **签证** | 类型、停留期、能否覆盖恢复期 |
| **停留时间** | 术后恢复期是否够用 |
| **复诊** | 回国后怎么复诊？并发症怎么处理？ |
| **记录认可** | 境外医疗记录回国后能否被认可 |
| **费用与保险** | 总费用、保险是否覆盖 |
| **语言** | 沟通是否顺畅，能否准确描述症状 |
| **陪护** | 是否有人陪同，住宿怎么安排 |

上游的[泰国旅行指南](https://mtf.wiki/zh-cn/docs/srs/thailand/thailand-tips)是境外就医场景的一个参考。

**本站不提供境外就医建议。** 涉及具体国家的法律与医疗制度，请查上游条目和目的国的官方信息。

## 隐私提醒

**护照、通行证照片含有完整身份信息与证件号。**

**任何情况下都不要发到公开平台**，包括：

- 「帮我看看填得对不对」
- 「这个号码是什么意思」
- 群里提问时的截图

**需要提问时先打码**，遮掉姓名、证件号、签发机关、照片。

## 常见问题

**「必须换发吗？」**
**已签发的旅行证件一般不能直接改信息，需要申请换发。**

**「换发要多久？」**
**有制证时间，换发期间无法使用旧证出行。**

**「旧护照上的签证还有效吗？」**
**通常不再有效。** 一般需重新申请，**以目的国规定为准**。

**「可以新旧护照一起用吗？」**
**不同国家规定不同。** 有些允许，有些不允许。**必须查目的国的官方说明。**

**「换发还是补发？」**
**两者材料不同。** 换发是信息变更，补发是遗失或损坏。

**「需要预约吗？」**
**多数地区需要。**

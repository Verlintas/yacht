## FFS 不是一项手术

**FFS（Facial Feminization Surgery，面部女性化手术）是一组手术的统称。** 上游的[FFS 综述](https://mtf.wiki/zh-cn/docs/ffs/overview)把喉结整形、脱发治疗等项目也纳入这个概念下。

常见项目：

| 部位 | 项目 |
| --- | --- |
| 额头 | 额骨重塑、眉弓降低、发际线调整 |
| 眉与眼 | 提眉、眼睑 |
| 鼻 | 鼻整形 |
| 面中部 | 颧骨、苹果肌 |
| 下半脸 | 下颌角、下巴（颏成形） |
| 唇 | 唇部形态 |
| 喉部 | 喉结整形，见下 |
| 其他 | 脱发治疗、面部脂肪填充 |

**没有人必须全做。** 有人只做一项，有人做多项，取决于具体困扰。

## 哪些改变最明显

**这是咨询时最该问的问题。** 不同项目对「整体观感」的影响差别很大，通常：

- **额骨与眉弓** 常被认为是影响最大的项目之一
- **下颌角与下巴** 影响下半脸轮廓
- **鼻** 影响面部比例
- **喉结** 单独看，但对外观影响直接

**但「影响大」不等于「适合你」。** 具体要看你的面部结构与医生评估。

## 顺序上的考虑

1. **先确认是否需要**。对照[HRT 会改变什么](/wiki/hrt-effects/)——面部骨骼不会因激素改变。
2. **先做对整体影响大的项目**。如果预算有限，这个顺序更划算。
3. **考虑恢复期的叠加**。多项一起做恢复期更辛苦，但省时间与麻醉次数。
4. **考虑与喉结手术的关系**。喉结整形通常恢复较快，可以单独安排。
5. **脱发治疗要早**。见[脱发与头发](/wiki/hair-loss/)。

## 喉结整形

上游有专门的[喉结整形术综述](https://mtf.wiki/zh-cn/docs/ffs/tracheal-shave/tracheal-shave-overview)。

要点：

- 目的：减小喉结突出
- 相对其他 FFS 项目，创伤较小、恢复较快
- **存在影响声音的风险**，需要由有经验的医生操作
- 术前要问清医生如何处理与声带的关系

## 咨询时问什么

- 您建议我做哪几项？为什么？
- 每项的预期改变是什么？有没有示意图或案例？
- 恢复期分别多长？多久能见人？
- 常见并发症有哪些？
- 是否需要二次修整？
- 总费用多少？包含哪些？
- 和我的其他计划（HRT、其他手术）有冲突吗？

<div class="guide">
<strong>一个提醒</strong>
<p>FFS 是<b>改变结构</b>的手术，不是「微调」。绝大多数项目不可完全逆。</p>
<p>而且它不是「必须做」的：不做 FFS 的人很多，过得也很好。是否做，取决于你具体的困扰程度，不取决于任何标准。</p>

## 费用与保险

**国内基本不纳入医保。** 费用因项目数、医院、医生差异很大，需要直接咨询机构。国外就医还涉及签证、停留期、复诊安排等问题。

## 关于费用与保险

**国内基本不纳入医保。**

| 事项 | 说明 |
| --- | --- |
| 费用构成 | 按项目数计算，项目越多总价越高 |
| 差异来源 | 医院、医生、项目组合、是否二次修整 |
| **医保** | 通常不纳入（见[医保与社保](/wiki/healthcare-insurance/)） |
| 商业保险 | 条款通常明确排除，**投保前看清合同** |
| 国外就医 | 还涉及签证、停留期、复诊安排、医疗记录认可 |

**具体费用直接咨询机构，本站不复述数字**（差异太大且会变化）。

**如果预算有限：** 先做对整体观感影响最大的项目，不必一次全做，见[手术五类导览](/wiki/surgery-overview/)。

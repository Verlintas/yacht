## 找谁

| 事项 | 对象 |
| --- | --- |
| **日常称呼、团队沟通** | 直属上级 |
| **人事系统、社保、合同** | HR |
| **工牌、邮箱、通讯录** | HR 或 IT / 行政 |
| **保密要求** | HR（**明确书面提出**） |

**建议顺序：先上级，后 HR。**

**上级需要知道你之后怎么被称呼；HR 需要处理系统信息。**

## 说什么

**信息最小化。多数人只需要知道怎么称呼你。**

**对上级：**

> 之后请叫我（名字），用「她」。人事系统里的信息我会单独和 HR 处理。

**对 HR：**

> 我需要更新人事系统里的姓名和性别信息。我的证件已经（或即将）变更。这件事我希望知情人控制在必要范围内。

**不需要说：**

| 不必说 | 原因 |
| --- | --- |
| 诊断 | 与工作无关 |
| 用药 | 属于个人医疗信息 |
| 手术计划 | 同上 |
| 医疗记录 | 同上 |

## 明确要求保密

**口头要求不够，最好留下书面记录。**

**邮件模板：**

> 请确认：我的个人医疗信息与身份信息，仅在办理必要人事业务时由相关同事知悉，不向其他同事或部门披露。

**邮件发一遍，保留回执。** 这既是提醒，也是记录。

## 要同步更新的东西

- [ ] 人事系统姓名、性别
- [ ] 社保、公积金信息
- [ ] 劳动合同（姓名变更通常签补充协议）
- [ ] 工牌
- [ ] 公司邮箱与账号
- [ ] 内部通讯录
- [ ] 门禁与考勤
- [ ] 各类业务系统的账号信息
- [ ] 名片（如有）
- [ ] 报销与审批系统

**列一张清单逐项确认。漏掉一个，就可能在某个场合被叫到旧名字。**

<div class="guide">
<strong>一个实用提醒</strong>
<p>系统更新往往需要时间，也可能漏掉某个角落。建议更新完两周后，<b>自己主动检查一遍</b>：邮件、通讯录、考勤系统。</p>
<p>发现遗漏时，直接告诉 HR 具体哪个系统，比笼统说「还有地方没改」有效。</p>
</div>

## 如果 HR 不配合

| 步骤 | 做法 |
| --- | --- |
| 1 | **要求书面答复** —— 「请问是流程上不允许，还是需要补充什么材料？」 |
| 2 | **找上级** —— 有时是执行层面的问题，上级推动更快 |
| 3 | **走内部渠道** —— 工会、纪检监察 |
| 4 | **外部渠道** —— 劳动监察、人社部门，见[就业歧视与劳动权益](/wiki/employment-discrimination/) |
| 5 | **咨询专业人士** —— 见[常见法律问题索引](/wiki/legal-faq-index/) |

## 关于「同事会不会知道」

**人事信息属于个人医疗信息，用人单位有保密义务。**

**但实际操作中，HR 之外的人可能接触到**（例如办理社保的同事）。

**降低风险的做法：**

| 做法 | 说明 |
| --- | --- |
| **尽早明确保密要求** | 最好有书面记录 |
| **缩小知情范围** | 只和必要的人沟通 |
| **保留书面记录** | 邮件即可 |
| **如果被泄露** | 见[个人信息与隐私保护](/wiki/privacy-law/) |

## 关于「劳动合同」

**姓名变更通常需要签补充协议。**

| 事项 | 说明 |
| --- | --- |
| 是否需要重签 | 通常不需要，签补充协议即可 |
| 性别信息 | 一般不在劳动合同中体现 |
| 社保、公积金 | 跟随身份证信息更新 |
| 保留旧合同 | 建议保留，用于证明工作经历连续性 |

## 常见问题

**「必须告诉 HR 吗？」**
**如果证件信息已变更，通常需要**（社保、合同等要跟着更新）。**如果尚未变更，可以不主动说。**

**「可以只告诉直属上级吗？」**
**取决于是否需要更新人事系统。** 如果不需要更新系统，只告诉上级（为了称呼）可能就够。

**「HR 会告诉别人吗？」**
**人事信息属于个人医疗信息，用人单位有保密义务。** 但实际操作中，办理业务的相关同事可能接触到。

**「怎么要求保密？」**
**最好留下书面记录**（邮件即可）。见下模板。

**「HR 不配合怎么办？」**
逐级走：上级 → 内部渠道 → 外部渠道。见下。

**「同事问起来怎么回答？」**
「这个我不太想聊」是完整的回答。

**「工牌和邮箱能改吗？」**
**通常可以**，需要向 HR 或 IT 提。**建议一起提，避免遗漏。**

## 要同步更新的完整清单

- [ ] **人事系统**姓名、性别
- [ ] **社保、公积金**信息
- [ ] **劳动合同**（姓名变更通常签补充协议）
- [ ] **工牌**
- [ ] **公司邮箱与账号**
- [ ] **内部通讯录**
- [ ] **门禁与考勤**
- [ ] **各类业务系统账号**（报销、审批、OA）
- [ ] **名片**（如有）
- [ ] **公司微信 / 钉钉等通讯工具**
- [ ] **工位名牌**（如有）
- [ ] **人事档案**（如有）

**列一张清单逐项确认。漏掉一个，就可能在某个场合被叫到旧名字。**

## 邮件模板

**给 HR 的沟通邮件（可参考）：**

> 主题：关于更新人事信息的说明
>
> 您好，
>
> 我需要更新人事系统中的姓名和性别信息。相关证件已经（或即将）完成变更。
>
> 另外有一个请求：我的个人医疗信息与身份信息，希望仅在办理必要人事业务时由相关同事知悉，不向其他同事或部门披露。如需要我提供什么材料，请告知。
>
> 谢谢。
> （署名）

**要点：**

| 要素 | 为什么 |
| --- | --- |
| **说明需求** | 明确要办什么 |
| **不解释原因** | 不需要说明诊断或病史 |
| **明确保密要求** | 留下书面记录 |
| **表示配合** | 询问需要什么材料 |

## 系统更新的实际经验

**⚠️ 以下为经验整理。**

| 经验 | 说明 |
| --- | --- |
| **系统更新需要时间** | 不是提交就立刻生效 |
| **会漏掉某些角落** | 尤其是历史遗留系统 |
| **建议两周后自查** | 邮件、通讯录、考勤系统各试一次 |
| **发现遗漏时直接说具体系统** | 比笼统说「还有地方没改」有效 |
| **保留旧工牌或旧系统截图** | 需要证明身份沿革时有用 |
| **社保与公积金可能要单独办** | 不总是自动同步 |

## 关于「同事会不会知道」

**降低风险的做法：**

| 做法 | 说明 |
| --- | --- |
| **尽早明确保密要求** | 最好有书面记录 |
| **缩小知情范围** | 只和必要的人沟通 |
| **保留书面记录** | 邮件即可 |
| **如果被泄露** | 见[个人信息与隐私保护](/wiki/privacy-law/) |

**⚠️ 一个现实提醒：** 在中小公司或关系紧密的团队里，信息更难控制。**如果你对此有强烈顾虑，可以考虑换工作或换团队** —— 这也是合理的策略，不是逃避。

「我该先干什么」是问得最多、也最容易卡住的问题。

**答案取决于你在哪一步，而不是取决于你懂多少。**

## 三条路径

| 你现在的状态 | 建议先做的事 | 去哪读 |
| --- | --- | --- |
| **还在确认自己的感受**，没有明确打算 | 先了解概念和社群，**不急着做医疗决定** | [术语表](/wiki/glossary/) · [常见误区](/wiki/myths/) · [性别焦虑是什么](/wiki/gender-dysphoria/) |
| **已经比较确定**，想走医疗流程 | 先弄清「诊断证明 → HRT → 手术」这条链上每一环产出什么 | [全流程地图](/wiki/full-path-map/) · [第一次去精神科](/wiki/psych-first-visit/) |
| **已经在过渡**，卡在证件或生活问题 | 直接看证件顺序与生活条目 | [实名信息变更总览](/wiki/real-name-overview/) · [生活分类](/wiki/path/life/) |

**三条路径不是阶梯。** 有人直接停在第一条，有人从第三条开始倒着补前面的。**都可以。**

## 为什么顺序重要

**国内的医疗流程大致是串行的：**

```
精神科评估 → 诊断证明（或介绍信）→ 内分泌科 / HRT → 手术
```

**每一步的产出都是下一步的入场材料，跳过前一步通常会在后一步被退回。**

上游资料里可以清楚看到这条依赖链：

| 环节 | 依赖 | 依据 |
| --- | --- | --- |
| 精神科 | 无，通常是第一步 | [精神科资源综述](https://mtf.wiki/zh-cn/docs/psyco/overview) |
| HRT | 多数机构要求先有精神科材料 | [HRT 医疗资源综述](https://mtf.wiki/zh-cn/docs/hrt/overview) |
| 手术 | 通常要求精神科材料 + 一定时长的 HRT | [SRS 综述](https://mtf.wiki/zh-cn/docs/srs/china/overview) |
| 证件 | 通常需要医院出具的手术证明 | [实名信息变更指引](https://mtf.wiki/zh-cn/docs/useful-info/real-name-info) |

**这是现实约束，不是价值判断。** 具体到某家医院要什么材料，请直接看上游的医院条目——那里更新得比任何二手总结都快。

## 关于诊断这件事

**ICD-11 已经把跨性别相关条目从「精神与行为障碍」章节移出，改放在「性健康相关状况」下。**

这件事的实际影响是：**诊断的意义正在从「你有病」转向「你需要这项医疗服务」**。

**但制度惯性存在。** 国内办证、开药、手术，目前多数环节仍然要求精神科出具的证明材料。

**理解这一点，能让你少生很多气：它不说明你有什么问题，只说明流程还没改完。**

详细说明见 [ICD-11 与去病理化](/wiki/icd11-depathologization/)。

## 三件可以先做的事

**不管你在哪条路径上，这三件事都可以立刻开始：**

| 事项 | 说明 |
| --- | --- |
| **1. 建立信息基础** | 读一遍[术语表](/wiki/glossary/)与[常见误区](/wiki/myths/)，知道哪些说法不可信 |
| **2. 保护自己** | 看[安全与隐私基础](/wiki/safety-privacy/)，尤其是数字痕迹与账号分层 |
| **3. 找到人** | 社群、朋友、咨询师。见[社群与互助](/wiki/community/) |

**这三件事不需要任何材料、任何审批、任何人同意。**

## 这一页不做什么

| 不做 | 为什么 |
| --- | --- |
| **不判断你「是不是」跨性别** | 这件事只有你自己能定，也没有考试 |
| **不推荐具体的医院或医生** | 上游有按城市整理的名单且持续更新，比这里可靠 |
| **不催你做决定** | 医疗步骤的可逆性不同，慢一点没有损失 |
| **不复述剂量与名单** | 变化太快，见[这个百科怎么维护的](/wiki/wiki-maintenance/) |

上游的 [HRT 医疗资源综述](https://mtf.wiki/zh-cn/docs/hrt/overview)按医院整理了内分泌科资源。

**本站不复制名单。** 医生接诊情况变化很快，复制就会过时。这一页讲**怎么用那份名单**。

## 名单怎么读

| 字段 | 怎么看 |
| --- | --- |
| 医院 / 科室 | 确认是内分泌科还是其他科室 |
| 医生 | 挂号用 |
| **接诊条件** | 是否要求先有精神科材料，是否接受外地患者 |
| **可开药物** | 有的医院只有部分剂型 |
| **复诊要求** | 多久复查一次，复查哪些项目 |
| 更新时间 | 越新越好 |

**关键提醒：** 多数医疗机构要求先有精神科材料。**去之前一定打电话确认。**

## 开药前要确认什么

1. **是否要求精神科材料**（多数要求，但具体形式不同）
2. **复诊安排**（多久复查、查哪些项目）——这直接影响你能不能在当地长期跟进
3. **能开什么剂型**（有的医院只有口服，有的能开凝胶或贴片）
4. **药物在本地能不能买到**，还是必须每次来医院开
5. **挂号难度**（号源紧张程度，是否需要提前很久抢号）

## 开药前要准备什么

- [ ] 精神科材料（诊断证明或介绍信）
- [ ] 既往检查报告（**近期的肝功能、血常规、激素水平**）
- [ ] 正在使用的药物清单
- [ ] 既往病史、过敏史、**家族病史**（尤其血栓、乳腺癌、心血管疾病）
- [ ] 身份证、医保卡
- [ ] 问题清单（写下来）

**完整的就诊准备见[就医前准备清单](/wiki/clinic-prep/)，检查项目见[体检项目清单](/wiki/health-checkup/)。**

## 开药时要问的问题

- 我这种情况适合哪种剂型？为什么？
- 需要查哪些项目，多久查一次？
- 采血时间点有什么要求？
- 如果指标异常，怎么处理？
- 复诊怎么挂号？
- 药物在本地能买到吗，还是必须来医院开？
- 出现什么情况要立刻联系您？

## 开药后

- **按医嘱用药，不要自行调整。** 觉得有问题，先联系医生。
- **按时复查。** 这是整个流程里唯一能提前发现问题的环节，见[治疗期间的监测](/wiki/monitoring-index/)。
- **记录自己的情况。** 用药后的身体变化、情绪变化、睡眠、不适，记下来复诊时用，见[用药记录怎么做](/wiki/hrt-log/)。
- **保留处方与检查单。** 换医院、办证、做手术都可能要用到。

## 关于剂型选择

上游在[雌激素药物](https://mtf.wiki/zh-cn/docs/medicine/estrogen)部分列出了各途径的对比：

| 途径 | 利用率 | 血栓风险 | 获取难度 |
| --- | --- | --- | --- |
| 口服 | 5% | 相对最高 | 低 |
| 舌下 / 含服 | 10–20% | 低于口服 | 低 |
| 贴片 | ~10% | 最低 | 较低 |
| 凝胶 | ~10% | 最低 | 较低 |
| 注射 | 100% | 同剂量下低于口服 | 高 |

**选哪种要由医生结合你的情况决定**，不要照着网上的偏好直接选。详细对照见[雌激素类药物对照](/wiki/estrogen-compare/)。

## 长期跟进的现实问题

**这是很多人低估的部分：**

| 问题 | 说明 |
| --- | --- |
| 复诊距离 | 如果医院在外地，每次复诊都要跑 |
| 挂号难度 | 热门医生号源紧张 |
| 换医院 | 换医院时对方可能要求重新检查 |
| 长期用药 | 几年甚至几十年的用药，需要稳定的开药渠道 |
| 费用 | 挂号、检查、药物的长期累计 |

**所以在选医院时，「能不能长期跟进」比「这家最好」更重要。**

## 本站的边界

本站：

- **不复述具体药物剂量** —— 见[药物剂量速查](/wiki/medication-doses/)（每行附来源）
- **不推荐医生** —— 主观且可能失准
- **不评价医院** —— 经验差异大，且会变化

这三件事交给上游和你的主治医生。

## 常见问题

**「本地没有资源怎么办？」**
看上游「其它地区」部分、考虑邻省、先做精神科、问社群。见下。

**「去之前要确认什么？」**
**是否要求精神科材料、复诊安排、能开什么剂型、药物本地能不能买到。**

**「可以换医院吗？」**
可以。**换医院时对方可能要求重新检查。**

**「一次要花多少钱？」**
北医三院的初诊检查总花费介于 **1000–2000 元之间**。

**「要多久？」**
**染色体检查需要 30 天；超声排期可能需要 3 个工作日以上。**

**「外地怎么安排？」**
**可在当地做完检查后携带报告前往，检查有效期三个月。**

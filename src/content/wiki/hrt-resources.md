上游的 [HRT 医疗资源综述](https://mtf.wiki/zh-cn/docs/hrt/overview)按医院整理了内分泌科资源，包括北京、上海、广州、长沙、杭州、苏州、重庆、青岛、辽宁等地，以及港澳和海外部分。

**本站不复制名单。** 医生接诊情况变化很快，复制就会过时。

## 那份名单怎么读

| 字段 | 怎么看 |
| --- | --- |
| 医院 / 科室 | 确认是内分泌科还是其他科室 |
| 医生 | 挂号用 |
| 接诊条件 | 是否要求先有精神科材料，是否接受外地患者 |
| 可开药物 | 有的医院只有部分剂型 |
| 复诊要求 | 多久复查一次，复查哪些项目 |
| 更新时间 | 越新越好 |

## 开药前

1. **确认是否要求精神科材料。** 多数医院要求，但具体要求不同。
2. **确认复诊安排。** 首次开药后多久复查、查哪些项目，直接影响你能不能在当地长期跟进。
3. **整理既往检查报告。** 如果有近期的肝功能、血常规、激素水平报告，带上。
4. **想清楚要问的问题**：
   - 我这种情况适合哪种剂型？
   - 需要查哪些项目，多久查一次？
   - 如果指标异常，怎么处理？
   - 复诊怎么挂号？
   - 药物在本地能买到吗，还是必须来医院开？

## 开药后

- **按医嘱用药，不要自行调整。** 觉得有问题，先联系医生。
- **按时复查。** 这是整个流程里唯一能提前发现问题的环节，见[治疗期间的监测](/wiki/monitoring-index/)。
- **记录自己的情况。** 用药后的身体变化、情绪变化、睡眠、不适，记下来复诊时用。
- **保留处方与检查单。** 换医院、办证、做手术都可能要用到。

## 关于剂型选择

不同剂型（口服、贴片、凝胶、针剂）在吸收方式、使用频率、费用、可获得性上都有差别。**选哪种要由医生结合你的情况决定**，不要照着网上的偏好直接选。各类剂型的说明见上游的[雌激素药物](https://mtf.wiki/zh-cn/docs/medicine/estrogen)条目。

## 如果本地没有资源

- 看综述页的「其它地区」部分，有时邻省有接诊的医院。
- 部分医生支持线上复诊，但首次通常需要线下。
- 咨询公益组织，他们可能知道最新的接诊情况。

## 本站的边界

本站不推荐医生、不评价医院；剂量另见[药物剂量速查](/wiki/medication-doses/)（每行附来源，标草稿）。具体方案以你的主治医生为准。

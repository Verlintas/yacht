## 为什么会有「公证」这一步

部分手术需要一份法律文件，用来证明当事人是在**知情、自愿**的情况下同意手术。这是医院规避法律风险的做法，也是对当事人的一种保护。

**具体是否要求、要求什么形式，各医院不同。** 上游的[术前公证](https://mtf.wiki/zh-cn/docs/srs/china/notarization)条目有更细的说明。

公证的一般流程与常见问题见[公证是什么](/wiki/notarization/)。

## 材料链：手术不是孤立的

**手术是整个流程里材料要求最集中的一环。** 它同时依赖前面几环的产出：

```
精神科材料（诊断证明 / 介绍信）
        │
        ├──► 手术科室受理
        │         │
        │         ├──► 术前检查
        │         ├──► 知情同意 / 公证
        │         └──► 排期
        │
        └──► 术后手术证明 ──► 证件变更
```

**注意最后一环：手术证明是证件变更的前置材料。** 所以手术材料要**多开一份并妥善保管**，见[实名信息变更总览](/wiki/real-name-overview/)与[材料与档案管理](/wiki/records-management/)。

## 通常涉及的材料

| 类别 | 内容 |
| --- | --- |
| 身份 | 身份证、户口本 |
| 医疗 | 精神科材料、既往就诊记录、检查报告 |
| 知情同意 | 手术知情同意书、部分医院要求的公证文书 |
| 家属 | 部分医院对家属知情有要求，具体看医院规定 |
| 费用 | 手术费用与住院押金 |

**这份清单是框架，不是标准。** 各医院要求不同，**以你要去的那家医院的要求为准**。

## 公证怎么办

| 事项 | 说明 |
| --- | --- |
| 办理地点 | 通常是有管辖权的公证处（户籍地、经常居住地等，各地规则不同） |
| 需要材料 | 身份证、户口本、医院相关材料、公证处要求的其他材料 |
| 时间 | 几个工作日到两周不等 |
| 费用 | 按公证类型计算，直接问公证处 |
| 是否需要本人到场 | 通常需要 |

**办之前打电话问清五件事：**

1. 我这个事项需要公证吗？需要公证什么内容？
2. 需要哪些材料？要不要原件？
3. 你们这里能办吗？有没有管辖要求？
4. 多少钱？多久能拿到？
5. 需要本人到场吗？

## 排期与时间安排

1. **先确认材料齐不齐**，再去排期。材料不齐排了也没用。
2. **问清等待时间**，排期通常以月计。
3. **留出恢复期。** 术后需要一段无法正常学习工作的时间，提前安排，见[请假与考试](/wiki/leave-exam/)与[职场](/wiki/workplace/)。
4. **安排陪护。** 多数医院允许，术后几天有人帮忙会轻松很多，见[就医陪同](/wiki/hospital-companion/)。
5. **确认复诊安排。** 术后复查的时间点要提前知道。
6. **考虑异地就医的额外时间**（住宿、交通、备案）。

## 术前要问清的问题

**把答案写下来。** 这类信息量大且重要，靠记容易漏。

| 类别 | 问题 |
| --- | --- |
| 材料 | 需要哪些材料？有效期多久？是否需要公证？ |
| 排期 | 大概多久？ |
| 住院 | 住院几天？ |
| 恢复 | 恢复期多长？多久能回到工作或学习？ |
| 费用 | 总费用多少，包含哪些、不包含哪些？ |
| 风险 | 常见并发症有哪些，出现时怎么处理？ |
| 修整 | 如果结果不满意，有没有修复空间？ |
| 复诊 | 术后复诊怎么安排？异地怎么办？ |

更完整的清单见[就医前准备清单](/wiki/clinic-prep/)与[手术评价与技术选择](/wiki/surgery-evaluation/)。

## 术前通常需要停用部分药物

**具体停哪些、停多久，由医生安排。** 本站不给出停药方案——这取决于手术类型、你使用的药物、以及麻醉评估结果。

**必须主动告知医生你正在使用的全部药物**，包括 HRT、抗雄、保健品与中药，见[药物相互作用与合并用药](/wiki/drug-interactions/)。

**如果做过嗓音手术**，务必术前与麻醉科医师确认气管插管的风险，见[嗓音手术](/wiki/vocal-surgery/)。

## 心理上的准备

- **把期待写下来。** 术前想清楚自己期待解决什么，术后对照看，能减少落差带来的困扰。
- **知道这是不可逆的。** 这一项和其他可逆的调整不一样，值得给自己足够的时间考虑。
- **不需要被催。** 排期可以等，决定也可以改。任何时候说「我再想想」都是合理的。
- **准备好恢复期的安排。** 身体不适 + 活动受限 + 独处，容易放大情绪波动。提前安排陪护与支持，见[术后护理与恢复](/wiki/surgery-recovery/)。
- **不需要向任何人解释你的决定。** 包括家人、朋友、社群。

## 关于「要不要做」

**没有任何一项手术是必须做的。** 上游把各类手术分别设条目，本身就说明它们是独立的、可选的决定。

有人全做，有人一项都不做，都正常。**手术解决的是具体的身体困扰，不是资格认证。**

见[手术五类导览](/wiki/surgery-overview/)。

## 常见问题

**「材料要提前多久准备？」**
**越早越好。** 公证需要几天到两周，染色体检查需要 30 天。

**「一定要公证吗？」**
**部分医院要求。** 具体问你要去的那家医院。

**「要告诉家属吗？」**
**法规要求提供「已告知直系亲属」的证明。** 具体形式各院不同。

**「术前要停药吗？」**
**上游：建议术前一个月内停用雌、孕激素，术后卧床期间也应停用。** 具体由医生安排。

**「做过嗓音手术要注意什么？」**
**上游明确提示：全麻涉及气管插管，务必术前与麻醉科医师确认风险。**

**「要住院多久？」**
视术式。**问医生。**

## 术前停药

**上游的明确要求：**

> 长年服用高剂量雌、孕激素，或者**接受手术前**，应格外注意；**建议术前一个月内停用雌、孕激素，术后卧床期间也应停用**，对于醋酸环丙孕酮（本质是人工合成孕激素）也应酌情调整用药或主动咨询专业医生。

**⚠️ 具体停哪些、停多久，由医生安排。本站不给出停药方案。**

**必须主动告知医生你正在使用的全部药物**，包括 HRT、抗雄、保健品与中药。

**如果做过嗓音手术**，务必术前与麻醉科医师确认气管插管的风险，见[嗓音手术](/wiki/vocal-surgery/)。

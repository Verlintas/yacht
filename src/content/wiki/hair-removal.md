## 对照表

| 方式 | 维持时间 | 疼痛 | 成本 | 适合 |
| --- | --- | --- | --- | --- |
| 剃刀 | 1–3 天 | 无 | 极低 | 应急、大面积 |
| 脱毛膏 | 2–5 天 | 无（可能过敏） | 低 | 四肢，**不推荐面部** |
| 拔毛 / 蜜蜡 | 2–4 周 | 明显 | 低到中 | 小面积、四肢 |
| 激光 / 光电 | 长期（需多次疗程） | 中等 | 中到高 | 深色毛发、大面积 |
| 电解 | 永久 | 明显 | 高（按时间计费） | 浅色毛发、小面积、面部精细部位 |

## 怎么选

**几个实际的判断维度：**

1. **毛色与肤色对比度。** 激光对深色毛发效果好，对白色、金色、灰色毛发基本无效——这类只能靠电解。
2. **面积。** 大面积用激光更现实，电解逐根处理，面积大了耗时极长。
3. **部位。** 面部皮肤敏感，慎用拔毛和脱毛膏。
4. **预算与时间。** 激光需要多次疗程（间隔数周），电解需要大量时间。
5. **是否近期要手术。** 部分手术对术区有脱毛要求，需要提前安排，见下。

## 面部优先

如果只能先做一个部位，**建议先做面部**。面部对面部观感影响最直接，而且日常最容易被看到。

见[日常入门的顺序](/wiki/daily-basics/)。

## 与手术的关系

**部分手术（尤其是生殖器相关手术）对术区有脱毛要求**，具体是否要求、要求什么方式，各医院不同。

**这件事要提前问，因为脱毛需要时间：**

- 激光需要多次疗程，间隔数周
- 电解更慢，按小时计

**别等到排期前一个月才想起来。** 上游的[术前科普](https://mtf.wiki/zh-cn/docs/srs/faq)与各医院条目会说明要求。

## 激光 / 光电

- **需要多次疗程**，因为毛发生长周期不同步
- **术前术后要避光**，按机构要求防晒
- **可能有色素沉着或色素减退**，深色皮肤风险更高
- **要选正规医疗机构**，美容院设备的参数与操作水平差异很大

上游有医院脱毛项目的记录，例如[上海九院激光脱毛](https://mtf.wiki/zh-cn/docs/hair-removal/shanghai/sh9-hair-removal)。

## 电解

- **唯一被认可为永久的方式**
- **逐根处理**，因此耗时与费用都高
- **适合小面积精细部位**与浅色毛发
- 需要找有经验的操作者

## 家用设备

市面上的家用光子/激光设备**能量通常远低于医疗设备**，效果有限，对深色皮肤还有风险。**不要用家用设备处理面部。**

## 常见问题

**会不会越剃越粗？**
不会。剃刀只切断露出皮肤的部分，不影响毛囊。视觉上「变粗」是因为断口是平的。

**脱毛膏能用在脸上吗？**
多数产品不建议。面部皮肤敏感，容易灼伤或过敏。**先小面积试用**，任何产品都一样。

**激光做完就永久不长了吗？**
不是。多数人需要定期维护，具体效果与毛发颜色、激素状态、设备参数都有关。

**HRT 会让体毛变少吗？**
会让肢端毛发生长变慢变细，**但不会让已经长出的毛发消失**。见 [HRT 会改变什么](/wiki/hrt-effects/)。

## 关于术前脱毛

**部分手术（尤其是生殖器相关手术）对术区有脱毛要求。**

| 事项 | 说明 |
| --- | --- |
| 是否要求 | **各医院不同，必须提前问** |
| 要求方式 | 有的接受激光，有的要求电解 |
| 时间安排 | **激光需要多次疗程（间隔数周），电解更慢（按小时计）** |
| 完成标准 | 由医院判断，可能需要医生确认 |

**关键：这件事要提前问，因为脱毛需要时间。**

**别等到排期前一个月才想起来。** 上游的[术前科普](https://mtf.wiki/zh-cn/docs/srs/faq)与各医院条目会说明要求。

见[术前准备与公证](/wiki/surgery-prep/)。

## 常见问题

**「激光能永久脱毛吗？」**
**通常不能保证永久。** 多数人需要定期维护，具体效果与毛发颜色、激素状态、设备参数都有关。**电解是唯一被认可为永久的方式。**

**「深色皮肤能做激光吗？」**
可以，但**风险更高**（色素沉着或色素减退）。**必须选有处理深色皮肤经验的机构。**

**「白色/金色毛发怎么办？」**
**激光基本无效**，只能靠电解。

**「家用设备有用吗？」**
**能量通常远低于医疗设备**，效果有限。**对深色皮肤还有风险。不要用家用设备处理面部。**

**「会不会越剃越粗？」**
**不会。** 剃刀只切断露出皮肤的部分，不影响毛囊。视觉上「变粗」是因为断口是平的。

**「脱毛膏能用在脸上吗？」**
**多数产品不建议。** 面部皮肤敏感，容易灼伤或过敏。**任何产品都先小面积试用。**

**「HRT 会让体毛变少吗？」**
会让肢端毛发生长**变慢变细**，**但不会让已经长出的毛发消失**。

**「术前脱毛要提前多久？」**
**越早越好。** 激光需要多次疗程（间隔数周），电解更慢（按小时计）。**别等排期前一个月才想起来。**

## 各类方式的详细对照

| 方式 | 维持时间 | 疼痛 | 成本 | 适合 | 风险 |
| --- | --- | --- | --- | --- | --- |
| **剃刀** | 1–3 天 | 无 | 极低 | 应急、大面积 | 皮肤刺激、毛囊炎 |
| **脱毛膏** | 2–5 天 | 无 | 低 | 四肢 | **过敏、化学灼伤** |
| **拔毛 / 蜜蜡** | 2–4 周 | 明显 | 低到中 | 小面积、四肢 | 毛囊炎、内生毛 |
| **激光 / 光电** | 长期（需多次） | 中等 | 中到高 | 深色毛发、大面积 | 色素改变、灼伤 |
| **电解** | 永久 | 明显 | 高（按时间） | 浅色毛发、小面积、面部精细部位 | 疤痕、色素改变 |

## 面部脱毛的特别注意

**面部是最敏感、也最容易被看到的地方。**

| 要点 | 说明 |
| --- | --- |
| **不推荐脱毛膏** | 面部皮肤薄，化学刺激风险高 |
| **慎用拔毛** | 可能引起毛囊炎和内生毛 |
| **激光要选专业机构** | 面部参数设置不当容易留疤或色素改变 |
| **电解适合精细部位** | 如唇上、下巴 |
| **术前术后要防晒** | 按机构要求 |
| **先做小面积测试** | 任何方式都一样 |

## 激光 / 光电的完整流程

| 阶段 | 事项 |
| --- | --- |
| **咨询** | 确认设备类型、参数、操作者资质、预计次数 |
| **术前** | 避免日晒、不要拔毛（会移除毛根）、按机构要求准备 |
| **疗程** | 通常需要多次，**间隔数周**（因为毛发生长周期不同步） |
| **术后** | 防晒、避免刺激、按机构要求护理 |
| **维护** | 多数人需要定期维护 |

**⚠️ 术前不要拔毛。** 激光作用于毛囊中的黑色素，拔掉毛根会影响效果。

## 电解的完整流程

| 阶段 | 事项 |
| --- | --- |
| **特点** | **逐根处理**，因此耗时与费用都高 |
| **适合** | 小面积精细部位（面部）、浅色毛发 |
| **单次时长** | 通常按小时计费 |
| **总时长** | 面部可能需要数十小时，分多次完成 |
| **疼痛** | 明显，可用表面麻醉（问操作者） |
| **术后** | 可能红肿，按操作者要求护理 |
| **操作者** | **必须找有经验的操作者** |

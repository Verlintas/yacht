## 公证做什么

公证是**由公证机构对某个事实或文书的真实性、合法性进行证明**。

**在这一路上，公证常见于两种场景：**

| 场景 | 证明什么 |
| --- | --- |
| **手术前的知情同意公证** | 证明当事人是在知情、自愿的情况下同意手术 |
| **证件变更中的材料公证** | 部分地区的窗口要求某些材料经过公证 |

**为什么要做：** 对医院和窗口来说，公证是一种风险控制手段；对当事人来说，它是一份有法律效力的书面记录。

## 谁来要求

**不是所有环节都要求。**

| 决定因素 | 说明 |
| --- | --- |
| 医院的规定 | 部分医院要求术前公证 |
| 当地窗口的规定 | 部分地区要求材料公证 |
| 具体办理的事项 | 同一地区不同业务要求可能不同 |

**所以办之前必须问清：** 「你们需要公证吗？需要公证什么内容？」

## 一般流程

```
确认要求 → 准备材料 → 到公证处申请 → 缴费 → 领取公证书
```

**大致需要的材料：**

- 身份证、户口本
- 需要公证的文书或证明材料
- 相关医疗材料（如术前公证）
- 公证处要求的其他材料

**办理地点：** 通常是有管辖权的公证处（户籍地、经常居住地、事实发生地等，**各地规则不同**）。

**时间：** 从几个工作日到两周不等，取决于公证类型和公证处工作量。

## 常见问题

**「公证书有有效期吗？」**
公证书本身通常长期有效，但**使用方可能要求「近期出具」**。办理前问清对方的时间要求。

**「可以异地办吗？」**
取决于公证类型与管辖规则。有些可以，有些要求特定地点。**直接打电话问。**

**「要办几份？」**
**建议多办一份备用。** 有些环节收原件，补办要重新走流程。

**「费用大概多少？」**
按公证类型与标的额计算，差异较大。直接问公证处。

**「可以委托他人办理吗？」**
部分公证类型可以（需授权委托书），部分要求本人到场（如涉及身份确认）。**问公证处。**

**「公证和认证有什么区别？」**
公证是公证处出具证明；认证通常指外交或领事认证，用于文书在境外使用。**涉外用途要问清是否需要认证。**

## 关于「被要求额外公证」

**如果窗口或机构要求的公证明显超出常规范围**，可以：

| 步骤 | 做法 |
| --- | --- |
| 1 | **请对方说明依据** —— 哪条规定要求 |
| 2 | **换一个窗口或上级部门确认** |
| 3 | **咨询律师或公益组织**，见[常见法律问题索引](/wiki/legal-faq-index/) |
| 4 | **记录办理过程**（时间、窗口、答复内容），必要时有用 |

**「额外要求」有两种可能：** 一是确实有地方性规定，二是经办人对流程不熟悉。**问清依据就能区分。**

## 术前公证的特别说明

**部分手术医院要求术前公证**，用于证明知情同意。

**要点：**

- **提前问清**是否需要、需要什么内容（不要等到排期前才问）
- **留出办理时间**（几天到两周）
- **多办一份**（医院可能收原件）
- **保管好公证书**，后续办证可能用得上

见[术前准备与公证](/wiki/surgery-prep/)与上游的[术前公证](https://mtf.wiki/zh-cn/docs/srs/china/notarization)条目。

## 公证的类型与适用

| 类型 | 用途 | 常见场景 |
| --- | --- | --- |
| **术前公证** | 证明知情同意 | 部分手术医院要求 |
| **材料公证** | 证明材料真实性 | 部分证件变更窗口要求 |
| **三甲性别鉴定公证** | 用于户口身份证变更 | 上游提到「一般凭出院材料走 A) 三甲性别鉴定公证即可」 |
| **意定监护公证** | 指定监护人 | 伴侣关系、独居者 |
| **遗嘱公证** | 明确财产分配 | 一般人群也适用 |
| **授权委托公证** | 委托他人代办 | 异地办事 |

## 公证与伴侣关系

**⚠️ 本站不提供法律意见。**

**伴侣关系（未婚）在国内缺乏法定保障，公证是常见的弥补方式：**

| 类型 | 作用 |
| --- | --- |
| **意定监护公证** | 在特定情形下赋予伴侣相应权利 |
| **遗嘱公证** | 明确财产安排 |
| **财产约定公证** | 共同财产的书面约定 |

**具体效力与办理方式，咨询公证处与律师。** 见[婚姻、伴侣与家庭关系](/wiki/marriage-partnership/)。

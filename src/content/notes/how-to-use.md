小窝不是作品集，是给自己用的地方。主站 `verlintas.github.io` 对外，这里对内。

## 四个板块

| 板块 | 放什么 |
| --- | --- |
| 小窝 | 四处泊位的实时天况、空气质量、海况 |
| 泊位 | 四个常驻点的对照视图 |
| 港口 | 常用入口，按用途分组 |
| 航海日志 | 笔记、收藏、代码片段 |
| 船坞 | 项目清单与进度 |
| 百科 | MtF 资源索引（建设中） |

## 笔记怎么写

在 `src/content/notes/` 下新建一个 `.md` 文件，开头写 frontmatter：

```yaml
---
title: 标题
date: 2026-09-21
tags: [标签一, 标签二]
summary: 一句话摘要，会显示在列表里
pinned: false
---
```

正文用普通 Markdown。写完 `git push`，GitHub Actions 会自动部署，大约一分钟生效。

## 几条约定

- 不写个人医疗记录、证件号、住址这类东西，仓库是公开的。
- 真实地名不写进文件，站点上只用泊位代号。
- 笔记不追求完整，写下来比写得好重要。
